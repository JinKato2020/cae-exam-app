第5章 有限要素法の実践

CAE計算力学技術者 固体力学2級・オリジナル問題（問題／解答／解説／図）
5-1 全体剛性行列への組立て(アセンブリ) 難2・全体剛性行列のアセンブリ
複数の要素が同じ節点を共有するとき、その節点に対応する全体剛性行列の成分の正しい求め方はどれか。実務でありがちな誤りも踏まえて選べ。
  1. 共有する要素のうち代表となる1つだけの値を採用する。
  2. 共有する要素の値の単純平均を採用する。
  3. 共有するすべての要素の局所剛性行列の該当成分を全体座標系に変換し、加算する。
  4. 共有する要素のうち最も大きい値だけを採用し、他は無視する。
正解 : 3
【基礎】全体剛性行列は、各要素の局所剛性行列を全体座標系に変換したうえで、対応する節点番号の位置に重ね合わせる(足し込む)ことで作られます。これをアセンブリと呼びます。
【考え方】複数の要素が同じ節点を共有する場合、その節点は複数要素から同時に力を受け持つので、剛性への寄与もすべて加算されなければつり合いが表現できません。
【ポイント】アセンブリの本質は『重なる部分は全部足す』。1つの要素だけ代表させたり平均したりすると、他の要素の抵抗が反映されず全体剛性が過小評価されます。
【引っかけ】1は代表1要素のみ採用という見落とし(実務でメッシュが複雑だと起きがちな入力ミス)。2は平均という誤った処理(合計すべきところを均してしまう)。4は大きい方だけ採用という恣意的な誤り。いずれも『足し合わせる』という原則を外している。
5-2 全体剛性行列の成分計算(アセンブリ) 難2・全体剛性行列のアセンブリ
3節点(1,2,3)からなる2つの棒要素(要素1:節点1-2、要素2:節点2-3)を直列に接続する。要素1の $EA/L=900$ N/mm、要素2の $EA/L=1500$ N/mm のとき、全体剛性行列の対角成分 $K_{22}$ の値はいくらか。
  1. 900 N/mm
  2. 2400 N/mm
  3. 1500 N/mm
  4. 1200 N/mm
正解 : 2
【基礎】節点2は要素1と要素2の両方に属するので、$K_{22}$ には両方の局所剛性行列の対角成分が加算されます。
【考え方】各棒要素の局所剛性行列は $\dfrac{EA}{L}\begin{bmatrix}1&-1\\-1&1\end{bmatrix}$ で、節点2はどちらの要素でも『対角成分=$EA/L$』の位置にあります。
【計算】$K_{22}=(EA/L)_1+(EA/L)_2=900+1500=2400$ N/mm。
【ポイント】共有節点の対角成分は必ず関係する全要素の値を単純加算する。
【引っかけ】1は要素1のみ、3は要素2のみを採用した見落とし。4は $(900+1500)/2=1200$ と平均してしまった誤り。加算であって平均ではない。
5-3 直接法・反復法の使い分け 難1・連立方程式の解法選択(実務判断)
有限要素法の連立方程式 $Ku=f$ の解法として、直接法(LU分解等)と反復法(共役勾配法等)の実務的な使い分けに関する記述として、最も適切なものはどれか。
  1. 同じ剛性行列で荷重ケースだけ多数変えて解く場合は、一度分解した直接法の方が使い回しが効いて効率的である。
  2. 節点数が数百万に達する大規模解析でも、直接法の方がメモリ使用量が少なく常に有利である。
  3. 反復法は必ず直接法より高精度な解が得られる。
  4. 直接法・反復法のどちらを使っても計算結果や適性に差はまったく生じない。
正解 : 1
【基礎】直接法はガウスの消去法やLU分解のように行列を直接分解して解く方法、反復法は近似解を繰り返し更新して収束させる方法(共役勾配法など)です。
【考え方】直接法は一度分解($K=LU$)してしまえば、右辺 $f$ が変わる荷重ケースの追加でも再利用でき効率的です。一方、大規模疎行列では分解時に非ゼロ要素が増える(フィルイン)ためメモリを多く消費しやすく、反復法の方がメモリ効率で有利になる場合が多いです。
【ポイント】『荷重ケースが多い→直接法が有利』『超大規模・疎行列→反復法が有利』という実務的な傾向を押さえる。
【引っかけ】2は大規模解析で直接法が常にメモリ有利とする誤り(実際は逆の傾向になりやすい)。3は反復法が必ず高精度とする誤り(収束条件や反復回数次第で精度は変わる)。4は差がないとする誤り(規模や用途で明確に向き不向きがある)。
5-4 境界条件の分類と実装(ディリクレ条件) 難2・境界条件の実装(ディリクレ)
有限要素法における『変位を規定する境界条件(第1種・基本境界条件、ディリクレ条件)』の説明と実装方法の組合せとして、正しいものはどれか。
  1. 力・応力を指定する条件であり、荷重ベクトルへ加算するだけで実装する。
  2. 変位そのものを指定する条件であり、連立方程式 $Ku=f$ の該当自由度を縮約(消去)するか、対角要素を置換するなどして左辺(行列)側で処理する。
  3. 変位・力のどちらを指定してもディリクレ条件と呼び、実装方法は常に同一である。
  4. 熱伝導解析にのみ現れる条件で、構造解析には存在しない。
正解 : 2
【基礎】ディリクレ条件(第1種・基本境界条件)は場の量そのもの、構造なら変位、熱なら温度を直接指定する条件です。既に値が分かっている自由度なので、連立方程式の左辺(剛性行列)側を操作して実装します。
【考え方】力(ノイマン条件)が右辺の荷重ベクトルの操作で済むのに対し、変位(ディリクレ条件)は未知数そのものを既知値に固定するため、行列の縮約や対角置換など『左辺の構造を変える』処理が必要になります。
【ポイント】ディリクレ=変位=左辺(行列)側の処理、ノイマン=力=右辺(荷重)側の処理、と対で覚える。分野が変わっても(構造でも熱でも)この対応は同じ。
【引っかけ】1は力の指定と実装方法(荷重ベクトルへの加算)をディリクレの説明として書いており、ノイマン条件との取り違え。3は変位と力を区別せず同一視した誤り。4は構造解析に存在しないとする誤り(変位固定はまさに構造解析で常用する条件)。
5-5 ディリクレ条件の実装手法の比較 難3・境界条件の実装手法(ペナルティ法・縮約・対角置換)
ディリクレ条件(既知変位)を連立方程式 $Ku=f$ に課す3つの代表的な手法、ペナルティ法・行列縮約(消去)法・対角置換法の説明として、正しいものはどれか。
  1. ペナルティ法は既知変位を厳密に満たす解が必ず得られ、数値誤差は一切生じない。
  2. 行列縮約法は、既知自由度の行・列を残したまま行列サイズを変えずに解く方法である。
  3. 対角置換法は該当行の対角要素を0にし、非対角要素を1にして右辺に既知値を代入する。
  4. ペナルティ法は対角要素に非常に大きな数を加算し既知変位に対応する荷重を右辺に与える近似法、行列縮約法は既知自由度の行・列を取り除いて未知数のみの小さい行列を解く厳密な方法、対角置換法は対角要素を1・非対角要素を0にして行列サイズは変えずに既知値を右辺へ反映する方法である。
正解 : 4
【基礎】3手法はいずれもディリクレ条件を線形方程式に組み込む方法ですが、扱い方が異なります。ペナルティ法は対角に非常に大きな数(例えば行列成分の $10^{6}$〜$10^{20}$ 倍程度)を足し、右辺にその大きな数×既知変位を与えて『事実上その自由度をその値に固定する』近似法です。行列縮約法は既知自由度の行・列を完全に取り除き、残りの未知数だけの小さい連立方程式を解く厳密な方法です。対角置換法は行列サイズは変えずに該当行の対角要素を1、非対角要素を0にし、右辺にその既知値を直接代入する方法です。
【考え方】3つとも『最終的に同じ既知変位を再現する』点は共通ですが、行列サイズを変えるかどうか(縮約は変える、対角置換・ペナルティ法は変えない)、近似か厳密か(ペナルティ法は大きな数のとり方次第で丸め誤差が残る近似、他の2つは理論上厳密)という違いがあります。
【ポイント】ペナルティ法=近似・大きな数、行列縮約=厳密・サイズ変更、対角置換=厳密・サイズ据置き、と整理する。
【引っかけ】1はペナルティ法を『誤差が一切生じない』とする誤り(大きな数のとり方が不適切だと丸め誤差や条件数の悪化を招く)。2は行列縮約法を『サイズを変えない』とする誤り(縮約とはサイズを小さくする操作そのもの)。3は対角置換法の対角・非対角を逆にした誤り(対角を1、非対角を0にするのが正しい)。
5-6 荷重(力)境界条件の処理 難1・荷重(ノイマン)条件の実装
荷重(力)境界条件の有限要素法での処理方法として、正しいものはどれか。
  1. 等価節点力として連立方程式の右辺(荷重ベクトル)に加えるだけで、剛性行列は変更しない。
  2. その自由度に対応する剛性行列の対角要素を大きな数に置き換える。
  3. その自由度の変位をあらかじめ固定してから解く。
  4. 剛性行列の該当する行・列を削除してから解く。
正解 : 1
【基礎】力(ノイマン)条件は連立方程式 $Ku=f$ の右辺 $f$(荷重ベクトル)だけを操作すれば実装できます。分布荷重であれば、先に等価節点力へ換算してから加えます。
【考え方】剛性行列 $K$ は材料と形状(幾何)だけで決まる量で、どのように荷重を与えるかとは無関係です。荷重は右辺のみを動かす操作である点がディリクレ条件(変位規定、左辺の操作)との違いです。
【ポイント】力=右辺(荷重ベクトル)のみ操作、行列 $K$ は不変。
【引っかけ】2・4は剛性行列(左辺)を操作しており、これはディリクレ条件の実装(対角置換・縮約)との混同。3は変位を固定する操作で、これも力ではなく変位規定のやり方。
5-7 分布圧力の等価節点力への換算 難3・等価節点力(圧力・線形分布)
長さ $L=100$ mm の2節点直線辺(節点1,2)に、節点1側で $p_1=200$ N/mm、節点2側で $p_2=400$ N/mm と線形に変化する分布荷重(単位長さあたりの力)が作用している。線形形状関数を重みとする等価節点力は $f_1=\dfrac{L}{6}(2p_1+p_2)$、$f_2=\dfrac{L}{6}(p_1+2p_2)$ で与えられる。節点2の等価節点力 $f_2$ はいくらか。
  1. 20000 N
  2. 15000 N
  3. 16667 N
  4. 13333 N
正解 : 3
【基礎】分布荷重は仮想仕事の原理から $\{f\}=\int N^{T}p\,dS$ として節点力に換算します。線形2節点辺で圧力も線形分布のときは、上記の重み付き式になります(圧力が大きい側の節点により多く配分される)。
【考え方】まず全体の合力(等価な集中力)を求めると検算になります。合力は台形の面積 $=(p_1+p_2)/2\times L=(200+400)/2\times100=30000$ N。$f_1+f_2$ はこれと一致するはずです。
【計算】$f_2=\dfrac{100}{6}(200+2\times400)=\dfrac{100}{6}\times1000\approx16667$ N。$f_1=\dfrac{100}{6}(2\times200+400)=\dfrac{100}{6}\times800\approx13333$ N。検算:$f_1+f_2=13333+16667=30000$ N で合力と一致。
【ポイント】圧力が大きい節点2の方が $f_2>f_1$ になる(単純な半々ではない)。
【引っかけ】1の20000 Nは $p_2\times L/2=400\times50$ と、あたかも節点2に圧力のピーク値だけを集中させた誤り。2の15000 Nは合力を単純に半分ずつ均等配分した誤り(圧力が一様でない限り均等配分にはならない)。4の13333 Nは $f_1$ の値を $f_2$ と取り違えた誤り。
5-8 物体力(自重)の等価節点力 難2・物体力(自重)の体積積分による換算
断面積 $A=500$ mm²、長さ $L=1000$ mm の2節点棒要素が鉛直に置かれ、単位体積あたりの自重 $\gamma=7.7\times10^{-5}$ N/mm³ が軸方向に作用する。等価節点力 $\{f\}=\int N^{T}\gamma A\,dx$ により両端の節点に配分される力は、線形要素では各節点に均等に配分される。各節点の等価節点力はいくらか。
  1. 38.5 N(各節点)
  2. 19.25 N(各節点)
  3. 9.625 N(各節点)
  4. 0 N(自重は無視してよい)
正解 : 2
【基礎】自重のような物体力(体積力)は、仮想仕事の原理により体積積分 $\{f\}=\int N^{T}b\,dV$ で等価節点力に換算します。線形2節点棒要素では形状関数が対称なので、結果的に総荷重を両端で均等に折半する形になります。
【考え方】まず要素にかかる自重の総量(総荷重)を求め、次にそれを両節点へ配分するという2段階で考えます。
【計算】総重量 $W=\gamma AL=7.7\times10^{-5}\times500\times1000=38.5$ N。線形要素なので各節点には $W/2=19.25$ N ずつ配分される。
【ポイント】物体力=体積積分→荷重ベクトルに加算(剛性行列は変えない)。線形要素なら均等折半という結果になる。
【引っかけ】1は総重量38.5 Nをそのまま1節点分として使ってしまった誤り(半分にし忘れ)。3は $W/2$ をさらに誤って半分にした(4分の1にした)計算ミス。4は自重を無視してよいとする誤り(自重が無視できない構造は多く、常に確認が必要)。
5-9 強制変位のある系の解法(直列3ばね) 難3・強制変位を含む剛性方程式(内部節点の縮約)
ばね定数 $k_1=100$ N/mm、$k_2=200$ N/mm、$k_3=200$ N/mm の3つのばねを直列に接続する(節点1-2-3-4の順)。節点1を固定($u_1=0$)、節点4に強制変位 $u_4=6$ mm を与え、節点2・節点3には外力を作用させない。内部節点の変位 $u_2$ はいくらか。
  1. 3 mm
  2. 2 mm
  3. 4 mm
  4. 6 mm
正解 : 1
【基礎】節点2・節点3のつり合い式は、それぞれ $-k_1u_1+(k_1+k_2)u_2-k_2u_3=0$、$-k_2u_2+(k_2+k_3)u_3-k_3u_4=0$ です($F_2=F_3=0$)。
【考え方】既知の $u_1=0$、$u_4=6$ を代入すると、未知数 $u_2,u_3$ だけの2元連立方程式に縮約されます。これを解きます。
【計算】代入すると $300u_2-200u_3=0$、$-200u_2+400u_3=1200$。1本目より $u_3=1.5u_2$。2本目に代入: $-200u_2+600u_2=1200\Rightarrow400u_2=1200\Rightarrow u_2=3$ mm(このとき $u_3=4.5$ mm)。
【ポイント】ばねが硬いほど伸びにくいので、柔らかい $k_1$ 側の節点2はあまり伸びず(3 mm)、$k_2=k_3$ 側の節点3寄りでより伸びが進む、という傾向とも整合する。
【引っかけ】2の2 mmは $k_2,k_3$ を無視し $k_1,k_3$ のみの単純な2ばね近似などによる誤り。3の4 mmは節点3の変位($u_3=4.5$ mmに近い数)と取り違えた誤り。4の6 mmは節点4と同じだけ動く(剛体的)と誤認した誤り。内部節点を正しく連立方程式で解くことが要点。
5-10 棒要素の軸力と縮約方程式(2要素) 難3・強制変位のない系での軸力による変位(縮約)
節点1-2-3の順に2つの棒要素を直列に接続する。要素1(節点1-2)の $EA/L=600$ N/mm、要素2(節点2-3)の $EA/L=900$ N/mm。節点1を固定し、節点3の先端に軸力 $P=3600$ N を作用させる(節点2には外力なし)。境界条件を代入して縮約した連立方程式を解くと、先端節点3の変位 $u_3$ はいくらか。
  1. 6 mm
  2. 4 mm
  3. 2.4 mm
  4. 10 mm
正解 : 4
【基礎】$u_1=0$ を代入して縮約すると、節点2・3についての方程式 $\begin{bmatrix}k_1+k_2&-k_2\\-k_2&k_2\end{bmatrix}\begin{Bmatrix}u_2\\u_3\end{Bmatrix}=\begin{Bmatrix}0\\P\end{Bmatrix}$ が残ります($k_1=600,k_2=900$)。
【考え方】これは直列に力を伝える構造なので、各要素に生じる軸力はどちらも同じ $P$ になるはずです(静力学的な検算)。
【計算】$1500u_2-900u_3=0\Rightarrow u_2=0.6u_3$。$-900u_2+900u_3=3600$ に代入: $-540u_3+900u_3=3600\Rightarrow360u_3=3600\Rightarrow u_3=10$ mm($u_2=6$ mm)。検算:要素2の軸力 $=k_2(u_3-u_2)=900\times4=3600$ N、要素1の軸力 $=k_1u_2=600\times6=3600$ N で共に $P$ と一致。
【ポイント】直列の棒では、全体の伸びは各要素の伸び($P/k_1$と$P/k_2$)の単純和になる:$3600/600+3600/900=6+4=10$ mm。
【引っかけ】1の6 mmは中間節点2の変位と先端節点3の変位を取り違えた誤り。2の4 mmは要素2の伸びだけを答え、要素1の伸びを足し忘れた誤り。3の2.4 mmは2つのばねを並列(合成剛性 $k_1+k_2=1500$)として $P/1500$ と計算した誤りで、直列と並列を混同している。
5-11 縮約後の反力の計算 難2・反力の算出(境界条件を課した後の後処理)
5-10と同じ棒(要素1: $EA/L=600$ N/mm、要素2: $EA/L=900$ N/mm、節点1固定、節点3に軸力 $P=3600$ N)で、節点2の変位は $u_2=6$ mmであった。固定端(節点1)に生じる反力の大きさはいくらか。
  1. 0 N
  2. 3600 N
  3. 1800 N
  4. 7200 N
正解 : 2
【基礎】縮約する前の1行目(節点1の式)は $k_1u_1-k_1u_2=R_1$ の形をしており、これが反力を求める式として残っています($R_1$は固定端反力)。
【考え方】$u_1=0$、$u_2=6$、$k_1=600$を代入すれば反力が求まります。全体のつり合い(外力Pと反力がつり合う)でも検算できます。
【計算】$R_1=k_1(u_1-u_2)=600\times(0-6)=-3600$ N。大きさは $3600$ N(符号は圧縮/引張の向きを表す)。全体のつり合い $R_1+P=0$ からも $R_1=-3600$ Nと一致。
【ポイント】固定端反力は、外力とつり合う(大きさが等しく逆向き)ことを使うと検算しやすい。
【引っかけ】1の0 Nは固定端に反力が生じないという誤り(固定端は必ず外力とつり合う反力を生じる)。3の1800 Nは $k_1u_2/2$ のように値を半分にした計算ミス。4の7200 Nは反力を2倍にした誤り(例えば要素1・要素2の寄与を両方カウントするなどの誤り)。
5-12 対称面に課す境界条件 難2・対称境界条件の適用判断
形状・材料・荷重・拘束のすべてが左右対称な部品を、対称面で切って半分だけモデル化したい。対称面上の節点に課すべき境界条件として、正しいものはどれか。
  1. 対称面上の全変位成分(面内・面外すべて)を0に固定する。
  2. 対称面には何も拘束を与えず自由端として解析する。
  3. 対称面に垂直な方向の変位成分のみを0に拘束し(ローラー支持)、面内方向は拘束しない。
  4. 対称面上の節点にだけ、実際にはない外力を追加で与える。
正解 : 3
【基礎】荷重・形状・拘束が完全に対称なら、変形も対称になり、対称面をまたいで面直方向に動くことはできません(左右が鏡像で引っ張り合うため)。一方、面内方向には自由に動けます。
【考え方】『対称面を越えて反対側へめり込む・離れる』ことは物理的に起きないので、面に垂直な成分だけをゼロに拘束する『ローラー支持』がちょうど半分モデルの正しい境界条件になります。
【ポイント】対称面=法線方向のみ拘束(ディリクレ条件の一種)、面内方向は自由。
【引っかけ】1は面内方向まで固定してしまう過剰拘束で、実際より部品を硬く評価してしまう(実務で頻発するミス)。2は自由端とする誤りで、対称条件を反映できず面直方向に不自然な変形を許してしまう。4は存在しない外力を加える誤りで、対称性は拘束条件であって荷重ではない。
5-13 対称性を利用した小さい連立方程式の求解 難3・対称性を利用した解の簡略化(計算)
頂点(apex)から左右対称に角度45°で伸びる2本のトラス部材(軸方向剛性 $k=800$ N/mm、材質・長さとも左右同一)が支持する構造に、頂点へ鉛直下向きの荷重 $P=400$ N が作用する。対称性より頂点の水平変位は0になることを利用すると、頂点の鉛直変位 $v$ を求める式は $v=\dfrac{P}{2k\cos^{2}\theta}$($\theta$は鉛直軸からの角度)となる。$v$ はいくらか。
  1. 1.0 mm
  2. 0.5 mm
  3. 0.25 mm
  4. 0.35 mm
正解 : 2
【基礎】対称性から頂点の水平変位は0と分かるので、本来2自由度(水平・鉛直)ある頂点の未知数を鉛直方向1個だけに減らせます。これが『対称性を利用した連立方程式の縮小』です。各部材の軸方向剛性のうち、鉛直方向に効く成分は角度の余弦の2乗倍になります。
【考え方】部材1本あたりの鉛直方向剛性は $k\cos^{2}\theta$。左右2本あるので合計 $2k\cos^{2}\theta$ が頂点の鉛直方向の等価剛性になり、$v=P/(2k\cos^{2}\theta)$ で解けます。
【計算】$\theta=45°$ なので $\cos^{2}45°=0.5$。$v=\dfrac{400}{2\times800\times0.5}=\dfrac{400}{800}=0.5$ mm。
【ポイント】対称性を使うと、本来解くべき2元(または、より大きな)連立方程式が実質1元の式にまで簡略化できる。
【引っかけ】1の1.0 mmは対称性による『2本分』の効果を数え忘れ、1本の部材だけで計算した誤り($400/(800\times0.5)=1$)。3の0.25 mmは角度の投影(余弦の2乗)を掛け忘れ、単純に $P/(2k)$ とした誤り。4の0.35 mmは $\cos^{2}\theta$ の代わりに $\cos\theta$ を使ってしまった誤り。
5-14 平面応力・平面ひずみのモデル化判断 難2・平面応力・平面ひずみの使い分け
断面形状・荷重が長手方向に一様で、両端が厚い壁で拘束され軸方向の伸縮がほとんど生じない、非常に長いトンネル(暗渠)の横断面の応力解析を2次元でモデル化したい。最も適切な仮定はどれか。
  1. 面外方向の応力を0とみなす平面応力を適用する。
  2. 薄い板とみなし、シェル要素で面外方向の曲げを表現する。
  3. 回転体とみなし、軸対称要素でモデル化する。
  4. 面外方向(長手方向)のひずみを0とみなす平面ひずみを適用する。
正解 : 4
【基礎】平面応力は面外方向の応力が0とみなせる『薄い板』向け、平面ひずみは面外方向のひずみが0とみなせる『非常に長く、両端が拘束されて伸縮できない』部材向けの仮定です。
【考え方】この暗渠は断面が長手方向に変化せず、両端が厚い壁で軸方向にほとんど伸縮できないため、断面から離れた位置では面外(長手)方向のひずみが実質0とみなせます。これはまさに平面ひずみの前提です。
【ポイント】薄い板(面外応力0)→平面応力、長くて面外方向が拘束(面外ひずみ0)→平面ひずみ、回転対称形状→軸対称、と使い分ける。
【引っかけ】1は平面応力を適用する誤りで、この構造は『薄い』のではなく『長い』ので前提が逆。2はシェル要素とする誤りで、これは薄板の面外曲げ用のモデル化であり、断面内の応力分布を見たいこの問題には合わない。3は軸対称とする誤りで、暗渠の断面は回転対称形状ではない(軸対称は円筒・円盤など回転体に限る)。
5-15 平面ひずみのD行列への数値代入 難2・平面ひずみの応力-ひずみマトリクス
縦弾性係数 $E=200000$ N/mm²、ポアソン比 $\nu=0.3$ の等方性材料について、平面ひずみのD行列(応力-ひずみマトリクス)の非対角成分 $D_{12}=\dfrac{E\nu}{(1+\nu)(1-2\nu)}$ の値はいくらか。
  1. $2.69\times10^{5}$ N/mm²
  2. $1.15\times10^{5}$ N/mm²
  3. $7.69\times10^{4}$ N/mm²
  4. $6.00\times10^{4}$ N/mm²
正解 : 2
【基礎】平面ひずみのD行列は $D_{11}=D_{22}=\dfrac{E(1-\nu)}{(1+\nu)(1-2\nu)}$、$D_{12}=\dfrac{E\nu}{(1+\nu)(1-2\nu)}$、せん断項 $D_{33}=G=\dfrac{E}{2(1+\nu)}$ で与えられます。
【考え方】分母 $(1+\nu)(1-2\nu)$ を先に計算してから分子 $E\nu$ を割ります。
【計算】$(1+\nu)(1-2\nu)=1.3\times0.4=0.52$。$D_{12}=\dfrac{200000\times0.3}{0.52}=\dfrac{60000}{0.52}\approx115385$ N/mm² $=1.15\times10^{5}$ N/mm²。
【ポイント】$D_{11}\approx2.69\times10^{5}$、せん断項 $G\approx7.69\times10^{4}$ もついでに押さえておくと他成分の問題にも対応できる。
【引っかけ】1の$2.69\times10^{5}$は$D_{11}$の値を$D_{12}$と取り違えた誤り。3の$7.69\times10^{4}$はせん断項$G$の値を$D_{12}$と取り違えた誤り。4の$6.00\times10^{4}$は分子$E\nu=60000$を求めた時点で分母の割り算を忘れた誤り。
5-16 軸対称モデル化の判断 難2・軸対称要素の適用判断
円筒形の圧力容器の鏡板(回転体形状で、形状・材料・内圧荷重・拘束条件がすべて中心軸まわりに回転対称)の応力解析を効率よく行いたい。最も適した2次元モデル化はどれか。
  1. 薄板とみなして平面応力でモデル化する。
  2. 長い部材とみなして平面ひずみでモデル化する。
  3. 中心軸を含む断面(r-z平面)だけを軸対称要素でモデル化する。
  4. 対称性は使わず、必ず3次元ソリッドで全周をモデル化する。
正解 : 3
【基礎】形状・荷重・拘束条件がすべて中心軸まわりに回転対称(軸対称)であれば、中心軸を含む1つの断面(r-z平面)だけを2次元の軸対称要素でモデル化すれば、全周の挙動を再現できます。
【考え方】平面応力・平面ひずみは『面外方向に伸びる平板・柱状』の近似であり、回転体そのものの周方向のつり合いは表現できません。回転対称形状には専用の軸対称要素(周方向ひずみを半径 $r$ と変位から計算する定式化)が適しています。
【ポイント】回転対称形状+回転対称な荷重・拘束=軸対称要素で断面だけ解く、が最も効率的。
【引っかけ】1・2は平面応力・平面ひずみを適用する誤りで、これらは回転体特有の周方向のつり合いを表現できない(別のモデル化前提)。4は対称性を使わず必ず3次元フルモデルにする誤りで、軸対称性がある場合はそれを使わないと計算コストを大きく損する(実務上の判断ミス)。
5-17 要素選択:厚みのあるブロック構造 難2・要素選択(ソリッド要素の適用判断)
下図のように、厚み・幅・奥行きがいずれも同程度の大きさをもつブロック状の支持構造の応力解析を行いたい。最も適した要素はどれか。
  1. 六面体・四面体などのソリッド(3次元)要素
  2. 面外の曲げを表現するシェル(板)要素
  3. 軸力のみを伝えるトラス要素
  4. 曲げ・せん断・軸力を1次元で表すはり(ビーム)要素
正解 : 1
【基礎】要素は解きたい構造の寸法比に合わせて選びます。3方向の寸法が同程度で『薄い』とも『細長い』とも言えない塊状の構造は、内部の3次元的な応力分布を表現できるソリッド要素が適します。
【考え方】薄い板→シェル、細長い部材→はり・トラス、塊状の構造→ソリッド、という寸法比による判断が基本です。
【ポイント】3方向とも同程度の寸法=ソリッド一択。
【引っかけ】2のシェル要素は面外方向に薄いことが前提の板・曲面向けで、厚みのある塊には板理論の仮定が成り立たない。3のトラス要素は軸力のみを伝える細長い部材向けで、曲げやブロック内部の応力分布は表現できない。4のはり要素も1方向が卓越する細長い部材向けで、3方向とも同程度の塊には適用できない。
5-18 要素選択:面外の曲げが問題となる薄板 難2・要素選択(シェル要素の適用判断)
面外方向の曲げ・そりが挙動の中心となる薄い板状のカバー部品を解析したい。ソリッド要素を厚さ方向に1層だけ並べてモデル化した場合に起こりやすい問題として、正しいものはどれか。
  1. 計算精度が向上し、シェル要素より常に良い結果が得られる。
  2. 要素の自由度が減り、計算がシェル要素より高速になる。
  3. 面外変形をまったく表現できず、平坦なままになる。
  4. 板厚方向に極端に扁平な要素になり、曲げに対して過度に硬い(ロッキングしやすい)結果になりやすい。
正解 : 4
【基礎】薄い板をソリッド要素で表すと、要素の板厚方向の寸法が面内方向に比べて極端に小さい『扁平要素』になります。低次のソリッド要素は曲げ変形の表現が苦手なため、このような扁平要素では曲げに対して不自然に硬い結果(せん断ロッキングに類する現象)になりやすいことが知られています。
【考え方】シェル要素は板厚方向の仮定(キルヒホッフ/ミンドリンの板理論)を組み込み、面内・面外の変形を少ない自由度で精度よく表現できるよう設計されています。薄板の曲げには本来このシェル要素が向いています。
【ポイント】薄板の曲げ=シェル要素が定石。ソリッド要素を無理に薄く積んで代用すると精度・計算コストの両面で不利になりやすい。
【引っかけ】1はソリッド1層の方が常に良い結果とする誤り(実際は逆で、扁平要素は精度低下を招きやすい)。2は自由度が減り高速化するという誤り(むしろソリッド要素は節点当たりの自由度・要素数が増えがちで、シェルより非効率になりやすい)。3はまったく変形を表現できないとする誤り(表現はできるが精度が悪化しやすい、が正しい)。
5-19 要素選択:トラスとはりの使い分け 難2・要素選択(トラス要素・はり要素の適用判断)
トラス橋の斜材(両端がピン接合で、軸力のみを伝えるように設計された部材)と、片持ちのブラケット(根元が剛接合され、先端荷重により曲げモーメントも生じる部材)を、それぞれ有限要素でモデル化するとき、最も適切な要素の組合せはどれか。
  1. 斜材=はり要素、ブラケット=トラス要素
  2. 斜材=トラス要素、ブラケット=はり要素
  3. どちらもトラス要素でよい(曲げは常に無視できる)。
  4. どちらもはり要素でよい(トラス要素を使う意味はない)。
正解 : 2
【基礎】トラス要素は軸力(引張・圧縮)のみを伝え、曲げモーメントを持たない要素です。はり要素は軸力に加え曲げモーメント・せん断力も伝えます。
【考え方】斜材はピン接合で軸力のみが働く設計なので、余分な曲げ自由度を持たないトラス要素で十分かつ適切です。一方ブラケットは根元が剛接合され先端荷重で曲げモーメントが生じるため、曲げを表現できるはり要素が必要です。
【ポイント】ピン接合・軸力のみ→トラス要素、剛接合・曲げを伴う→はり要素、と接合条件と力の伝わり方で判断する。
【引っかけ】1は組合せを逆にした誤り。3はどちらもトラス要素でよいとする誤りで、ブラケットの曲げを無視すると重要な応力(曲げ応力)を見落とす。4はどちらもはり要素でよいとする誤りで、トラス要素の方が自由度が少なく効率的な場面(純粋な軸力部材)まで不必要に複雑化させてしまう。
5-20 熱応力解析に必要な材料定数 難1・熱応力解析の設定
熱応力解析を行うために、通常の弾性解析で用いる縦弾性係数 $E$・ポアソン比 $\nu$ に加えて必ず必要となる材料定数はどれか。
  1. 密度
  2. 比熱
  3. 線膨張係数 $\alpha$
  4. 熱伝導率
正解 : 3
【基礎】温度が変化すると材料は伸縮しようとします。この伸縮量を決めるのが線膨張係数 $\alpha$ で、熱ひずみ(初期ひずみ)は $\varepsilon_0=\alpha\Delta T$ と表されます。
【考え方】熱応力は『温度変化による熱ひずみが構造の拘束によって妨げられる』ことで生じます。応力を弾性論で計算するには $E,\nu$ に加え、熱ひずみを与える $\alpha$ が不可欠です。
【ポイント】熱応力解析=$E,\nu,\alpha$ が三点セット(温度分布が既知の場合)。
【引っかけ】1の密度は動解析(慣性項)や自重の計算で使う量で熱応力そのものには直接不要。2の比熱と4の熱伝導率は温度場を求める熱伝導解析で必要な量で、温度分布が既に分かっているなら熱応力の計算自体には不要(熱応力の主役は$\alpha$)。
5-21 熱ひずみ(初期ひずみ)の計算 難2・熱ひずみ
線膨張係数 $\alpha=23\times10^{-6}$ /K の材料の温度を $\Delta T=50$ K 上昇させた。拘束のない自由膨張での熱ひずみ(初期ひずみ)$\varepsilon_0=\alpha\,\Delta T$ はいくらか。
  1. $1.15\times10^{-3}$
  2. $1.15\times10^{-4}$
  3. $2.30\times10^{-3}$
  4. $5.75\times10^{-4}$
正解 : 1
【基礎】温度変化で生じる熱ひずみは $\varepsilon_0=\alpha\,\Delta T$ です。FEMではこれを初期ひずみとして扱い、拘束が無ければこのひずみ分だけ自由に伸縮し、応力は生じません。
【考え方】$\alpha$ と $\Delta T$ を単純に掛け合わせます。指数計算に注意します。
【計算】$\varepsilon_0=23\times10^{-6}\times50=1150\times10^{-6}=1.15\times10^{-3}$。
【ポイント】$\times10^{-6}$ と $\times10^{1}$ の掛け算で指数が1つ繰り上がることを押さえる。
【引っかけ】2は指数を1つ間違え、桁を1桁落とした誤り。3は $\Delta T=100$ Kと取り違えた(2倍にした)誤り。4は正しい値をさらに半分にした計算ミス。
5-22 拘束された熱ひずみによる熱応力 難3・熱応力の計算(初期ひずみの符号)
縦弾性係数 $E=70000$ N/mm² の部材が、温度上昇 $\Delta T=50$ K により熱ひずみ $\varepsilon_0=1.15\times10^{-3}$(線膨張係数 $\alpha=23\times10^{-6}$/K)を生じようとしたが、両端が完全に固定されて全ひずみが0に拘束された。このとき部材に生じる応力 $\sigma=E(\varepsilon-\varepsilon_0)$ はいくらか(引張を正とする)。
  1. $+80.5$ N/mm²(引張)
  2. $-161$ N/mm²(圧縮)
  3. $-40.3$ N/mm²(圧縮)
  4. $-80.5$ N/mm²(圧縮)
正解 : 4
【基礎】全ひずみ $\varepsilon$ は拘束によって0です。応力は弾性ひずみ(全ひずみから初期ひずみを引いたもの)によって生じるので $\sigma=E(\varepsilon-\varepsilon_0)=E(0-\varepsilon_0)=-E\varepsilon_0$ となります。
【考え方】温度が上がって伸びたいのに、拘束されて伸びられない→材料は『押し縮められた』状態と同じになるので圧縮応力が生じます。符号(向き)を落とさずに考えることが重要です。
【計算】$\sigma=-70000\times1.15\times10^{-3}=-80.5$ N/mm²(圧縮)。
【ポイント】加熱+完全拘束=圧縮応力、冷却+完全拘束=引張応力、と向きを覚えておくと符号ミスを防げる。
【引っかけ】1は符号を落として引張としてしまった誤り(加熱で伸びを妨げられると圧縮になるのが正しい、初期ひずみの符号の取り違え)。2は $\Delta T$ を2倍にする等で値を2倍にした計算ミス。3は正しい値を半分にした計算ミス。いずれも大きさか符号のどちらかを誤っている。
5-23 焼きばめによる残留応力の解析 難2・焼きばめ(しめしろ)のモデル化
軸と穴の焼きばめ(しめしろ)による残留応力を有限要素法で求める代表的な方法として、正しいものはどれか。
  1. しめしろを無視し、軸と穴を接触させずに解析する。
  2. しめしろ(半径方向の重なり量)を初期ひずみ、または内外部品間の温度差として与えて解析する。
  3. 外部からの押込み力(外力)として、しめしろに相当する荷重を推定して与える。
  4. 材料を弾塑性から強制的に線形弾性へ置き換えて解析する。
正解 : 2
【基礎】焼きばめは、穴よりわずかに大きい軸を熱膨張差や圧入で組み込み、冷却・復元後の締め付け力(しめしろ)で残留応力を生む接合です。
【考え方】FEMでは、この『半径方向の重なり量(しめしろ)』を初期ひずみとして各要素に与える方法や、内側・外側の部品に温度差を設定し熱膨張差でしめしろを再現する方法、あるいは接触解析で幾何学的な干渉量を直接指定する方法が使われます。
【ポイント】しめしろ=初期ひずみ(または温度差)で表現するのが定石。焼きばめは幾何学的な『重なり』が原因で、外部から加えた力ではない点に注意する。
【引っかけ】1はしめしろを無視する誤りで、残留応力の原因そのものを消してしまう。3は外力として与える誤りで、しめしろは幾何学的な干渉量であり、外力に置き換えると変位や応力分布を正しく再現できない。4は弾塑性から線形弾性へ強制的に置き換える誤りで、焼きばめの解析対象は材料モデルの選択とは別の問題であり、必要なら弾塑性のまま解析してよい。
5-24 貼合せ板(バイメタル)の残留応力とそり 難2・異材貼合せのモデル化
線膨張係数の異なる2枚の薄板を全面接着した部材を加熱すると生じる現象として、最も適切なものはどれか。
  1. 接着面で応力は生じるが、部材の形状(平坦さ)は変わらない。
  2. 線膨張係数の小さい側にだけ応力が生じ、大きい側には応力は生じない。
  3. 各層が伸びたい量の差が接着により拘束され、残留応力が生じるとともに部材全体がそる(反る)。
  4. 接着面がすべり、2枚の板は独立に自由膨張するため応力は生じない。
正解 : 3
【基礎】線膨張係数が異なる2枚を接着すると、温度変化で各層が『本来伸びたい量』が異なります。しかし接着により界面で変位が拘束され、同じ伸びに揃えられるため、その差が内部応力として蓄積します。
【考え方】断面内で応力分布が層ごとに非対称になるため、単なる引張・圧縮だけでなく曲げモーメントが生じ、部材全体が反ります(バイメタル温度計と同じ原理)。
【ポイント】異材貼合せ+温度変化=残留応力+そり、両方セットで生じる。
【引っかけ】1は応力は生じるが形状は変わらないとする誤り(層の伸び差が非対称なので必ず曲げ・そりを伴う)。2は片方の層にしか応力が生じないとする誤り(拘束し合うので両層に応力が生じる)。4は接着面がすべって応力が生じないとする誤り(全面接着が前提であり、実際には拘束されて応力・そりが生じる)。
5-25 収束性の実務的確認(メッシュ細分) 難2・収束性の確認
有限要素解析で得た応力の最大値が、メッシュを細かくするたびに一貫して大きくなり続け、収束する気配がない場合の実務的な対処として、最も適切なものはどれか。
  1. 応力集中部(形状の角・穴の縁など)に理論的な特異点がないか確認し、必要なら評価点を変えるか丸み・フィレットを含めてモデル化するなど、評価方法自体を見直す。
  2. メッシュをさらに無限に細かくし続ければ、いずれ必ず有限の値に収束するので、そのまま細分化を続ける。
  3. 収束しない場合でも、最も細かいメッシュで得られた値をそのまま設計に採用する。
  4. 収束の確認自体が不要なので、メッシュは粗いまま最初の結果を採用する。
正解 : 1
【基礎】メッシュを細かくしても応力最大値が収束せず増加し続ける場合、多くは鋭い角(応力特異点)のように数学的に応力が発散する形状を評価点にしていることが原因です。
【考え方】収束性の確認は『メッシュをある程度細かくしても結果がほぼ変わらないこと』を確かめる作業です。増加し続けて収束しないときは、メッシュを細かくすること自体では解決せず、モデル化(丸み・フィレットの付与や評価点・評価方法の見直し)側の問題を疑うのが実務的に正しい対応です。
【ポイント】『細かくすれば必ず収束する』とは限らない(特異点では発散する)。収束しないこと自体が形状・評価方法を見直す重要なサインになる。
【引っかけ】2は無限に細分化すれば必ず収束するという誤り(応力特異点では理論上メッシュを細かくするほど値が増加し発散する)。3は収束しない値をそのまま採用する誤りで、信頼性のない過大な値を設計に使ってしまう。4は収束確認自体が不要とする誤りで、メッシュ依存性の確認は解析結果の信頼性を担保する基本的な手順である。
5-26 変位法による解析手順 難1・FEM解析の計算手順
変位法(剛性法)による有限要素解析の計算手順として、正しい順序はどれか。
  1. 境界条件適用 → 要素剛性行列作成 → 連立方程式を解く → 全体剛性行列組立 → ひずみ・応力計算
  2. 連立方程式を解く → 全体剛性行列組立 → 要素剛性行列作成 → 境界条件適用 → ひずみ・応力計算
  3. ひずみ・応力計算 → 要素剛性行列作成 → 全体剛性行列組立 → 境界条件適用 → 連立方程式を解く
  4. 要素剛性行列作成 → 全体剛性行列へ組立 → 境界条件適用 → 連立方程式を解く → ひずみ・応力計算
正解 : 4
【基礎】変位法の基本的な流れは、(1)各要素の剛性行列を作る、(2)それらを全体剛性行列に組み立てる(アセンブリ)、(3)境界条件(拘束・荷重)を適用する、(4)連立方程式 $Ku=f$ を解いて節点変位を求める、(5)得られた変位からひずみ・応力を計算する、という一本道です。
【考え方】『部品を作る→組み立てる→条件を入れる→解く→後処理』という自然な順番で覚えます。応力・ひずみは変位が求まった後の後処理なので、途中や先頭には来ません。
【ポイント】要素→全体→境界条件→求解→応力、の順序を崩さない。
【引っかけ】1は境界条件を要素剛性行列の作成より前に置き、かつ応力計算を求解より前に置く誤り。2は求解を先頭に置く誤り(全体剛性行列も境界条件もまだ整っていない段階で解けない)。3は応力・ひずみ計算を最初に置く誤り(変位が求まっていないのに応力は計算できない)。

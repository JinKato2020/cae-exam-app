第4章 有限要素法の定式化

CAE計算力学技術者 固体力学2級・オリジナル問題（問題／解答／解説／図）
4-1 FEMを用いる動機 難1・FEMの基本概念
有限要素法(FEM)を数値解法として用いる主な動機として、最も適切なものはどれか。
  1. 複雑な形状・境界条件をもつ対象で厳密な解析解が得にくい場合に、要素分割と節点値の補間によって近似解を求めるため。
  2. 微分方程式そのものが存在しない問題に対して、力の釣合いだけから厳密解を得るため。
  3. 実験を一切行わずに、ヤング率など材料定数そのものを決定するため。
  4. 要素分割を粗くするほど、真の解析解に近づく性質を利用するため。
正解 : 1
【基礎】FEMは、複雑な形状や境界条件のため手計算で解析解を求められない対象に対し、近似解を数値的に得るための方法です。
【考え方】物体を要素に分割し、節点の値を形状関数で補間して全体をつなぎ、連立方程式に帰着させて解きます。あくまで支配方程式(の弱形式)を近似的に満たす解を求めるのであって、方程式なしに答えが出るわけではありません。
【ポイント】FEMは(1)離散化(2)節点値の補間(3)連立方程式、という手順で近似解を得る点が本質です。
【引っかけ】選択肢2は『微分方程式が存在しない』としていますが、FEMも支配方程式(平衡方程式の弱形式)を解いており誤りです。選択肢3は材料定数はFEMへの入力であり、FEMが決定するものではありません。選択肢4は逆で、要素分割を細かくするほど真の解析解に近づきます(粗くすると誤差が増えます)。
4-2 半無限領域に適した離散化手法 難2・FEM/FDM/BEMの比較(適用判断)
地盤や遠方境界をもつ問題のように、外部境界が非常に遠くまで広がる領域を、内部を要素分割せずに境界だけを離散化して解きたい場合に最も適した手法はどれか。
  1. 差分法(FDM)。支配方程式の微分を格子点上の差分商で置き換える。
  2. モンテカルロ法。乱数による確率的な試行の平均から解を推定する。
  3. 境界要素法(BEM)。境界だけを要素に分割し、内部は基本解(積分公式)で表現する。
  4. 有限要素法(FEM)。領域全体を要素に分割し弱形式を近似する。
正解 : 3
【基礎】離散化手法は、どこを・どう離散化するかで得意分野が分かれます。
【考え方】BEMは境界だけを要素分割し、内部は基本解を使った積分表現で扱うため、遠方まで広がる領域や無限領域でも内部メッシュが不要という利点があります。FDMは格子点全体が必要、FEMも領域全体を要素分割する必要があるため、この用途では不利です。
【ポイント】『境界だけ分割→内部は積分公式』がBEMの目印で、遠方境界・半無限領域との相性が良い理由です。
【引っかけ】選択肢1(FDM)は格子点法で領域全体が必要。選択肢2(モンテカルロ法)は確率的手法で、この種の境界値問題の標準的解法ではありません。選択肢4(FEM)は領域分割が必要なため、遠方境界の扱いにはBEMほど適していません。
4-3 ガラーキン法を採用する理由 難2・重み付き残差法・ガラーキン法
重み付き残差法において、重み関数を近似解の形状関数と同じにとる(ガラーキン法)ことの利点として、最も適切なものはどれか。
  1. 得られる係数行列(剛性行列)が対称になりやすく、仮想仕事の原理など既知の変分原理と一致した定式化が得られるため。
  2. 得られる係数行列が対角行列になり、連立方程式を解く必要がなくなるため。
  3. 重み関数を形状関数と同じにとれば、境界条件を考慮しなくても正しい解が自動的に得られるため。
  4. 選点法(コロケーション法)よりも、解くべき未知数(節点自由度)の数そのものを減らせるため。
正解 : 1
【基礎】重み付き残差法では重み関数 $w$ の選び方で手法名が変わり、ガラーキン法は『重み関数=近似解に使った形状関数(試験関数)』と定義されます。
【考え方】重みと試験関数を同じにすると、行列の $(i,j)$ 成分と $(j,i)$ 成分が同じ積分形になりやすく対称行列が得られます。これは仮想仕事の原理や最小ポテンシャルエネルギー原理から導かれる剛性方程式と一致し、物理的な変分原理に基づく定式化として整合します。
【ポイント】ガラーキン法の利点は『対称性』と『既知の変分原理との整合性』であり、行列が対角になるわけでも境界条件が不要になるわけでもありません。
【引っかけ】選択肢2は対角行列になるという誤り(一般に非対角成分をもちます)。選択肢3は境界条件が不要になるという誤り(重みの選び方によらず境界条件は別途組み込む必要があります)。選択肢4は未知数の数は節点・自由度の数で決まり、重み関数の選び方では変わりません。
4-4 仮想仕事(弱形式)が置換する式 難2・強形式と弱形式
仮想仕事の原理(弱形式)は、微分方程式で表された何を積分形に置き換えたものと解釈できるか。最も適切なものを選べ。
  1. 適合条件(ひずみ-変位関係)を積分形にしたもの。
  2. 応力とひずみの関係(構成則)を積分形にしたもの。
  3. 領域内部の平衡方程式と、力(応力)の境界条件を積分形(弱形式)にまとめたもの。
  4. 変位の境界条件(幾何学的境界条件)を近似的に満たすための罰則(ペナルティ)項。
正解 : 3
【基礎】固体の支配方程式は(1)平衡方程式(2)適合条件(3)構成則の3本柱で、仮想仕事の原理はこのうち平衡に対応します。
【考え方】仮想仕事の式を部分積分すると、領域内部の平衡方程式と、境界での力の条件(トラクション条件)が同時に含まれることが分かります。つまり微分形の平衡(強形式)を、微分の階数を下げた積分形(弱形式)に置き換えたものが仮想仕事の原理です。
【ポイント】適合条件や構成則は別途、ひずみ-変位関係と材料則として組み込みます。仮想仕事が代替するのは『平衡+力の境界条件』です。
【引っかけ】選択肢1(適合条件)・2(構成則)は仮想仕事が代替する対象ではありません。選択肢4は変位境界条件(幾何学的境界条件)の話で、これは仮想変位そのものに『許容条件』として課すものであり、仮想仕事の式が置換する対象ではありません。
4-5 仮想仕事の原理の内容 難2・仮想仕事の原理
仮想仕事の原理に関する説明として、最も適切なものはどれか。
  1. 物体が平衡状態にあるとき、拘束条件を満たす任意の微小な仮想変位に対して、外力のなす仮想仕事と内力(応力)のなす内部仮想仕事が等しい。
  2. 仮想変位は、その物体に実際に生じる変位の一部でなければならない。
  3. 仮想仕事の原理は微小変形の線形弾性体にだけ限って成立する特殊な関係である。
  4. 仮想仕事が釣り合う状態とは、外力のなす仕事がゼロになる状態を指す。
正解 : 1
【基礎】仮想仕事の原理は『物体が平衡なら、拘束条件を満たすどんな仮想変位を与えても、外力仕事=内部仕事になる』という原理です。逆に、これが成り立てば平衡だといえます。
【考え方】仮想変位 $\delta u$ は『実際に起こる変位』ではなく、頭の中で与える微小な想像上の変位です。ただし拘束条件(境界での固定など)は満たす必要があります(=幾何学的に許容)。材料則によらず成立する一般原理であり、線形・非線形を問いません。
【ポイント】『任意の許容仮想変位』『内部仕事=外部仕事』『材料の線形・非線形によらず成立』の3点が核心です。
【引っかけ】選択肢2は『実際の変位の一部でなければならない』が誤り(想像上でよい)。選択肢3は『線形弾性に限る』が誤り(一般に成立)。選択肢4は『外力仕事がゼロ』という別物で、平衡の定義ではありません。
4-6 表面力の仮想仕事項 難2・3次元仮想仕事の各項
3次元弾性体の仮想仕事の式のうち、物体表面に作用する表面力(表面トラクション $t_i$)がなす外部仮想仕事を表す項はどれか。$\delta u_i$ は仮想変位、$\delta\varepsilon_{ij}$ は仮想ひずみ、$b_i$ は体積力、$\rho\ddot u_i$ は慣性力、$V$ は体積、$S$ は表面である。
  1. $\displaystyle\int_V b_i\,\delta u_i\,dV$
  2. $\displaystyle\int_V \sigma_{ij}\,\delta\varepsilon_{ij}\,dV$
  3. $\displaystyle\int_S t_i\,\delta u_i\,dS$
  4. $\displaystyle\int_V \rho\,\ddot{u}_i\,\delta u_i\,dV$
正解 : 3
【基礎】仮想仕事の式は『内部仮想仕事=外部仮想仕事』の形をしており、外部仕事は体積力・表面力(動的問題では慣性力も)の寄与に分かれます。
【考え方】表面力は物体の『表面 $S$』に単位面積あたりの力 $t_i$ として作用します。それが仮想変位 $\delta u_i$ とともにする仕事は、表面上での積分 $\int_S t_i\,\delta u_i\,dS$ になります。
【ポイント】積分領域が『表面 $S$』であること、被積分項が『力×仮想変位』であることが表面力項の目印です。
【引っかけ】選択肢1は体積力(重力など体積 $V$ 上の積分)、選択肢2は内部仮想仕事(応力×仮想ひずみ)、選択肢4は慣性力の仮想仕事(動的項)です。積分が $dV$ か $dS$ か、掛かる相手が $\delta u$ か $\delta\varepsilon$ かで見分けます。
4-7 仮想仕事とガラーキン法の対応 難3・仮想仕事とガラーキン法・弱形式の導出
仮想仕事の原理とガラーキン法(重み付き残差法)の関係についての説明として、最も適切なものはどれか。
  1. 平衡方程式の残差に重み関数(=仮想変位)を掛けて領域積分し部分積分すると、内部仮想仕事の項(応力×仮想ひずみの体積積分)と表面力による境界項が現れ、仮想仕事の原理と一致する。
  2. 部分積分を行うと慣性項が消えるため、仮想仕事の原理は静的問題にしか使えない式に必ず変わってしまう。
  3. 重み関数を仮想変位に対応させると、力の境界条件をまったく考慮しなくてよい式になる。
  4. ガラーキン法は部分積分を行わずに、節点力の釣合い式を直接与える手法である。
正解 : 1
【基礎】仮想仕事の原理と重み付き残差法(ガラーキン法)は、出発点は違っても、FEMの弱形式としては同じ式にたどり着きます。
【考え方】平衡方程式の残差に重み関数を掛けて積分するのが残差法です。この重み関数を『仮想変位 $\delta u$』と読み替え、部分積分して微分の階数を1つ下げると、応力×仮想ひずみの体積積分(内部仮想仕事)と、表面力×仮想変位の境界積分(外部仮想仕事の表面項)が現れ、仮想仕事の式そのものになります。
【ポイント】部分積分の過程で力の境界条件(自然境界条件)が式の中に自然に現れるのであって、消えるわけでも無視されるわけでもありません。
【引っかけ】選択肢2は部分積分と静的/動的の別は無関係で、慣性項を含めたまま同様に弱形式化できます。選択肢3は境界条件が現れなくなるという誤りで、実際は力の境界条件が自然に組み込まれます。選択肢4はガラーキン法が部分積分を経ずに節点力釣合いを直接与えるとする誤りで、部分積分による弱形式化が本質的な過程です。
4-8 最小ポテンシャルエネルギー原理 難2・最小ポテンシャルエネルギーの原理
最小ポテンシャルエネルギーの原理を正しく述べているものはどれか。
  1. 真の変位はポテンシャルエネルギーを最大にする変位である。
  2. 全ポテンシャルエネルギーは、拘束条件を満たさない変位場も含めたすべての変位場で定義され、その中の平均値を与える変位が真の解である。
  3. 幾何学的に許容な(拘束条件を満たす)変位場のうち、真の平衡状態は全ポテンシャルエネルギーを最小(停留)にする。
  4. 全ポテンシャルエネルギーを停留にする変位場は、外力の作用点における変位を最大にする変位場と必ず一致する。
正解 : 3
【基礎】最小ポテンシャルエネルギーの原理は、変位を主役にした平衡条件の言い換えです。
【考え方】拘束条件(変位境界条件)を満たすあらゆる変位場を考え、それぞれについて全ポテンシャルエネルギー $\Pi=(ひずみエネルギー)-(外力のなす仕事)$ を計算すると、真の平衡状態のときに $\Pi$ が最小(数学的には停留)になります。FEMではこの原理から剛性方程式が導けます。
【ポイント】『許容変位場の中で最小』『停留=変分ゼロ』が核心です。安定な平衡では最小になります。
【引っかけ】選択肢1は最大としており逆(安定平衡は最小)。選択肢2は『拘束を満たさない場も含めて平均値』という誤りで、そもそも許容変位場(拘束条件を満たす場)の中だけで比較する原理です。選択肢4は、汎関数 $\Pi$ 全体の停留条件と、特定の1点の変位を最大化することは一般に一致しないため誤りです。
4-9 ポテンシャルと補エネルギーの双対性 難2・エネルギー原理の双対
全ポテンシャルエネルギーと補(余)エネルギーに関する説明として、最も適切なものはどれか。
  1. 全ポテンシャルエネルギーは変位を独立変数にとり最小(停留)にする原理、補エネルギーは応力(力)を独立変数にとり停留にする原理であって、互いに双対な関係にある。
  2. 全ポテンシャルエネルギーは応力を独立変数にとり、補エネルギーは変位を独立変数にとる。
  3. 補エネルギーは、変位境界条件がまったく存在しない自由な物体にしか定義できない特殊なエネルギーである。
  4. 補エネルギーは動的な問題(慣性力を含む場合)にのみ定義できる。
正解 : 1
【基礎】固体力学のエネルギー原理は、変位を主役にする流れ(ポテンシャルエネルギー)と、力・応力を主役にする流れ(補エネルギー)の2本立てになっています。
【考え方】全ポテンシャルエネルギー $\Pi$ は変位場を独立変数とし、これを最小にする変位が平衡解になります(最小ポテンシャルエネルギーの原理)。補エネルギー $\Pi^{*}$ は応力・力を独立変数とし、これを停留にする応力が適合解になります(最小補エネルギーの原理)。両者は独立変数(変位 vs 力)を入れ替えた双対(ペア)の関係です。
【ポイント】『変位を動かすのがポテンシャル、力を動かすのが補エネルギー』。FEMの変位法はポテンシャルエネルギー側に立脚します。
【引っかけ】選択肢2は独立変数を左右逆にした誤り。選択肢3は補エネルギーが変位境界条件のある系にも定義できるため誤り。選択肢4は静的問題でも定義できるため誤りです。
4-10 変位法と応力法の使い分け 難2・変位法・応力法
構造解析における変位法(剛性法)と応力法(たわみ度法・力法)の説明として、最も適切なものはどれか。
  1. 変位法は応力を未知数にとって解く方法である。
  2. 応力法は、静定・不静定を問わず同じ手間で機械的に適用でき、汎用FEMソフトの標準になっている。
  3. 変位法は節点変位を未知数にとり、応力法は力(応力、不静定力)を未知数にとる。自由度の管理がしやすいため、汎用FEMソフトの主流は変位法である。
  4. 変位法は静定構造にしか適用できず、不静定構造には応力法しか使えない。
正解 : 3
【基礎】構造解析の定式化には、何を『まず求める未知数』にするかで2つの立場があります。
【考え方】変位法(剛性法)は節点変位を未知数にとり、$[K]\{d\}=\{f\}$ を解いてから応力を計算します。応力法(力法)は不静定力(応力)を未知数にとりますが、不静定次数が増えるほど選び方の手間や場合分けが急増し、機械的なプログラム化が難しくなります。このため市販の汎用FEMはほぼすべて変位法を採用しています。
【ポイント】『変位法=変位が未知数、応力法=力が未知数、FEM主流は変位法(プログラム化しやすいため)』とセットで覚えます。
【引っかけ】選択肢1は未知数を取り違えた誤り。選択肢2は応力法が汎用FEMの標準としていますが、実際は不静定次数が増えると手間が急増するため主流ではありません。選択肢4は変位法が不静定構造でも使える(むしろ得意)ため誤りです。
4-11 2次元のひずみエネルギー密度 難2・ひずみエネルギー密度
2次元弾性体において、単位体積あたりに蓄えられるひずみエネルギー(ひずみエネルギー密度 $U_0$)を正しく表す式はどれか。ここで $\sigma_x,\sigma_y$ は垂直応力、$\tau_{xy}$ はせん断応力、$\varepsilon_x,\varepsilon_y$ は垂直ひずみ、$\gamma_{xy}$ は工学せん断ひずみである。
  1. $U_0=\sigma_x\varepsilon_x+\sigma_y\varepsilon_y+\tau_{xy}\gamma_{xy}$
  2. $U_0=\dfrac{1}{2}\left(\sigma_x\varepsilon_y+\sigma_y\varepsilon_x\right)$
  3. $U_0=\dfrac{1}{2}\left(\sigma_x\varepsilon_x+\sigma_y\varepsilon_y+\tau_{xy}\gamma_{xy}\right)$
  4. $U_0=\dfrac{1}{2}\left(\sigma_x^{2}+\sigma_y^{2}\right)$
正解 : 3
【基礎】線形弾性体のひずみエネルギー密度は、応力とひずみの積の総和の半分、すなわち $U_0=\tfrac{1}{2}\{\sigma\}^{T}\{\varepsilon\}$ で与えられます。
【考え方】各成分は『同じ向きの応力とひずみ』を掛け合わせます。垂直応力 $\sigma_x$ には垂直ひずみ $\varepsilon_x$、せん断応力 $\tau_{xy}$ には工学せん断ひずみ $\gamma_{xy}$ を対応させ、それらを足して $\tfrac{1}{2}$ を掛けます。
【計算】展開すると $U_0=\tfrac{1}{2}(\sigma_x\varepsilon_x+\sigma_y\varepsilon_y+\tau_{xy}\gamma_{xy})$。三角形の面積(力×変位×1/2)と同じく、線形だから係数 $1/2$ が付くと理解するとよいです。
【ポイント】『係数1/2』『同じ向き同士の積』『せん断は τ と γ の組』の3点が正しさの決め手です。

4-28 非ゼロ変位境界条件の課し方 難3・変位境界条件と荷重ベクトル

  1. 荷重ベクトル $\{f\}$ をすべてゼロにしてから解けばよい。
  2. 既知の変位に対応する自由度を未知数から外し、その寄与($[K]$ の該当列と既知変位の積)を移項して荷重ベクトル側に組み込んだ上で、残った未知自由度について解く。
  3. 剛性マトリックス $[K]$ を転置してから解けばよい。
  4. 境界条件は連立方程式を解いた後に、得られた変位の値を境界の値で上書きするだけでよく、方程式そのものへ反映する必要はない。
正解 : 2

【考え方】既知変位(たとえば支点で $d=\delta\neq0$)の自由度は未知数から外します。このとき、その既知変位が他の未知自由度の式に与える影響($[K]$ のその列と既知変位 $\delta$ の積)を右辺(荷重ベクトル)側へ移項して組み込む必要があります。単に0を上書きするだけでは、非ゼロの強制変位が他の節点の変位・応力に及ぼす影響が方程式に反映されません。
【ポイント】境界条件は『解く前に、方程式そのものへ』組み込む必要があり、これで初めて $[K]$ が正則になり、非ゼロ変位の影響も正しく解に反映されます。

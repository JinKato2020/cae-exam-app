第6章 数値計算法の基礎

CAE計算力学技術者 固体力学2級・オリジナル問題（問題／解答／解説／図）
6-1 直接法と反復法 難1・解法の分類
連立一次方程式 $[K]\{u\}=\{f\}$ を解く数値解法は、大きく「直接法」と「反復法」に分けられる。この分類として最も適切なものはどれか。
  1. 直接法はガウス消去法やLU分解のように有限回の演算で(丸め誤差を除けば)厳密解を得る方法で、反復法はヤコビ法や共役勾配法のように近似解を反復更新して収束させる方法である。
  2. 直接法は初期値を与えて残差が許容値以下になるまで解を更新していく方法で、反復法はガウス消去法のように一度の演算だけで厳密解を得る方法である。
  3. 直接法も反復法も、残差が許容値以下になったら打ち切るという同じ収束判定基準で終了する点で共通しており、両者の違いは扱う行列が疎か密かだけである。
  4. 直接法は密行列・疎行列を問わず反復法よりメモリ使用量が少なく済む方法で、大規模な疎行列を使う有限要素解析でも標準的に用いられる。
正解 : 1
【基礎】連立一次方程式の数値解法は、有限回の演算で解ききる「直接法」と、近似解を繰り返し改良する「反復法」に大別されます。
【考え方】直接法(ガウス消去法・LU分解・コレスキー分解など)は決まった手順を有限回行えば、丸め誤差を除いて厳密解が得られます。反復法(ヤコビ法・ガウスザイデル法・SOR法・共役勾配法など)は、初期値から出発し残差が十分小さくなるまで解を更新します。
【ポイント】終了の仕方そのものが本質的に異なります(直接法=手順が終われば終わり/反復法=収束判定が必要)。大規模疎行列では反復法のほうが記憶量・計算量とも有利になりやすいです。
【引っかけ】選択肢2は直接法と反復法の定義を入れ替えた誤り。選択肢3は「収束判定で終わる」という反復法特有の性質を直接法にも当てはめた誤り(直接法は手順が有限回で確定しており収束判定を必要としません)。選択肢4は大規模疎行列で有利なのはむしろ反復法である場合が多く、逆の主張になっています。
6-2 ガウス消去法の手順 難1・ガウス消去法
連立一次方程式をガウス消去法で解く手順の説明として、正しいものはどれか。
  1. 後退代入で係数行列を上三角に変形してから、前進消去で最下段の未知数から順に上へ向かって未知数を求める。
  2. 前進消去を用いて対角より上下とも成分を消していき、最後に対角成分で割ることで全未知数を一度に得る。
  3. 前進消去で係数行列を上三角行列に変形し、続く後退代入で最下段の未知数から順に上へ向かって未知数を求める。
  4. 前進消去で得られた係数から逆行列を陽に構成し、それを右辺ベクトルに掛けることで解を得る。
正解 : 3
【基礎】ガウス消去法は「前進消去」と「後退代入」の2段階からなる直接法です。
【考え方】前進消去は各列のピボットを使ってその下の成分を上から順にゼロにし、係数行列を上三角行列に変形します。後退代入は最下段の式(未知数1個)から解いて順に1つ上へ代入していきます。
【ポイント】『前進消去=上三角化』『後退代入=下から上へ解く』の順序と向きが要点です。逆行列を陽に作る必要はなく、その方が計算量も多くなります。
【引っかけ】選択肢1は前進と後退の役割・順序を逆にした誤り。選択肢2は対角化まで行うガウス・ジョルダン法と混同した誤り(消去だけで全未知数が一度に求まるわけではありません)。選択肢4は逆行列を必ず作るとする誤りで、消去法は逆行列を陽に作らずに解けるのが利点です。
6-3 前進消去の計算 難2・ガウス消去法
行列 $[A]=\begin{bmatrix}2&4&-2\\4&9&-3\\-2&-3&7\end{bmatrix}$ にガウスの前進消去を行い、上三角行列に変形する。第1列・第2列の消去をすべて終えたとき、右下の成分(第3行3列)の値はいくらか。
  1. $1$
  2. $4$
  3. $7$
  4. $11$
正解 : 2
【基礎】前進消去では、各列の下側成分を『行の引き算』でゼロにします。引く倍率(乗数)は「消したい成分÷その列のピボット」です。
【考え方】まず第1列を消し、続いて更新後の第2列を消してから、第3行3列を読み取ります。
【計算】第1列(ピボット $2$): 第2行の乗数 $=4/2=2$。第2行$-2\times$第1行 $=(0,\,9-8,\,-3+4)=(0,1,1)$。第3行の乗数 $=-2/2=-1$。第3行$-(-1)\times$第1行 $=(0,\,-3+4,\,7-2)=(0,1,5)$。
次に第2列(ピボット $1$): 第3行の乗数 $=1/1=1$。第3行$-1\times$第2行 $=(0,0,\,5-1)=(0,0,4)$。よって第3行3列は $4$。
【ポイント】乗数の分母は必ず『いま使っている行のピボット』です。更新後の値を使って次の列を消すのを忘れないこと。
【引っかけ】選択肢1は第2列消去を忘れて中間値をそのまま読んだ誤り。選択肢3は消去前の元の値 $7$ をそのまま答えた誤り。選択肢4は乗数の符号を取り違え、引くべきところを足してしまった誤りです。
6-4 後退代入の計算(3元) 難3・ガウス消去法
前進消去の結果、次の上三角の連立方程式が得られた。後退代入で $x_1,\ x_2,\ x_3$ をすべて求めよ。 $x_1+2x_2-x_3=-3,\quad 3x_2+x_3=0,\quad 2x_3=6$
  1. $x_1=2,\ x_2=-1,\ x_3=3$
  2. $x_1=7,\ x_2=-2,\ x_3=6$
  3. $x_1=1,\ x_2=-1,\ x_3=3$
  4. $x_1=-4,\ x_2=-1,\ x_3=3$
正解 : 1
【基礎】後退代入は、未知数が1個だけの最下段の式から解き、得た値を上の式に順に代入していきます。
【考え方】$x_3\to x_2\to x_1$ の順に、下から上へ解きます。
【計算】$2x_3=6\Rightarrow x_3=3$。次に $3x_2+x_3=0\Rightarrow 3x_2=-3\Rightarrow x_2=-1$。最後に $x_1+2x_2-x_3=-3\Rightarrow x_1=-3-2x_2+x_3=-3-2(-1)+3=-3+2+3=2$。よって $x_1=2,\ x_2=-1,\ x_3=3$。
【ポイント】最上段の式は未知数3個をすべて含むため、必ず $x_2,x_3$ を先に確定させてから代入します。移項時の符号(特に $-x_3$)を丁寧に扱うこと。
【引っかけ】選択肢2は最下段の式で $2$ で割るのを忘れ $x_3=6$ のまま伝播させた誤り($x_2=(0-6)/3=-2$、$x_1=-3-2(-2)+6=7$)。選択肢3は最上段の $x_2$ の係数 $2$ を掛け忘れた誤り($x_1=-3-(-1)+3=1$)。選択肢4は最上段の $-x_3$ の符号を $+x_3$ と取り違えた誤り($x_1=-3-2(-1)-3=-4$)です。
6-5 LU分解の意味 難1・LU分解
係数行列 $[A]$ の LU 分解に関する説明として、正しいものはどれか。
  1. $[A]$ を対角行列 $[D]$ と単位下三角・単位上三角行列の積 $[A]=[D][I]$ に分け、対角成分をそのまま解として使う操作である。
  2. $[A]$ を下三角行列 $[L]$ と上三角行列 $[U]$ の積 $[A]=[L][U]$ に分解する操作で、いったん分解すれば右辺が変わっても前進・後退代入だけで解ける。
  3. $[A]$ を直交行列 $[Q]$ と上三角行列 $[R]$ の積 $[A]=[Q][R]$ に分解し、固有値をそのまま対角成分から読み取る操作である。
  4. LU分解は反復法の前処理としてのみ用いられる手法で、分解した $[L],[U]$ だけでは連立方程式を解くことができない。
正解 : 2
【基礎】LU分解は、係数行列 $[A]$ を下三角行列 $[L]$ と上三角行列 $[U]$ の積で表す直接法です。
【考え方】$[A]=[L][U]$ と分解できれば、$[A]\{x\}=\{b\}$ は $[L]\{y\}=\{b\}$(前進代入)と $[U]\{x\}=\{y\}$(後退代入)の2段階に分けて解けます。分解自体の手間はガウス消去と同程度ですが、いちど $[L][U]$ を作れば、右辺 $\{b\}$ が何通りあっても代入だけで解けるのが最大の利点です。
【ポイント】『下三角×上三角』『右辺の使い回しに強い』が要点。構造解析で荷重ケースを多数解くときに有効です。
【引っかけ】選択肢1は対角行列への分解(対角化)と混同した誤り。選択肢3は直交行列への分解(QR分解、固有値分解と混同)であってLU分解ではありません。選択肢4はLU分解自体で連立方程式が解ける(前進・後退代入だけでよい)ことを見落とした誤りです。
6-6 LU分解の計算 難3・LU分解
行列 $[A]=\begin{bmatrix}1&2&1\\3&8&6\\2&2&3\end{bmatrix}$ を、対角成分がすべて $1$ の下三角行列 $[L]$ と上三角行列 $[U]$ の積に分解する(ドゥーリトル法)。このとき $[L]$ の第3行2列成分 $l_{32}$ はいくらか。
  1. $l_{32}=2$
  2. $l_{32}=1$
  3. $l_{32}=-1$
  4. $l_{32}=-3$
正解 : 3
【基礎】ドゥーリトル法では、$[L]$ の対角を $1$ に固定し、$[U]$ の行と $[L]$ の列を上・左から順に決めていきます。
【考え方】まず1行目・1列目、次に2行目・2列目…と進め、$l_{32}$ を求めます。
【計算】1行目: $u_{11}=1,\ u_{12}=2,\ u_{13}=1$。1列目: $l_{21}=3/1=3,\ l_{31}=2/1=2$。
2行目: $u_{22}=8-l_{21}u_{12}=8-3\cdot2=2,\ u_{23}=6-3\cdot1=3$。
$l_{32}=\dfrac{a_{32}-l_{31}u_{12}}{u_{22}}=\dfrac{2-2\cdot2}{2}=\dfrac{-2}{2}=-1$。よって $l_{32}=-1$。
【ポイント】$l_{32}$ の分子では『すでに求めた $l_{31}u_{12}$』を必ず引き、分母は $u_{22}$ です。$u_{33}=3-(l_{31}u_{13}+l_{32}u_{23})=3-(2-3)=4$ と続きます。
【引っかけ】選択肢1は $a_{32}=2$ をそのまま答えた誤り。選択肢2は $l_{31}u_{12}$ の引き算を忘れた誤り。選択肢4は $l_{21}$ の値 $3$ と取り違え、符号もそろえた誤りです。
6-7 部分ピボット選択 難2・ピボッティング
ガウス消去法における「部分ピボット選択(部分ピボッティング)」の目的として、最も適切なものはどれか。
  1. 各列で絶対値が最大の成分をピボットに来るよう行を入れ替え、微小なピボットで割ることによる桁落ち・丸め誤差の増大を防ぐための操作である。
  2. 各列の消去を早く終えるために、ピボット以下の成分をまとめて $0$ とみなして省略する近似操作である。
  3. 係数行列を対称行列に変換し、コレスキー分解が使えるように整えるための下準備の操作である。
  4. 行を入れ替えることで連立方程式の解の自由度を増やし、複数の解を同時に得るための操作である。
正解 : 1
【基礎】前進消去では乗数を『消す成分÷ピボット』で作るため、ピボットが極端に小さいと乗数が巨大になり、丸め誤差が拡大します。
【考え方】部分ピボット選択は、各段でその列の(対角より下を含む)絶対値最大の成分を選び、その行を対角位置に持ってきてからピボットにします。これにより乗数の絶対値が $1$ 以下に抑えられ、数値的に安定します。
【ポイント】目的は『安定化(丸め誤差の抑制)』であって、消去自体を省略したり解を増やしたりする操作ではありません。行の入れ替えは解を変えません。
【引っかけ】選択肢2はピボット以下を省略する近似だとする誤り(実際はすべて正しく消去し、行の順番だけを変えます)。選択肢3は対称化とは無関係。選択肢4は行入れ替えで解の個数が増えるという誤りで、入れ替えは同じ解を与えます。
6-8 直接法の計算量 難2・演算量
$n$ 元の密な連立一次方程式をガウス消去法(またはLU分解)で解くとき、乗除算の回数はおよそ $\dfrac{n^3}{3}$ に比例する。未知数の数 $n$ を 2 倍にすると、演算量はおよそ何倍になるか。
  1. 約2倍
  2. 約3倍
  3. 約4倍
  4. 約8倍
正解 : 4
【基礎】密行列に対する直接法の演算量は、最高次の項が $n^3$ に比例します(前進消去が支配的)。
【考え方】演算量 $\propto n^3$ なので、$n\to 2n$ とすると比は $\dfrac{(2n)^3}{n^3}=2^3$ になります。
【計算】$2^3=8$。よって約8倍です。
【ポイント】未知数が2倍で計算量は8倍。大規模問題で直接法が急に重くなる理由がこれで、疎性を活かすバンド法・スカイライン法や反復法が重要になります。
【引っかけ】選択肢1は $n$ に比例($2^1$)と誤ったもの。選択肢2は指数 $3$ をそのまま倍率と勘違いした誤り。選択肢3は $n^2$ に比例($2^2=4$)と誤ったものです。指数は『掛かる回数』であって倍率そのものではありません。
6-9 帯行列とスカイライン法の記憶方式 難2・帯行列・スカイライン法
有限要素法の剛性マトリックス $[K]$ の記憶方式に関する説明として、正しいものはどれか。半バンド幅を $b$、未知数の数を $n$ とする一定バンド幅法と、列ごとに可変長で記憶するスカイライン法を比較して考えよ。
  1. バンド幅は要素分割だけで決まる量で、節点番号の付け方には依存せず、スカイライン法は一定バンド幅法より記憶量が多くなりがちな方式である。
  2. 一定バンド幅法の記憶量はおよそ $n(b+1)$ に比例し、$b$ は結合する節点の番号差で決まる。スカイライン法は列ごとに最上位の非零成分から対角までを可変長で記憶し、一定バンド幅法よりさらに無駄な $0$ の記憶を減らせる。
  3. スカイライン法はすべての列を最大バンド幅にそろえて記憶する方式で、逆に一定バンド幅法のほうが列ごとに可変長で記憶量を切り詰められる方式である。
  4. 節点番号を、同じ要素に属さない離れた節点どうしを結ぶように付け直すと、バンド幅が狭まり記憶量・計算量とも削減できる。
正解 : 2
【基礎】剛性マトリックスは疎で、非零成分が対角の周りに帯状に集まります。この帯の幅がバンド幅であり、列ごとの非零開始位置の高さが『スカイライン』です。
【考え方】半バンド幅 $b$ が分かれば帯の内側だけを配列に詰めて記憶でき、必要量はおよそ $n(b+1)$ です。$b$ は互いに結合する節点(同じ要素に属する節点)の番号差の最大で決まるため、番号の付け方に強く依存します。スカイライン法は各列で『一番上の非零成分から対角まで』を可変長で記憶し、一定バンド幅法が帯の中に抱える無駄な $0$ をさらに削ります。
【ポイント】『バンド幅は番号付けで変わる』『スカイライン=列ごとに可変長でさらに節約』が要点。番号最適化(バンド幅低減)は前処理として重要です。
【引っかけ】選択肢1は番号付けと無関係に一定という誤りと、スカイライン法のほうが記憶量が多いという逆の誤りを含みます。選択肢3は一定バンド幅法とスカイライン法の特徴を入れ替えた誤り。選択肢4は離れた節点を結ぶとバンド幅がむしろ広がるのが実際で、狭めたいなら近い番号の節点どうしを結ぶ必要があり、逆の主張になっています。
6-10 疎行列の格納 難2・疎行列
大規模な有限要素解析で現れる疎行列(要素のほとんどが $0$)の記憶方法に関する説明として、正しいものはどれか。
  1. 疎行列は将来的に非零成分の位置が増える可能性があるので、あらかじめ $n^2$ 全成分を配列に確保しておくのが最も安全で効率的な格納方法である。
  2. 疎行列は非零成分の位置が要素分割ごとに不規則に変わるため、あらかじめ決まった圧縮格納の方式を作ることはできず、演算のたびに全成分を走査するほかない。
  3. 疎行列を行・列の添字ではなく通常の2次元配列(密行列と同じ形式)で記憶すると、非零成分だけを記憶する圧縮形式よりも結果的にメモリを節約できる。
  4. 非零成分の値と、その行・列の位置情報(添字)だけを組にして記憶すれば、$0$ を保持せずに大幅にメモリを節約でき、非零成分だけを使う演算も可能になる。
正解 : 4
【基礎】有限要素法の剛性マトリックスは、1つの節点が結合する相手が限られるため、ほとんどの成分が $0$ の疎行列になります。
【考え方】$0$ を律儀に記憶するのは無駄なので、非零成分の値とその位置(行・列の添字)だけを対応表として持ちます(CRS/CCSなどの圧縮格納)。こうすれば $n$ が大きくても記憶量は非零成分の数にほぼ比例し、消去や行列ベクトル積も非零成分だけで実行できます。
【ポイント】『値+位置(添字)だけを持つ』のが疎行列格納の核心。反復法の行列ベクトル積と特に相性が良いです。
【引っかけ】選択肢1は全 $n^2$ 記憶が最も効率的という誤り(非零成分の数に比例する記憶で十分です)。選択肢2は圧縮格納の方式が存在しないという誤り(CRS/CCSなど確立した方式があります)。選択肢3は密記憶のほうが省メモリという逆の誤りです。
6-11 対称正定値とコレスキー 難2・対称正定値・コレスキー分解
有限要素法の剛性マトリックスの多くは対称正定値(すべての固有値が正)である。この性質とコレスキー分解に関する説明として、正しいものはどれか。
  1. 対称正定値であっても、対角成分がすべて等しくなるように事前にスケーリングしておかないと、消去の途中でピボットが $0$ に近づきやすく数値的に不安定になる。
  2. コレスキー分解は非対称行列に対して、対称化の前処理をせずに直接 $[A]=[L][L]^{T}$ の形へ分解できる汎用的な手法である。
  3. 対称正定値行列は $[A]=[L][L]^{T}$(下三角×その転置)の形に分解でき、ピボット選択なしで安定に解け、一般のLU分解よりおよそ半分の演算量・記憶量で済む。

【考え方】SPD行列は $[A]=[L][L]^{T}$ と分解できます(コレスキー分解)。対称性を利用して下三角 $[L]$ だけを求めればよく、ピボット選択なしで数値的に安定、演算量・記憶量とも一般のLU分解のおよそ半分で済みます。
【ポイント】『対称正定値→コレスキー→半分の手間・ピボット不要』が要点。反復法の共役勾配法もSPDを前提にします。
【引っかけ】選択肢1はSPDならピボットなしで安定という事実に反し、事前スケーリングを必須とする誤り。選択肢2はコレスキー分解を非対称行列向けとする誤り(むしろ対称正定値専用です)。選択肢4はSPDの定義(固有値がすべて正)に反し、直接法でも安定に解けます。
6-12 反復法の性質 難2・反復法

  1. 反復法は係数行列が対角優位でなくても、反復回数を増やしていけば収束に近づいていく性質を持つため、収束判定を省略しても実用上は問題にならない。

  4. 反復法は行列ベクトル積を繰り返すため、係数行列をあらかじめ密行列として保持しておく必要があり、疎行列の圧縮格納とは相性が悪い手法である。
正解 : 2
【基礎】反復法は、近似解を繰り返し更新して真の解に近づける方法です。
【考え方】三角分解(LU)を作らず、各反復では主に『行列×ベクトル』と『ベクトルの足し引き・内積』を行うだけなので、1反復は軽く、疎行列の非零成分だけを使えます。うまく収束すれば、大規模疎行列では直接法より総演算量・記憶量を小さくできることがあります。
【ポイント】『分解不要・1反復が軽い・疎行列向き』が長所。ただし収束は行列の性質に依存し、収束判定(残差が小さいか)が必須です。
【引っかけ】選択肢1は『収束判定は省略できる』が誤り(対角優位でない一般の行列では収束自体が保証されず、判定を怠ると発散に気づけません)。選択肢3は『反復回数が少なく総演算量でも有利』という一般化が誤り(問題によっては直接法のほうが有利です)。選択肢4は疎行列に使えないとする誤りで、むしろ疎行列で威力を発揮します。
6-13 ヤコビ法の1反復 難3・ヤコビ法

  2. $x_2^{(1)}=0.75$
  3. $x_2^{(1)}=0.5$
  4. $x_2^{(1)}=1.0$
正解 : 3
【基礎】ヤコビ法は各式を対角の未知数について解き、右辺には『すべて1つ前の反復の値』を代入して同時に更新します。
【考え方】$x_2$ の更新式は $x_2^{(1)}=\dfrac{2+x_1^{(0)}+x_3^{(0)}}{4}$。ヤコビ法では右辺は必ず前ステップ値 $x_1^{(0)},x_3^{(0)}$ を使います。
【計算】$x_2^{(1)}=\dfrac{2+0+0}{4}=\dfrac{2}{4}=0.5$。
【ポイント】ヤコビ法の要点は『右辺は全部“前の”値』。この回では他成分も $x_1^{(1)}=3/4=0.75,\ x_3^{(1)}=3/4=0.75$ と、すべて古い値から計算します。
【引っかけ】選択肢1($0.6875$)は先に更新した $x_1^{(1)}=0.75$ を右辺に使うガウスザイデル法の値で、ヤコビ法では誤り。選択肢2($0.75$)は $x_1,x_3$ の値と取り違えたもの。選択肢4は分母 $4$ で割り忘れた誤りです。
6-14 ガウスザイデル法の1反復 難3・ガウスザイデル法
連立方程式 $\begin{cases}4x_1+x_2=6\\2x_1+5x_2=12\end{cases}$ をガウスザイデル法で解く。初期値 $x_1^{(0)}=x_2^{(0)}=0$ から始め、$x_1\to x_2$ の順に更新するとき、1回目の反復で得られる $x_2^{(1)}$ はいくらか。

  2. $x_2^{(1)}=2.4$
  3. $x_2^{(1)}=1.5$
  4. $x_2^{(1)}=2.0$
正解 : 1
【基礎】ガウスザイデル法は、同じ反復の中で先に求めた最新値を、後の式の右辺にすぐ使います。
【考え方】まず $x_1^{(1)}=\dfrac{6-x_2^{(0)}}{4}$ を求め、その最新の $x_1^{(1)}$ を $x_2$ の式にすぐ代入します。
【計算】$x_1^{(1)}=\dfrac{6-0}{4}=1.5$。次に $x_2^{(1)}=\dfrac{12-2x_1^{(1)}}{5}=\dfrac{12-2\cdot1.5}{5}=\dfrac{12-3}{5}=\dfrac{9}{5}=1.8$。
【ポイント】ガウスザイデル法の要点は『最新値をすぐ使う』こと。ヤコビ法より一般に速く収束します。
【引っかけ】選択肢2($2.4=12/5$)は、$x_1$ をまだ更新せず $x_1^{(0)}=0$ を使うヤコビ法の値で誤り。選択肢3($1.5$)は $x_1^{(1)}$ の値と取り違えたもの。選択肢4は途中の割り算を丸めた誤りです。
6-15 ヤコビ法とガウスザイデル法 難2・反復法の比較
ヤコビ法とガウスザイデル法の違いに関する説明として、正しいものはどれか。
  1. ヤコビ法は同じ反復内で更新済みの最新値をただちに使い、ガウスザイデル法はすべて前ステップの値だけを使う。
  2. ヤコビ法もガウスザイデル法も反復のたびに係数行列の三角分解をやり直す点で共通しており、違いは更新量に緩和係数を掛けるかどうかだけである。
  3. ガウスザイデル法は前ステップの値だけを使って各成分を更新するため、成分どうしの更新が互いに独立になり並列計算に極めて向いている。
  4. ヤコビ法は右辺にすべて前ステップの値を使い、ガウスザイデル法は同じ反復内で先に求めた最新値をただちに使うため、一般にガウスザイデル法の方が収束が速い。
正解 : 4
【基礎】どちらも各式を対角未知数について解いて更新する反復法ですが、右辺に使う値のタイミングが違います。
【考え方】ヤコビ法は1反復の間、右辺にすべて『前ステップの値』を使い、まとめて更新します。ガウスザイデル法は、同じ反復の中で先に更新した成分の『最新値』を後の式にすぐ使います。最新情報を早く反映する分、一般にガウスザイデル法の方が収束が速くなります。
【ポイント】『ヤコビ=全部旧値・並列向き』『GS=最新値を即利用・収束が速い傾向』と対で覚えます。
【引っかけ】選択肢1はヤコビ法とガウスザイデル法の定義を入れ替えた誤り。選択肢2はLU分解やSOR法と混同した誤り(両者とも三角分解は行いません)。選択肢3は『前ステップの値だけを使い並列向き』なのはヤコビ法の特徴であり、ガウスザイデル法と取り違えています。
6-16 SOR法と緩和係数 難2・SOR法
SOR法(逐次過緩和法)と緩和係数 $\omega$ に関する説明として、正しいものはどれか。
  1. SOR法は緩和係数 $\omega$ をガウスザイデル法の収束が遅いときにだけ $0$ 未満の値にとり、更新量を反転させることで収束を速める方法である。
  2. SOR法はガウスザイデル法の更新量に緩和係数 $\omega$ を掛けて補正する方法で、収束のためには $0<\omega<2$ が必要、$\omega>1$(過緩和)で収束を加速でき、$\omega=1$ でガウスザイデル法に一致する。
  3. 緩和係数 $\omega$ は $2$ 以上にとるほど1回あたりの更新量が大きくなるため、反復回数を減らして収束を速めることができる。
  4. SOR法はガウスザイデル法に緩和係数を掛ける分、1反復あたりの計算コストが増えるため、同じ反復回数で比べるとガウスザイデル法より収束が遅くなりやすい手法である。
正解 : 2
【基礎】SOR法は、ガウスザイデル法の1回の更新量を緩和係数 $\omega$ で拡大・縮小して収束を調整する反復法です。
【考え方】更新式は $x_i^{(new)}=(1-\omega)x_i^{(old)}+\omega\, x_i^{GS}$ の形で、$\omega=1$ でちょうどガウスザイデル法になります。収束のためには $0<\omega<2$ が必要で、$1<\omega<2$(過緩和)にすると多くの問題で収束を加速できます。最適な $\omega$ は問題ごとに異なります。
【ポイント】『$0<\omega<2$ で収束』『$\omega=1$ でGS』『適切な過緩和で加速』が要点です。
【引っかけ】選択肢1は $\omega$ を負にとるという誤り(収束のためには正の範囲 $0<\omega<2$ が必要です)。選択肢3は $\omega\ge2$ では発散するにもかかわらず『大きいほど速い』とした誤り。選択肢4は『必ず遅くなる』に近い誤りで、適切な $\omega$ ならガウスザイデル法より明らかに速く収束します。
6-17 SOR法の最適緩和係数 難3・SOR法
ヤコビ法の反復行列のスペクトル半径が $\rho_J=0.8$ であるとき、SOR法の収束を最も速める最適な緩和係数は、$\omega_{opt}=\dfrac{2}{1+\sqrt{1-\rho_J^{2}}}$(対称でコンシステントな順序を持つ行列に対する見積もり公式)で与えられる。この $\omega_{opt}$ の値はいくらか。

  2. $\omega_{opt}=0.8$
  3. $\omega_{opt}=1.11$
  4. $\omega_{opt}=1.25$
正解 : 4
【基礎】SOR法の収束の速さは緩和係数 $\omega$ に強く依存し、対称でコンシステントな順序を持つ行列では、ヤコビ法の反復行列のスペクトル半径 $\rho_J$ から最適な $\omega$ を見積もる公式 $\omega_{opt}=\dfrac{2}{1+\sqrt{1-\rho_J^{2}}}$ が知られています。
【考え方】$\rho_J=0.8$ を公式に代入します。まず $\rho_J^{2}$、次に $1-\rho_J^2$ の平方根を計算してから分母を作ります。

【引っかけ】選択肢1($1.47$)は平方根を取らずに $\dfrac{2}{2-\rho_J^{2}}$ と誤って計算したもの。選択肢2($0.8$)はスペクトル半径 $\rho_J$ そのものを最適 $\omega$ と取り違えたもの。選択肢3($1.11$)は平方根の中の $1-\rho_J^2$ を計算せず $\dfrac{2}{1+\rho_J}$ とした誤りです。
6-18 反復法の収束条件 難2・収束条件

  2. 係数行列の固有値がすべて実数であることが、反復法の収束を保証する条件として広く用いられている。

  4. 係数行列の行列式の絶対値が $1$ より大きいことが、ヤコビ法・ガウスザイデル法の収束を保証する条件として知られている。

【考え方】代表的な十分条件が『(狭義)対角優位』です。各行で $|a_{ii}| > \sum_{j\ne i}|a_{ij}|$ が成り立てば、ヤコビ法・ガウスザイデル法は収束します。対称正定値であることも(ガウスザイデル法・SOR法の)収束を保証する別の十分条件であり、対角優位と並ぶ代表例です。
【ポイント】『対角が大きいほど収束しやすい』が直感。剛性マトリックスは物理的に対角優位・対称正定値になりやすく、反復法と相性が良いです。
【引っかけ】選択肢1は対称正定値を『唯一の』十分条件としている点が誤り(対角優位も独立した十分条件であり、唯一ではありません)。選択肢2の固有値が実数というだけでは収束は保証されません。選択肢4の行列式の絶対値の大小は収束条件と直接結びつきません。
6-19 スペクトル半径と収束 難3・スペクトル半径

  2. $\rho(M)=1$ で、境界上なので収束しない。
  3. $\rho(M)=0.25$ で、$\rho<1$ だから収束する。

【考え方】$[M]=\begin{bmatrix}0&-1/2\\-1/2&0\end{bmatrix}$ の固有値は、特性方程式 $\lambda^2-\left(\tfrac{1}{2}\right)^2=0$ より $\lambda=\pm\tfrac{1}{2}$。

6-20 共役勾配法の性質 難2・共役勾配法(CG)
共役勾配法(CG法)に関する説明として、正しいものはどれか。
  1. 共役勾配法は非対称・不定な行列に対して最も安定に収束する手法であり、対称正定値行列には残差が振動してしまうため使用できない。
  2. 共役勾配法は反復のたびに係数行列を下三角×上三角に分解し直し、その分解結果を使って探索方向を求める手法である。
  3. 共役勾配法は探索方向を毎回ランダムに選び直す確率的な手法で、反復回数は問題の規模 $n$ に依存せず一定回数で厳密解に到達する。
  4. 共役勾配法は対称正定値行列を対象とし、丸め誤差がなければ理論上は $n$ 元の問題を高々 $n$ 回の反復で厳密解に到達でき、前処理(ICCGなど)と組み合わせて収束を速められる。
正解 : 4
【基礎】共役勾配法(CG)は、対称正定値行列に対する代表的な反復法で、探索方向を互いに共役にとって効率よく解に近づきます。
【考え方】理論上(丸め誤差なし)は、$n$ 元の問題を高々 $n$ 回の反復で厳密解に到達します。実際には丸め誤差があるため反復法として扱い、収束を速めるために前処理を施します。不完全コレスキー分解を前処理に用いたものがICCG法です。
【ポイント】『対称正定値向け・高々 $n$ 回・前処理で加速(ICCG)』が要点。大規模疎行列で広く使われます。
【引っかけ】選択肢1は対象を逆にした誤り(CGは対称正定値向けで、非対称・不定行列にはそのままでは使えません)。選択肢2は毎回三角分解が要るとする誤りで、行列ベクトル積が主体です。選択肢3は『ランダム・一定回数』が誤りで、探索方向は共役性を保つよう決定的に選ばれ、収束は問題の条件数などに依存します。
6-21 前処理・条件数と誤差増幅 難3・前処理・条件数
反復法における前処理(プリコンディショニング)と条件数に関する説明として、正しいものはどれか。ある連立一次方程式の係数行列の条件数が $\kappa=100$、右辺ベクトルの相対誤差が $0.1\%$($=0.001$)であるとき、解の相対誤差の上限の目安は $\dfrac{\|\Delta x\|}{\|x\|}\lesssim \kappa\cdot\dfrac{\|\Delta b\|}{\|b\|}$ で見積もる。
  1. 前処理は係数行列を単位行列に近づけて条件数を小さくし反復法の収束を速める操作で、ICCG法は不完全コレスキー分解を用いる。この例では解の相対誤差の上限はおよそ $\kappa\times0.1\%=100\times0.001=10\%$ と見積もられる。
  2. 前処理は係数行列の対角成分だけを $1$ にそろえる操作で、ICCG法は不完全LU分解を用いる。この例では入力誤差がそのまま解に伝わるだけなので、解の相対誤差もおよそ $0.1\%$ にとどまると見積もられる。
  3. 前処理は条件数を小さくして固有値をそろえる操作で、ICCG法は不完全コレスキー分解を用いる。この例では誤差増幅の目安は条件数の平方根 $\sqrt{\kappa}=10$ 倍になるため、解の相対誤差はおよそ $10\times0.1\%=1\%$ と見積もられる。
  4. 前処理は条件数を小さくして反復法の収束を速める操作で、ICCG法は不完全コレスキー分解を用いる。この例では相対誤差 $0.1$(=$10\%$)に条件数を掛けるため、解の相対誤差の上限はおよそ $100\times10\%=1000\%$ と見積もられる。
正解 : 1
【基礎】条件数は、行列の『解きにくさ』を表す量で、おおむね最大固有値と最小固有値の比で決まります。条件数が大きいほど、入力(右辺や係数)の小さな誤差が解の誤差として増幅されやすく、反復法の収束も遅くなります。
【考え方】前処理は $[A]$ に適当な近似逆行列 $[M]^{-1}$ を掛け、$[M]^{-1}[A]$ を単位行列に近づけて条件数を小さくします。ICCG法は不完全コレスキー分解を前処理に使う代表例です。誤差増幅の目安は $\dfrac{\|\Delta x\|}{\|x\|}\lesssim\kappa\cdot\dfrac{\|\Delta b\|}{\|b\|}$ で与えられます。
【計算】$\kappa\times\dfrac{\|\Delta b\|}{\|b\|}=100\times0.001=0.1=10\%$。
【ポイント】『前処理で条件数↓→誤差増幅・収束ともに改善』『誤差増幅の目安は条件数をそのまま倍率として掛ける』が要点です。$0.1\%$ の入力誤差が $\kappa=100$ で $10\%$ まで増幅されうることは、条件数の大きさが実務上いかに危険かを示します。
【引っかけ】選択肢2は条件数による増幅を忘れて入力誤差がそのまま出力誤差になるとした誤り(前処理の説明もICCGを不完全LU分解とする誤りを含みます)。選択肢3はCG法の収束率の評価などで現れる $\sqrt{\kappa}$ と、誤差増幅の目安に使う $\kappa$ 自体を取り違えた誤り。選択肢4は $0.1\%=0.001$ を $0.1$(=$10\%$)と読み違えた誤り(百分率と小数の変換ミス)です。
6-22 条件数の計算 難3・条件数
対称行列 $[A]=\begin{bmatrix}5&3\\3&5\end{bmatrix}$ の2ノルムに基づく条件数を求めよ。条件数は(対称正定値行列では)最大固有値と最小固有値の比 $\kappa=\dfrac{\lambda_{\max}}{\lambda_{\min}}$ で与えられる。
  1. $\kappa=1$
  2. $\kappa=1.5$
  3. $\kappa=4$
  4. $\kappa=8$
正解 : 3
【基礎】対称正定値行列の2ノルム条件数は、最大固有値と最小固有値の比です。条件数が大きいほど、丸め誤差に敏感で反復法の収束も遅くなります。
【考え方】固有値を特性方程式から求め、その比をとります。$2\times2$ 対称行列 $\begin{bmatrix}a&b\\b&a\end{bmatrix}$ の固有値は $a\pm b$ です。
【計算】$\lambda=5\pm3$ より $\lambda_{\max}=8,\ \lambda_{\min}=2$。よって $\kappa=\dfrac{8}{2}=4$。
【ポイント】『条件数=固有値の最大/最小』。$\kappa=1$(単位行列的)が最も解きやすく、大きいほど悪条件です。
【引っかけ】選択肢1は $\kappa=1$(悪条件でないと誤認)。選択肢2は固有値の比 $8/2$ ではなく差や別の比を計算した誤り。選択肢4は最大固有値 $8$ をそのまま条件数と取り違えた誤りです。
6-23 数値積分の必要性 難1・数値積分
有限要素法で要素剛性マトリックスを計算する際、被積分関数の積分をガウスの数値積分(ガウス求積)で評価することが多い理由として、最も適切なものはどれか。
  1. ガウス積分は積分点を増やすほど積分点どうしの重み付けが複雑になり数値的に不安定化しやすいため、要素剛性の評価では1点積分を基本とするのが一般的である。
  2. ガウス積分は同じ積分点数のシンプソンの公式(ニュートン・コーツ)と比べて、境界の関数値を使わない分だけ精度が体系的に低くなる傾向がある。
  3. 数値積分は真の関数を多項式で置き換えて評価するため、被積分関数がどのような形であっても打切り誤差なしに厳密値と完全に一致する。
  4. 要素剛性マトリックスは形状関数のヤコビアンなどを含み解析的な積分が難しいことが多く、少数の積分点での関数値の重み付き和で高い精度が得られるガウス積分が効率的だから。
正解 : 4
【基礎】要素剛性マトリックスは $\int [B]^{T}[D][B]\,dV$ の形で、等パラメトリック要素ではヤコビアンなどが入り、手で解析的に積分するのが難しくなります。
【考え方】そこで数値積分を使います。ガウス積分は、区間内の特別に選んだ少数の積分点での関数値に重みを掛けて足すだけで、同じ点数の他の公式より高い精度が得られます。だから要素積分で広く使われます。
【ポイント】『解析積分が難しい→少数点で高精度なガウス積分』が要点。積分点では応力・ひずみの評価精度も高くなります。
【引っかけ】選択肢1は積分点を増やすと不安定化するという誤りで、実際には点数を増やせば(丸め誤差を除き)精度は向上します(低減積分はアワーグラス制御やコスト削減など別の目的で使われるもので、不安定化を避けるためではありません)。選択肢2はガウス積分のほうが同点数のニュートン・コーツより高精度という事実と逆の誤り。選択肢3は数値積分が常に厳密値と一致するという誤りで、被積分関数の次数が積分点で扱える次数を超えれば打切り誤差が生じます。
6-24 ガウス積分の次数と点数選択 難3・ガウス積分の次数
被積分関数 $f(x)=x^{4}+x^{2}$ の定積分 $\displaystyle\int_{-1}^{1}f(x)\,dx$ をガウスの数値積分で誤差なく(厳密に)求めるには、最低何点の積分点が必要か。
  1. $2$ 点
  2. $3$ 点
  3. $4$ 点
  4. $5$ 点
正解 : 2
【基礎】$n$ 点のガウス積分は $(2n-1)$ 次までの多項式を厳密に積分できます。被積分関数の最高次数を超える最小の点数を選ぶ必要があります。
【考え方】$f(x)=x^4+x^2$ の最高次数は $4$。厳密に積分するには $2n-1\ge4$ を満たす最小の整数 $n$ を求めます。
【計算】$2n-1\ge4\Rightarrow n\ge2.5$。整数で最小なのは $n=3$($2\times3-1=5\ge4$)。実際、$2$ 点($2n-1=3$)では次数不足で $\displaystyle\int_{-1}^1(x^4+x^2)dx=\dfrac{2}{5}+\dfrac{2}{3}=\dfrac{16}{15}\approx1.067$ に対し2点ガウス値は $\approx0.889$ と誤差が出ますが、$3$ 点なら一致します。
【ポイント】『最高次数 $\le 2n-1$』を満たす最小の $n$ を選ぶのが要点。$n=2.5$ のような非整数は使えないため、必ず切り上げます。
【引っかけ】選択肢1($2$点)は $2n\ge4$ のように『$-1$』を落として $n=2$ とした誤り(2点では3次までしか厳密にならず4次項が残ります)。選択肢3($4$点)は『点数=次数』と誤って対応させたもの。選択肢4($5$点)は『$2n-1=$次数』を $n=$次数$+1$ と誤って解いたものです。
6-25 2点ガウス積分の計算 難3・ガウス積分の計算
2点のガウス数値積分 $\displaystyle\int_{-1}^{1} f(x)\,dx \approx f\!\left(-\tfrac{1}{\sqrt3}\right)+f\!\left(\tfrac{1}{\sqrt3}\right)$(積分点 $\pm\tfrac{1}{\sqrt3}$、重みは各 $1$)を用いて、$\displaystyle\int_{-1}^{1}(x^2+1)\,dx$ を計算せよ。
  1. $2$
  2. $\dfrac{8}{3}$
  3. $\dfrac{4}{3}$
  4. $4$
正解 : 2
【基礎】2点ガウス積分は、$\pm\dfrac{1}{\sqrt3}$ の2点での関数値に重み $1$ を掛けて足すだけで積分を近似します。
【考え方】$f(x)=x^2+1$ を2つの積分点で評価して合計します。積分点の $2$ 乗は $\left(\pm\dfrac{1}{\sqrt3}\right)^2=\dfrac{1}{3}$。
【計算】$f\!\left(\pm\tfrac{1}{\sqrt3}\right)=\dfrac{1}{3}+1=\dfrac{4}{3}$。重み各 $1$ なので和は $\dfrac{4}{3}+\dfrac{4}{3}=\dfrac{8}{3}$。
被積分関数は2次(3次以下)なので、2点ガウス積分は厳密で、実際 $\displaystyle\int_{-1}^{1}(x^2+1)dx=\left[\tfrac{x^3}{3}+x\right]_{-1}^{1}=\dfrac{8}{3}$ と一致します。
【ポイント】重みを掛け忘れず、$2$ 点の値を必ず両方足すこと。2点で3次まで厳密なので、この2次関数は誤差ゼロです。
【引っかけ】選択肢1($2$)は1点だけ($f(0)=1$)で近似し重み $2$ を掛けた粗い誤り。選択肢3($4/3$)は片方の点しか足していない誤り。選択肢4($4$)は $\int(x^2+1)$ の定数項だけ($\int_{-1}^11dx=2$)や範囲を取り違えた誤りです。
6-26 要素の積分点数 難2・要素の数値積分
3次元の8節点六面体要素を、各方向2点のガウス積分で完全積分(フルインテグレーション)する。要素全体で必要な積分点の総数はいくつか。
  1. $4$
  2. $6$
  3. $8$
  4. $27$
正解 : 3
【基礎】多次元のガウス積分は、各座標方向の1次元ガウス積分を掛け合わせた(テンソル積の)形で行います。積分点は各方向の点数の積になります。
【考え方】3次元で各方向2点なら、総数は $2\times2\times2$ です。
【計算】$2\times2\times2=8$ 点。
【ポイント】2次元4節点四辺形の完全積分は $2\times2=4$ 点、3次元8節点六面体は $2\times2\times2=8$ 点。高次要素(2次元8節点四辺形や3次元20節点六面体)の完全積分は各方向3点で、それぞれ $3\times3=9$ 点、$3\times3\times3=27$ 点になります。

6-27 ラグランジュ補間の計算 難3・ラグランジュ補間
3点 $(x_1,y_1)=(0,1),\ (x_2,y_2)=(2,5),\ (x_3,y_3)=(4,17)$ を通る2次のラグランジュ補間多項式を用いて、$x=1$ における $y$ の値を求めよ。補間式は $y=\displaystyle\sum_{i}\left(\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}\right)y_i$。
  1. $2$
  2. $3$
  3. $4$
  4. $5$
正解 : 1
【基礎】ラグランジュ補間は、各データ点に対応する基底(その点で $1$、他点で $0$ になる多項式)の重み付き和で補間曲線を作ります。
【考え方】各基底 $L_i(x)$ を $x=1$ で評価し、$y_i$ を掛けて合計します。
【計算】$L_1(1)=\dfrac{(1-2)(1-4)}{(0-2)(0-4)}=\dfrac{(-1)(-3)}{(-2)(-4)}=\dfrac{3}{8}$。$L_2(1)=\dfrac{(1-0)(1-4)}{(2-0)(2-4)}=\dfrac{(1)(-3)}{(2)(-2)}=\dfrac{-3}{-4}=\dfrac{3}{4}$。$L_3(1)=\dfrac{(1-0)(1-2)}{(4-0)(4-2)}=\dfrac{(1)(-1)}{(4)(2)}=-\dfrac{1}{8}$。
よって $y=1\cdot\dfrac{3}{8}+5\cdot\dfrac{3}{4}+17\cdot\left(-\dfrac{1}{8}\right)=\dfrac{3+30-17}{8}=\dfrac{16}{8}=2$。
【ポイント】基底の分母は $x_i$ と他の点の差の積。符号を丁寧に扱えば、各 $L_i$ の和は必ず $1$ になります(検算に使えます)。
【引っかけ】選択肢2($3$)は最初の2点 $(0,1),(2,5)$ だけで直線補間して $x=1$ とした誤り($y=3$)。選択肢3・4は基底の符号や分母を取り違えたり、$L_3$ の負号を落とした誤りです。
6-28 丸め誤差と打切り誤差 難1・誤差の分類
数値計算で生じる「丸め誤差」と「打切り誤差」の説明として、正しいものはどれか。
  1. 丸め誤差は反復や級数を有限項で止めることによる誤差、打切り誤差は有限桁で数を表すことによる誤差である。
  2. 丸め誤差と打切り誤差はどちらもコンピュータが浮動小数点で数を近似することだけに起因する同一の現象であり、呼び方が違うだけで発生原因を区別する実益はない。
  3. 積分点の数や計算に使う桁数を増やしていくと、丸め誤差と打切り誤差はどちらも同じ割合で小さくなっていくため、両者を分けて考える実用上の意味は薄い。
  4. 丸め誤差はコンピュータが有限桁(有限のビット数)で数を表すために生じる誤差、打切り誤差は無限に続く反復や級数・積分を有限回・有限項で打ち切ることによる誤差である。
正解 : 4
【基礎】数値計算の誤差は、大きく『丸め誤差』と『打切り誤差』に分けられます。
【考え方】丸め誤差は、コンピュータが実数を有限桁(浮動小数点の有限ビット)でしか表せないために、演算のたびに端数を丸めて生じます。打切り誤差は、本来は無限に続く反復・級数・積分を、有限回・有限項・有限個の積分点で打ち切るために生じます。
【ポイント】『丸め=有限桁の表現に由来』『打切り=無限を有限で止めることに由来』。積分点や項数を増やすと打切り誤差は減りますが、演算回数が増えて丸め誤差はむしろ増える傾向があり、両者はトレードオフになることがあります。
【引っかけ】選択肢1は2つの定義を逆(丸め=有限項で止める・打切り=有限桁)にした誤り。選択肢2は『同一の現象で区別する実益がない』とする誤り(発生原因が異なる別の誤差です)。選択肢3は『同じ割合で必ず小さくなる』とする誤りで、実際は一方を減らすと他方が増えることがあります。

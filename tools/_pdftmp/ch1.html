第1章 計算力学のための数学の基礎

1-1 3次行列式(余因子展開) 難3・行列式
行列 $A=\begin{pmatrix}2&3&1\\0&1&4\\5&2&0\end{pmatrix}$ の行列式 $\det A$ を、第1列に沿った余因子展開で求めるといくらか。
  1. $39$
  2. $-71$
  3. $-16$
  4. $3$
正解 : 1
【基礎】$3\times3$行列式は、ある1列(または1行)に沿って余因子展開できます。第1列 $(2,\ 0,\ 5)$ に沿うと、符号は $(-1)^{i+1}$ より上から $+,\ -,\ +$ です。
【考え方】各成分に、その成分を消した$2\times2$小行列式(余因子)を掛けて足し合わせます。$0$の成分は計算を省けます。
【計算】$M_{11}=\det\begin{pmatrix}1&4\\2&0\end{pmatrix}=1\times0-4\times2=-8$。$M_{31}=\det\begin{pmatrix}3&1\\1&4\end{pmatrix}=3\times4-1\times1=11$。よって $\det A=+2\times(-8)-0\times(\cdots)+5\times11=-16+0+55=39$。
【ポイント】$0$を含む行・列を展開の軸に選ぶと計算量が減ります。符号パターン $(+,-,+,-,\ldots)$ を忘れないことが重要です。
【引っかけ】$-71$は第3項の符号を$+$ではなく$-$と取り違え($-16-55$)たもの。$-16$は第3項($5\times11=55$)を丸ごと足し忘れたもの。$3$は対角成分の和$2+1+0$、トレースとの混同です。
1-2 逆行列による連立方程式の解 難2・逆行列
連立方程式 $\begin{cases}2x+y=5\\x+3y=10\end{cases}$ を、係数行列 $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$ の逆行列 $A^{-1}$ を使って解くと、$(x,\ y)$ はどれか。
  1. $(x,\ y)=(5,\ 15)$
  2. $(x,\ y)=(1,\ 3)$
  3. $(x,\ y)=(0,\ 5)$
  4. $(x,\ y)=(5,\ 5)$
正解 : 2
【基礎】$A\mathbf{x}=\mathbf{b}$ の解は $\mathbf{x}=A^{-1}\mathbf{b}$。$2\times2$の逆行列は $A^{-1}=\dfrac{1}{\det A}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$。
【考え方】まず $\det A$ を求め、逆行列の公式に当てはめてから $\mathbf{b}=(5,\ 10)$ に掛けます。
【計算】$\det A=2\times3-1\times1=5$。$A^{-1}=\dfrac{1}{5}\begin{pmatrix}3&-1\\-1&2\end{pmatrix}$。$\mathbf{x}=A^{-1}\mathbf{b}=\dfrac{1}{5}\begin{pmatrix}3\times5-1\times10\\-1\times5+2\times10\end{pmatrix}=\dfrac{1}{5}\begin{pmatrix}5\\15\end{pmatrix}=\begin{pmatrix}1\\3\end{pmatrix}$。検算: $2\times1+3=5$、$1+3\times3=10$ で一致。
【ポイント】最後に $\det A$ で割る($\dfrac{1}{5}$倍する)のを忘れないこと。検算でもとの式に戻して確認する習慣が大切です。
【引っかけ】$(5,\ 15)$は$\det A=5$で割るのを忘れた値(随伴行列のみ)。$(0,\ 5)$は逆行列公式で対角成分$3,2$を入れ替えるのを忘れた誤り。$(5,\ 5)$は非対角成分の符号反転を忘れた誤りです。
1-3 対称行列の固有値・固有ベクトル 難3・固有値・固有ベクトル
対称行列 $A=\begin{pmatrix}5&2\\2&2\end{pmatrix}$ の固有値と、大きい方の固有値に対応する固有ベクトルの向きの組み合わせとして正しいものはどれか。
  1. 固有値は$1,\ 6$。$\lambda=6$の固有ベクトルの向きは$(1,\ -2)$
  2. 固有値は$2,\ 5$。$\lambda=5$の固有ベクトルの向きは$(2,\ 1)$
  3. 固有値は$1,\ 6$。$\lambda=6$の固有ベクトルの向きは$(2,\ 1)$
  4. 固有値は$1,\ 6$。$\lambda=6$の固有ベクトルの向きは$(1,\ 2)$
正解 : 3
【基礎】固有値は特性方程式 $\lambda^2-(\mathrm{tr}A)\lambda+\det A=0$ の解。固有ベクトルは $(A-\lambda I)\mathbf{v}=\mathbf{0}$ を満たす $\mathbf{v}$ です。
【考え方】トレース$=5+2=7$、$\det A=5\times2-2\times2=6$ から固有値を求め、大きい方を $(A-\lambda I)\mathbf{v}=\mathbf{0}$ に代入して固有ベクトルを求めます。
【計算】$\lambda^2-7\lambda+6=0\Rightarrow(\lambda-1)(\lambda-6)=0\Rightarrow\lambda=1,\ 6$。$\lambda=6$のとき $A-6I=\begin{pmatrix}-1&2\\2&-4\end{pmatrix}$、$-v_1+2v_2=0\Rightarrow v_1=2v_2$ より固有ベクトルの向きは$(2,\ 1)$。検算: $A(2,1)^{\mathrm T}=(5\times2+2\times1,\ 2\times2+2\times1)=(12,\ 4)=6\times(2,1)$ で一致。
【ポイント】$A$は対称行列なので固有値は必ず実数になり、異なる固有値に対応する固有ベクトル同士は直交します($\lambda=1$の固有ベクトル$(1,-2)$との内積は$2\times1+1\times(-2)=0$で確認できます)。
【引っかけ】①は$\lambda=1$の固有ベクトル$(1,-2)$を$\lambda=6$のものと取り違えています。②は$\det A$の計算を誤り($10$等と誤算)固有値を$2,5$としたもの。④は固有ベクトルの成分$v_1,v_2$を取り違えたものです。
1-4 パラメータを含む連立方程式の可解性 難3・連立一次方程式の可解性
連立方程式 $\begin{cases}kx+2y=b_1\\3x+6y=b_2\end{cases}$ の係数行列 $A=\begin{pmatrix}k&2\\3&6\end{pmatrix}$ が $\det A=0$ となる $k$ の値と、そのときの解の有無に関する記述として正しいものはどれか。
  1. $k=1$のとき、$\mathbf{b}=(4,\ 12)$なら解なし、$\mathbf{b}=(4,\ 10)$なら解は無数にある
  2. $k=2$のとき、$\mathbf{b}=(4,\ 12)$なら解は無数にあり、$\mathbf{b}=(4,\ 10)$なら解なし
  3. $k=1$のとき、$\mathbf{b}=(4,\ 12)$と$\mathbf{b}=(4,\ 10)$のどちらでも解は無数にある
  4. $k=1$のとき、$\mathbf{b}=(4,\ 12)$なら解は無数にあり、$\mathbf{b}=(4,\ 10)$なら解なし
正解 : 4
【基礎】$\det A=0$ のとき、解は $\mathbf{b}$ によって「無数にある」か「存在しない」かのどちらかになります(一意解はもたない)。
【考え方】まず $\det A=0$ から $k$ を求めます。次にそのときの2式が同じ直線かどうかを、具体的な $\mathbf{b}$ で確認します。
【計算】$\det A=6k-6=0\Rightarrow k=1$。このとき $A=\begin{pmatrix}1&2\\3&6\end{pmatrix}$ で、第2式は第1式の$3$倍。$\mathbf{b}=(4,\ 12)$なら $3\times4=12$ で第2式も自動的に成立 $\Rightarrow$ 直線が完全に重なり解は無数。$\mathbf{b}=(4,\ 10)$なら $3\times4=12\neq10$ で矛盾 $\Rightarrow$ 平行で重ならず解なし。
【ポイント】$2$直線が「平行で離れている」か「完全に重なる」かは右辺 $\mathbf{b}$ が第1式の$3$倍になっているかどうかで決まります。
【引っかけ】①は無数/なしの対応を逆にしたもの。②は $\det A=6k-6$ を計算せず$k=2$としており、実際は $\det A=6\neq0$で正則になってしまいます。③はどちらの $\mathbf{b}$ でも重なると誤解したもので、$(4,10)$では実際は重なりません。
1-5 3次元ベクトルのなす角 難2・内積・なす角
$2$つのベクトル $\mathbf{a}=(1,\ 1,\ 2)$、$\mathbf{b}=(2,\ -1,\ 1)$ のなす角 $\theta$ はいくらか。
  1. $60^\circ$
  2. $90^\circ$
  3. $45^\circ$
  4. $30^\circ$
正解 : 1
【基礎】$\cos\theta=\dfrac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}||\mathbf{b}|}$。$3$次元でも内積は各成分の積の和です。
【考え方】内積と各ベクトルの大きさを別々に計算してから $\cos\theta$ を求めます。
【計算】$\mathbf{a}\cdot\mathbf{b}=1\times2+1\times(-1)+2\times1=2-1+2=3$。$|\mathbf{a}|=\sqrt{1^2+1^2+2^2}=\sqrt6$、$|\mathbf{b}|=\sqrt{2^2+(-1)^2+1^2}=\sqrt6$。$\cos\theta=\dfrac{3}{\sqrt6\times\sqrt6}=\dfrac{3}{6}=\dfrac12\Rightarrow\theta=60^\circ$。
【ポイント】$|\mathbf{a}|=|\mathbf{b}|=\sqrt6$ とたまたま等しいですが、内積の符号(正)から鋭角であることも事前に見当がつきます。
【引っかけ】$90^\circ$は内積を誤算し$0$に近いと錯覚した誤り。$45^\circ$は$\cos\theta=1/\sqrt2$との混同。$30^\circ$は$\cos\theta=\sqrt3/2$との混同です。
1-6 外積と平行四辺形の面積 難2・ベクトルの外積
$2$つのベクトル $\mathbf{a}=(4,\ -3,\ 0)$、$\mathbf{b}=(0,\ 0,\ 1)$ が張る平行四辺形の面積 $|\mathbf{a}\times\mathbf{b}|$ はいくらか。
  1. $0$
  2. $5$
  3. $25$
  4. $7$
正解 : 2
【基礎】外積 $\mathbf{a}\times\mathbf{b}=(a_2b_3-a_3b_2,\ a_3b_1-a_1b_3,\ a_1b_2-a_2b_1)$ の大きさが、$2$ベクトルが張る平行四辺形の面積になります。
【考え方】まず外積の$3$成分を計算し、その後にノルム(大きさ)を求めます。
【計算】$\mathbf{a}\times\mathbf{b}=((-3)\times1-0\times0,\ 0\times0-4\times1,\ 4\times0-(-3)\times0)=(-3,\ -4,\ 0)$。$|\mathbf{a}\times\mathbf{b}|=\sqrt{(-3)^2+(-4)^2+0^2}=\sqrt{25}=5$。
【ポイント】外積の大きさは $|\mathbf{a}||\mathbf{b}|\sin\theta$ とも一致します。ここでは $\mathbf{a},\mathbf{b}$ が直交する($\mathbf{a}\cdot\mathbf{b}=0$)ので $|\mathbf{a}\times\mathbf{b}|=|\mathbf{a}||\mathbf{b}|=5\times1=5$ と検算できます。
【引っかけ】$0$は外積ではなく内積($\mathbf{a}\cdot\mathbf{b}=0$)を答えてしまった誤り。$25$は最後の平方根をとり忘れた値。$7$は各成分の絶対値をそのまま足す($3+4+0$)というピタゴラスの定理を無視した誤りです。
1-7 マクローリン展開と打切り誤差のオーダー 難3・テイラー展開
関数 $f(x)=\cos x$ を $x=0$ のまわりで$4$次までマクローリン展開した近似式と、その打切り誤差のオーダーの組み合わせとして正しいものはどれか。
  1. 近似式 $1-\dfrac{x^2}{2}+\dfrac{x^4}{24}$、誤差のオーダー $O(x^5)$
  2. 近似式 $1-\dfrac{x^2}{2}-\dfrac{x^4}{24}$、誤差のオーダー $O(x^6)$
  3. 近似式 $1-\dfrac{x^2}{2}+\dfrac{x^4}{24}$、誤差のオーダー $O(x^6)$
  4. 近似式 $x-\dfrac{x^3}{6}$、誤差のオーダー $O(x^4)$
正解 : 3
【基礎】$\cos x=1-\dfrac{x^2}{2!}+\dfrac{x^4}{4!}-\dfrac{x^6}{6!}+\cdots$。$\cos x$は偶関数なので奇数次の項はすべて$0$です。
【計算】$4$次までの項は $1-\dfrac{x^2}{2}+\dfrac{x^4}{24}$。次に現れる項は本来$5$次ですが、偶関数のため$x^5$の項の係数は$0$で、次に残る非零項は$x^6$の項($-\dfrac{x^6}{720}$)です。したがって打切り誤差のオーダーは$O(x^5)$ではなく$O(x^6)$になります。
【ポイント】一般に$n$次までの打切り誤差は$O(x^{n+1})$ですが、偶関数・奇関数のように特定次数の係数が恒等的に$0$になる場合は、次に現れる非零項の次数まで誤差のオーダーが上がる(精度が良くなる)ことに注意が必要です。
【引っかけ】①は近似式は正しいものの、機械的に「$n+1$次だから$O(x^5)$」としてしまい、$x^5$項が$0$であることを見落としています。②は$x^4$項の符号を誤り。④は$\sin x$の展開($x-\dfrac{x^3}{6}$)と混同したものです。
1-8 前進差分の近似値と誤差のオーダー 難3・数値微分(前進差分)
関数 $f(x)=x^3$ について、$x=1$、刻み幅 $h=0.1$ の前進差分 $\dfrac{f(x+h)-f(x)}{h}$ で $f'(1)$ を近似した値と、その誤差のオーダーの組み合わせとして正しいものはどれか。
  1. 近似値 $3.31$、誤差のオーダー $O(h^2)$
  2. 近似値 $3.0$(誤差なし)、誤差のオーダー $O(h)$
  3. 近似値 $3.31$、誤差のオーダー $O(1)$(刻み幅によらず一定)
  4. 近似値 $3.31$、誤差のオーダー $O(h)$
正解 : 4
【基礎】前進差分 $\dfrac{f(x+h)-f(x)}{h}$ をテイラー展開すると $f'(x)+\dfrac{h}{2}f''(x)+\cdots$ となり、主要誤差項は$h$の$1$乗、すなわち$O(h)$です。
【計算】$f(1.1)=1.1^3=1.331$、$f(1)=1$。近似値 $=\dfrac{1.331-1}{0.1}=3.31$。真の値は $f'(1)=3\times1^2=3$ なので誤差は $3.31-3=0.31$。$h=0.05$で同様に計算すると誤差は約$0.1525$となり、$h$を半分にすると誤差もほぼ半分になる($O(h)$の特徴)ことが確認できます。
【ポイント】前進差分は$1$次精度($O(h)$)です。$2$次精度($O(h^2)$)にしたいときは中心差分を使います。
【引っかけ】①は近似値は正しいのに精度を中心差分と同じ$O(h^2)$と取り違えたもの。②は差分商を計算せず真の導関数値をそのまま答え、誤差がないと誤解したもの。③は「誤差が刻み幅によらず一定」とする誤りで、実際は$h\to0$で誤差も$0$に近づきます。
1-9 2階中心差分の近似値と誤差 難3・数値微分(2階中心差分)
関数 $f(x)=x^4$ について、$x=1$、刻み幅 $h=0.1$ の$2$階中心差分 $\dfrac{f(x+h)-2f(x)+f(x-h)}{h^2}$ で $f''(1)$ を近似した値と誤差の組み合わせとして正しいものはどれか。
  1. 近似値 $12.02$、誤差 $+0.02$(オーダー $O(h^2)$)
  2. 近似値 $12.02$、誤差 $+0.02$(オーダー $O(h)$)
  3. 近似値 $12.0$、誤差 $0$(中心差分は打切り誤差を持たないという誤解)
  4. 近似値 $11.98$、誤差 $-0.02$(オーダー $O(h^2)$)
正解 : 1
【基礎】$2$階中心差分の打切り誤差の主要項は $\dfrac{h^2}{12}f^{(4)}(x)$ で、オーダーは$O(h^2)$です。
【計算】$f(1.1)=1.1^4=1.4641$、$f(1)=1$、$f(0.9)=0.9^4=0.6561$。近似値 $=\dfrac{1.4641-2\times1+0.6561}{0.1^2}=\dfrac{0.1202}{0.01}=12.02$。真の値は $f''(1)=12\times1^2=12$。誤差 $=12.02-12=+0.02$。理論式でも $\dfrac{h^2}{12}f^{(4)}(1)=\dfrac{0.01}{12}\times24=0.02$ と一致します。
【ポイント】近似値が真値より大きい(過大評価)のは $f^{(4)}(1)=24>0$、すなわち$f$が上に反っているためです。中心差分でも打切り誤差は$0$にはなりません。
【引っかけ】②は誤差の値は合っているのにオーダーを$O(h)$と取り違えたもの(前進差分と混同)。③は中心差分は打切り誤差を持たないという誤解で誤差を$0$としたもの。④は分子の計算で符号を取り違え、真値より小さい($11.98$)と誤算したものです。
1-10 台形公式による数値積分と誤差 難2・数値積分(台形則)
定積分 $\displaystyle\int_0^2 x^3\,dx$ を、区間を$2$等分($h=1$、節点 $x=0,1,2$)して台形公式で近似したときの近似値・真値・誤差の組み合わせとして正しいものはどれか。
  1. 近似値 $5$、真値 $\dfrac{16}{3}$、誤差 $=5-\dfrac{16}{3}$
  2. 近似値 $5$、真値 $4$、誤差 $+1$(過大評価)
  3. 近似値 $4$、真値 $5$、誤差 $-1$
  4. 近似値 $5$、真値 $4$だが、凸関数では過小評価になると取り違えた場合の誤り
正解 : 2
【基礎】複合台形公式は $\displaystyle\int_a^b f\,dx\approx h\left[\dfrac{f_0+f_n}{2}+f_1+\cdots+f_{n-1}\right]$。両端の値だけ$\dfrac12$倍します。
【計算】$f_0=0^3=0,\ f_1=1^3=1,\ f_2=2^3=8$、$h=1$。近似値 $=1\times\left[\dfrac{0+8}{2}+1\right]=4+1=5$。真値は $\displaystyle\int_0^2x^3dx=\left[\dfrac{x^4}{4}\right]_0^2=\dfrac{16}{4}=4$。誤差 $=5-4=+1$。
【ポイント】$x^3$は$x>0$の範囲で$f''(x)=6x>0$(凸関数)なので、台形公式は曲線の下をまっすぐな線分で結ぶため過大評価になります。
【引っかけ】①は真値の計算で指数を$4$ではなく$3$で割る誤り($\dfrac{x^4}{3}$)をして$\dfrac{16}{3}$としたもの。③は近似値と真値を取り違えたもの。④は近似値・真値は正しいのに、過大・過小の向きを逆に判断したものです。
1-11 勾配ベクトルと方向微分 難2・偏微分・勾配
関数 $f(x,y)=x^2y+y^3$ の点 $(1,\ 2)$ における勾配ベクトル $\nabla f$ を求め、単位ベクトル $\dfrac{1}{5}(3,\ 4)$ 方向の方向微分係数を計算するといくらか。
  1. $64$
  2. $11$
  3. $12.8$
  4. $16$
正解 : 3
【基礎】方向微分係数は $\nabla f\cdot\mathbf{u}$($\mathbf{u}$は単位ベクトル)で求まります。勾配は $\nabla f=\left(\dfrac{\partial f}{\partial x},\ \dfrac{\partial f}{\partial y}\right)$。
【考え方】まず$2$つの偏微分を計算して点$(1,2)$を代入し勾配を求め、その後に単位ベクトルとの内積をとります。
【計算】$\dfrac{\partial f}{\partial x}=2xy,\ \dfrac{\partial f}{\partial y}=x^2+3y^2$。点$(1,2)$で $\nabla f=(2\times1\times2,\ 1^2+3\times2^2)=(4,\ 13)$。方向ベクトル$(3,4)$の大きさは$\sqrt{3^2+4^2}=5$なので単位ベクトルは$\left(\dfrac35,\ \dfrac45\right)$。方向微分係数 $=4\times\dfrac35+13\times\dfrac45=\dfrac{12}{5}+\dfrac{52}{5}=\dfrac{64}{5}=12.8$。
【ポイント】方向微分は「勾配を、進みたい向きの単位ベクトルに正射影したもの」です。向きベクトルを正規化せずに使うと値が変わってしまいます。
【引っかけ】$64$は単位ベクトルに正規化せず、$(3,4)$のまま内積をとった($\div5$を忘れた)誤り。$11$は勾配の成分$4,13$を取り違えて内積をとったもの。$16$は方向ベクトルの大きさを$\sqrt{3^2+4^2}=5$ではなく$4$と誤算したものです。
1-12 変数変換のヤコビ行列式 難3・ヤコビアン
変数変換 $u=x^2-y^2,\ v=2xy$ について、点 $(x,\ y)=(2,\ 1)$ におけるヤコビ行列 $J=\begin{pmatrix}\partial u/\partial x&\partial u/\partial y\\\partial v/\partial x&\partial v/\partial y\end{pmatrix}$ の行列式 $\det J$ はいくらか。
  1. $12$
  2. $18$
  3. $8$
  4. $20$
正解 : 4
【基礎】ヤコビ行列式は座標変換にともなう面積(体積)の拡大率を表し、$\det J\neq0$なら局所的に逆変換が可能です。
【考え方】$4$つの偏微分を求めて$2\times2$行列を作り、行列式の公式($ad-bc$)を使います。
【計算】$\dfrac{\partial u}{\partial x}=2x,\ \dfrac{\partial u}{\partial y}=-2y,\ \dfrac{\partial v}{\partial x}=2y,\ \dfrac{\partial v}{\partial y}=2x$。点$(2,1)$で $J=\begin{pmatrix}4&-2\\2&4\end{pmatrix}$。$\det J=4\times4-(-2)\times2=16+4=20$。
【ポイント】この変換は複素数の$2$乗写像 $w=z^2$ に対応し、$\det J=4x^2+4y^2=4|z|^2$ という一般式でも検算できます($4\times(2^2+1^2)=20$)。
【引っかけ】$12$は非対角成分の符号を取り違え($16-4$)たもの。$18$は$\partial v/\partial x$の係数$2$を掛け忘れ$\partial v/\partial x=1$として計算した誤り。$8$は行列式ではなく全成分の単純和($4-2+2+4$)を答えたものです。

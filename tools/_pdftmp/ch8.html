第8章 モデリングの基礎

CAE計算力学技術者 固体力学2級・オリジナル問題（問題／解答／解説／図）
8-1 次元の理想化の選択 難2・次元の理想化
断面寸法に比べて長さが約30倍ある一様断面の支柱に、軸力と曲げが同時に作用する。計算効率を優先しつつ軸力・曲げ・たわみを妥当に評価したい。モデル化として最も適切なのはどれか。
  1. はり(1D)要素で軸力・曲げ・たわみを効率よく評価する
  2. 曲げには曲面が要るとみて、部材の表面全体をシェル(2D)要素で覆う
  3. 面内薄板向けの平面応力(2D)要素で断面をモデル化する
  4. 汎用性を重視し1次四面体ソリッドで全体を細かく分割する
正解 : 1
【基礎】部品の形状に応じて1D(はり/トラス)・2D(シェル/平面)・3D(ソリッド)を使い分けるのがモデリングの第一歩。
【考え方】長さ≫断面寸法の細長い部材ははり理論が成り立ち、はり要素なら少ない自由度で軸力・曲げ・たわみを表せる。
【ポイント】まず「1D/2D/3Dのどれに帰着できるか」を考えると効率と精度を両立できる。
【引っかけ】②シェルは薄肉“面”構造向けで中実の細長棒には不適。③平面応力は面内荷重の薄板専用で3次元的な柱には使えない。④1次四面体は曲げに過度に剛く、要素数も膨大で非効率。
8-2 平面ひずみが適する問題 難2・平面ひずみ
次のうち「平面ひずみ状態」で近似するのが最も適切な問題はどれか。
  1. 面内荷重を受ける薄い板の面内応力解析
  2. 軸方向に十分長いダム(重力式)の任意の横断面の解析
  3. 円形断面の丸棒を軸方向に引張る解析
  4. 薄い円板の面外曲げ解析
正解 : 2
【基礎】平面ひずみは、奥行き方向に十分長く断面形状が一定で、その方向のひずみが $\varepsilon_z\approx0$ とみなせる問題に使う(ダム・トンネル・擁壁・長い軸など)。
【考え方】軸方向に長いダムの横断面は、どの断面も同じ変形をするため奥行きひずみが拘束され $\varepsilon_z=0$ と近似できる。
【ポイント】薄いか厚い(長い)かで平面応力/平面ひずみを選ぶ。
【引っかけ】①は薄板の面内=平面応力。③は軸対称(または1次元)問題。④は板の面外曲げで平面問題ではない。
8-3 軸対称モデルの適用可否 難2・軸対称
軸対称モデル(2次元)でそのまま解いてよいのは、形状・荷重・拘束のすべてが回転軸まわりに軸対称なときである。次のうち、単純な軸対称モデルをそのまま適用できないのはどれか。
  1. 内圧を受ける円筒圧力容器
  2. 回転軸まわりに一様な温度分布を受ける円板
  3. 側方からの一様な横風荷重を受ける円筒サイロ
  4. 軸方向の自重(重力)を受ける直立した円筒タンク
正解 : 3
【基礎】軸対称モデルは形状・荷重・拘束が回転軸まわりにすべて軸対称のときだけ、3次元問題を2次元(r-z断面)に縮約できる。
【考え方】横風荷重は円周方向(角度θ)によって大きさが変わる非軸対称荷重なので、単純な2次元軸対称モデルでは表せない(非軸対称荷重に対応した特殊軸対称か3Dが必要)。
【ポイント】“形状が軸対称”でも荷重・拘束が非軸対称なら軸対称モデルは使えない。
【引っかけ】①②④は形状・荷重・拘束がいずれも軸対称で軸対称モデルにできる。③だけ荷重が周方向に非対称。
8-4 平面ひずみの板厚方向応力 難2・平面ひずみ
平面ひずみ状態($\varepsilon_z=0$)にある等方性弾性体で、面内応力が $\sigma_x=60\,\mathrm{MPa}$、$\sigma_y=20\,\mathrm{MPa}$、ポアソン比 $\nu=0.3$ である。板厚(z)方向の垂直応力 $\sigma_z$ に最も近いのはどれか。
  1. $24\,\mathrm{MPa}$
  2. $0\,\mathrm{MPa}$
  3. $80\,\mathrm{MPa}$
  4. $34\,\mathrm{MPa}$
正解 : 1
【基礎】平面ひずみでは奥行き方向のひずみが $\varepsilon_z=0$ に拘束される。フックの法則 $\varepsilon_z=\dfrac{1}{E}\{\sigma_z-\nu(\sigma_x+\sigma_y)\}=0$ より $\sigma_z=\nu(\sigma_x+\sigma_y)$。
【計算】$\sigma_z=0.3\times(60+20)=0.3\times80=24\,\mathrm{MPa}$。
【ポイント】平面ひずみでは面外応力 $\sigma_z$ は0ではなく、面内応力から従属的に決まる(この点が平面応力との決定的な違い)。
【引っかけ】②平面応力($\sigma_z=0$)と混同。③ $\nu$ を掛け忘れ $\sigma_x+\sigma_y=80$。④誤って $\nu/(1-\nu)$ を掛けた($\approx34$)。
8-5 平面応力の板厚方向ひずみ 難2・平面応力
平面応力状態($\sigma_z=0$)の薄板で、面内応力 $\sigma_x=100\,\mathrm{MPa}$、$\sigma_y=40\,\mathrm{MPa}$。$E=200\,\mathrm{GPa}$、$\nu=0.3$ のとき、板厚(z)方向の垂直ひずみ $\varepsilon_z$ に最も近いのはどれか。
  1. $0$
  2. $-2.1\times10^{-4}$
  3. $+2.1\times10^{-4}$
  4. $-7.0\times10^{-4}$
正解 : 2
【基礎】平面応力では $\sigma_z=0$ だが、$\varepsilon_z$ は0ではない。$\varepsilon_z=\dfrac{1}{E}\{\sigma_z-\nu(\sigma_x+\sigma_y)\}=-\dfrac{\nu}{E}(\sigma_x+\sigma_y)$。
【計算】$\varepsilon_z=-\dfrac{0.3}{200000}\times(100+40)=-\dfrac{0.3\times140}{200000}=-2.1\times10^{-4}$($E=200\,\mathrm{GPa}=200000\,\mathrm{MPa}$)。
【ポイント】応力が0でもひずみは0とは限らない。板は面内引張で板厚方向に縮む($\varepsilon_z<0$)。
【引っかけ】①「$\sigma_z=0$ だから $\varepsilon_z=0$」と応力とひずみを混同。③符号ミス。④ $\nu$ の掛け忘れ($-140/200000=-7.0\times10^{-4}$)。
8-6 平面ひずみ2軸応力のひずみ比 難3・平面ひずみ
十分に厚い長方形板(平面ひずみ状態、$\varepsilon_z=0$)に $\sigma_x=p$、$\sigma_y=2p$ を同時に作用させる。等方性で $\nu=0.3$。面内ひずみ比 $\varepsilon_x/\varepsilon_y$ に最も近いのはどれか。
  1. $0.5$
  2. $0.235$
  3. $0.091$
  4. $0.13$
正解 : 3
【基礎】平面ひずみのフックの法則は $\varepsilon_x=\dfrac{1}{E}\{(1-\nu^2)\sigma_x-\nu(1+\nu)\sigma_y\}$、$\varepsilon_y=\dfrac{1}{E}\{(1-\nu^2)\sigma_y-\nu(1+\nu)\sigma_x\}$($\sigma_z=\nu(\sigma_x+\sigma_y)$ を消去した形)。
【計算】$1-\nu^2=0.91$、$\nu(1+\nu)=0.39$。$\varepsilon_x\propto0.91\times1-0.39\times2=0.13$、$\varepsilon_y\propto0.91\times2-0.39\times1=1.43$。よって $\varepsilon_x/\varepsilon_y=0.13/1.43\approx0.091$。
【ポイント】平面ひずみでは面外拘束の項 $\nu(1+\nu)$ が効くため、単純な $\sigma_x/\sigma_y$ にはならない。
【引っかけ】①単純に $\sigma_x/\sigma_y=1/2=0.5$ とした。②平面応力の式 $(\sigma_x-\nu\sigma_y)/(\sigma_y-\nu\sigma_x)$ で計算($\approx0.235$)。④ $\varepsilon_x$ の比例値 $0.13$ をそのまま比と取り違えた。
8-7 対称性が使えない荷重 難2・対称性
対称性を利用してモデルを縮小できるのは、形状だけでなく荷重・拘束も対称面に関して対称なときである。次のうち、幾何形状は左右対称でも単純な1/2対称モデルにそのまま縮小できないのはどれか。
  1. 左右対称な板に、対称軸に関して左右対称な引張荷重が作用する
  2. 左右対称な円孔付き板に、対称な内圧が作用する
  3. 左右対称なブラケットに、対称面に垂直で左右対称な荷重が作用する
  4. 左右対称な板に、対称軸まわりのねじり(反対称)荷重が作用する
正解 : 4
【基礎】対称モデルに縮小できる条件は「形状・荷重・拘束のすべてが対称面に関して対称」であること。
【考え方】ねじりのような反対称荷重は、対称面の左右で向きが逆になるため、対称条件では表せない(反対称条件=対称面上で面内変位を拘束し面外を自由、が必要)。
【ポイント】形状が対称でも荷重が反対称なら“対称”モデルにはできない。反対称なら反対称境界を使う。
【引っかけ】①②③は荷重も対称なので1/2対称モデルに縮小できる。④だけ荷重が反対称。
8-8 応力集中部のメッシュ設計 難1・メッシュ密度
応力集中が予想される部位を含む部品のメッシュ設計として最も適切なのはどれか。
  1. 応力勾配が急な応力集中部を細かく、応力がほぼ一様な部位は粗く分割する
  2. 全領域を一様な細かいメッシュにすれば効率よく最良の精度が得られる
  3. 応力集中部を粗く、応力がほぼ一様な部位を細かく分割する
  4. 応力集中部の要素を大きくしても、要素内で平均化されピーク応力を捉えられる
正解 : 1
【基礎】メッシュは「応力勾配が急なところほど細かく」が原則。勾配が緩い所は粗くして計算量を節約する。
【考え方】応力集中部(穴・フィレット・切欠き)は狭い範囲で応力が急変するので、細かい要素でないとピークを捉えられない。
【ポイント】必要な所に密、それ以外は粗、が効率と精度の両立。
【引っかけ】②一様細分は精度は出るが要素数が無駄に増え非効率。③粗密が逆でピークを取り逃す。④粗い要素はピーク応力を平均化して過小評価する。
8-9 メッシュ収束の判断 難2・メッシュ収束
メッシュ収束(収束解析)の考え方として最も適切なのはどれか。
  1. 要素数が最も少なく計算が軽いときの解を収束解とみなす
  2. 着目量(最大応力など)がメッシュ細分でほとんど変化しなくなった状態を収束とみなす
  3. 計算時間が最短になったときのメッシュの解を収束解とする
  4. 変位が最大に評価されるメッシュの解を採用する
正解 : 2
【基礎】有限要素解はメッシュを細かくするほど真の解に近づく。着目量が要素サイズを変えても変わらなくなった状態が「収束」。
【考え方】要素サイズを段階的に半分にしていき、着目量の変化が許容誤差以下になったら十分細かいと判断する。
【ポイント】収束の判断基準は「解の安定」であって、要素数や計算時間ではない。
【引っかけ】①粗い解ほど誤差が大きい。③計算時間は精度の指標にならない。④最大変位を与えるメッシュは収束の指標ではない。
8-10 応力と変位の収束の速さ 難2・メッシュ収束
同じ問題を要素サイズを段階的に小さくして解いた。収束の速さに関する記述として正しいものはどれか。
  1. 応力の方が変位より速く収束するので、応力を基準に判定すれば少ない要素で十分である
  2. 変位も応力もメッシュ細分に対して同じ速さで収束する
  3. 一般に変位は比較的粗いメッシュでも収束しやすく、応力(特にピーク応力)は変位より収束が遅い
  4. 十分に粗いメッシュでもピーク応力は正しく得られる
正解 : 3
【基礎】変位は要素内で直接補間される基本量、応力はその微分(ひずみ)から求まる派生量。微分すると精度が落ちるため応力の収束は遅い。
【考え方】特に応力集中部のピーク応力は勾配が急で、粗いメッシュでは過小評価されやすい。
【ポイント】「変位が合っている=応力も合っている」ではない。応力評価にはより細かいメッシュが要る。
【引っかけ】①逆(変位の方が速い)。②微分量の応力は変位より遅い。④粗メッシュではピークを取り逃す。
8-11 要素のアスペクト比 難1・要素品質
四辺形要素の長辺が $20\,\mathrm{mm}$、短辺が $4\,\mathrm{mm}$ である。アスペクト比の値と、それに関する一般的な指針の組合せとして正しいのはどれか。
  1. アスペクト比 $0.2$。1に近いほど精度がよい
  2. アスペクト比 $5$。大きいほど精度がよい
  3. アスペクト比 $80$。値は要素の面積で決まる
  4. アスペクト比 $5$。1に近いほど精度がよく、大きすぎると精度が低下する
正解 : 4
【基礎】アスペクト比は要素の「長辺/短辺」で、細長さの指標。理想は1(正方形・正三角形)に近いこと。
【計算】$\text{アスペクト比}=\dfrac{20}{4}=5$。
【ポイント】アスペクト比が大きい(細長い)ほど、特に応力勾配のある方向で精度が低下する。応力集中部では1に近づける。
【引っかけ】①長辺/短辺の逆数(0.2)を取った。②大小の傾向が逆(1に近いほど良い)。③面積(20×4=80)と取り違えた。
8-12 要素形状の品質とヤコビアン 難2・要素品質
要素形状の品質に関する記述として正しいものはどれか。
  1. 要素が凹形に歪んでヤコビアンが負になると、正しく積分できず解が不正確・計算不能になる
  2. 要素は歪んでいるほど内部の積分点が増えて精度が上がる
  3. アスペクト比やヤコビアンは要素品質の指標だが解析精度とは無関係である
  4. 中間節点を辺の中央から大きくずらすほど要素の品質が向上する
正解 : 1
【基礎】要素内部の座標変換(実要素↔基準要素)の局所的な体積比がヤコビアン。これが負になると要素が“裏返る/凹む”状態で、数値積分が破綻する。
【考え方】歪み・アスペクト比・ヤコビアンは要素品質の代表指標で、悪いと精度低下や計算エラーを招く。
【ポイント】メッシュ作成後は品質チェック(負ヤコビアン・過大歪みの検出)を行う。
【引っかけ】②歪みは精度を下げる(積分点は増えない)。③品質指標は精度に直結する。④中間節点を寄せすぎるとヤコビアンが負になり品質は悪化する。
8-13 要素次数の選択(曲げ) 難2・要素次数
曲げが支配的な部品を四面体要素で解くとき、要素次数の選択として最も適切なのはどれか。
  1. 1次四面体は2次四面体より高精度なので、そのまま1次で解けばよい
  2. 1次四面体は曲げに過度に剛くなりやすいので、2次四面体を使うか要素数を大幅に増やす
  3. 要素次数は解析精度に関係しないので、1次のままで十分である
  4. 2次要素は節点数が減るので計算が速く有利である
正解 : 2
【基礎】1次四面体は変位が線形で要素内のひずみが一定になり、曲げを表すのが苦手で過度に剛くなる(せん断ロッキング的挙動)。2次要素は辺中間節点を持ち曲げ・曲面をよく表す。
【考え方】曲げ支配なら2次要素を使うか、1次なら要素数を大幅に増やして補う。
【ポイント】曲げ・応力集中の精度が要るなら2次要素が有利(ただし節点は増える)。
【引っかけ】①逆で2次の方が高精度。③次数は精度に直結する。④2次要素は節点が増える(減らない)。
8-14 形状の簡略化(削除の可否) 難2・形状簡略化
解析効率のため形状を簡略化する。次のうち、削除(省略)してよい可能性が最も高いのはどれか。
  1. 応力集中を評価したい、まさにその止まり穴のフィレット部
  2. 危険断面にあって応力集中源となっている切欠き
  3. 着目部から十分離れ、荷重伝達にほぼ寄与しない小さな取付け穴やロゴ刻印
  4. 荷重を受け持ち剛性に寄与している主要なリブ
正解 : 3
【基礎】簡略化してよいのは「着目量にほとんど影響しない細部」。逆に応力集中源や主要な荷重経路は残す。
【考え方】着目部から遠く荷重伝達にほぼ寄与しない小穴・刻印は、メッシュを簡単にするため省略できることが多い。
【ポイント】“評価したい応力に効くか”で残す/消すを判断する。迷えば残す方が安全。
【引っかけ】①フィレットは応力集中の評価対象なので削除不可。②切欠きは危険断面の応力源で削除不可。④主要リブは剛性・荷重経路に効くので削除不可。
8-15 フィレット省略と応力特異点 難2・形状簡略化
応力集中部のフィレット(丸み)を「メッシュが面倒だから」と削除して鋭い角(入隅)にモデル化した。その角で起こることとして正しいのはどれか。
  1. 角部の応力は、フィレットがある場合とほぼ同じ値に収束する
  2. 角部の応力は逆にゼロに近づいて安全側になる
  3. 応力特異点は生じるが、細分するほど正しいピーク応力に収束する
  4. 角部の応力が理論上無限大に発散(応力特異点)し、細分するほど応力が増え続けて収束しない
正解 : 4
【基礎】弾性論では、丸みのない鋭い入隅(再突入角)で応力が理論上無限大になる(応力特異点)。
【考え方】特異点ではメッシュを細かくするほど応力が上がり続け、いつまでも収束しない。実物のフィレットの丸み半径を残さないと意味のあるピーク応力が得られない。
【ポイント】応力評価したい隅は必ず実際のフィレットをモデル化する。
【引っかけ】①鋭角にすると値が大きく変わる。②角部はむしろ応力が増大する。③特異点では細分しても収束せず発散する。
8-16 サブモデリングの手法 難2・サブモデリング
サブモデリング(部分詳細解析)の手法として正しいのはどれか。
  1. 全体を粗く解いた後、着目部を切り出して細かく作り直し、切断面に全体解析の変位を境界値として与えて解く
  2. 全体を一度に最も細かいメッシュで作成して解くこと
  3. モデル全体を小さく作り替えたうえで材料定数を変更すること
  4. 対称性を利用してモデルを半分や1/4に縮小すること
正解 : 1
【基礎】サブモデリングは、全体を粗く解いて全体挙動を得た後、応力を詳しく見たい部分だけを細かいモデルにして、その境界に全体解析の変位を与えて解く二段階法。
【考え方】全体を一度に細かくすると計算が膨大。着目部だけ細かくすれば効率よく詳細応力が得られる。
【ポイント】前提は「着目部の局所細分が全体の挙動をほとんど変えない」こと。
【引っかけ】②それは単なる全体細分でサブモデリングではない。③材料定数変更は別概念。④対称縮小は別手法。
8-17 質量・剛性の等価化 難2・等価化
大きなアセンブリ解析で、構造剛性にはほとんど寄与しないが質量の大きい搭載機器を扱う。効率的な等価化として最も適切なのはどれか。
  1. 機器を実形状の細かいソリッドでモデル化しないと、質量の影響は評価できない
  2. 機器の形状は詳細に作らず、集中質量として重心に与え、取付け部へ剛体要素等で結合する
  3. 剛性に寄与しない部品なので、質量まで含めて完全に省略してよい
  4. 質量点は剛性も持つので、構造剛性の評価にも使える
正解 : 2
【基礎】剛性への寄与が小さく質量が主な影響である部品は、実形状を作らず集中質量(質量点)で表し、取付け部へ剛体要素やMPCで結び付ければ十分。
【考え方】振動・慣性・自重の影響は質量点で表現でき、要素数を大幅に削減できる。
【ポイント】「剛性に効くか/質量に効くか」を見極めて等価化する。
【引っかけ】①集中質量で十分表せる。③質量は慣性・自重に効くので無視できない。④質量点は剛性を持たない。
8-18 単位系の整合 難2・単位系
FEMでは入力する物理量の単位系を整合させる必要がある。長さを $\mathrm{mm}$、力を $\mathrm{N}$ とする(このとき応力は $\mathrm{MPa}=\mathrm{N/mm^2}$)。縦弾性係数 $E=206\,\mathrm{GPa}$ を入力する値として正しいのはどれか。
  1. $2.06\times10^{2}\,\mathrm{N/mm^2}$
  2. $2.06\times10^{8}\,\mathrm{N/mm^2}$
  3. $2.06\times10^{5}\,\mathrm{N/mm^2}$
  4. $2.06\times10^{11}\,\mathrm{N/mm^2}$
正解 : 3
【基礎】単位系はすべて一貫させる。mm-N系では応力・弾性係数は $\mathrm{N/mm^2}=\mathrm{MPa}$ で表す。
【計算】$206\,\mathrm{GPa}=206\times10^{9}\,\mathrm{Pa}=206\times10^{9}\,\mathrm{N/m^2}$。$1\,\mathrm{m^2}=10^{6}\,\mathrm{mm^2}$ だから $\div10^{6}$ して $206\times10^{3}=2.06\times10^{5}\,\mathrm{N/mm^2}$。
【ポイント】$1\,\mathrm{GPa}=1000\,\mathrm{MPa}=1000\,\mathrm{N/mm^2}$ を覚えておくと速い。密度なども同じ系(例:$\mathrm{tonne/mm^3}$)に揃える。
【引っかけ】①GPaの数値206をそのまま入力(換算忘れ)。②中途半端な換算。④Pa($\mathrm{N/m^2}$)の値をそのまま使用(mm系への変換忘れ)。
8-19 結合と接触のモデル化 難2・結合・接触
2部品の接合部のモデル化方針として最も適切なのはどれか。
  1. 接合部はすべて接触(contact)解析にすれば最も速く解ける
  2. 接合部は一体化(結合)しておけば、離れや滑りは考えなくてよい
  3. 接触解析は線形なので、収束の良し悪しは気にしなくてよい
  4. 離れも滑りもしない箇所は結合(bonded)で簡略化し、離れ・滑りが生じ得る箇所は接触(contact)を用いる
正解 : 4
【基礎】接合部は、挙動に応じて「結合(常に一体)」と「接触(離れ・滑りを許す)」を使い分ける。
【考え方】常に密着したままなら結合で簡略化でき線形で速い。離れ・滑りが起こり得るなら接触(非線形)が必要。
【ポイント】まず“離れる/滑るか”を考えて選ぶ。過剰に接触を使うと計算コストが増す。
【引っかけ】①接触は非線形で計算コストが大きく、常に最速ではない。②離れ・滑りがある箇所を一体化すると実挙動と乖離。③接触は非線形で収束に注意が要る。
8-20 はり要素の適用限界 難2・はり要素
はり要素で妥当に解析できる条件として、最も適切な記述を選べ。
  1. 長さが断面寸法より十分大きければはり理論が成立し、短く背の高い部材ではせん断変形で精度が落ちる
  2. はり要素は長さに関係なく、高精度に応力・変形を求められる
  3. 短く太い部材ほど、はり要素の精度はむしろ高くなる
  4. はり要素は断面情報を持たないので、応力は計算できない
正解 : 1
【基礎】ベルヌーイ・オイラーはり理論は「長さ≫断面寸法」でせん断変形を無視できる前提。細長い部材で成立する。
【考え方】短く背の高い(せいが大きい)部材はせん断変形が効くため、はり要素では誤差が大きくなる(ティモシェンコ梁やソリッドが必要)。
【ポイント】L/h(スパン/せい)が小さいほどはり近似は悪くなる。
【引っかけ】②短い部材ではせん断変形で誤差が増える。③逆(短く太いほど不利)。④はり要素は断面諸量から曲げ・軸応力を算出できる。
8-21 メッシュ収束の相対誤差 難2・メッシュ収束
ある切欠きの最大応力を、要素サイズを半分ずつにしながら求めたところ、$180,\ 198,\ 205,\ 207\,\mathrm{MPa}$ と変化した。最も細かい解($207$)を基準にしたとき、3番目($205$)の相対誤差と収束の判断の組合せとして最も適切なのはどれか。
  1. 約 $13\%$ で、まだ収束していない
  2. 約 $1\%$ で、変化が十分小さく収束に近い
  3. 約 $10\%$ で、発散している
  4. 誤差 $0\%$。最初の $180$ が正解である
正解 : 2
【基礎】相対誤差 = |評価値 − 基準値| / 基準値。最も細かい解を暫定の“真値”とみなして評価する。
【計算】$\dfrac{|205-207|}{207}=\dfrac{2}{207}\approx0.0097=0.97\%\approx1\%$。
【ポイント】値が $180\to198\to205\to207$ と一定値へ漸近しており、変化率が十分小さくなったので収束に近い。
【引っかけ】①最も粗い $180$ を基準にした値($\approx13\%$)。③漸近であって発散ではない。④最粗解を正解と誤認。
8-22 三次元ソリッドが必要な場合 難1・次元の理想化
次のうち、三次元ソリッド要素でのモデル化が最も必要になるのはどれか。
  1. 十分に薄く、面内の荷重だけを受ける平らな板
  2. 断面が軸まわりに一様で、軸対称な荷重を受ける円筒
  3. 板・軸対称・はりのいずれにも帰着できない、三次元的な応力状態の塊状部品
  4. 細長い一様断面の棒に、軸方向の力だけが作用する部材
正解 : 3
【基礎】まず1D/2D(平面・軸対称・シェル)に帰着できないかを検討し、どれにも当てはまらない真に三次元的な問題だけを3Dソリッドで解く。
【考え方】塊状で形状・荷重・応力が三次元的な部品は低次元化できないので3Dソリッドが必要。
【ポイント】3Dは自由度が大きく高コスト。安易に3Dにせず、帰着できる理想化がないか先に考える。
【引っかけ】①は平面応力(2D)。②は軸対称(2D)。④ははり/トラス(1D)に帰着でき3Dは不要。
8-23 薄板を平面ひずみで解く誤り 難2・平面ひずみ
面内引張応力を受ける薄い平板を、誤って平面ひずみ状態で解析した。板厚方向のひずみ $\varepsilon_z$ の扱いに関する記述として正しいのはどれか。ただしポアソン比は0でないとする。
  1. 薄板でも平面ひずみで解析すれば $\varepsilon_z$ が正しく得られる
  2. 平面ひずみでは板厚方向ひずみ $\varepsilon_z$ が最大に評価される
  3. 平面応力と平面ひずみは、薄板では同じ解になる
  4. 平面ひずみは $\varepsilon_z=0$ を強制し、薄板で本来生じる板厚方向の縮みを禁じるので実際と合わない
正解 : 4
【基礎】薄板の面内荷重は自由に板厚方向へ縮める(平面応力、$\sigma_z=0$、$\varepsilon_z\neq0$)。一方、平面ひずみは $\varepsilon_z=0$ を強制する。
【考え方】薄板に平面ひずみを当てると、本来生じる板厚方向の縮みを禁止し、余計な面外応力 $\sigma_z$ を生むため、応力・変位が実際と食い違う。
【ポイント】薄板は平面応力、奥行きの長い厚い体は平面ひずみ。選び違えると誤差になる。
【引っかけ】①薄板は平面応力が適切。②$\varepsilon_z$ は0に固定される(最大評価ではない)。③薄板では両者は一般に一致しない。
8-24 部品のばね等価化 難2・等価化
取付けボルト(直径 $d=10\,\mathrm{mm}$、長さ $L=50\,\mathrm{mm}$、$E=200\,\mathrm{GPa}$)を軸方向のばねで等価化する。ばね定数 $k=\dfrac{EA}{L}$($A=\dfrac{\pi d^2}{4}$)に最も近いのはどれか。
  1. 約 $1.3\times10^{6}\,\mathrm{N/mm}$
  2. 約 $3.1\times10^{2}\,\mathrm{N/mm}$
  3. 約 $4.0\times10^{4}\,\mathrm{N/mm}$
  4. 約 $3.1\times10^{5}\,\mathrm{N/mm}$
正解 : 4
【基礎】軸荷重を受ける棒の軸剛性は $k=\dfrac{EA}{L}$。細部の形状を作らずばね1本で表すのが等価化。
【計算】まず断面積 $A=\dfrac{\pi\times10^2}{4}\approx78.5\,\mathrm{mm^2}$。$E=200\,\mathrm{GPa}=2\times10^{5}\,\mathrm{N/mm^2}$。$k=\dfrac{2\times10^{5}\times78.5}{50}\approx3.14\times10^{5}\,\mathrm{N/mm}$。
【ポイント】面積→剛性の2段階。単位はmm-N系で $E$ を $\mathrm{N/mm^2}$ に直してから代入する。
【引っかけ】① $A=\pi d^2$ と $1/4$ を忘れた($\approx1.3\times10^{6}$)。② $E$ をGPaのまま(200)入れた($\approx3.1\times10^{2}$)。③ 断面積を $A=d$ と誤った($\approx4.0\times10^{4}$)。

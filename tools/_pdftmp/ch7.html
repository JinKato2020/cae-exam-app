第7章 要素テクノロジーの基礎

CAE計算力学技術者 固体力学2級・オリジナル問題（問題／解答／解説／図）
7-1 要素の分類 難1・要素の分類
有限要素は一般に構造要素と連続体要素に大別される。要素の分類の組み合わせとして正しいものはどれか。
  1. 構造要素:トラス・はり・シェル / 連続体要素:平面要素・三次元ソリッド要素
  2. 構造要素:トラス・はり・平面要素 / 連続体要素:シェル・三次元ソリッド要素
  3. 構造要素:トラス・シェル・三次元ソリッド要素 / 連続体要素:はり・平面要素
  4. 構造要素:はり・平面要素・三次元ソリッド要素 / 連続体要素:トラス・シェル
正解 : 1
【基礎】構造要素は、はり理論や板・シェル理論など構造力学的な仮定(断面の剛性を1本の軸線や1枚の中立面に集約するなど)を取り込んだ要素で、トラス・はり・シェルが該当します。連続体要素はそうした仮定を置かず、応力・ひずみを三次元(または二次元)の連続体としてそのまま扱う要素で、平面要素・三次元ソリッド要素が該当します。
【考え方】『断面や厚さ方向の挙動を理論で簡略化しているか』が分かれ目です。シェル要素は面外方向を薄板理論で簡略化しているので構造要素、ソリッド要素は簡略化せず要素形状の中で直接三次元応力を解くので連続体要素です。
【ポイント】構造要素=トラス・はり・シェル(理論内蔵)、連続体要素=平面要素・三次元ソリッド要素(理論の簡略化なし)。
【引っかけ】2はシェルと連続体要素を取り違え、逆に平面要素を構造要素側に入れた誤り。3はソリッド要素を構造要素側に、はりを連続体要素側に入れ違えた誤り。4はトラス・シェルを連続体要素側に、はり・平面要素・ソリッドを構造要素側にほぼ丸ごと取り違えた誤り。
7-2 トラス要素の特徴 難1・トラス要素
トラス要素の力学的特徴として正しいものはどれか。
  1. 軸力に加えてせん断力も伝えるが、曲げモーメントは伝えない。
  2. 両端がピン結合として扱われ、部材軸方向の引張・圧縮力のみを伝える。節点は回転を拘束されないため曲げモーメントは生じない。
  3. 節点に回転自由度をもち、はり要素と同様に曲げモーメントを両端に伝達できる。
  4. 軸方向の力は伝えず、もっぱら面外のねじりモーメントを伝達する部材である。
正解 : 2
【基礎】トラス要素は両端がピン(自由に回転)で結ばれた棒を模した要素で、部材軸方向の引張・圧縮力だけを伝えます。
【考え方】節点が回転自由(回転自由度をもたない)なので、曲げモーメントは伝わりません。せん断力も、部材軸に直交する力を両端のピンで保持できないため伝わりません。トラス構造は各部材が軸力のみを負担するという理想化に対応します。
【ポイント】トラス=軸力のみ。せん断力・曲げモーメントを扱いたいならはり要素を使う。
【引っかけ】1はせん断力まで伝えるとする誤り(せん断力も伝わらない、軸力のみ)。3は回転自由度をもち曲げを伝えるとする誤り(それははり要素の特徴)。4はねじりを主に伝えるとする誤り(トラスは軸力専用で、ねじりも伝えない)。
7-3 はり要素の節点未知量 難2・はり要素
一般的なはり要素が各節点にもつ未知量(節点自由度)として正しいものはどれか。
  1. 変位(たわみ)と曲げモーメントを未知数とする。
  2. 変位(たわみ)とせん断力を未知数とする。
  3. 変位(たわみ)とたわみ角(回転角)を未知数とする。
  4. 変位(たわみ)と曲率を未知数とする。
正解 : 3
【基礎】はり要素は曲げを扱う構造要素で、各節点にたわみ(横変位)とたわみ角(回転角)をもたせます。この2つを未知数にすることで、要素間でたわみだけでなく傾きも連続に接続できます。
【考え方】曲げモーメント・せん断力・曲率はいずれも、たわみ・たわみ角から材料則や微分で求まる『結果量』であって、節点未知量そのものではありません。未知数はあくまで変位に関する量(たわみと回転)です。
【ポイント】はり要素の節点自由度=たわみ+たわみ角。角度まで連続にするのが曲げ要素の特徴。
【引っかけ】1の曲げモーメントは、たわみ角の勾配(曲率)に比例する結果量で節点未知数ではない。2のせん断力も同様に結果量。4の曲率はたわみ角をさらに微分した結果量で、これも節点未知数ではない。
7-4 シェル要素とソリッド要素の自由度 難3・要素の節点自由度
シェル要素とソリッド(三次元連続体)要素の節点自由度の違いについて、最も適切な記述はどれか。
  1. シェル要素・ソリッド要素とも並進自由度のみをもち、回転自由度は一切もたない。
  2. ソリッド要素も曲げを扱うため、各節点に回転自由度をもつ。
  3. シェル要素は面の法線まわりの回転(ドリリング自由度)を主要な未知数としてもち、面内の曲げ回転はもたない。
  4. シェル要素は面外方向の並進と面に沿う2方向の曲げ回転を節点自由度にもつのが一般的で、面の法線まわりの回転(ドリリング自由度)は通常の定式化では明示的な未知数に含めない。ソリッド要素は並進自由度のみで回転自由度をもたない。
正解 : 4
【基礎】シェル要素は薄板・曲面を1枚の中立面で近似する構造要素で、各節点に並進(3方向)に加え、面に沿う2方向の曲げ回転(たわみ角に相当)を未知数としてもつのが標準的です。面の法線まわりの回転(ドリリング自由度)は、通常の薄板理論では剛性が定義しにくく、基本定式化では未知数に含めません。
【考え方】一方ソリッド要素は、はり・シェルのような断面理論を用いず要素内部の変位場をそのまま三次元で内挿するため、節点は並進自由度のみをもち、回転自由度をもちません。曲げに相当する挙動は、複数の節点の並進変位の分布(厚さ方向に複数層の節点を置く、あるいは高次要素を使う)で表現します。
【ポイント】シェル=並進+面内2方向の曲げ回転(ドリリングは基本は含まない)、ソリッド=並進のみで回転自由度なし、と対応させて覚える。
【引っかけ】1はシェルも回転自由度をもたないとする誤り(シェルは曲げ回転をもつ)。2はソリッドが回転自由度をもつとする誤り(ソリッドの曲げは並進変位の分布で表現し、節点回転は未知数にしない)。3はドリリング自由度を主要未知数とし曲げ回転をもたないとする誤り(標準的なシェル要素は逆で、曲げ回転が主要未知数)。
7-5 形状関数の性質 難2・形状関数
有限要素の形状関数 $N_i$ の基本的な性質として正しいものはどれか。
  1. 各 $N_i$ は自分の節点で1、他の節点で0となり、全形状関数の和は1($\sum N_i=1$)である。
  2. 各 $N_i$ は要素内の位置によらず同じ一定値をとる。
  3. 全形状関数の和は節点数に等しい。
  4. $N_i$ は負の値をとることはない。
正解 : 1
【基礎】形状関数 $N_i$ は、節点 $i$ の量を要素内へ広げる重み関数です。定義上、自分の節点では $N_i=1$、他の節点では $N_i=0$(クロネッカーのデルタ性)を満たします。
【考え方】剛体的に全節点を同じだけ動かしたとき、要素内も同じだけ動く必要があります。これを保証するのが『和が1』の条件 $\sum N_i=1$(単位分割・partition of unity)です。
【ポイント】$N_i(\text{自節点})=1$、$N_i(\text{他節点})=0$、$\sum N_i=1$ の3点セット。この性質から剛体運動・一定ひずみが正しく表せます。
【引っかけ】2は $N_i$ が一定値とする誤り(位置で変化する)。3は和が節点数に等しいとする誤り(和は常に1)。4は負の値をとることはないとする誤り(1次要素の $N_i$ は要素内で $0\sim1$ の範囲だが、8節点四辺形など高次要素の隅節点の形状関数は要素内の一部で負の値をとり得る)。
7-6 FEM解の連続性 難2・解の連続性
通常よく用いられる変位法に基づく有限要素法(C0要素)による応力解析で得られる解の連続性について、最も適切な記述はどれか。
  1. 変位・ひずみ・応力のすべてが要素内・要素間で連続である。
  2. 変位は要素内・要素間で連続だが、ひずみと応力は要素間では一般に不連続になる。
  3. 変位とひずみは連続だが、応力だけが要素間で不連続になる。
  4. 要素内部でも変位が節点ごとに不連続に飛ぶ。
正解 : 2
【基礎】変位法FEMは、節点変位を未知数として要素ごとに形状関数で変位を内挿します。隣り合う要素は節点を共有するので、変位は境界(辺)をまたいでも連続に保たれます。
【考え方】ひずみは変位の微分、応力はさらにひずみに比例する量です。要素ごとに別々の形状関数で内挿しているため、微分した量(ひずみ・応力)は要素の境界で値がそろわず、一般に段差(不連続)が生じます。要素内部では形状関数自体が連続なので、変位もひずみも応力も連続です。
【ポイント】『変位=連続、その微分(ひずみ・応力)=要素間で不連続』が基本。要素間の応力の食い違いが小さいほどメッシュが十分細かい目安になります(応力平滑化・平均化で表示することが多い)。
【引っかけ】1はすべて連続とする誤り(微分量は要素間で段差が出る)。3は『ひずみは連続で応力だけ不連続』とする誤り(ひずみの時点で不連続、応力だけの問題ではない)。4は要素内部でも変位が不連続とする誤り(節点未知数と形状関数により要素内部の変位は連続)。
7-7 熱伝導の連続性 難2・熱伝導の連続性
有限要素法で熱伝導解析を行うとき、辺を共有する要素間の温度および熱流束の連続性について正しいものはどれか。
  1. 温度も熱流束もともに連続である。
  2. 温度も熱流束もともに不連続である。
  3. 温度は連続だが、熱流束は一般に不連続である。
  4. 温度は不連続だが、熱流束は連続である。
正解 : 3
【基礎】熱伝導解析では場の量が温度 $T$ です。要素は節点温度を共有するので、辺を共有する要素間で温度は連続になります。
【考え方】熱流束はフーリエの法則 $q=-k\,\nabla T$ のように温度の勾配(微分)で決まります。温度を要素ごとに別々の形状関数で内挿しているため、微分した熱流束は要素境界で一般にそろわず不連続になります。構造解析の『変位=連続、ひずみ・応力=不連続』と同じ構図です。
【ポイント】場の値(温度)は連続、その勾配・流束(熱流束)は要素間で不連続、と対応で覚える。
【引っかけ】1は熱流束まで連続とする誤り(勾配量は段差が出る)。2は温度まで不連続とする誤り(温度は節点共有で連続)。4は温度と熱流束の連続・不連続を逆にした誤り。
7-8 定ひずみ三角形要素 難2・3節点三角形要素
3節点三角形要素(線形三角形要素)を用いた二次元応力解析における、要素内のひずみ・応力の分布について最も適切なものはどれか。
  1. 要素内でひずみは二次関数的に分布する。
  2. 要素内で応力は節点ごとに大きく異なる値を示す。
  3. 3節点三角形要素は純粋な曲げを要素1個で精度よく表現できる。
  4. 要素内でひずみ・応力はいずれも一定値になる(定ひずみ要素)。
正解 : 4
【基礎】3節点三角形要素は、要素内の変位を $u=a_0+a_1 x+a_2 y$ のように座標の一次式(線形)で仮定します。
【考え方】ひずみは変位の微分 $\varepsilon_x=\partial u/\partial x=a_1$ などになり、一次式を微分すると定数になります。よって要素内のどの点でもひずみ(したがって応力)は一定です。これを定ひずみ要素(CST: Constant Strain Triangle)と呼びます。
【ポイント】CST=要素内ひずみ・応力一定。応力勾配の大きい場所では細かく分割しないと精度が出ません。
【引っかけ】1は二次分布とする誤り(線形変位なので微分は定数)。2は節点ごとに応力が大きく異なるとする誤り(そもそも要素内は一様な定数で、節点の位置による違いという概念自体が当てはまらない)。3は曲げを1要素で精度よく表現できるとする誤り(定ひずみでは曲げの応力勾配(高さ方向の直線分布)を1要素内で表せず、多数の層に分割しないと精度が出ない)。
7-9 定ひずみ要素のεxと限界 難3・3節点三角形要素
3節点三角形要素の節点を $A(0,0)$、$B(5,0)$、$C(0,4)$ とし、$x$ 方向変位を要素内で $u=a_0+a_1x+a_2y$ と表す。各節点の $x$ 方向変位が $u_A=0.008$、$u_B=0.033$、$u_C=0.020$ mm(座標の単位は mm)のとき、この要素の $\varepsilon_x$ の値と、この結果から言えることの組み合わせとして最も適切なものはどれか。
  1. $\varepsilon_x=0.005$。この要素は内部で一定のひずみしか表現できないため、要素の内部に応力集中のような急な勾配があっても最大値までは再現できず、局所的なピークを捉えるにはさらに要素を細分する必要がある。
  2. $\varepsilon_x=0.003$($y_C=4$ と $u_C$ から決まる $y$ 方向の勾配 $a_2$ を $\varepsilon_x$ と取り違えた値)。この要素は応力集中部でも十分な精度が得られるため、追加の細分は不要である。
  3. $\varepsilon_x=0.007$($u_B$ を $x_B$ で割っただけで $u_A$ を引き忘れた値)。この要素1個の結果から、要素内部の応力の最大値と最小値の両方を正確に読み取れる。
  4. $\varepsilon_x=0.008$(節点 $A$ の変位 $u_A$ をそのまま $\varepsilon_x$ とした値)。要素の変位が節点で一致していれば、ひずみの分布形状まで自動的に正確に再現される。
正解 : 1
【基礎】定ひずみ要素では $\varepsilon_x=\partial u/\partial x=a_1$ で、要素内一定です。係数 $a_1$ は $x$ 方向に並ぶ節点($A$ と $B$)の変位差から決まり、$y$ 方向の情報($C$)には依存しません。
【考え方】$A(0,0)$ で $u_A=a_0$、$B(5,0)$ で $u_B=a_0+5a_1$ なので $a_1=(u_B-u_A)/5$。一方 $C(0,4)$ で決まる $a_2=(u_C-u_A)/4$ は $y$ 方向の勾配で $\varepsilon_x$ には無関係です。CSTは要素内で1つの定数しか持てないため、要素の中に応力が急変する領域(応力集中など)があっても、その急変を表現できず、平均的な一定値しか得られません。
【計算】$a_1=(0.033-0.008)/5=0.025/5=0.005$。よって $\varepsilon_x=0.005$。検算として $a_2=(0.020-0.008)/4=0.012/4=0.003$(これは $\varepsilon_x$ ではなく $y$ 方向勾配)。
【ポイント】$\varepsilon_x$ は $x$ 方向に並ぶ2点の変位差を距離で割った量。さらに『CSTは要素内一定値しか表せないので、応力勾配が大きい領域は細分が要る』という限界まで押さえる。
【引っかけ】2は $a_2=0.003$ を $\varepsilon_x$ と取り違えた値の誤りに加え、応力集中部でも十分とする誤り(定ひずみでは局所ピークを表せない)。3は $u_A$ を引き忘れた計算ミス($0.033/5=0.0066\approx0.007$)に加え、1要素から最大・最小の両方が読み取れるとする誤り(定ひずみ要素は要素内で1つの値しか持たない)。4は $u_A$ をそのまま $\varepsilon_x$ とした誤りに加え、節点変位が一致すれば分布形状まで再現されるとする誤り(節点で一致するのは変位のみで、要素内部のひずみ分布形状(勾配)までは再現されない)。
7-10 アイソパラメトリック要素の定義 難2・アイソパラメトリック要素
アイソパラメトリック要素の定義として最も適切なものはどれか。
  1. 節点座標を用いず、要素の中心点だけから形状を決める要素。
  2. 座標(形状)の内挿と変位の内挿に同一の形状関数を用いる要素。
  3. 変位は二次関数で内挿し、座標は一次関数で内挿するというように、内挿の次数を変位側だけ高くする要素。
  4. 応力・ひずみを形状関数で直接定義し、変位の内挿は行わない要素。
正解 : 2
【基礎】『アイソ(iso=同一)パラメトリック』の名の通り、要素の形状(節点座標)を表す内挿と、変位を表す内挿に、同一の形状関数 $N_i$ を用いるのがアイソパラメトリック要素です。局所座標 $(\xi,\eta)$ で $x=\sum N_i x_i$、$u=\sum N_i u_i$ のように、座標と変位を同じ $N_i$ で表します。
【考え方】この工夫により、四辺形や六面体の辺を曲げて任意形状に近づけつつ、変位場もその形状に合わせて滑らかに定義できます。座標の次数と変位の次数をわざと変える要素(サブパラメトリック・スーパーパラメトリック要素)もありますが、それらはアイソパラメトリックとは呼びません。
【ポイント】アイソパラメトリック=座標と変位を同一の $N_i$ で内挿。これにより曲線境界と滑らかな変位場を両立できる。
【引っかけ】1は中心点だけから形状を決めるとする誤り(節点座標と形状関数で形状を決める)。3は変位側だけ次数を高くするとする誤り(座標と変位を異なる次数にするのはサブパラメトリック要素の考え方で、アイソパラメトリックの定義ではない)。4は変位を内挿しないとする誤り(変位法FEMでは変位が主たる未知数であり、必ず内挿する)。
7-11 8節点要素と円弧境界 難2・アイソパラメトリック要素
形状の一部に円弧を含む薄板の平面応力解析を、8節点四辺形アイソパラメトリック要素で行う。円弧境界の表現に関する記述として最も適切なものはどれか。
  1. 中間節点を隣り合う頂点の直線中点に置くだけで、円弧は自動的に精度よく表現される。
  2. 8節点要素でも辺は直線でしか表せないので、円弧境界は表現できない。
  3. 8節点要素は二次形状関数をもつので、中間節点を円弧上に配置すれば曲線境界を精度よく表現でき、同じ形状関数で変位も内挿する。
  4. 座標の内挿には一次関数、変位の内挿には二次関数というように、次数の異なる形状関数を組み合わせて使うのがアイソパラメトリック要素の標準的な定義である。
正解 : 3
【基礎】8節点四辺形は辺の中点にも節点をもつ二次要素で、辺を二次曲線として表せます。アイソパラメトリック要素なので、座標(形状)も変位も同一の形状関数で内挿します。
【考え方】中間節点を実際の円弧上に配置してはじめて、辺の二次曲線が円弧に沿います。中間節点を直線の中点に置いてしまうと辺は直線に近いままで、円弧はうまく近似できません。
【ポイント】8節点は二次で曲線を表せる+中間節点を円弧上に置く、の両方が必要。座標と変位は同じ関数(アイソパラ)。
【引っかけ】1は直線中点に置けば自動的に精度よく表現されるとする誤り(中点配置では辺はほぼ直線のままで、円弧上に置く必要がある)。2は曲線を表せないとする誤り(二次形状関数で辺を曲線として表せる)。4は座標と変位で次数の異なる関数を組み合わせるのが標準的な定義とする誤り(それはサブパラメトリック要素の考え方で、アイソパラメトリックは同一次数の関数を使う)。
7-12 ヤコビ行列式の意味 難2・ヤコビアン
アイソパラメトリック要素で用いるヤコビ行列式 $\det J$ の意味として最も適切なものはどれか。
  1. $\det J$ は要素の材料剛性(ヤング率)を表す量である。
  2. $\det J$ は要素の辺の長さの単純な平均で決まり、要素の形状(ゆがみ)には左右されない。
  3. $\det J$ が負になった場合でも、要素の変位場の精度には影響するが応力の計算結果自体は正しい値が得られる。
  4. $\det J$ は局所座標から全体座標への面積(体積)の拡大率を表し、要素が過度にゆがむと $\det J$ が0以下になり得て、そこでは写像が一対一に対応しなくなり計算が破綻する(要素として不正)。
正解 : 4
【基礎】ヤコビ行列 $J$ は、正規化した局所座標 $(\xi,\eta)$ の微小変化を全体座標 $(x,y)$ の微小変化へ換算する行列で、$dx\,dy=\det J\,d\xi\,d\eta$ の関係があります。
【考え方】$\det J$ は面積(3次元なら体積)の拡大率です。正常な要素では要素内のどこでも $\det J>0$。要素が極端にゆがむ・つぶれる・裏返ると、局所座標から全体座標への対応が1対1でなくなり、$\det J$ が0以下になります。この点では被積分関数が定義できず、剛性行列の数値積分そのものが破綻し、変位だけでなく応力を含む解全体が信頼できなくなります。
【ポイント】$\det J$ は面積・体積の倍率。全要素・全積分点で正であることが要素品質の条件。
【引っかけ】1は材料剛性とする誤り(幾何学的な写像の量で、材料定数とは無関係)。2は辺の長さの平均で決まり形状に左右されないとする誤り(実際には要素のゆがみ方によって $\det J$ は場所ごとに変化する)。3は負になっても応力は正しく求まるとする誤り(写像が破綻すると積分自体が成立しなくなり、変位・応力とも信頼できる値は得られない)。
7-13 ヤコビ行列式の計算と妥当性判定 難3・ヤコビアン
$x$ 方向の長さが8、$y$ 方向の長さが6の長方形要素を、局所座標 $-1\le\xi,\eta\le 1$ に写像した。ヤコビ行列式 $\det J$ の値と、この結果から言えるこの要素の妥当性判定の組み合わせとして最も適切なものはどれか。
  1. $\det J=12$。この長方形要素はゆがみのない軸平行な形状であり、位置によらず一定の正の値をとるため、妥当な要素(不正要素ではない)と判定できる。
  2. $\det J=24$(片方の辺で局所座標の全幅2ではなく辺の長さ8をそのまま使った計算)。値が正であれば要素の形状によらず高い解析精度が保証される。
  3. $\det J=48$(実際の要素面積48をそのまま $\det J$ とした計算)。$\det J$ は局所→全体の写像とは無関係に要素の面積そのものを表す量である。
  4. $\det J=3$(局所座標の幅を2ではなく4として計算した値)。この程度の小さい値は、それだけで要素が過度に押しつぶされていることを示す。
正解 : 1
【基礎】長方形要素は軸が平行なのでヤコビ行列 $J$ は対角行列になり、$\det J=\dfrac{\partial x}{\partial\xi}\cdot\dfrac{\partial y}{\partial\eta}$ です。局所座標は各方向とも幅2($-1$ から $1$)。
【考え方】$\partial x/\partial\xi=8/2=4$、$\partial y/\partial\eta=6/2=3$。長方形要素(軸平行・辺が直線)ではこの比が要素内のどこでも同じなので、$\det J$ は要素内で一定の正の値になります。$\det J$ の符号が正で位置によらず変わらないことは、この要素が不正要素(写像が裏返る・つぶれる要素)ではないことを意味します。
【計算】$\det J=4\times3=12$。検算:実面積 $8\times6=48$、局所面積 $2\times2=4$、比は $48/4=12$ で一致。
【ポイント】$\det J$ は『実面積 ÷ 局所面積』の拡大率。符号(正か0以下か)が妥当性(不正要素かどうか)を決め、大きさそのものは妥当性の判定基準ではない(大きさは実際の寸法に依存するだけ)。
【引っかけ】2は片辺で局所座標幅2で割るのを忘れた計算ミス($8\times3=24$)に加え、値が正なら形状によらず高精度が保証されるとする誤り(精度はアスペクト比・ゆがみにも左右される)。3は実面積48をそのまま $\det J$ とした誤りに加え、$\det J$ を写像と無関係な面積そのものとする誤り(局所座標系での面積との比で決まる量)。4は局所座標幅を4と誤った計算($8/4\times6/4=3$)に加え、値が小さいこと自体が押しつぶれを示すとする誤り(この長方形要素はゆがみがなく妥当であり、小さい値それ自体は不正要素の証拠にはならない)。
7-14 完全積分の積分点数 難2・数値積分
(a) 双一次4節点四辺形要素、(b) 三次元8節点六面体要素、それぞれの剛性行列を標準的なガウス積分で完全積分するときの積分点の総数の組み合わせとして正しいものはどれか。
  1. (a) 4点(2×2)、(b) 4点(2×2)
  2. (a) 4点(2×2)、(b) 8点(2×2×2)
  3. (a) 1点、(b) 8点
  4. (a) 9点(3×3)、(b) 27点(3×3×3)
正解 : 2
【基礎】要素剛性行列は積分で計算し、実務では多項式を効率よく厳密積分できるガウス求積を用います。1次元 $n$ 点ガウス求積は $2n-1$ 次までの多項式を厳密に積分できます。
【考え方】双一次4節点要素・8節点六面体要素とも、辺方向の補間は双一次(各方向1次)で、剛性の被積分項は各方向2次程度なので、各方向2点(2次まで厳密)あれば足ります。二次元では $2\times2=4$ 点、三次元では $2\times2\times2=8$ 点が完全積分です。
【ポイント】完全積分の点数は『各方向のガウス点数の積』。4節点四辺形=2×2=4点、8節点六面体=2×2×2=8点(いずれも1次補間の要素)。3×3=9点や3×3×3=27点は、二次(8節点四辺形・20節点六面体など)の完全積分に必要な点数で、今回の4節点・8節点(1次)要素には過剰。
【引っかけ】1は(b)を二次元と同じ4点にした誤り(三次元では方向が1つ増えるので $2\times2\times2=8$ 点が必要)。3は(a)を次数低減積分の1点にした誤り(完全積分ではない)。4は8節点・20節点相当の二次要素向けの点数(9点・27点)を、今回の1次要素に当てはめた誤り。
7-15 次数低減積分 難3・数値積分
有限要素解析における次数低減積分(reduced integration)についての記述として最も適切なものはどれか。
  1. 完全積分よりも積分点数を増やし、計算コストを上げてでも精度を高める手法である。
  2. 積分点を減らすと計算は軽くなるが、精度への影響は要素の種類や変形モードによらずおおむね一様に現れる。
  3. せん断ロッキングや体積ロッキングを緩和する効果がある一方、積分点が不足すると砂時計モード(偽のゼロエネルギー変形)を招く恐れがある。
  4. 積分点を減らす目的は数値積分の丸め誤差を消すことにあり、ロッキング現象とは無関係である。
正解 : 3
【基礎】次数低減積分は、完全積分より少ない積分点で要素剛性を評価する手法です。
【考え方】積分点を減らすと計算が軽くなるうえ、低次要素が曲げで過剛になるせん断ロッキングや、非圧縮での体積ロッキングを緩和できる利点があります。反面、積分点が少なすぎると、その点でひずみエネルギーを生じない偽の変形(砂時計モード)を許してしまう欠点があります。効果は一様ではなく、曲げ変形やほぼ非圧縮な変形では大きな改善になる一方、要素の変形モードによっては砂時計モードという副作用が顕在化します。
【ポイント】次数低減積分=軽い+ロッキング緩和、ただし砂時計モードに注意(砂時計制御で対策)。
【引っかけ】1は積分点を増やす手法とする誤り(実際には減らす)。2は精度への影響が要素・変形モードによらず一様とする誤り(曲げでは有利に働く一方、変形モードによっては砂時計モードという顕著な副作用が出るなど、一様ではない)。4は丸め誤差の解消が目的でロッキングと無関係とする誤り(狙いはロッキング緩和と計算コスト削減)。
7-16 せん断ロッキング 難3・要素のロッキング
低次(双一次4節点)完全積分要素を曲げの解析に用いたときに生じる、せん断ロッキングの説明として最も適切なものはどれか。
  1. 曲げ剛性を過小評価してたわみを過大評価する。
  2. 高次要素ほどせん断ロッキングが顕著に悪化する。
  3. 引張のみで生じ、曲げでは生じない。
  4. 辺が変形後も直線のままなので寄生的なせん断ひずみを生じ、曲げ剛性を過大評価してたわみを過小評価する。
正解 : 4
【基礎】双一次要素の辺は変形しても直線のままです。本来の曲げでは辺は円弧状に曲がるべきなので、そのズレが余分なせん断ひずみ(寄生せん断)として現れます。
【考え方】余分なせん断ひずみは要素を実際より硬くします。その結果、曲げ剛性を過大評価し、計算されるたわみは実際より小さく(過小評価)なります。これがせん断ロッキングです。
【ポイント】せん断ロッキング=低次要素の曲げで過剛+たわみ過小。次数低減積分・非適合要素・高次要素で対策する。
【引っかけ】1は剛性過小・たわみ過大とする逆の誤り。2は高次要素ほど悪化するとする誤り(高次要素や次数低減積分・非適合要素はむしろロッキングを改善する対策になる)。3は引張のみで生じるとする誤り(せん断ロッキングは曲げ変形で顕著に生じ、単純な引張では問題にならない)。
7-17 体積ロッキング 難3・要素のロッキング
体積ロッキング(volumetric locking)が起こりやすい条件と対策として最も適切なものはどれか。
  1. 非圧縮に近い材料(ポアソン比が0.5に近いゴムや塑性変形時など)で低次完全積分要素が体積一定条件により過剰拘束され、要素が過度に硬くなる。次数低減積分や混合(u/p)要素などで緩和する。
  2. 圧縮性の高い材料ほど激しく起こる現象で、対策を講じる必要は乏しい。
  3. ポアソン比が0.5よりも0に近いときに最も激しく起こる現象である。
  4. 低次要素であっても、ポアソン比0.3程度の一般的な金属材料であれば、非圧縮材料と同程度に顕著な体積ロッキングを生じる。
正解 : 1
【基礎】ゴムや塑性域の金属のように体積がほとんど変わらない(非圧縮に近い)材料では、要素が『体積一定』という強い条件を各積分点で満たそうとします。
【考え方】低次の完全積分要素は自由度が少ないため、この体積一定条件で自由度が使い尽くされ過剰に拘束されます。結果として要素が異常に硬くなり、変形が出なくなります。これが体積ロッキングで、ポアソン比が0.5に近いほど顕著です。0.3程度の一般的な金属材料は非圧縮からまだ離れており、この現象はほとんど問題になりません。
【ポイント】体積ロッキング=非圧縮に近い材料(ν→0.5)+低次完全積分で過剛。次数低減積分・B-bar法・混合(u/p)要素で対策。
【引っかけ】2は圧縮性材料で激しいとする誤り(非圧縮側で起こる現象で、対策も必要)。3はポアソン比0近傍で最も激しいとする誤り(0.5近傍で激しい、逆側)。4はν=0.3の一般的な金属で非圧縮材料と同程度に顕著とする誤り(0.5から離れているため体積ロッキングは目立たない)。
7-18 砂時計モード 難3・砂時計モード
1点(次数低減)積分要素に現れる砂時計モード(hourglass mode)についての記述として最も適切なものはどれか。
  1. 完全積分要素で主に問題になる変形モードである。
  2. 1点(次数低減)積分の積分点でひずみエネルギーを生じない変形モードで、砂時計制御(スタビライゼーション)や要素分割の見直しなどで抑える。
  3. 材料を硬くする(ヤング率を上げる)と、この変形モードによる変位も比例して小さくなり実質的に解消する。
  4. 要素の体積変化(圧縮・膨張)として現れる現象で、体積ロッキング対策と同じ手法だけで対処できる。
正解 : 2
【基礎】砂時計モードは、1点積分などの次数低減積分で、その積分点においてひずみ(したがってひずみエネルギー)を生じないのに実際には変形している、偽のゼロエネルギー変形モードです。名前は要素が砂時計状にくびれる形に由来します。
【考え方】剛性が働かない変形なので、放置すると解が乱れて非物理的な網目状の変形が出ます。砂時計制御(人工的な安定化剛性)や、完全積分・十分な要素分割で抑えます。この変形モードはひずみを生じない(ひずみエネルギーがゼロ)ことが本質なので、材料剛性(ヤング率)をいくら上げても、その方向の剛性自体が働かず抑制されません。また、要素が体積一定で過拘束される体積ロッキングとは発生の仕組みが異なる別の現象で、対策の考え方(スタビライゼーション vs 混合要素・次数低減)も異なります。
【ポイント】砂時計モード=次数低減積分の副作用(ゼロエネルギー変形)。砂時計制御で対策。ヤング率を上げても消えない点、体積ロッキングとは別現象である点に注意。
【引っかけ】1は完全積分で主に問題になるとする誤り(次数低減積分・特に1点積分で問題になる)。3は材料を硬くすれば解消するとする誤り(ひずみを生じないモードなので材料剛性は効かない)。4は体積ロッキングと同じ現象・同じ対策とする誤り(体積一定条件による過拘束とゼロエネルギー変形は別の現象で、対策も異なる)。
7-19 要素のアスペクト比と品質 難2・要素品質
要素の形状(アスペクト比・ゆがみ)と解析精度の関係として最も適切なものはどれか。
  1. アスペクト比は大きい(細長い)ほど精度が良い。
  2. 要素のゆがみは精度に無関係である。
  3. アスペクト比が1に近く、ゆがみ(スキュー・テーパ)が小さいほど精度が良く、細長い・ゆがんだ要素は特に応力や曲げで精度を落とす。
  4. 要素形状は精度に関係せず、要素数だけで精度が決まる。
正解 : 3
【基礎】アスペクト比は要素の縦横比(理想は1)、ゆがみは要素が長方形・立方体からどれだけ崩れているか(スキュー=傾き、テーパ=先すぼまり)を表す指標です。
【考え方】細長い要素やゆがんだ要素では、ヤコビアンが場所によって大きく変わり、形状関数による近似が悪くなります。特に応力集中部や曲げでは誤差が増えます。品質の良い要素はアスペクト比が1に近く、内角が直角に近いものです。
【ポイント】アスペクト比→1、ゆがみ小、が高精度の条件。
【引っかけ】1はアスペクト比が大きいほど良いとする逆の誤り。2はゆがみが精度に無関係とする誤り(ヤコビアンの偏りを通じて精度に影響する)。4は形状が精度に無関係で要素数だけで決まるとする誤り(同じ要素数でも形状で精度は大きく変わる)。
7-20 六面体と四面体要素 難2・要素選択
三次元ソリッド解析で六面体要素と四面体要素を選ぶ際の一般的な判断として、最も適切なものはどれか。
  1. 一次四面体要素は、六面体要素よりも同じ要素数で高い曲げ精度が得られる傾向がある。
  2. 六面体要素は複雑形状でも人手をかけずに自動生成しやすいため、四面体要素より優先して使うべきである。
  3. 要素形状(四面体か六面体か)は計算時間だけに影響し、解析精度には影響しない。
  4. 一次四面体要素は曲げに対して剛くなりやすく精度が劣る傾向があるが、複雑形状の自動メッシュ生成に向く。精度が必要なら六面体要素や二次(10節点)四面体要素を用いる。
正解 : 4
【基礎】三次元では六面体(ヘキサ)と四面体(テトラ)がよく使われます。一次四面体は自由度あたりの表現力が低く、曲げでは剛くなりがちで精度が劣ります。
【考え方】一方、四面体は任意形状を自動で埋めやすく、複雑形状のメッシュ生成に向きます。精度が必要なら、規則的に並べれば高精度な六面体を使うか、四面体でも中間節点をもつ二次(10節点)四面体を使うのが定石です。逆に六面体要素は規則的な形状では高精度ですが、複雑形状に対する自動メッシュ生成は四面体より難しく、人手での調整が必要になりがちです。
【ポイント】複雑形状=四面体(自動メッシュ)、高精度=六面体または二次四面体。
【引っかけ】1は一次四面体が六面体より曲げ精度が高いとする誤り(実際は逆で、一次四面体は曲げに弱い)。2は六面体が複雑形状でも自動生成しやすいとする誤り(六面体の自動メッシュ生成は四面体より難しい)。3は要素形状が精度に無関係とする誤り(要素の種類は精度にも大きく影響する)。
7-21 要素数一定の精度と時間 難2・要素次数と精度
ある領域を一次要素と高次要素で解析する。要素数が同じ場合の、解の精度と解析時間の関係として最も妥当なものはどれか。
  1. 一般に高次要素の方が精度は良いが、節点(自由度)が増えるため解析時間は増大する。
  2. 一般に一次要素の方が精度が良く、一次要素の方が解析時間も増大する。
  3. 解の精度は要素の種類に無関係で同程度だが、高次要素の方が解析時間だけ増大する。
  4. 一般に高次要素の方が精度は良いが、解析時間は要素の種類によらずほぼ同じである。
正解 : 1
【基礎】高次要素は要素あたりの節点数が多く、辺を曲線で表せるなど表現力が高いので、同じ要素数なら一般に精度が上がります。
【考え方】ただし要素数が同じでも、高次要素は節点(自由度)が増えるため、連立方程式の規模が大きくなり計算量・解析時間は増えます。精度と時間はトレードオフです。
【ポイント】要素数が同じ ⇒ 高次の方が精度良、しかし自由度増で時間増、が基本。
【引っかけ】2は一次の方が精度良いとする誤り(高次が有利)。3は精度が要素種類に無関係とする誤り(種類で精度は変わる)。4は解析時間が要素種類によらずほぼ同じとする誤り(これは『節点数(自由度)が同じ場合』の話と混同したトラップで、『要素数が同じ場合』は高次の方が自由度が多く時間が増える)。
7-22 節点数一定の精度と時間 難2・要素次数と精度
同じ領域を一次要素と高次要素で解析する。総節点数(自由度)がほぼ同じになるように分割した場合の、精度と解析時間の関係として最も妥当なものはどれか。
  1. 一般に一次要素の方が精度が良い。
  2. 一般に高次要素の方が精度は良く、総自由度がほぼ同じなので解析時間は大きくは変わらない。
  3. 高次要素は精度も解析時間も一次要素より劣る。
  4. 解の精度は要素の種類に無関係で決まる。
正解 : 2
【基礎】解析時間は主に総自由度(総節点数)で決まります。高次要素は要素あたりの節点が多い分、少ない要素数で同じ総自由度に到達します。
【考え方】総自由度をそろえれば連立方程式の規模はほぼ同じなので、解析時間は大きくは変わりません。一方、同じ自由度でも高次要素の方が変位場をなめらかに表せるため精度は良くなる傾向です。
【ポイント】節点数(自由度)をそろえる比較では、高次の方が精度良・時間はほぼ同等、が妥当。
【引っかけ】1は一次が精度良いとする誤り(自由度をそろえた比較では高次が有利)。3は高次が時間も精度も劣るとする誤り(自由度をそろえれば時間はほぼ同等で、精度は高次が有利)。4は精度が要素種類に無関係とする誤り(同じ自由度でも要素の次数で精度は変わる)。
7-23 4節点と8節点の曲げ精度 難2・要素次数と精度
片持ちはりの曲げ問題を平面応力要素で解く。8節点(二次)要素では高さ方向4分割・長さ方向10分割、4節点(双一次)要素では高さ方向6分割・長さ方向20分割としたときの記述として最も適切なものはどれか。
  1. 4節点要素モデルの方が分割が細かいため、要素の次数の違いを考えなくても曲げ応力分布の精度で4節点モデルが上回る。
  2. 8節点要素は一次要素と同等の表現力しかもたないため、分割が細かい4節点モデルの方が有利である。
  3. 8節点(二次)要素は高さ方向に線形変化する曲げ応力を1要素内で表現できるため、粗い8節点分割でも細かい4節点分割に匹敵、またはそれを上回る曲げ精度が得られる。
  4. 8節点要素で4節点要素と同等以上の精度を得るには、4節点要素と同程度まで細かく分割する必要がある。
正解 : 3
【基礎】曲げでは断面内(高さ方向)で応力が直線的に変化します。8節点二次要素は要素内で二次まで変位を表せるので、この直線的な曲げ応力を1要素の中で正しく表現できます。
【考え方】4節点(双一次・定ひずみ的)要素は要素内で応力がほぼ一定なので、高さ方向の応力変化を表すには多くの層に分ける必要があります。したがって、粗い8節点メッシュでも細かい4節点メッシュと同等以上の精度になり得ます。分割の細かさだけで単純比較できるものではなく、要素の次数(表現力)が精度を大きく左右します。
【ポイント】曲げには高次要素が効く。要素数が少なくても8節点の方が有利になり得る。
【引っかけ】1は要素の次数を考えず分割の細かさだけで4節点が上回るとする誤り(要素の次数の違いが精度を大きく左右する)。2は8節点が一次と同等の表現力とする誤り(二次形状関数で高さ方向の直線的な曲げ応力を表現できる)。4は8節点で同等の精度を得るには4節点と同程度の細かさが必要とする誤り(粗い分割でも足りることが多い)。
7-24 扁平要素と曲げ精度 難2・要素品質
厚さ一定・長さ150、高さ20の片持ち板を4節点四辺形要素で曲げ解析する。分割案(A)高さ方向3・長さ方向12分割と、(B)高さ方向12・長さ方向3分割を比べたときの記述として最も適切なものはどれか。
  1. 扁平(高アスペクト比)な要素の方が曲げをよく表せるので(B)が有利である。
  2. アスペクト比は精度に無関係なので(A)と(B)の精度は同じである。
  3. (B)は高さ方向の分割が多いので、アスペクト比によらず精度が最も高い。
  4. 扁平で高アスペクト比の要素は曲げ精度を著しく損なうため、要素がほぼ正方形に近い(A)の方が先端たわみの精度が良い。
正解 : 4
【基礎】各要素の寸法は、(A)が高さ $20/3\approx6.7$・長さ $150/12=12.5$ でアスペクト比 約2、(B)が高さ $20/12\approx1.7$・長さ $150/3=50$ でアスペクト比 約30です。
【考え方】(B)の要素は極端に細長い(高アスペクト比)ため、双一次要素のせん断ロッキングやヤコビアンの偏りが強く出て曲げ精度が大きく落ちます。(A)はほぼ正方形に近く、曲げをバランスよく表せます。高さ方向の分割数が多いこと自体は有利な材料ですが、それだけでは扁平さによる悪化を打ち消せません。
【ポイント】同じ要素数でもアスペクト比が1に近い分割の方が曲げ精度が良い。分割は高さと長さのバランスが重要。
【引っかけ】1は扁平要素が有利とする誤り(高アスペクト比は不利)。2はアスペクト比が精度に無関係とする誤り。3は高さ方向の分割数の多さだけでアスペクト比によらず精度が最も高いとする誤り((B)は高さ分割は多いが、長さ方向1要素あたりの長さが50と極端に長く全体としては高アスペクト比になり精度が落ちる)。
7-25 片持ちはりの先端たわみとFEMの収束 難3・はり理論解と収束
先端に集中荷重 $W$ を受ける片持ちはりの先端たわみは、はり理論で $\delta=\dfrac{WL^3}{3EI}$ で与えられる。$E=2\times10^{5}$ N/mm$^2$、断面二次モーメント $I=2500$ mm$^4$、長さ $L=100$ mm、荷重 $W=300$ N のとき、理論値 $\delta$ の値と、この問題を変位法FEM(適合要素)でメッシュを細かくしながら解いたときの計算値の挙動の組み合わせとして最も適切なものはどれか。
  1. $\delta=0.20$ mm。メッシュを十分細かくした変位法FEMの計算値はこれよりやや小さい値から理論値に近づいていき、理論値を超えて大きくなることはない。
  2. $\delta=0.20$ mm。メッシュを細かくするほど計算値は理論値を超えて増加し続ける。
  3. $\delta=0.60$ mm(分母の係数3を掛け忘れた値)。メッシュを細かくすると理論値へ下から近づいていく。
  4. $\delta=0.10$ mm(分母を $6EI$ とした値)。メッシュを細かくしても理論値には近づかない。
正解 : 1
【基礎】片持ちはりの先端集中荷重によるたわみは $\delta=\dfrac{WL^3}{3EI}$ です。変位法FEM(適合要素)は、仮定した形状関数の範囲でしか変形を許さないため実際よりわずかに硬めに評価する性質があり、分割を細かくするほど計算たわみは下側から理論解へ近づきます。
【考え方】分子は $WL^3$、分母は $3EI$。指数計算を丁寧に行います。
【計算】$L^3=100^3=1.0\times10^{6}$。$WL^3=300\times1.0\times10^{6}=3.0\times10^{8}$。$3EI=3\times2\times10^{5}\times2500=1.5\times10^{9}$。よって $\delta=\dfrac{3.0\times10^{8}}{1.5\times10^{9}}=0.20$ mm。この理論値に対し、変位法FEMの計算値はメッシュを細かくするほど下側(小さい側)から近づいていき、理論値を超えて発散することはありません。
【ポイント】$\delta=WL^3/3EI$。係数3を落とさないことが要点。さらに『変位法FEMは実際より硬く出る(たわみを小さく見積もる)ので、細分割しても理論値を超えない』という収束の向きまで押さえる。
【引っかけ】2は数値は正しいが、細分割で理論値を超えて増加し続けるとする誤り(変位法FEMは下側から収束し、理論値を超えない)。3は係数3を忘れて $WL^3/EI=0.60$ mmとした計算ミスの誤り(収束の向きの説明自体は正しい形をしているが、数値が誤り)。4は分母を $6EI$ とした計算ミス($0.10$ mm)に加え、メッシュを細かくしても理論値に近づかないとする誤り(適合要素は一般に理論値へ収束する)。

界面追跡・捕獲法 ― 各問の要点とキー公式

変形する気液界面を平均化せず解像して直接解く。全19問を A／B／C に整理。

A｜手法の分類と位置づけ
変形する界面を格子上で解く手法は、固定格子に界面を表す関数を移流させる界面捕獲法（VOF・レベルセット）と、固定格子上に界面要素を置いて追う界面追跡法（Front Tracking）に大別されます。いずれも界面を平均化せず解像するため混相流の直接解法と呼ばれ、格子を界面に合わせて動かすALE法とは発想が異なります。界面の厚さの扱いや、無からの気泡核生成のような多重スケール現象の難しさが各手法の特徴を決めます。

手法の大別

  • 13-1捕獲法・追跡法はどちらも固定格子が基本格子再生成は移動格子の考え　界面捕獲法／界面追跡法（Front Tracking）
  • 13-2VOFとレベルセットは扱う変数が違う固定格子で変数を移流　VOF=体積率F／Level Set=符号付き距離φ
  • 13-12直接解法と呼ばれる理由瞬時局所式を平均化せず解く　界面の跳躍条件を課す

移動格子法

  • 13-3ALE法は格子移動速度を流体と独立に定める純ラグランジュとオイラーの中間　ALE（界面形状を保ち格子の極端変形を防ぐ）

特徴と適用限界

  • 13-5界面厚さと予測できる現象Front Trackingは物性を数セルで平滑化　境界適合=厚さ零／合体は依然困難
  • 13-7最も困難な対象無からの気泡核生成は連続体法で困難　多重スケール（分子スケール）
B｜界面の数学的表現と界面力
界面を陽に扱うには、界面の位置・向き・曲率を数式で表す必要があります。相関数の勾配は界面上のデルタ関数として法線を与え、レベルセット関数の移流方程式と、その勾配の発散で平均曲率が求まります。距離関数の性質を保つ再初期化、VOFの高さ関数による曲率評価、拡散界面のCahn-Hilliard方程式、体積率から界面を復元する再構成法、界面をはさむ量のつり合いを与える跳躍条件が、この表現の道具立てです。

相関数と界面幾何

  • 13-9相関数の勾配は界面上のデルタ法線と逆向き　∇Xk = −δ nk
  • 13-10界面追跡方程式と平均曲率∂φ/∂t + u·∇φ = 0, κ = −∇·(∇φ/|∇φ|)
  • 13-11平滑化ヘビサイドの微分=平滑化デルタδε = dHε/dφ, δε(0) = 1/ε

曲率評価・再初期化

  • 13-14VOF高さ関数で界面曲率を評価|ny|>|nx|ならHyをxで微分　|κ| = |H″|/[1+(H′)²]³ᐟ²
  • 13-15符号付き距離|∇φ|=1を回復する再初期化∂φ/∂τ = sign(φ₀)[1 − |∇φ|]

拡散界面・再構成・跳躍条件

  • 13-17Cahn-Hilliard方程式の各項第1項バルク・第2項界面、保存型　∂φ/∂t = M(∇²f′(φ) − ξ∇⁴φ)
  • 13-18界面再構成法でないものCSFは表面張力モデル　再構成=SLIC/PLIC/MARS、CSFは別系統
  • 13-19跳躍条件に本質的に無関係な因子重力は体積力　関与=表面張力・相変化・粘性応力
C｜数値解法・計算条件
界面を鋭く保ちつつ安定に時間を進めるには、格子・スキーム・時間刻みの条件を押さえる必要があります。気泡の上昇速度を正しく解くには等価直径あたり十分なセル数が要り、高次差分だけでは各相の体積は保存しません。移流方程式はFTCSでは不安定で、TVD・CIP・ラグランジュ的手法を用います。表面張力（毛管波）を陽解法で扱うときは、波が1ステップで1セルを越えない時間刻みの上限で安定性が決まります。

格子解像・体積保存

  • 13-4単一気泡の上昇速度に要する格子幅等価直径あたり約20セル　Δx ≤ d/20
  • 13-6高次差分だけでは各相体積は保存しないソレノイダル条件・クーラン数・数値拡散

移流スキーム

  • 13-8界面移流方程式の数値解法FTCSは不安定で不適切　∂φ/∂t + u ∂φ/∂x = 0（TVD・CIP・ラグランジュ）

時間刻み・安定条件

  • 13-13液滴減衰振動の時間刻みの見積り表面張力項のクーラン数から　Δt = √(4ρRΔx²C/σ)
  • 13-16CSFの表面張力（毛管波）の安定条件波が1ステップで1セルを越えない　Δt < C(ρ/σ)¹ᐟ²(Δx)³ᐟ²

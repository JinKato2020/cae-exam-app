## Q 7-1　解の連続性

**問題**

同じ次数・共有辺で適合する、標準的なC0変位要素の未平均化出力について適切なのは？

**選択肢**

1. 変位・ひずみ・応力がすべて共有辺で必ず連続。
2. 変位は連続、ひずみ・応力は一般に要素間で不連続。
3. ひずみだけが必ず連続。
4. 要素内の変位も節点ごとに飛ぶ。

**正答** 2番：変位は連続、ひずみ・応力は一般に要素間で不連続。

**解説**

【C0適合】隣接要素が共有する辺で、変位の値がつながるという性質です。共有節点の変位が同じで、辺の補間も適合していれば、辺全体の変位が一致します。
【微分は別】ひずみは変位の微分です。つながった折れ線でも左右の傾きは変わるように、変位が連続でも微分が一致するとは限りません。応力もひずみから求めるので、要素別の未平均化値は一般に不連続です。肢2が適切です。
【出力の確認】節点平均で滑らかに表示されても、元の要素値が連続になったわけではありません。異材界面では物理的に跳び得る成分もあります。要素間の差を全て誤差と決めつけず、同じ材料内の収束と、界面で連続であるべき表面力成分を区別します。

## Q 7-2　温度と熱流束

**問題**

標準的な適合温度要素で、共有辺の要素別熱流束を平滑化せずに評価する。適切なのは？

**選択肢**

1. 温度・流束は常に両方連続。
2. 温度・流束は必ず両方不連続。
3. 温度は連続、流束は一般に点ごとには一致しない。
4. 温度は不連続、流束は常に連続。

**正答** 3番：温度は連続、流束は一般に点ごとには一致しない。

**解説**

【温度と微分】標準の適合温度要素ではTが共有辺で連続です。熱流束は $\mathbf q=-\lambda\nabla T$ なので、温度の傾きが要素間で異なれば未平均化流束も点ごとには一致しません。肢3が適切です。
【物理条件】熱が界面に蓄積せず表面熱源もなければ、入る熱と出る熱が等しく、法線熱流束が保存されます。異なる熱伝導率の材料では、同じ法線流束を伝えるために温度勾配が変わることがあります。
【数値解との違い】通常の温度型FEMは弱形式の釣合いを満たしますが、要素別流束の点ごとの一致を直接課してはいません。平均化前の差とメッシュ収束を確認し、異材界面で接線流束が異なり得ることとも区別します。

## Q 7-3　CSTの場

**問題**

直線辺CST、微小変形、一定D、初期ひずみなし。適切なのは？

**選択肢**

1. ひずみは二次分布。
2. 同一要素の応力が節点位置だけで変わる。
3. 一要素で一般の曲げ勾配を厳密再現。
4. ひずみ・応力は要素内で一定。

**正答** 4番：ひずみ・応力は要素内で一定。

**解説**

【CST】3節点直線三角形の変位は $u=a_1+a_2x+a_3y$、$v=b_1+b_2x+b_3y$ という一次式です。微分すると $\varepsilon_x=a_2$、$\varepsilon_y=b_3$、$\gamma_{xy}=a_3+b_2$ となり、要素内で一定です。
【応力】Dが一定で初期ひずみもなければ、$\boldsymbol\sigma=\mathbf D\boldsymbol\varepsilon$ も一定です。肢4が正答です。CSTはConstant Strain Triangle、つまり定ひずみ三角形の略です。
【限界】曲げのように応力が場所で変わる場は、一個の要素では一般に再現できません。多数の要素の一定値をつないで近似します。材料定数や熱ひずみが要素内で変われば、ひずみ一定でも応力一定とは限りません。

## Q 7-4　CSTのひずみ計算

**問題**

A(0,0),B(5,0),C(0,4) mm。x方向変位はuA=0.008、uB=0.033、uC=0.020 mm。εxは？

**選択肢**

1. 0.005
2. 0.003
3. 0.007
4. 0.008

**正答** 1番：0.005

**解説**

【変位補間】CSTなので $u=a+bx+cy$ と置きます。A(0,0)からa=0.008。B(5,0)から $b=(0.033-0.008)/5=0.005$。C(0,4)から $c=(0.020-0.008)/4=0.003$ です。
【ひずみ】$\varepsilon_x=\partial u/\partial x=b=0.005$ で、肢1を選びます。座標と変位の単位がどちらもmmなので、比は無次元です。0.005は0.5%の伸び率です。
【誤答の理由】0.003はuのy方向の勾配であり、x方向ひずみではありません。0.008mmはAの変位です。共通に全節点を動かす並進分aはひずみを生じません。ひずみには、変位の絶対値ではなく空間的な変化が効きます。

## Q 7-5　要素数をそろえる比較

**問題**

滑らかな解に対して同じ形状・要素数で、適切な一次要素と二次要素を比較する。妥当なのは？

**選択肢**

1. 二次は表現力を増やせるが、自由度や要素演算が増える。
2. 一次が必ず高精度。
3. 次数は精度に無関係。
4. 二次にすると計算時間が必ず半減。

**正答** 1番：二次は表現力を増やせるが、自由度や要素演算が増える。

**解説**

【表現力】同じ要素数なら、二次要素は中間節点などを使い、一次では不足する曲がった変位分布を表せます。滑らかな解では誤差を小さくできる場合があります。
【費用】節点・自由度が増え、要素剛性の成分数や積分点での演算も増えます。表現力と費用の両方を述べる肢1が適切です。高次化すれば計算時間が必ず短くなるわけではありません。
【公平な比較】形状、材料、荷重、評価量をそろえます。曲がった外形を使う場合は形状近似の差も関係します。特異点や大きく歪んだ要素では、次数を上げるだけで十分とは限りません。一次・二次という名前だけで絶対的な順位を付けず、収束と必要費用を確認します。

## Q 7-6　自由度をそろえる比較

**問題**

一次と高次の総未知自由度をほぼ同じにした。妥当なのは？

**選択肢**

1. 精度・時間は自由度数だけで完全に決まる。
2. 高次が滑らかな場で有利なことはあるが、同じ自由度数でも時間が同じとは限らない。
3. 高次の利点は一切ない。
4. 同じ自由度なら必ず同じ剛性行列になる。

**正答** 2番：高次が滑らかな場で有利なことはあるが、同じ自由度数でも時間が同じとは限らない。

**解説**

【自由度をそろえる】一次要素を細かくしたモデルと、高次要素を少なくしたモデルで、未知数の総数を近づける比較です。滑らかな場なら高次要素が有利なことがあるため、肢2が適切です。
【時間が同じでない理由】同じ行列の大きさでも、非零成分数や結合の密度は異なります。直接法のフィルイン、積分点数、反復法の収束や前処理も変わります。自由度数が同じという情報だけでは、メモリや時間は決まりません。
【評価】対象の変位・応力などの誤差と計算時間を実際に比較します。一つの値だけが合っても、応力勾配まで正確とは限りません。要素数をそろえる比較と、自由度数をそろえる比較は、条件が異なることを意識します。

## Q 7-7　二次辺の温度

**問題**

s=0,0.5,1で温度は60,40,40℃。二次補間に関する適切な説明は？

**選択肢**

1. 60から40へ直線で減少。
2. 全区間で必ず40〜60に収まる。
3. s=0.75で37.5℃となる。
4. 中間節点は分布に影響しない。

**正答** 3番：s=0.75で37.5℃となる。

**解説**

【三点の二次補間】$T(s)=a+bs+cs^2$ とします。s=0でa=60、s=0.5と1の条件からb=-60、c=40。したがって $T(s)=60-60s+40s^2$ です。
【最小値】$T'(s)=-60+80s=0$ よりs=0.75。$T(0.75)=60-45+22.5=37.5\,{}^\circ\mathrm C$。肢3が正答です。$T''=80>0$ なので、この補間曲線の最小値です。
【意味】三節点で最小の40℃より低い値が内部に現れます。二次補間には負の形状関数が現れる範囲があり、節点値の上下限を常に守るとは限りません。この37.5℃は与えた節点値の補間結果であって、実物の温度場の真の最小値を保証するものではありません。

## Q 7-8　円弧の二次近似

**問題**

標準Q8の円弧境界に関する適切な説明は？

**選択肢**

1. 中間節点を弦の中点に置けば厳密な円弧になる。
2. Q8の辺は必ず直線。
3. 中間節点を円弧上に置くことで、二次曲線により円弧を近似する。
4. isoでは座標一次・変位二次を必ず使う。

**正答** 3番：中間節点を円弧上に置くことで、二次曲線により円弧を近似する。

**解説**

【二次の辺】Q8の一辺は、両端と中間節点の三点で二次補間されます。中間節点を円弧上に置けば、曲がった境界を二次曲線で近似できます。肢3が適切です。
【直線との違い】中間節点を両端を結ぶ弦の中点へ置くと、三点が一直線上に並ぶため、その辺は直線になります。「中間節点があるだけで円弧になる」という説明は誤りです。
【近似の限界】通常の多項式二次写像は、一般の円弧そのものを厳密には表しません。三点で一致しても、その間に形状誤差が残ります。円弧の分割を増やし、曲率の近似とヤコビ行列を確認します。座標だけ一次、変位だけ二次を使うことがisoの定義でもありません。

## Q 7-9　構造要素と連続体要素

**問題**

一般的な分類として適切なのは？

**選択肢**

1. 構造：トラス・はり・シェル／連続体：平面・ソリッド
2. 構造：平面・ソリッド／連続体：はり・シェル
3. 構造：ソリッドのみ／連続体：トラスのみ
4. すべて同じ断面仮定を用いる。

**正答** 1番：構造：トラス・はり・シェル／連続体：平面・ソリッド

**解説**

【構造要素】トラス、はり、シェルは、棒の断面や板厚方向の挙動を一定の理論でまとめ、少ない自由度で全体挙動を表します。断面積、断面二次モーメント、板厚などを要素特性として与えます。
【連続体要素】平面要素やソリッド要素は、面や体積内の変位場を補間してひずみ・応力を求めます。分類が正しいのは肢1です。
【仮定の違い】連続体要素にも仮定があります。平面応力は面外応力を、平面ひずみは面外ひずみを0と近似します。構造要素にもEuler–BernoulliやTimoshenkoなどの違いがあります。名称だけでなく、評価したい現象と各要素が残す成分を確認して選びます。

## Q 7-10　はりの自由度

**問題**

標準的な二節点Euler–Bernoulliはりの一平面の曲げ自由度は？

**選択肢**

1. たわみと曲げモーメント
2. たわみとせん断力
3. たわみと断面回転
4. たわみと曲率

**正答** 3番：たわみと断面回転

**解説**

【自由度】二節点Euler–Bernoulliはりの一平面の曲げでは、各節点にたわみwと断面回転θを持ちます。要素全体では $[w_1,\theta_1,w_2,\theta_2]^T$ の四自由度です。肢3が正答です。
【補間】せん断変形を無視し、断面は軸線に垂直なままなので、回転はたわみの傾きと結び付きます。符号規約をそろえれば $\theta=dw/dx$。二点の値と傾きの四条件を、三次Hermite補間で表します。
【力との違い】曲げモーメントとせん断力は変位から計算する内力であり、本問の変位型要素の自由度ではありません。Timoshenkoはりではせん断変形を含むため、断面回転とたわみの傾きが独立となります。

## Q 7-11　分割の判断

**問題**

孔周辺の応力集中を評価する適切な方針は？

**選択肢**

1. 細長い外形に合わせ全要素を必ず極端に細長くする。
2. 孔周辺の曲率と応力勾配を解像し、収束を確認する。
3. 一様引張パッチテストだけで応力集中精度を保証する。
4. 一次四面体を使えば常に曲げ精度が最高。

**正答** 2番：孔周辺の曲率と応力勾配を解像し、収束を確認する。

**解説**

【応力集中】孔の周囲では、荷重が孔を避けて伝わり、応力が短い距離で大きく変化します。円周の曲率と応力勾配の両方を十分に表す分割が必要です。肢2が適切です。
【収束確認】孔近傍を段階的に細かくして、着目位置の応力や変位がどう変わるかを比較します。表示の節点平均だけに頼らず、出力位置や未平均化値も確認します。
【他の判断】一様なひずみを再現できるパッチテストは基本検証ですが、孔の急な勾配を解像できる保証ではありません。極端な要素歪みは避け、アスペクト比は場の方向性と要素種類も考えて評価します。要素名や外形の細長さだけで、最適な分割を一律に決めることはできません。

## Q 7-12　四面体と六面体

**問題**

三次元の曲げと複雑形状のメッシュについて妥当なのは？

**選択肢**

1. 一次四面体が常に最高精度。
2. 六面体なら品質検査は不要。
3. 形状・次数・積分は精度に無関係。
4. 四面体は複雑形状の自動分割に使いやすく、曲げには二次四面体や適切な六面体を検討する。

**正答** 4番：四面体は複雑形状の自動分割に使いやすく、曲げには二次四面体や適切な六面体を検討する。

**解説**

【四面体の利点】複雑な形状を自動的に分割しやすい要素です。ただし標準一次四面体の変位は一次で、微小ひずみは要素内で一定になります。粗い分割では曲げの変化を表しにくく、硬い応答を示しやすくなります。
【選択】曲げには二次四面体や、適切な定式化・品質の六面体などを検討します。形状への適合と曲げ性能の両方を述べる肢4が妥当です。
【保証ではない】六面体でも完全積分一次要素のロッキング、低減積分の零エネルギーモード、大きな歪みなどが問題になり得ます。四面体か六面体かだけで精度は決まりません。次数、積分、要素品質とメッシュ収束を合わせて確認します。

## Q 7-13　曲げとCST分割

**問題**

CSTを用いる片持ばりの曲げについて適切なのは？

**選択肢**

1. 要素内で二次応力を持つ。
2. 高さ方向の分割は不要。
3. 長手方向の変位変化と高さ方向の応力勾配の両方を解像する。
4. 孔の応力集中も分割と無関係。

**正答** 3番：長手方向の変位変化と高さ方向の応力勾配の両方を解像する。

**解説**

【曲げの分布】Euler–Bernoulli片持ばりの先端力によるたわみは長手方向に三次です。軸ひずみ・曲げ応力は断面高さ方向に一次となり、引張側から圧縮側へ変化します。
【CSTの限界】CST一要素のひずみ・応力は、本問で想定する一様な線形材料では一定です。曲げ場を、多くの一定値の組合せで近似する必要があります。
【分割】長手方向には変位・曲率の変化を、高さ方向には応力の符号と勾配を表す分割が必要なので、肢3が適切です。長さ方向だけを細かくしても、高さ方向が不足すれば曲げの精度は改善しきれません。両方向を段階的に変え、たわみと応力をそれぞれ確認します。

## Q 7-14　Q4とQ8の比較

**問題**

片持ばりをQ8で高さ4×長さ10、Q4で高さ6×長さ20に分割した。この情報から妥当な判断は？

**選択肢**

1. Q4が必ず高精度。
2. Q8はQ4と同じ補間空間。
3. 次数の違いがあるため、分割数だけでは順位を決めず同一評価量の収束で比較する。
4. Q8は常にQ4以上の要素数を必要とする。

**正答** 3番：次数の違いがあるため、分割数だけでは順位を決めず同一評価量の収束で比較する。

**解説**

【比較条件】Q8は40要素、Q4は120要素ですが、節点数と補間能力が違います。要素数の多い方が必ず正確とは判断できません。肢3が適切です。
【補間の差】Q4は双一次で、一般に定ひずみではありません。例えば $u=axy$ なら $\varepsilon_x=ay$ を表せます。ただし純曲げで必要な $v\propto x^2$ が不足し、不要なせん断が現れる場合があります。Q8は二次項を表せます。
【比較方法】同じ荷重・支持・材料・評価量で、各モデルの分割を段階的に細かくして収束を比べます。先端たわみ、応力、自由度数と計算費用を分けて見ると、必要精度に対して効率的なモデルを選べます。Q8の節点は隅と辺中間で、要素中央にはありません。

## Q 7-15　はり理論の基準値

**問題**

b=1 mm、h=20 mm、L=150 mm、E=200000 N/mm²、先端力W=10 NのEuler–Bernoulli片持ばり。面内曲げのIと先端たわみδの組合せは？

**選択肢**

1. I=1333.3 mm⁴、δ=0.0422 mm
2. I=666.7 mm⁴、δ=0.0844 mm
3. I=666.7 mm⁴、δ=0.1688 mm
4. I=2666.7 mm⁴、δ=0.0844 mm

**正答** 2番：I=666.7 mm⁴、δ=0.0844 mm

**解説**

【断面二次モーメント】曲げ方向の断面高さがhなので $I=bh^3/12=1\times20^3/12=666.6667\,\mathrm{mm^4}$ です。bとhを入れ替えると、異なる曲げ方向の値になります。
【先端たわみ】$\delta=WL^3/(3EI)=10\times150^3/(3\times200000\times666.6667)=0.084375\,\mathrm{mm}$。肢2が正答です。分子N·mm³、分母N·mm²なので結果はmmです。
【基準値の役割】これは問題が指定したEuler–Bernoulli理論の値です。二次元・三次元弾性体のFEMでは、せん断変形や固定端近傍の影響を含み、同じ物理モデルとは限りません。理論解との差を全てメッシュ誤差と決めつけず、FEMのモデル仮定も照合します。

## Q 7-16　変位比の読み方

**問題**

解析記録で、CSTモデルAの変位比δA/δref=0.25、Q4モデルBは0.60、Q8モデルCは1.00だった。δref=0.80 mm。Aのたわみと、この記録の解釈は？

**選択肢**

1. 0.20 mm、この結果だけで全問題のCST精度が保証される。
2. 3.20 mm、比で割る。
3. 0.20 mm、この三モデルではAの荷重点変位が最小。
4. 0.80 mm、要素種類によらず同じ。

**正答** 3番：0.20 mm、この三モデルではAの荷重点変位が最小。

**解説**

【比から実量へ】$\delta_A/\delta_{\mathrm{ref}}=0.25$ なので、$\delta_A=0.25\times0.80=0.20\,\mathrm{mm}$。同様にBは0.48mm、Cは0.80mmです。この三モデルではAが最小なので、肢3を選びます。
【硬さの解釈】同じ荷重を受ける同じ荷重点で比べれば、小さいたわみはその評価に対して硬い応答を示します。比0.25は基準の25%の変位という意味で、0.80を0.25で割りません。
【評価の限界】この記録は特定の三モデルの結果です。CSTが全ての問題で同じ比になるという性質ではありません。Cの変位比が1.00でも、応力分布まで正しい保証にはなりません。基準値のモデル、荷重条件、評価位置も確認します。

## Q 7-17　正方形要素の写像

**問題**

一辺a=5 mmの軸に平行なQ4を[−1,1]²から写像する。同じ材料・厚さ・積分・向き・局所節点順の、平行移動だけ異なる要素を比較する。適切なのは？

**選択肢**

1. det J=6.25 mm²で一定、要素剛性は同じ。
2. det J=25 mm²、絶対位置で剛性が変わる。
3. det J=2.5 mm²、厚さを変えても剛性は同じ。
4. det J=0、正方形は不正要素。

**正答** 1番：det J=6.25 mm²で一定、要素剛性は同じ。

**解説**

【写像】物理座標を $x=x_c+(a/2)\xi$、$y=y_c+(a/2)\eta$ と表します。微分すると $\mathbf J=\operatorname{diag}(a/2,a/2)$。a=5mmなら $\det\mathbf J=(2.5)^2=6.25\,\mathrm{mm^2}$ です。
【面積の確認】基準正方形の面積は4なので、物理面積は $4\times6.25=25\,\mathrm{mm^2}$。25は要素面積で、ヤコビ行列式ではありません。
【並進と剛性】中心位置 $x_c,y_c$ を変えても座標の微分は変わりません。本問の材料、厚さ、積分、向き、節点順をそろえた要素では剛性行列も同じなので、肢1です。絶対位置で変わる材料や、異なる局所節点順まで無条件に同じ行列になるという意味ではありません。

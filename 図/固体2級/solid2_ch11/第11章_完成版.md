## 11-1 円孔板の応力集中

全幅W=100 mm、厚さt=2 mmの帯板の中央に直径d=20 mmの円孔がある。長手x方向に全断面の合力P=4000 Nを与える。最小断面の公称応力に基づく応力集中係数をα=2.5とする。孔縁最大応力はどれか。

1. 62.5 MPa
2. 50 MPa
3. 25 MPa
4. 125 MPa

**正解：1**

最小断面積A=(W−d)t=160 mm²、公称応力P/A=25 MPa。最大応力はαP/A=62.5 MPa。Wは引張方向に直交する全幅、Pは全体モデルの荷重である。係数の基準が総断面か最小断面かを区別する。

## 11-2 固定円板のたわみ

半径a=400 mm、厚さt=8 mmの円板の周縁を固定し、一様圧力p=0.05 N/mm²を与える。E=200000 N/mm²、ν=0.3。微小たわみ薄板理論のD=Et³/[12(1−ν²)]、w0=pa⁴/(64D)を用いる。中央たわみの基準値はどれか。

1. 21.3 mm
2. 2.13 mm
3. 0.20 mm
4. 8.53 mm

**正解：2**

D=9377289.38 N·mm、w0=2.1328125 mm。分布はw(r)=w0[1−(r/a)²]²で、周縁でwとdw/drがともにゼロ。理論値は薄板・微小たわみの仮定に対する検証基準である。

## 11-3 外挿と相対誤差

内圧円筒で内表面から5 mmの周方向応力は42.0 MPa、15 mmでは37.0 MPaだった。この2点を直線で内表面へ外挿する。理論の内表面応力45.5 MPaに対する絶対相対誤差はどれか。

1. 2.2%
2. 7.7%
3. 13%
4. 19%

**正解：1**

勾配は(37−42)/(15−5)=−0.5 MPa/mm。表面への外挿は42−(−0.5)×5=44.5 MPa。誤差は|44.5−45.5|/45.5×100=2.1978%。表面への直線外挿自体にも近似誤差がある。

## 11-4 薄肉断面のねじり検証

薄肉開断面の継ぎ目を離散的なスポット溶接で結び、FEMのねじり角を連続閉断面のはり理論と比較する。最も適切な判断はどれか。

1. スポットが1点あれば連続閉断面と完全に同じ
2. メッシュさえ細かければ理論の仮定は不要
3. 溶接ピッチ・結合剛性・そり拘束・端部条件の違いを確認して比較する
4. FEMねじり角は理論値の必ず半分

**正解：3**

離散結合は連続閉断面を常に再現しない。せん断流の伝達、溶接間の変形、端部のそり拘束などで剛性が変わる。比較に意味はあるが、根拠のない一致率や「閉断面として働く」という断定をしない。

## 11-5 非中央荷重の最大たわみ

一様なEuler–Bernoulli単純支持ばりの長さL=1000 mm、左支点からa=200 mmに下向き集中荷重Pを与える。最大たわみ位置xを左支点から測ると、最も近い値はどれか。

1. 200 mm
2. 500 mm
3. 0 mm
4. 434 mm

**正解：4**

荷重点より右でw=Pa(L−x)[L²−a²−(L−x)²]/(6LEI)。dw/dx=0よりx=L−√[(L²−a²)/3]=434.315 mm。荷重点と中央の間に最大値があり、中央荷重と同じにはならない。

## 11-6 荷重配置の比較

同じ一様単純支持ばり、同じ総荷重Pで、A：中央1点、B：x=L/4,L/2,3L/4に各P/3、C：全長に一様分布P/Lを与える。最大たわみの大小はどれか。

1. A=B=C
2. C>B>A
3. B>A>C
4. A>B>C

**正解：4**

対称性より各ケースの最大は中央。PL³/EIを共通因子として、A=1/48、B=19/1152、C=5/384。24/1152>19/1152>15/1152となる。「分散すれば必ず小さい」を任意の配置へ一般化せず、荷重位置を特定した。

## 11-7 曲げ応力とたわみの最大位置

11-5と同じ、L=1000 mm、a=200 mmの単純支持ばりで、局所荷重導入の応力集中を除くはり理論の曲げ応力最大位置はどれか。断面は一様。

1. 最大たわみ点x≈434 mm
2. 荷重点x=200 mm
3. 左支点x=0
4. 全断面で同じ

**正解：2**

曲げ応力はσx=My/I。一定断面では|M|が最大の荷重点で最大になる。たわみ最大点は異なる。旧中央荷重では両点が一致して選択肢が重複するため、非中央条件へ改めた。

## 11-8 偏心剛体部の内力

x方向の片持ちはりの先端Bに、下向きの長さaの剛体腕を接続する。剛体腕の下端に右向き力Pが作用する。微小変形でBへ伝達される力・モーメントはどれか。

1. 力Pだけで曲げはない
2. 剛体なので力は伝わらない
3. 右向きPと反時計回りPa
4. 下向きPとP/a

**正解：3**

Bから荷重点への位置r=(0,−a)、力F=(P,0)なので、r×F=+Pa e_z。はりには軸力と端モーメントが作用し、軸伸びと曲げ・回転が生じる。P/aはモーメントの次元をもたない。

## 11-9 剛体挿入物の変位

弾性帯板の中央に完全接着した剛体挿入物があり、対称な軸引張により剛体の回転はゼロである。挿入物内の荷重方向変位はどうなるか。

1. 位置とともに必ず線形増加
2. 左右で変位が不連続
3. 全帯板で同じ
4. 挿入物内は一定、接着界面で変位は連続

**正解：4**

回転ゼロの剛体は並進だけなので内部の荷重方向変位は一定。一般の剛体は回転をもてるため、全変位が常に一定とはいえない。空洞の円孔には内部変位を定義しないので「剛体の円孔」を「剛体挿入物」へ修正した。

## 11-10 円筒壁の定常温度

内側材料1と外側材料2が完全接着する二層円筒壁を考える。軸方向一定、定常、発熱なしで外向き熱流量Q>0。界面の同じ半径rでλ1=10、λ2=1 W/(m·K)。界面両側の温度勾配の絶対値の比 |T′2|/|T′1| はどれか。

1. 1/10
2. 10
3. 1
4. 半径だけで決まりλは無関係

**正解：2**

Q=−2πrLλ dT/drより、同じrでは勾配比はλ1/λ2=10。各層のTはln rの関数で、平板の直線分布ではない。温度は完全接着界面で連続。表面の流体との温度差はQ/(h·2πrL)で、hだけでなく表面積にも依存する。

## 11-11 反力による検証

収束した静解析で物体力・表面力・集中荷重など全外力を含め、反力を確認する。適切なのはどれか。

1. 力とモーメントのつり合いを確認し、不一致なら入力・集計・収束などを調べる
2. 反力は必ずゼロ
3. 力がつり合えば材料・拘束・精度もすべて正しい
4. 不一致の原因は必ず荷重入力だけ

**正解：1**

全体の力・モーメントつり合いは必要な確認だが、十分な正しさの証明ではない。動解析では慣性力等も含む。集計範囲、符号、単位、接触内力の二重計上、収束も確認する。

## 11-12 応力の単位

長さmm、力N、弾性係数N/mm²を用いる一貫単位系で、応力の単位はどれか。

1. N/mm
2. N·mm
3. N/mm²=MPa
4. kg/mm³

**正解：3**

応力は力/面積。N/mm²は10⁶ N/m²=MPaである。ソフトが単位を自動換算するか、数値だけを扱うかを確認する。

## 11-13 質量密度の単位

長さm、力N、時間sの一貫単位系で自重を扱う。質量密度の単位はどれか。

1. N/m³
2. kg/m³
3. kg/mm³
4. N/mm²

**正解：2**

N=kg·m/s²から質量の単位はkg。重量密度N/m³と質量密度kg/m³を区別し、重力加速度を重ねて掛けない。

## 11-14 一様E変更の影響

単一等方材料の微小変位線形弾性静解析。全体のνは一定、変位境界はゼロ、力荷重は同じ、熱・初期ひずみなし。Eを正値のまま3倍にするとどうなるか。

1. 応力3倍、変位同じ
2. 応力1/3、変位3倍
3. 応力も変位も3倍
4. 応力同じ、変位1/3

**正解：4**

K=E K0なのでu=K⁻¹fは1/Eに比例し、σ=E D0 B uは不変。非零の強制変位、異材、熱ひずみ、接触・幾何非線形等へこの結論を無条件に適用しない。誤入力は原稿・データを修正し、前提を確認して再検証する。

## 11-15 GPaとMPaの混同

11-14と同じ前提の力制御解析で、mm-N系の正しいE=200000 MPaを、GPaの数値200のまま入力した。応力・変位の数値を正しい単位に復元する関係はどれか。

1. 応力は同じ、誤計算の変位を1000で割る
2. 応力も変位も1000倍する
3. 応力を1000で割り、変位は同じ
4. あらゆる条件で結果の復元は不可能

**正解：1**

入力Eは正値の1/1000で、変位・ひずみは1000倍。応力はこの限定条件では同じ。記録と入力を正し、再計算・比較で確認する。複数の単位ミスや非線形解析では、この単純補正は保証されない。

## 11-16 コード検証と妥当性確認

数理モデルAを離散化・実装して計算モデルBを作る。A→Bの実装を調べる活動Cと、計算と実験を対象の用途で比較する活動Dの組合せはどれか。

1. C=妥当性確認、D=コード検証
2. C=コード検証、D=妥当性確認
3. C=設計変更、D=メッシュ生成
4. C=入力省略、D=バグ不存在の証明

**正解：2**

コード検証は数理モデルの実装が正しいかを調べる。妥当性確認は実験・観測との比較などを通じ、目的に対するモデルの適切さを評価する。付属図は教材用整理図であり、ASME原図の転載・完全再現ではない。

## 11-17 V&Vの限界

検証・妥当性確認について誤った説明はどれか。

1. 既知解との比較は数値実装や求解の検証に役立つ
2. 実験比較は測定・入力・数値の不確かさを考慮する
3. いくつかのベンチマークに合えばコードにバグがないと証明できる
4. 解検証では離散化や反復求解の誤差を検討する

**正解：3**

有限個のテストであらゆる入力・処理のバグ不存在は証明できない。検証は数式を正しく解くこと、妥当性確認は用途に照らしたモデルと現実の比較を中心にする。最終値の比較だけに限定せず、評価量と不確かさを明示する。

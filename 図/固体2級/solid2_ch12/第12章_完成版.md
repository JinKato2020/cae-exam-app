## 12-1 丸め誤差

有限精度の数値表現による丸め誤差の説明はどれか。

1. 演算の正確な実数値を表現可能な近い値へ置き換えることによる誤差
2. 級数を有限項で打ち切る誤差だけ
3. メッシュを有限個にする誤差だけ
4. 境界条件の仮定による誤差だけ

**正解：1**

表現・演算の有限桁による誤差と、打切り・離散化・モデル化誤差を区別する。丸め方式によって最も近い値以外へ丸める場合もある。

## 12-2 計算順序と誤差

浮動小数点演算について正しいのはどれか。

1. 加算順序は常に無関係
2. 同じ数学的な式でも評価順序や算法で誤差が変わり得る
3. 整数の桁あふれは常に実数へ自動変換される
4. CPUが高速なら同じ精度形式でも必ず誤差が小さい

**正解：2**

有限精度では加算の結合則が一般に成り立たない。小さい項の集約や補償加算などが役立つ場合がある。速度と精度形式は別である。

## 12-3 整数式の評価

整数同士の除算で小数部分を捨てるものとする。全数値・全演算を整数型で行い、通常の括弧と演算優先順位で 1+(1÷2−1)×2+1÷2 を評価する。結果はどれか。

1. 0
2. 0.5
3. −1
4. 2

**正解：3**

1÷2=0なので1+(0−1)×2+0=−1。途中の除算を実数で行う場合とは結果が違う。

## 12-4 有限桁計算の実例

10進の有効数字4桁で、各演算後に最も近い値へ丸める。1234+1.987−1233を左から計算した値はどれか。入力は正確とする。

1. 2.987
2. 2.000
3. 0
4. 3.000

**正解：4**

加算の正確値1235.987を1236へ丸め、その後1236−1233=3.000。正確な結果2.987との差は0.013。減算はこの入力では正確だが、加算時の誤差が結果に残り、相対誤差は約0.435%。「減算したら必ず新しい誤差が生じる」とはしない。

## 12-5 桁落ち

入力値に小さな相対誤差が含まれている場合、差の相対精度を大きく失いやすい演算はどれか。

1. ほぼ等しい同符号の2数の減算
2. 桁の異なる2数の乗算だけ
3. どんな2数の加算も同程度
4. 正確な2整数の比較

**正解：1**

近い値を引くと大きな共通部分が消え、もとの入力誤差が小さい差に対して大きくなる。減算命令そのものが必ず不正確になるという意味ではない。

## 12-6 改行コード

あるコンパイラがLF改行だけを受け付けると明記されている。CR+LFのソースが拒否された。直接的な対処はどれか。

1. 英数字をすべて別の文字にする
2. 内容を保って改行をLFに変換する
3. 実数の計算を削除する
4. CPU数を増やす

**正解：2**

条件で指定された改行形式へ変換する。すべてのUNIX環境やC処理系がCR+LFを拒否するわけではない。文字コードの不一致は別途確認する。

## 12-7 仮想記憶

仮想記憶の説明として適切なのはどれか。

1. CPUの演算回路そのもの
2. 電源を切っても保持する記憶だけ
3. プロセスの仮想アドレスを物理記憶へ対応付け、保護や必要に応じたページ退避を行う仕組み
4. RAM増設と同じ速度を常に実現する仕組み

**正解：3**

仮想記憶はアドレス空間の抽象化・保護を含む。ディスクへのページ退避はその機能の一つで、仮想記憶の定義を「不足RAMをハードディスクで代用」に限定しない。退避・読み戻しが多いと大きく遅くなる。

## 12-8 演算器とキャッシュ

説明として誤っているものはどれか。

1. FPUは浮動小数点演算を扱う
2. GPGPUはGPUを汎用的な並列計算に用いる
3. DSPは積和など信号処理に適した演算を行う
4. キャッシュは浮動小数点乗算だけを行う専用回路

**正解：4**

キャッシュは頻用されるデータ・命令を速く供給する記憶で、乗算器ではない。GPUの並列性が全ての算法を高速化するとは限らない。

## 12-9 64ビットと精度

CPUやOSが32ビットから64ビットへ変わることについて、誤った説明はどれか。

1. 同じ浮動小数点形式でも計算精度が必ず2倍になる
2. 利用可能なアドレス空間が広がり得る
3. 扱えるメモリ上限はOS等の条件にも依存する
4. 64ビットCPUでも32ビットの数値形式を使うことがある

**正解：1**

数値精度は単精度・倍精度などの表現形式と算法で決まる。CPUのビット数と、浮動小数点の有効桁数は同義ではない。

## 12-10 DMAの役割

DMAの説明として適切なのはどれか。

1. CPUが全バイトを個別命令でコピーすることだけ
2. DMA機構がCPUの逐次コピーを減らしてデータを転送する
3. 浮動小数点の桁数を増やす回路
4. ライセンスを配る機能

**正解：2**

CPUが設定・同期等に関与しても、各データの転送をDMA機構に任せられる。転送と計算の重なりやCPU負担の低減で処理全体が速くなる場合があるため、「高速化に寄与しない」という旧問を修正した。

## 12-11 光ディスクの区別

読出専用・追記等の書込可能だが消去して書換え不可・繰返し書換え可能に対応する組合せはどれか。

1. CD-R／CD-RW／CD-ROM
2. CD-RW／CD-ROM／CD-R
3. CD-ROM／CD-R／CD-RW
4. CD-ROM／CD-RW／CD-R

**正解：3**

CD-Rは記録済み領域を消去して書き換えられないが、条件によって複数回の追記が可能。「1回だけ書込み」と「追記も一切不可」を混同しない。

## 12-12 指定容量の比較

製品一般の最大容量ではなく、ここに記した容量だけを比較する。最大なのはどれか。

1. 0.7 GB
2. 4 GB
3. 4.7 GB
4. 128 GB

**正解：4**

与えられた数値では128 GBが最大。USBメモリ等の代表容量を普遍的な上限として扱わない。

## 12-13 記憶階層

CPUと主記憶の速度差を埋めるため、頻用データを保持する高速・小容量の記憶はどれか。

1. キャッシュ
2. スワップファイル
3. 光ディスク
4. ファイルの圧縮率

**正解：1**

キャッシュへのアクセスは通常主記憶より高速だが、容量・アクセス局所性・ミス率によって効果が変わる。

## 12-14 OSの役割

OSの役割はどれか。

1. 構造解析の物理モデルを必ず自動決定する
2. プロセス・メモリ・入出力などの資源を管理する
3. ソフトの数値誤差を必ずゼロにする
4. 全業務アプリを標準で含む

**正解：2**

OSは資源管理やサービスを提供する基本ソフト。利用者の操作環境を提供する場合もあるが、必ずグラフィカルな画面が必要というわけではない。

## 12-15 LinuxとOS

正しい説明はどれか。

1. Linuxは表計算のファイル形式
2. macOSは必ずLinuxカーネルを使う
3. Linuxカーネルはオープンソースで、各種ソフトと組み合わせたディストリビューションで利用される
4. UNIXはプログラミング言語の名称

**正解：3**

Linuxは厳密にはカーネル名で、OS全体を指す通称としても使われる。カーネルと、配布される全ソフト・サービスの権利や条件を一括に扱わない。

## 12-16 オープンソースの利用条件

オープンソースソフトの利用について適切なのはどれか。

1. ライセンス条文が存在しない
2. 必ず商用利用が禁止
3. どんな再配布条件もない
4. ライセンスが認める範囲と条件を確認して利用・改変・再配布する

**正解：4**

ソース公開や無償入手は無条件利用を意味しない。LinuxカーネルのGPLと、同梱ソフトや商用サポートの条件を区別する。「ライセンスフリー」の曖昧な表現を削除した。

## 12-17 OS更新の手順

業務用OSを更新する際に適切なのはどれか。

1. 対応環境を確認し、バックアップと検証・復旧手段を用意して導入する
2. 新OSなら全旧アプリが自動で動くと仮定する
3. 本番環境を最初の試験環境とする
4. OSとソルバは無関係なので確認しない

**正解：1**

ソルバ・ライセンス管理・ドライバ・連携ツールの対応を確認し、検証して導入する。実際の対応状況は対象製品・版の公式情報で確認する。

## 12-18 CAE環境の選定

CAE環境の選定で不適切なのはどれか。

1. 対象ソフトの対応OSを確認する
2. 普及率だけで選び、対応や連携を確認しない
3. 計算規模に対するメモリを確認する
4. 必要な周辺システムとの接続を確認する

**正解：2**

普及率だけでは対象ソフトの互換性・解析規模・保守運用を判断できない。

## 12-19 コンパイルと実行

コンパイラ・インタプリタの説明として適切なのはどれか。

1. インタプリタは必ず全体を事前にネイティブ機械語にする
2. コンパイルの有無だけで速度が一意に決まる
3. 実行方式には事前変換・実行時変換・中間コードなどがあり、速度は実装や処理に依存する
4. コンパイルすれば同じ計算は必ず速い

**正解：3**

事前コンパイル、解釈実行、JITなどは併用されることもある。言語名だけで処理方式や速度を断定しない。

## 12-20 実行形式の互換性

あるCPU・OS向けのネイティブ実行ファイルについて適切なのはどれか。

1. どのCPU・OSでもそのまま動く
2. 毎回必ず利用者がソースを翻訳する
3. 機械語を一切含まない
4. 別のCPU・OSでは互換層や再ビルド等が必要な場合がある

**正解：4**

命令セット・実行形式・ABI・ライブラリ等に依存する。中間コードと仮想機械による可搬性とは区別する。

## 12-21 科学技術計算の言語

Fortranについて正しい説明はどれか。

1. 科学技術計算に広く使われ、数値計算のライブラリ資産がある
2. 事務処理専用で数値計算はできない
3. 特定の1台のCPUでしか使えない
4. 文書編集のマクロだけに使う

**正解：1**

Fortranは数値計算で長く使われてきた。言語の歴史だけで現代の性能や適性を一意に決めるのではなく、実装・ライブラリ・保守性も考慮する。

## 12-22 言語と機械語

高水準言語の特徴として適切なのはどれか。

1. すべての命令が必ず特定CPUと一対一に対応する
2. 算法やデータを機械命令より抽象的に記述できる
3. 翻訳・実行環境が不要である
4. 数値演算は記述できない

**正解：2**

数値計算の式・ループ・配列等を抽象的に記述でき、処理系が実行へ結び付ける。旧問の歴史知識の重複を、言語の役割を問う内容へ改めた。

## 12-23 低水準言語

一般に高水準言語に分類されないものはどれか。

1. C++
2. Java
3. アセンブリ言語
4. Perl

**正解：3**

アセンブリ言語はCPUの命令セットに近い記述を用いる。個々の言語の実行方式と高水準・低水準の区別は別である。

## 12-24 フローティング管理

この契約では複数PCへの導入を認め、同時使用数をサーバで管理する。誤っている説明はどれか。

1. 同時使用数は契約上限内にする
2. 導入台数が同時使用数より多くてもよい
3. サーバが使用権の払い出しを管理する
4. 導入台数と同時使用ライセンス数は必ず一致する

**正解：4**

ここで指定した契約では導入台数と同時使用数は別。実製品には利用者・機能・CPU数などの追加条件もある。

## 12-25 オフライン使用の条件

同時使用3本の契約で、サーバ接続が必須、貸出し・オフライン権なしと明記されている。認められない使い方はどれか。

1. サーバから完全に切り離した3台で同時に使う
2. 接続した10台のうち最大3台で同時使用する
3. 3本使用中の4台目が空きを待つ
4. 接続した5台へ導入し、同時使用を3本以内にする

**正解：1**

指定した条件では非接続での払い出しができない。貸出し機能等がある製品へ、オフライン不可を一般化しない。

## 12-26 LANとWAN

用語の説明として適切なのはどれか。

1. LANは必ず全世界を結ぶ
2. LANは建物や拠点内など比較的限定された区域のネットワーク
3. WANは必ず1室だけの通信
4. LANとWANは同義

**正解：2**

LANは局所的なネットワーク、WANは地理的に広い範囲を接続するネットワークを指す。媒体や回線事業者の有無だけで定義しない。

## 12-27 機密データの送付

組織の規定で承認済みの転送方式を使える。機密解析データを相手へ送る適切な対応はどれか。

1. 公開サーバへ無制限で置く
2. 平文メールなら宛先確認は不要
3. 承認方式で暗号化と本人確認・アクセス制限を行い、宛先と送付範囲を確認する
4. 記録媒体なら暗号化・輸送管理は一切不要

**正解：3**

通信経路だけでなく誤送信、保存先、アクセス権、媒体紛失も考慮する。郵送なら最も安全という旧問を実務的な判断へ変更した。

## 12-28 ネットワークファイル共有

遠隔ファイルをファイルシステムとして利用するプロトコルの例はどれか。

1. NIS
2. RAID
3. CPUの命令セット
4. NFS

**正解：4**

NFSはネットワークファイルシステムのプロトコル。RAIDは記憶装置の構成、NISは名前・管理情報のサービスであり役割が違う。

## 12-29 ファイル転送

名称としてファイル転送を主目的とするプロトコルはどれか。

1. FTP
2. POP3
3. SMTP
4. IMAP

**正解：1**

FTPはファイル転送、POP3・IMAPはメール取得等、SMTPはメール送信等に用いる。FTPという名称自体は安全な暗号化を保証しない。

## 12-30 並列計算のモデル

一般的な並列プログラミングの説明として適切なのはどれか。

1. MPIは分散メモリで使えない
2. MPIはプロセス間通信、OpenMPは主に共有メモリ並列を扱い、併用もできる
3. OpenMPは全ての分散プロセス間通信を自動で実装する
4. 自動並列化はどんなコードも無変更で理想加速する

**正解：2**

MPIは同じ計算機の共有メモリ環境でも使え、MPIとOpenMPのハイブリッドも可能。自動並列化には依存関係・コンパイラ・処理内容による制約がある。

## 12-31 並列効率

逐次時間T1=100 s、4プロセッサでの時間T4=40 s。効率η=T1/(4T4)はどれか。

1. 40%
2. 100%
3. 62.5%
4. 250%

**正解：3**

加速率S=T1/T4=2.5、効率η=S/4=0.625=62.5%。250%は加速率を百分率で表した値で、効率ではない。逐次基準と計時範囲を同じにする。

## 12-32 リバースエンジニアリング

ソフトウェアのリバースエンジニアリングの目的の例はどれか。

1. 既存ソフトを解析せず一から作るだけ
2. 速度だけを計測することに限定
3. 内容を読めなくすることだけ
4. 既存の実装から構造・仕様等を理解し、修正や再開発に役立てる

**正解：4**

既存の振る舞い・設計情報を分析する。実施時には対象の権利・契約・許される範囲も確認する。

## 12-33 セキュリティ方針

組織の情報セキュリティ方針の役割はどれか。

1. 守る情報資産と基本方針・責任を明示し、規程・手順の拠り所にする
2. 製品名と価格だけを書く
3. 個人が気分で変更する
4. 対外宣伝だけを目的とする

**正解：1**

基本方針に沿って管理規程・具体的手順を整備する。方針だけで対策が完了するわけではなく、教育・運用・見直しも必要。

## Q 5-1　アイソパラメトリック要素

**問題**

誤った記述はどれか。

**選択肢**

1. 座標と変位を同じ形状関数で補間する。
2. 形状関数は必ず二次以上である。
3. 同じ基準座標で座標写像と変位補間を定義する。
4. 一次・二次などの要素がある。

**正答** 2番：形状関数は必ず二次以上である。

**解説**

【定義】アイソパラメトリック要素では、要素内の位置と変位を同じ形状関数で補間します。位置は $x=\sum_iN_ix_i$、変位は $u=\sum_iN_iu_i$ と表します。$x_i,u_i$ は節点の座標と変位、$N_i$ は各節点値が内部の点へ与える寄与を表す関数です。
【正答の理由】「同じ補間を使う」という定義であり、「二次以上」という条件はありません。一次の4節点四辺形Q4や8節点六面体H8も該当するため、誤りは肢2です。
【実務とのつながり】基準要素上の簡単な関数を、実際の形へ写像して使います。物理座標に関する微分にはヤコビ行列が必要です。ガラーキン法の「試行関数と重み関数を同じに選ぶ」という条件とは、比較する対象が異なります。

## Q 5-2　補間の分類

**問題**

座標側の補間次数を基準とした正しい分類は？

**選択肢**

1. 同一補間はサブ。
2. 同一はiso、座標が変位より高次ならsuper、低次ならsub。
3. 座標が高次ならsub、低次ならsuper。
4. 節点数が同じなら基底が異なっても必ずiso。

**正答** 2番：同一はiso、座標が変位より高次ならsuper、低次ならsub。

**解説**

【比較するもの】座標補間は要素の形を、変位補間は変形の分布を表します。両者の補間次数・形状関数を比較して分類します。同じ補間ならiso、座標側が高次ならsuper、低次ならsubです。
【具体例】座標も変位も一次ならiso。曲がった境界を二次の座標補間で表し、変位を一次にすればsuperです。直線形状を一次で表し、変位だけを二次にすればsubです。したがって肢2が適切です。
【誤答の理由】肢1と3は名称の対応が逆です。肢4の節点数だけでは、実際に同じ補間を用いているか判断できません。「何個あるか」だけでなく「どの関数で表すか」を確認します。

## Q 5-3　四辺形要素の次数

**問題**

標準的なQ4とQ8について正しい組合せは？

**選択肢**

1. Q4二次・Q8一次
2. Q4双一次・Q8二次セレンディピティ
3. 両者とも定数
4. Q4一次・Q8三次ラグランジュ

**正答** 2番：Q4双一次・Q8二次セレンディピティ

**解説**

【Q4】4隅の節点を使い、基準座標 $\xi,\eta$ で $1,\xi,\eta,\xi\eta$ を組み合わせます。各座標については一次なので「双一次」です。$\xi\eta$ の総次数が2でも、通常は一次要素と呼びます。
【Q8】4隅と4辺の中間、合計8節点を持つ二次セレンディピティ要素です。$\xi^2,\eta^2$ に加えて $\xi^2\eta,\xi\eta^2$ なども含みます。肢2が正しい対応です。
【整理】「要素を一次・二次と呼ぶ分類」と「各項の指数を足した総次数」は別の数え方です。Q8を単純に総次数2以下の全多項式だけと考えたり、9節点ラグランジュQ9と同じ節点配置だと考えたりしないようにします。

## Q 5-4　基準要素と座標写像

**問題**

標準的なQ4/Q8で、要素の写像は一対一かつdet J>0とする。誤った説明は？

**選択肢**

1. 三角形の面積座標L1,L2,L3をそのまま基準四辺形の座標にする。
2. 基準座標ξ,ηを使う。
3. 基準要素内の点と物理要素内の点が一対一に対応する。
4. Jによって微分を変換する。

**正答** 1番：三角形の面積座標L1,L2,L3をそのまま基準四辺形の座標にする。

**解説**

【基準要素】Q4やQ8では、通常 $-1\le\xi,\eta\le1$ の正方形を出発点にします。三角形の面積座標は三角形用の別の表現であり、そのまま四辺形の標準座標にはなりません。誤りは肢1です。
【写像の意味】形状関数で基準要素の点を実際の要素へ対応させます。ヤコビ行列は、この対応によって微小な長さ・面積や微分がどう変わるかを表します。
【条件の確認】本問は写像が一対一で $\det\mathbf J>0$ と仮定しています。点対応と微分変換はこの条件内の説明です。節点を交差する順に結んだ要素や逆転した要素でも自動的に正しい写像になる、という意味ではありません。

## Q 5-5　座標補間

**問題**

節点座標を $(x_i,y_i)$、形状関数を $N_i(\xi,\eta)$ とする。アイソパラメトリック要素の正しい座標補間式はどれか。

**選択肢**

1. $x=\sum_iN_ix_i,\quad y=\sum_iN_iy_i$
2. $x=\sum_i(\partial N_i/\partial\xi)x_i,\quad y=\sum_i(\partial N_i/\partial\eta)y_i$
3. $x=\sum_iN_i^2x_i,\quad y=\sum_iN_i^2y_i$
4. $x=\sum_ix_i/N_i,\quad y=\sum_iy_i/N_i$

**正答** 1番：$x=\sum_iN_ix_i,\quad y=\sum_iN_iy_i$

**解説**

【補間式】$x=\sum_iN_ix_i$、$y=\sum_iN_iy_i$ が正しく、肢1を選びます。$N_i$ は無次元、$x_i,y_i$ は長さなので、得られる $x,y$ も長さになります。
【重みの働き】標準的な節点型形状関数は、節点iで $N_i=1$、他の節点で0になります。そのため節点では入力座標を再現します。また $\sum_iN_i=1$ なので、全節点を同じ距離だけ動かせば要素全体も同じ距離だけ移動します。
【誤答の理由】肢2の微分はヤコビ行列を求める段階で使う量で、位置の補間式ではありません。肢3の二乗や肢4の逆数に置き換えると、元の形状関数が持つ節点再現性などを失います。特に $N_i=0$ で逆数は定義できません。

## Q 5-6　Q4の曲げ表現

**問題**

長方形の標準Q4一要素で厳密には再現できない変位場は？

**選択肢**

1. u=ax、v=0
2. u=0、v=by
3. u=cy、v=0
4. u=−κxy、v=κx²/2（κ≠0）

**正答** 4番：u=−κxy、v=κx²/2（κ≠0）

**解説**

【Q4の表現範囲】軸に沿う長方形Q4の変位は $1,x,y,xy$ の組合せです。$ax,by,cy$ はこの範囲で表せますが、$x^2$ は含まれません。肢4の $v=\kappa x^2/2$ を厳密に表せないため、これが正答です。
【曲げとの関係】肢4では $\varepsilon_x=\partial u/\partial x=-\kappa y$、$\gamma_{xy}=\partial u/\partial y+\partial v/\partial x=-\kappa x+\kappa x=0$ です。軸ひずみは高さ方向に一次で、不要なせん断ひずみがない曲げ運動を表します。
【数値上の影響】Q4では必要な二次変位が不足し、曲げに不要なせん断ひずみを作る場合があります。曲げ応力が二次になるのではありません。これは補間能力を調べる例で、任意のポアソン比に対する弾性体の完全な応力解を与える問題ではありません。

## Q 5-7　ヤコビ行列

**問題**

ヤコビ行列を $\mathbf J=\begin{bmatrix}\partial x/\partial\xi&\partial y/\partial\xi\\\partial x/\partial\eta&\partial y/\partial\eta\end{bmatrix}$ と定義する。この行列の役割として適切なのはどれか。

**選択肢**

1. 材料則
2. 節点力の直接計算
3. 基準座標微分を物理座標微分へ変換する
4. 質量集計

**正答** 3番：基準座標微分を物理座標微分へ変換する

**解説**

【連鎖律】形状関数 $N$ の微分は、問題の定義では $[N_{,\xi},N_{,\eta}]^T=\mathbf J[N_{,x},N_{,y}]^T$ です。コンマの後の記号は、その座標で微分する意味です。
【変換】$\det\mathbf J\ne0$ なら逆行列を使い、$[N_{,x},N_{,y}]^T=\mathbf J^{-1}[N_{,\xi},N_{,\eta}]^T$ と求めます。この物理座標微分から、変位をひずみへ変換するB行列を作るため、肢3が正答です。
【注意】Jは材料の硬さを表す行列ではなく、座標写像の行列です。資料によっては本問のJの転置をJと定義するので、変換式も変わります。公式を暗記する前に、行と列にどの微分が並ぶかを確認します。

## Q 5-8　内部変数の縮約

**問題**

要素内部の追加変数を静的縮約する曲げ改善手法について、誤ったものは？

**選択肢**

1. 曲げ表現を改善できる。
2. 追加変数は隣接要素と共有する節点自由度ではない。
3. 追加変数を要素内で消去できる。
4. 縮約後も追加変数すべてを全体未知数として残さなければならない。

**正答** 4番：縮約後も追加変数すべてを全体未知数として残さなければならない。

**解説**

【追加変数】通常の節点変位だけでは不足する曲げ表現を、要素内部の変数 $\boldsymbol\alpha$ で補います。隣の要素と共有する節点を必ず増やす方法ではありません。
【静的縮約】内部方程式から $\boldsymbol\alpha=\mathbf K_{\alpha\alpha}^{-1}(\mathbf f_\alpha-\mathbf K_{\alpha u}\mathbf u)$ と解き、節点の方程式へ代入します。縮約後の剛性は $\mathbf K_{uu}-\mathbf K_{u\alpha}\mathbf K_{\alpha\alpha}^{-1}\mathbf K_{\alpha u}$ です。逆行列の存在など、消去できる条件が必要です。
【正答と注意】内部変数を全体未知数として残す必要はないので、肢4が誤りです。要素内の演算は増え得ます。変位を拡張する非適合モードと、ひずみ・変形勾配を拡張する手法は同一ではなく、「内部変数だから全ての辺で必ず変位0」とは断定できません。

## Q 5-9　高次六面体

**問題**

標準的な二次要素について適切なのは？

**選択肢**

1. 27節点ラグランジュ要素に内部節点はない。
2. 20節点六面体は8隅と12辺中央の節点をもつセレンディピティ要素。
3. 同じ節点数ならセレンディピティが必ず高精度。
4. 内部節点の有無だけで積分点数が決まる。

**正答** 2番：20節点六面体は8隅と12辺中央の節点をもつセレンディピティ要素。

**解説**

【節点の数え方】H20は六面体の8隅に、12本の辺の中間節点を足して $8+12=20$ 節点です。面中央と体積中央には節点がありません。したがって肢2が正答です。
【H27との違い】二次ラグランジュH27は、さらに6面の中央と体積中央1点を加え、$20+6+1=27$ 節点になります。座標方向ごとに3点あるテンソル積としても $3^3=27$ と数えられます。
【判断の限界】節点配置は補間能力に関係しますが、精度は形状の歪み、積分法、解の滑らかさにも依存します。セレンディピティという名称だけで高精度を保証できません。積分点も節点とは別で、内部節点の有無だけでは積分点数は決まりません。

## Q 5-10　補間と微分

**問題**

長方形のQ8が u=ax²、v=0 を正確に補間したときのεxは？

**選択肢**

1. 2ax（一次）
2. ax²（二次）
3. a（定数）
4. 0

**正答** 1番：2ax（一次）

**解説**

【ひずみの定義】微小ひずみでは $\varepsilon_x=\partial u/\partial x$ です。$u=ax^2$ を微分すると $\varepsilon_x=2ax$ なので、肢1を選びます。
【式の意味】変位uは長さ、ひずみは長さの変化率で無次元です。したがってこの例のaは長さの逆数の単位を持ち、$2ax$ は無次元になります。変位が二次なら、この微分は一次です。
【適用範囲】本問は長方形Q8がこの変位場を正確に補間した場合を指定しています。一般の歪んだQ8では物理座標への写像が入り、ひずみが常に完全な一次多項式になるとは限りません。肢2は微分前の変位式、肢3はxに関する変化を落とした式です。

## Q 5-11　分布圧力の節点力

**問題**

分布圧力を与える適切な方法は？

**選択肢**

1. 合力を常に一節点へ集中する。
2. t=−pnを形状関数で積分して等価節点力へ換算する。
3. Paの値をそのままNとして各節点に入れる。
4. 常に接線方向の力にする。

**正答** 2番：t=−pnを形状関数で積分して等価節点力へ換算する。

**解説**

【圧力と力】外向き単位法線を $\mathbf n$、圧縮を正とする圧力をpとすると、単位面積当たりの力は $\mathbf t=-p\mathbf n$ です。圧力の単位はN/m²であり、節点力Nとは区別します。
【等価節点力】$\mathbf f_e=\int_\Gamma\mathbf N^T\mathbf t\,dS$ と積分します。節点変位による仮想仕事が分布荷重の仕事と一致するように換算するので、肢2が適切です。
【具体例】一定厚さt、長さLの直線辺に一定圧力pを与えると合力はptL。二節点辺なら各半分、標準三節点二次辺なら端・中間・端で $1:4:1$ です。曲面では法線と面積が場所で変わるため、その変化も積分します。合力だけを一節点へ移すと、仕事やモーメントの再現を損なう場合があります。

## Q 5-12　体積力と表面力

**問題**

体積力ではないものは？

**選択肢**

1. 材料密度ρと重力加速度gによるρg
2. 回転座標系での遠心力密度ρω²r
3. 帯電した体積に作用する電気力密度ρeE
4. 物体表面に作用する流体圧力

**正答** 4番：物体表面に作用する流体圧力

**解説**

【体積力】物体内部に分布し、単位体積当たりN/m³で表す力です。重力なら $\mathbf b=\rho\mathbf g$。密度kg/m³と加速度m/s²の積がN/m³になります。回転座標系の遠心力密度や、帯電体積の電気力密度もこの分類です。
【表面力】流体圧力は物体の表面へ作用し、単位面積当たりN/m²で表します。よって体積力でないものは肢4です。FEMでも体積力は体積積分、表面力は表面積分から節点力を作ります。
【区別】静水中の浮力は、物体表面に作用する圧力の合力として得られます。計算上それを等価な体積力に置き換えることはありますが、元の作用の分類と、等価モデルでの入力方法は分けて理解します。

## Q 5-13　変形に追従しない荷重

**問題**

本問ではdead loadを、解析中に固定した大きさ・全体座標方向の荷重と定義する。該当するものは？

**選択肢**

1. 固定方向の一定集中力
2. 常に変形後の面法線へ向く圧力
3. 時間とともに変わる移動力
4. 変位に比例するばね力

**正答** 1番：固定方向の一定集中力

**解説**

【本問の定義】dead loadは、大きさと全体座標での方向を変形に依存させず固定する荷重です。物体が回転しても矢印は同じ方向を向くため、肢1が該当します。
【追従荷重】follower loadは物体の向きに追従します。例えば圧力は変形後の面の法線に沿うので、面が回転すれば力の方向も変わります。大変形では荷重方向の変化が釣合い式の非線形性につながります。
【誤答と用語】時間とともに変わる移動力や変位に比例するばね力も、本問の固定した一定力ではありません。ここでは「変形への追従」を比較しています。建築で使う固定荷重・積載荷重という荷重用途の分類や、時間変動の有無とは分けて考えます。

## Q 5-14　指定変位

**問題**

指定変位 $u=\bar u$ を課すディリクレ境界条件を、既知自由度の消去によって処理する。適切な説明はどれか。

**選択肢**

1. 力として右辺に足すだけ。
2. 既知自由度を消去し、未知自由度の右辺にも既知変位の寄与を反映する。
3. 変位と力を常に同一の境界条件とする。
4. 構造解析には存在しない。

**正答** 2番：既知自由度を消去し、未知自由度の右辺にも既知変位の寄与を反映する。

**解説**

【自由度の分割】未知の自由度をf、指定された自由度をcとします。全体方程式の自由な行は $\mathbf K_{ff}\mathbf u_f+\mathbf K_{fc}\bar{\mathbf u}_c=\mathbf f_f$ です。
【移項】既知の変位を代入して $\mathbf K_{ff}\mathbf u_f=\mathbf f_f-\mathbf K_{fc}\bar{\mathbf u}_c$ とします。肢2が正答です。右辺に現れる項の単位は、剛性×変位なので力です。
【意味】支持点を動かせば、外力がなくても周囲へ力が伝わります。その効果が右辺の修正です。指定変位が0ならこの項も0になりますが、非零の強制変位では省略できません。拘束点の反力は、解いた変位を元の拘束行へ戻して求めます。

## Q 5-15　境界条件の実装

**問題**

正しい記述は？

**選択肢**

1. 有限のペナルティ係数で必ず厳密な拘束になる。
2. 縮約は未知数を減らさない。
3. 対角置換は対角0・非対角1にする。
4. 縮約は既知値を代入して自由方程式を解き、ペナルティ法は有限係数では近似拘束となる。

**正答** 4番：縮約は既知値を代入して自由方程式を解き、ペナルティ法は有限係数では近似拘束となる。

**解説**

【縮約】既知変位を代入し、未知変位だけの方程式を解きます。全体で解く未知数が減り、指定値は直接満たします。
【対角置換】対称性を保つ実装では、まず既知変位の列の寄与を右辺へ移します。その後、該当行・列の非対角項を0、対角を1、右辺を指定変位にします。行だけを置換する実装は対称性を失い得ます。
【ペナルティ】非常に硬いばねに相当する係数で拘束を近似します。有限の係数では拘束誤差が残り、係数を過大にすると行列の条件数が悪化し、丸め誤差や求解の難しさが増えます。各方法の特徴を正しく述べた肢4を選びます。

## Q 5-21　荷重の組込み

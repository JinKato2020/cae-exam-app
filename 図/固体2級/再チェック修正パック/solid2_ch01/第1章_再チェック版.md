# 第1章 再チェック修正版・本文

## 1-1 特異な係数行列と解の個数

**問題** 連立一次方程式 $A\boldsymbol{x}=\boldsymbol{b}$ の係数行列が $A=\begin{pmatrix}1&2\\2&4\end{pmatrix}$ である。右辺を変えたときの解に関する記述として正しいものはどれか。

1. $A$ は正則なので、右辺によらず解は一意に定まる。
2. $\boldsymbol b=(3,6)^T$ なら解は無数にあり、$(3,7)^T$ なら解は存在しない。
3. $\boldsymbol b=(3,6)^T$ なら解は存在せず、$(3,7)^T$ なら解は無数にある。
4. $\det A=0$ なので、右辺がどのような値でも解は存在しない。

**正解：2**

**解説** $\det A=1\times4-2\times2=0$ であり、第2行は第1行の2倍である。右辺が $(3,6)^T$ なら2式は同じ直線 $x_1+2x_2=3$ を表す。$x_2=t$ とすると $\boldsymbol x=(3-2t,t)^T$ で、任意の実数 $t$ に対して成立する。一方、$(3,7)^T$ では第2式から $x_1+2x_2=3.5$ となり、第1式と矛盾する。

一般に、この行列では $b_2=2b_1$ が解の存在条件である。これは右辺が $A$ の列空間（線形写像の値域）に属する条件であり、「第1行の値域」とは呼ばない。

## 1-2 行列式のスカラー倍と逆行列

**問題** $A$ は3次正方行列で、$\det A=4$ である。$\det(2A)$ と $\det(A^{-1})$ の組合せとして正しいものはどれか。

1. $8,\ 1/4$
2. $32,\ 1/4$
3. $8,\ 4$
4. $32,\ -4$

**正解：2**

**解説** $n$ 次正方行列では $\det(cA)=c^n\det A$ なので、$\det(2A)=2^3\times4=32$。また、$AA^{-1}=I$ の両辺の行列式を取ると $\det A\det A^{-1}=1$ より $\det A^{-1}=1/4$。体積の拡大率は $|\det A|$ であり、行列式の符号は向きの反転を表す。この問題では行列式が正なので、そのまま体積比として読める。

## 1-3 対称行列の固有値・固有ベクトル

**問題** 実対称行列 $A=\begin{pmatrix}5&2\\2&2\end{pmatrix}$ の固有値と、大きい方の固有値に対応する固有ベクトルの方向の組合せとして正しいものはどれか。方向を示すベクトルの非零定数倍は同じ固有方向とする。

1. 固有値は $1,6$、$\lambda=6$ の固有方向は $(1,-2)^T$。
2. 固有値は $2,5$、$\lambda=5$ の固有方向は $(2,1)^T$。
3. 固有値は $1,6$、$\lambda=6$ の固有方向は $(2,1)^T$。
4. 固有値は $1,6$、$\lambda=6$ の固有方向は $(1,2)^T$。

**正解：3**

**解説** $\det(A-\lambda I)=(5-\lambda)(2-\lambda)-4=\lambda^2-7\lambda+6=(\lambda-1)(\lambda-6)$ より固有値は1と6。$\lambda=6$ では $-v_1+2v_2=0$ なので固有ベクトルは $(2,1)^T$ の非零定数倍である。もう一方は $(1,-2)^T$ の非零定数倍で、内積 $2\times1+1\times(-2)=0$。単位長さに正規化するなら $(2,1)^T/\sqrt5$ とする。

## 1-4 2変数関数の1次近似

**問題** $f(x,y)=e^x\cos y$ を $(0,0)$ のまわりで1次までテイラー展開した近似式として正しいものはどれか。

1. $1+x$
2. $1+x-y^2/2$
3. $1+x+y$
4. $1+x-y$

**正解：1**

**解説** $f(0,0)=1$、$f_x(0,0)=1$、$f_y(0,0)=0$ なので、$f(x,y)=1+x+O(x^2+y^2)$。接平面は $z=1+x$ で、$y$ 方向には1次の傾きがない。選択肢2は1次近似を超えているうえ、完全な2次近似でもない。2次までなら $1+x+(x^2-y^2)/2$ となる。

## 1-5 極座標と連鎖律

**問題** 微分可能な関数 $w=f(x,y)$ を $x=r\cos\theta,\ y=r\sin\theta$ で表す。$r>0$ とし、半径 $r$ を一定に保った偏微分 $\partial w/\partial\theta$ を求める式はどれか。ただし $f_x=\partial f/\partial x,\ f_y=\partial f/\partial y$ は対応する点で評価する。

1. $\cos\theta\,f_x+\sin\theta\,f_y$
2. $-r\sin\theta\,f_x+r\cos\theta\,f_y$
3. $-\sin\theta\,f_x+\cos\theta\,f_y$
4. $r\cos\theta\,f_x+r\sin\theta\,f_y$

**正解：2**

**解説** $\partial x/\partial\theta=-r\sin\theta$、$\partial y/\partial\theta=r\cos\theta$ を連鎖律へ代入する。角度に対する位置変化ベクトルは接線方向を向き、その長さは $r$ である。単位接線方向の空間微分は $(1/r)\partial w/\partial\theta$ であり、角度微分そのものと区別する。

## 1-6 ガウス・グリーンの公式

**問題** 有界領域 $\Omega\subset\mathbb R^3$ の境界を $\Gamma$、外向き単位法線を $\boldsymbol n$ とする。$f$ と $\boldsymbol g$ は公式が適用できる程度に滑らかとする。正しい部分積分公式はどれか。

1. $\displaystyle\int_\Omega f\,\nabla\!\cdot\boldsymbol g\,dV=\int_\Gamma f\boldsymbol g\!\cdot\boldsymbol n\,dS-\int_\Omega\nabla f\!\cdot\boldsymbol g\,dV$
2. $\displaystyle\int_\Omega f\,\nabla\!\cdot\boldsymbol g\,dV=\int_\Omega\nabla f\!\cdot\boldsymbol g\,dV-\int_\Gamma f\boldsymbol g\!\cdot\boldsymbol n\,dS$
3. $\displaystyle\int_\Omega f\,\nabla\!\cdot\boldsymbol g\,dV=\int_\Gamma f\boldsymbol g\!\cdot\boldsymbol n\,dS+\int_\Omega\nabla f\!\cdot\boldsymbol g\,dV$
4. $\displaystyle\int_\Omega f\,\nabla\!\cdot\boldsymbol g\,dV=-\int_\Gamma f\boldsymbol g\!\cdot\boldsymbol n\,dS-\int_\Omega\nabla f\!\cdot\boldsymbol g\,dV$

**正解：1**

**解説** 積の微分 $\nabla\!\cdot(f\boldsymbol g)=\nabla f\!\cdot\boldsymbol g+f\nabla\!\cdot\boldsymbol g$ を領域内で積分し、発散定理を使う。$\int_\Omega\nabla\!\cdot(f\boldsymbol g)dV=\int_\Gamma f\boldsymbol g\!\cdot\boldsymbol n\,dS$ を整理すれば選択肢1になる。境界の法線が外向きであることが符号の基準である。

## 1-7 初期値問題と境界値問題

**問題** 次の解析について、初期条件と境界条件の説明として最も適切なものはどれか。静的解析は、初期応力・固有ひずみのない、微小変形の線形弾性問題とする。

1. 静的解析では初期速度を必要とせず、荷重と、剛体運動を除く適切な拘束条件によって変位を求める。
2. 静的解析でも初期速度を指定しなければ変位は一意に定まらない。
3. 非定常熱伝導解析では、一般に初期温度分布を指定する必要はない。
4. 時間積分による動的解析では、初期変位だけを指定すれば初期速度や荷重履歴を指定する必要はない。

**正解：1**

**解説** 静的線形弾性問題は時間発展を解く問題ではない。荷重、材料・形状、適切な境界条件によって釣合い変位を求める。自由な剛体運動が残る場合、変位はその分だけ一意でなくなる。

非定常熱伝導では一般に初期温度分布、構造動解析の時間積分では一般に初期変位・初期速度が必要である。動解析でも境界での力・変位条件や荷重履歴を設定するが、必ず変位拘束が必要という意味ではない。自由物体でも慣性と初期条件を含む運動方程式を解ける。周波数領域の定常応答や固有値解析は、初期値から時間積分する問題とは区別する。

## 1-8 三次元応力の釣合いと対称性

**問題** 物体力を無視できる三次元の静的な古典連続体を考える。体積偶力はない。$\tau_{ij}$ の第1添字は面の法線方向、第2添字は力の方向を表す。正しい記述はどれか。

1. x方向の釣合いは $\partial\sigma_x/\partial x+\partial\sigma_y/\partial y+\partial\sigma_z/\partial z=0$ である。
2. x方向の釣合いは $\partial\sigma_x/\partial x+\partial\tau_{yx}/\partial y+\partial\tau_{zx}/\partial z=0$ だが、一般に $\tau_{xy}\ne\tau_{yx}$ である。
3. $\tau_{xy}=\tau_{yx}$ は力の釣合いだけから導かれ、モーメントの釣合いとは無関係である。
4. x方向の釣合いは $\partial\sigma_x/\partial x+\partial\tau_{yx}/\partial y+\partial\tau_{zx}/\partial z=0$ であり、モーメントの釣合いから $\tau_{xy}=\tau_{yx}$ などの対称性が成り立つ。

**正解：4**

**解説** x面対、y面対、z面対からのx方向の合力を足すと、上記の微分式になる。法線応力だけではなく、y面とz面のせん断応力もx方向の釣合いへ寄与する。角運動量の釣合いから $\tau_{xy}=\tau_{yx},\ \tau_{yz}=\tau_{zy},\ \tau_{zx}=\tau_{xz}$。したがって応力の独立成分は法線3個・せん断3個の計6個である。動的な問題では慣性項、物体力がある問題では物体力項を加える。

## 1-9 線形解の重ね合わせ

**問題** 同じ領域で $-\Delta u=f$、$-\Delta v=g$ が成り立ち、$u,v$ はともに境界でゼロを満たす。$-\Delta w=2f-g$、$w=0$（境界上）を満たす解はどれか。

1. $w=u-2v$
2. $w=2(u-v)$
3. $w=2u-v$
4. $w=2u+v$

**正解：3**

**解説** 線形性から $-\Delta(2u-v)=2(-\Delta u)-(-\Delta v)=2f-g$。境界でも $2u-v=0$ なので選択肢3が成立する。同じ非零境界値を与えた2解では、任意の線形結合が同じ境界値を満たすとは限らない。重ね合わせでは方程式と境界条件の両方を確認する。

## 1-10 前進差分と中心差分

**問題** $f(x)=x^3$ の $x=1$ における導関数を、刻み幅 $h=0.1$ で近似する。前進差分 $[f(1+h)-f(1)]/h$ と中心差分 $[f(1+h)-f(1-h)]/(2h)$ の値・打切り誤差の次数として正しいものはどれか。丸め誤差は無視する。

1. 前進3.31〔$O(h^2)$〕、中心3.01〔$O(h)$〕。
2. 前進3.01〔$O(h)$〕、中心3.31〔$O(h^2)$〕。
3. 前進3.31〔$O(h)$〕、中心3.00〔打切り誤差なし〕。
4. 前進3.31〔$O(h)$〕、中心3.01〔$O(h^2)$〕。

**正解：4**

**解説** 真値は $f'(1)=3$。前進差分は $(1.331-1)/0.1=3.31$、中心差分は $(1.331-0.729)/0.2=3.01$。この例では前進差分を厳密に展開すると $3+3h+h^2$、中心差分は $3+h^2$ なので、打切り誤差はそれぞれ $3h+h^2$ と $h^2$。今回の絶対誤差は0.31と0.01で、中心差分は前進差分の1/31である。

一般の滑らかな関数で中心差分の分子をテイラー展開すると、偶数次項が相殺される。残った奇数次項を $2h$ で割るため、導関数の誤差は $O(h^2)$ となる。「奇数次項が相殺」とする説明は誤り。刻みを極端に小さくすると丸め誤差の影響が増す場合があり、ここではそれを除外している。

## 1-11 二階微分の中心差分

**問題** 十分滑らかな関数 $f$ の二階微分 $f''(x)$ を、$x-h,x,x+h$ の3点で二次精度に近似する式はどれか。$h>0$ とする。

1. $[f(x+h)-f(x-h)]/(2h)$
2. $[f(x+h)-f(x)+f(x-h)]/h^2$
3. $[f(x+2h)-2f(x+h)+f(x)]/h^2$
4. $[f(x+h)-2f(x)+f(x-h)]/h^2$

**正解：4**

**解説** 対称な2点の展開を足すと $f(x+h)+f(x-h)=2f(x)+h^2f''(x)+h^4f^{(4)}(x)/12+\cdots$。したがって選択肢4は $f''(x)+O(h^2)$。重みは $(1,-2,1)$、分母は $h^2$ である。

重みの和がゼロであることは定数をゼロへ写す条件にすぎない。一次関数をゼロへ写すには一次モーメントもゼロである必要がある。本式では $(-h)\times1+0\times(-2)+h\times1=0$ も満たす。選択肢3は $x$ で評価するなら一次精度だが、$x+h$ での二階微分として見れば二次精度の中心差分である。

## 1-12 有限要素解の収束次数

**問題** 滑らかな凸領域での二階線形楕円型問題を、$k$ 次の適合ラグランジュ有限要素（$k\ge1$）で解く。厳密解と双対問題の必要な正則性があり、形状正則・準一様なメッシュを用い、幾何近似・数値積分による精度低下はないものとする。代表寸法を $h$ としたとき、解の $L^2$ 誤差と一階微分の $L^2$ 誤差について、一般の滑らかな解に対する標準的な最適収束次数の組合せはどれか。

1. 解 $O(h^k)$、一階微分 $O(h^k)$。
2. 解 $O(h^{k-1})$、一階微分 $O(h^k)$。
3. 解 $O(h^{k+1})$、一階微分 $O(h^k)$。
4. 解 $O(h^{k+1})$、一階微分 $O(h^{k+1})$。

**正解：3**

**解説** 標準的な評価は $\|u-u_h\|_{L^2}\le C_0h^{k+1}$、$\|\nabla(u-u_h)\|_{L^2}\le C_1h^k$ である。ここで定数は $h$ に依存しない。一次要素では解が二次、一階微分が一次の評価となる。$L^2$ 誤差の一段高い次数には、解だけでなく双対問題の正則性なども必要となる。

これは誤差の上限評価であり、すべての問題で必ず同じ非零誤差や傾きが観測される意味ではない。厳密解を要素空間で完全に表せる場合や超収束では異なる挙動がある。特異点・強い要素ゆがみがある問題へ無条件に適用しない。応力には材料定数がかかるので、応力誤差と変位誤差の数値を単位の異なるまま直接比較しない。

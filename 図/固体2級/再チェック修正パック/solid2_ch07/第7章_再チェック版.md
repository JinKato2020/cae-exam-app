# 第7章 再チェック版（問題本文のみ）

このファイルには問題本文・選択肢・正解・解説だけを収録する。回答前の分類表示は抑制し、図は別添の適用一覧に従う。

## 7-1 解の連続性

同じ次数・共有辺で適合する、標準的なC0変位要素の未平均化出力について適切なのは？

1. 変位・ひずみ・応力がすべて共有辺で必ず連続。
2. 変位は連続、ひずみ・応力は一般に要素間で不連続。
3. ひずみだけが必ず連続。
4. 要素内の変位も節点ごとに飛ぶ。

**正解：2**

C0適合性は共有辺全体の変位連続を要求する。共有節点があるだけで、異なる補間や不整合な接続の辺全体の適合が自動保証されるわけではない。異材界面では物理的な成分差もあり、応力差をすべて離散化誤差とみなさない。

## 7-2 温度と熱流束

標準的な適合温度要素で、共有辺の要素別熱流束を平滑化せずに評価する。適切なのは？

1. 温度・流束は常に両方連続。
2. 温度・流束は必ず両方不連続。
3. 温度は連続、流束は一般に点ごとには一致しない。
4. 温度は不連続、流束は常に連続。

**正解：3**

q=−λ∇T。真の界面では表面熱源なしなら法線熱流束が保存されるが、通常の温度型FEMの未平均化流束は要素境界で点ごとには一致しない。物理的に接線成分が異なる異材界面とは区別する。

## 7-3 CSTの場

直線辺CST、微小変形、一定D、初期ひずみなし。適切なのは？

1. ひずみは二次分布。
2. 同一要素の応力が節点位置だけで変わる。
3. 一要素で一般の曲げ勾配を厳密再現。
4. ひずみ・応力は要素内で一定。

**正解：4**

変位が一次式なので微分は定数。Dや固有ひずみが変化する場合まで応力一定とは言えない。

## 7-4 CSTのひずみ計算

A(0,0),B(5,0),C(0,4) mm。x方向変位はuA=0.008、uB=0.033、uC=0.020 mm。εxは？

1. 0.005
2. 0.003
3. 0.007
4. 0.008

**正解：1**

u=0.008+0.005x+0.003y。εx=∂u/∂x=(0.033−0.008)/5=0.005。要素内で一定で、局所勾配の表現には細分化・高次化を検討する。節点変位をひずみと取り違えない。

## 7-5 要素数をそろえる比較

滑らかな解に対して同じ形状・要素数で、適切な一次要素と二次要素を比較する。妥当なのは？

1. 二次は表現力を増やせるが、自由度や要素演算が増える。
2. 一次が必ず高精度。
3. 次数は精度に無関係。
4. 二次にすると計算時間が必ず半減。

**正解：1**

高次化が有利になる条件と費用を合わせて評価する。特異性・要素歪み・積分方法などにより結果は変わり、精度や時間の絶対的順位は保証しない。

## 7-6 自由度をそろえる比較

一次と高次の総未知自由度をほぼ同じにした。妥当なのは？

1. 精度・時間は自由度数だけで完全に決まる。
2. 高次が滑らかな場で有利なことはあるが、同じ自由度数でも時間が同じとは限らない。
3. 高次の利点は一切ない。
4. 同じ自由度なら必ず同じ剛性行列になる。

**正解：2**

疎行列の非零数・結合密度・フィルイン・積分点数・条件数・前処理で計算時間は変わる。同じ自由度数という情報だけで同等時間を断定しない。

## 7-7 二次辺の温度

s=0,0.5,1で温度は60,40,40℃。二次補間に関する適切な説明は？

1. 60から40へ直線で減少。
2. 全区間で必ず40〜60に収まる。
3. s=0.75で37.5℃となる。
4. 中間節点は分布に影響しない。

**正解：3**

T(s)=60−60s+40s²。T′=−60+80s=0よりs=0.75、T=37.5℃。これは補間のアンダーシュートで、原問題の真の温度最小値が37.5℃と保証するものではない。

## 7-8 円弧の二次近似

標準Q8の円弧境界に関する適切な説明は？

1. 中間節点を弦の中点に置けば厳密な円弧になる。
2. Q8の辺は必ず直線。
3. 中間節点を円弧上に置くことで、二次曲線により円弧を近似する。
4. isoでは座標一次・変位二次を必ず使う。

**正解：3**

通常の多項式二次写像は一般の円弧を厳密には表さない。弦の中点に置いた三節点は一直線になる。曲率・角度・要素品質を確認し、必要な境界分割で形状誤差を減らす。

## 7-9 構造要素と連続体要素

一般的な分類として適切なのは？

1. 構造：トラス・はり・シェル／連続体：平面・ソリッド
2. 構造：平面・ソリッド／連続体：はり・シェル
3. 構造：ソリッドのみ／連続体：トラスのみ
4. すべて同じ断面仮定を用いる。

**正解：1**

構造要素は断面・板厚方向を梁・板理論などで縮約する。平面応力・平面ひずみも三次元からの仮定を含むため、「連続体要素は仮定を一切置かない」とは言わない。

## 7-10 はりの自由度

標準的な二節点Euler–Bernoulliはりの一平面の曲げ自由度は？

1. たわみと曲げモーメント
2. たわみとせん断力
3. たわみと断面回転
4. たわみと曲率

**正解：3**

節点のたわみと傾きを三次Hermite補間する。Timoshenkoはりでは断面回転とたわみの傾きはせん断変形により異なる。

## 7-11 分割の判断

孔周辺の応力集中を評価する適切な方針は？

1. 細長い外形に合わせ全要素を必ず極端に細長くする。
2. 孔周辺の曲率と応力勾配を解像し、収束を確認する。
3. 一様引張パッチテストだけで応力集中精度を保証する。
4. 一次四面体を使えば常に曲げ精度が最高。

**正解：2**

パッチテストは定式化・接続の基本検証に有用だが、局所場の解像度検証を代替しない。アスペクト比は場の方向性・要素種類を考えて判断し、1であれば無条件に最良とは言えない。

## 7-12 四面体と六面体

三次元の曲げと複雑形状のメッシュについて妥当なのは？

1. 一次四面体が常に最高精度。
2. 六面体なら品質検査は不要。
3. 形状・次数・積分は精度に無関係。
4. 四面体は複雑形状の自動分割に使いやすく、曲げには二次四面体や適切な六面体を検討する。

**正解：4**

低次四面体は一定ひずみで、粗い分割の曲げに硬い応答を示しやすい。ただし六面体も定式化・品質・分割次第で精度が変わる。

## 7-13 曲げとCST分割

CSTを用いる片持ばりの曲げについて適切なのは？

1. 要素内で二次応力を持つ。
2. 高さ方向の分割は不要。
3. 長手方向の変位変化と高さ方向の応力勾配の両方を解像する。
4. 孔の応力集中も分割と無関係。

**正解：3**

Euler–Bernoulliの先端力によるたわみは長手三次、曲げ応力は断面高さに対して一次。一定応力要素の組合せで近似するため、両方向の収束を調べる。

## 7-14 Q4とQ8の比較

片持ばりをQ8で高さ4×長さ10、Q4で高さ6×長さ20に分割した。この情報から妥当な判断は？

1. Q4が必ず高精度。
2. Q8はQ4と同じ補間空間。
3. 次数の違いがあるため、分割数だけでは順位を決めず同一評価量の収束で比較する。
4. Q8は常にQ4以上の要素数を必要とする。

**正解：3**

Q4は双一次であり一般に定ひずみではない。長方形のu=axyはεx=ayを表せるが、純曲げのv∝x²が不足するため寄生せん断が生じ得る。Q8は改善し得るが、提示分割数だけで任意条件の優劣を保証しない。

## 7-15 はり理論の基準値

b=1 mm、h=20 mm、L=150 mm、E=200000 N/mm²、先端力W=10 NのEuler–Bernoulli片持ばり。面内曲げのIと先端たわみδの組合せは？

1. I=1333.3 mm⁴、δ=0.0422 mm
2. I=666.7 mm⁴、δ=0.0844 mm
3. I=666.7 mm⁴、δ=0.1688 mm
4. I=2666.7 mm⁴、δ=0.0844 mm

**正解：2**

I=bh³/12=666.6667 mm⁴、δ=WL³/(3EI)=0.084375 mm。二次元弾性FEMと梁理論は同一モデルではなく、せん断・支持部影響などで差があり得る。一般の先端変位を「梁理論値へ必ず下から収束し、超えない」とは断定しない。

## 7-16 変位比の読み方

解析記録で、CSTモデルAの変位比δA/δref=0.25、Q4モデルBは0.60、Q8モデルCは1.00だった。δref=0.80 mm。Aのたわみと、この記録の解釈は？

1. 0.20 mm、この結果だけで全問題のCST精度が保証される。
2. 3.20 mm、比で割る。
3. 0.20 mm、この三モデルではAの荷重点変位が最小。
4. 0.80 mm、要素種類によらず同じ。

**正解：3**

δA=0.80×0.25=0.20 mm。同一荷重なら小さい荷重点変位はその評価で硬い応答を示す。ただし要素名だけから比の対応や全問題の優劣を逆算して保証することはできない。比1.00も他の応力量の正確さを保証しない。

## 7-17 正方形要素の写像

一辺a=5 mmの軸に平行なQ4を[−1,1]²から写像する。同じ材料・厚さ・積分・向き・局所節点順の、平行移動だけ異なる要素を比較する。適切なのは？

1. det J=6.25 mm²で一定、要素剛性は同じ。
2. det J=25 mm²、絶対位置で剛性が変わる。
3. det J=2.5 mm²、厚さを変えても剛性は同じ。
4. det J=0、正方形は不正要素。

**正解：1**

J=diag(a/2,a/2)、det J=a²/4=6.25 mm²。並進しても形状微分は変わらない。本問の共通条件を外して材料・厚さ・向き・番号順を変えれば、行列成分の同一性は無条件には成り立たない。

## 6-1 疎行列の記憶

疎行列の標準的な格納について適切なのは？

1. すべてのn²成分を必ず格納する。
2. 非零位置の情報は不要。
3. 密配列の方が必ず省メモリ。
4. 非零値と、その行・列位置を特定する添字を格納する。

**正解：4**

CSRは値・列添字・行開始位置を持つ。記憶量は概ね非零数に比例する。直接法の分解ではフィルインにより非零が増えるので、元の非零数だけで分解の費用は決まらない。

## 6-2 帯幅とスカイライン

対称行列の上三角を格納する。同じ自由度順序で比較した適切な説明は？

1. 帯幅は番号付けと無関係。
2. 半帯幅bの格納量は概ねn(b+1)、スカイラインは列ごとの包絡内を格納する。
3. スカイラインは全列を最大帯幅にそろえる。
4. 離れた自由度を近い番号にしないことが必ず帯幅を減らす。

**正解：2**

b=max|i−j|（結合する自由度）。節点当たり複数自由度なら、節点番号差そのものではなく自由度番号で測る。スカイラインは包絡内の零も格納するが、一定帯幅内の不要領域を減らせる。

## 6-3 ガウス消去法

標準的な解法の説明は？

1. 後退代入で上三角化してから消去する。
2. 係数の下三角だけを残して終了する。
3. 前進消去で上三角化し、後退代入で下の式から未知数を求める。
4. 上三角化すれば対角がそのまま解になる。

**正解：3**

必要に応じてピボットを選び、係数行列と右辺へ同じ行操作を行う。逆行列を陽に作る必要はない。

## 6-4 LU分解

必要なピボット交換をPに含める。PA=LUの利点は？

1. Uの対角だけが未知数の解になる。
2. 同じAで右辺だけが変わるとき、分解を再利用できる。
3. L,Uだけでは方程式を解けない。
4. LUは固有値分解そのものである。

**正解：2**

Ly=Pbを前進代入、Ux=yを後退代入で解く。一般の正則行列でも交換なしのLUが存在するとは限らない。

## 6-5 LUの成分

$A=\begin{pmatrix}1&2&1\\3&8&6\\2&2&3\end{pmatrix}$。$L$ の対角成分を1とする、行交換なしの分解 $A=LU$ で $\ell_{32}$ は？

1. 2
2. 1
3. −1
4. −3

**正解：3**

$U$ の第1行は $(1,2,1)$、$\ell_{21}=3$、$\ell_{31}=2$。$u_{22}=8-3\times2=2$、$u_{23}=6-3\times1=3$ より、$\ell_{32}=(2-2\times2)/2=-1$。$L=\begin{pmatrix}1&0&0\\3&1&0\\2&-1&1\end{pmatrix}$、$U=\begin{pmatrix}1&2&1\\0&2&3\\0&0&4\end{pmatrix}$。積 $LU=A$ で検算できる。

## 6-6 反復法の費用

疎な連立方程式の反復解法について適切なのは？

1. すべての行列で必ず収束する。
2. 疎行列の演算を利用して、直接法より省メモリ・高速になる場合がある。
3. 直接法より必ず少ない反復回数で解ける。
4. 必ず密行列を格納する。

**正解：2**

収束は方法・行列・前処理に依存する。不完全分解を使う前処理もあるため「反復法は分解を一切使わない」は不正確。残差だけでなく停止規準と精度要求を確認する。

## 6-7 解法の分類

適切な分類は？

1. LU・ガウス消去は直接法、ヤコビ・共役勾配は反復法。
2. 共役勾配は直接法、LUは反復法。
3. 疎行列ならすべて反復法。
4. 密行列なら反復法は使えない。

**正解：1**

直接法は分解・代入などの手順で解く。反復法は近似解を更新する。CGも厳密演算では有限次元の所定回数以内に終了し得るので、単に「有限回か無限回か」だけで区別しない。直接法にも残差検査や反復改良が有効。

## 6-8 求積点

標準Gauss–Legendreと閉型Newton–Cotesの違いは？

1. Gaussは必ず両端点を使う。
2. Gaussは内部のLegendre多項式の根、閉型Newton–Cotesは両端を含む等間隔点を使う。
3. 両者は点の位置が常に同じ。
4. 閉型Newton–Cotesは端点を使わない。

**正解：2**

Gaussの少点数の配置を含めて「常に不等間隔」と断定しない。n点Gauss–Legendreの多項式精度は2n−1。

## 6-9 要素の数値積分

ガウス求積が要素剛性に用いられる理由は？

1. すべての要素は一点積分しか使えない。
2. 任意の関数で常に誤差ゼロ。
3. 積分点は必ず応力の最高精度点になる。
4. 解析積分が複雑な場合にも、関数値と重みの和で効率よく評価できる。

**正解：4**

Ke=∫BᵀDB dV。座標写像を含むと非多項式になり得る。多項式の保証次数を超える関数では誤差が残る。点数を増やしても離散化誤差やモデル誤差は消えず、各点での応力精度も一律には保証されない。

## 6-10 板厚積分

板厚の両表面を積分点に含むシンプソン型の積分について正しい説明は？

1. 標準Q8の面内積分にはGaussを使用できない。
2. 点数だけを増やせば空間離散化誤差も必ずゼロ。
3. 両表面を評価点に含められるため、層・表面応力を扱うシェル定式化で用いられる。
4. n点Gaussの最高保証次数は常にnである。

**正解：3**

板厚積分法はソルバ・要素に依存し、Gauss型を使うシェルもある。応力の表面への外挿・評価と、剛性や断面力の積分を区別する。Gaussの保証次数は2n−1。

## 6-11 必要な求積点数

$\displaystyle\int_{-1}^{1}(x^4+x^2)\,dx$ を標準Gauss–Legendre求積で厳密に計算する最低点数は？

1. 2
2. 3
3. 4
4. 5

**正解：2**

三点なら五次まで正確。厳密値は2/5+2/3=16/15。二点では2(1/9+1/3)=8/9、一点では0なので一致しない。

## 6-12 二点Gauss

$\displaystyle\int_{-1}^{1}(x^2+1)\,dx$ を、二点Gauss求積（点 $\pm1/\sqrt3$、重み各1）で計算した結果は？

1. 2
2. 8/3
3. 4/3
4. 4

**正解：2**

両点の関数値は4/3。合計8/3。二次なので保証次数三以下に入り、厳密値と一致する。

## 6-13 三次元の点数

三次元で各基準座標方向に二点のテンソル積求積を用いる。総点数は？

1. 4
2. 6
3. 8
4. 27

**正解：3**

2×2×2=8。H8で通常「完全積分」と呼ばれる規則。ただし歪んだ写像で積分の数学的厳密性まで保証する呼称ではない。

## 6-14 値と傾きの補間

異なるn個の点を考える。適切な説明は？

1. Lagrangeは値と傾きを使う。
2. 値だけのLagrangeの最大次数はn。
3. Hermiteは値だけを使う。
4. 各点の値と一階微分を指定するHermite補間は、次数高々2n−1の多項式を定める。

**正解：4**

Lagrangeは値n個から高々n−1次。Hermiteは条件2n個から高々2n−1次。データによって実際の次数は下がる。二節点の三次HermiteはEuler–Bernoulliはりのたわみ・傾き補間に対応する。

## 6-15 三点補間

(x,y)=(0,1),(2,5),(4,17)を通る次数高々2の多項式のx=1での値は？

1. 2
2. 3
3. 4
4. 5

**正解：1**

基底の値は3/8、3/4、−1/8。和は1。y=3/8+15/4−17/8=2。多項式y=x²+1でも検算できる。

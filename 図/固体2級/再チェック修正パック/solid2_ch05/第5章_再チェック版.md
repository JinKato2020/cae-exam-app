## 5-1 アイソパラメトリック要素

誤った記述はどれか。

1. 座標と変位を同じ形状関数で補間する。
2. 形状関数は必ず二次以上である。
3. 同じ基準座標で座標写像と変位補間を定義する。
4. 一次・二次などの要素がある。

**正解：2**

isoは座標と変位の補間を同じにする意味。一次のQ4やH8もある。座標微分と変位微分で同じ基底を使うが、物理座標微分にはヤコビ行列による変換が必要。

## 5-2 補間の分類

座標側の補間次数を基準とした正しい分類は？

1. 同一補間はサブ。
2. 同一はiso、座標が変位より高次ならsuper、低次ならsub。
3. 座標が高次ならsub、低次ならsuper。
4. 節点数が同じなら基底が異なっても必ずiso。

**正解：2**

節点数だけで分類せず、座標と変位の補間空間・形状関数を比べる。

## 5-3 四辺形要素の次数

標準的なQ4とQ8について正しい組合せは？

1. Q4二次・Q8一次
2. Q4双一次・Q8二次セレンディピティ
3. 両者とも定数
4. Q4一次・Q8三次ラグランジュ

**正解：2**

Q4は各基準座標に関して一次だがξη項を含む。Q8は二次要素と呼ぶがξ²η、ξη²も含む。総次数と要素の呼称を混同しない。

## 5-4 基準要素と座標写像

標準的なQ4/Q8で、要素の写像は一対一かつdet J>0とする。誤った説明は？

1. 三角形の面積座標L1,L2,L3をそのまま基準四辺形の座標にする。
2. 基準座標ξ,ηを使う。
3. 基準要素内の点と物理要素内の点が一対一に対応する。
4. Jによって微分を変換する。

**正解：1**

四辺形では通常[−1,1]²を使う。点の一対一対応は要素が適切な写像を持つという前提が必要で、逆転・自己交差した要素まで保証しない。

## 5-5 座標補間

節点座標を $(x_i,y_i)$、形状関数を $N_i$ とする。正しい座標補間の式は？

1. $x=\sum_i N_i x_i,\quad y=\sum_i N_i y_i$
2. $x=\sum_i (\partial N_i/\partial\xi)x_i,\quad y=\sum_i (\partial N_i/\partial\eta)y_i$
3. $x=\sum_i N_i^2 x_i,\quad y=\sum_i N_i^2 y_i$
4. $x=\sum_i x_i/N_i,\quad y=\sum_i y_i/N_i$

**正解：1**

位置も節点値の補間であり、微分・二乗・逆数は使わない。

## 5-6 Q4の曲げ表現

長方形の標準Q4一要素で厳密には再現できない変位場は？

1. u=ax、v=0
2. u=0、v=by
3. u=cy、v=0
4. u=−κxy、v=κx²/2（κ≠0）

**正解：4**

Q4の空間は{1,x,y,xy}を含むがx²を含まない。純曲げでは変位の二次項が必要。曲げひずみ・応力は断面高さに対して一次分布であり、「曲げ応力が二次分布」ではない。

## 5-7 ヤコビ行列

次の定義のヤコビ行列 $J$ の役割はどれか。

$$J=\begin{pmatrix}\partial x/\partial\xi&\partial y/\partial\xi\\\partial x/\partial\eta&\partial y/\partial\eta\end{pmatrix}$$

1. 材料則
2. 節点力の直接計算
3. 基準座標微分を物理座標微分へ変換する
4. 質量集計

**正解：3**

連鎖律により、$\begin{pmatrix}\partial N/\partial\xi\\\partial N/\partial\eta\end{pmatrix}=J\begin{pmatrix}\partial N/\partial x\\\partial N/\partial y\end{pmatrix}$。$\det J\ne0$ のとき、$J^{-1}$ によって基準座標微分から物理座標微分を求める。この定義の転置をヤコビ行列とする資料では、変換式もその定義に合わせる。

## 5-8 内部変数の縮約

要素内部の追加変数を静的縮約する曲げ改善手法について、誤ったものは？

1. 曲げ表現を改善できる。
2. 追加変数は隣接要素と共有する節点自由度ではない。
3. 追加変数を要素内で消去できる。
4. 縮約後も追加変数すべてを全体未知数として残さなければならない。

**正解：4**

ブロック方程式から内部変数を消去するとSchur補行列が得られる。全体自由度は増えないが要素演算の費用は増え得る。非適合変位モードと拡張ひずみ型は異なり、すべてが境界変位の不連続を生むとは言えない。

## 5-9 高次六面体

標準的な二次要素について適切なのは？

1. 27節点ラグランジュ要素に内部節点はない。
2. 20節点六面体は8隅と12辺中央の節点をもつセレンディピティ要素。
3. 同じ節点数ならセレンディピティが必ず高精度。
4. 内部節点の有無だけで積分点数が決まる。

**正解：2**

H20には面中央・体積中央の節点がない。H27には6面中央と1体積中央が加わる。一次ラグランジュ要素にも必ず内部節点がある、という一般化は避ける。

## 5-10 補間と微分

長方形のQ8が u=ax²、v=0 を正確に補間したときのεxは？

1. 2ax（一次）
2. ax²（二次）
3. a（定数）
4. 0

**正解：1**

εx=∂u/∂x=2ax。特定の再現できる多項式を微分した結果を問う。一般の歪んだQ8のひずみ場が常に物理座標の完全一次多項式になるわけではない。

## 5-11 分布圧力の節点力

分布圧力を与える適切な方法は？

1. 合力を常に一節点へ集中する。
2. t=−pnを形状関数で積分して等価節点力へ換算する。
3. Paの値をそのままNとして各節点に入れる。
4. 常に接線方向の力にする。

**正解：2**

fe=∫Γ Nᵀt dS。法線nは外向き、正のpは圧縮。直線・一定厚さの二節点辺では等分、三節点二次辺の一定ベクトル荷重では1:4:1。曲面では法線・面積写像も積分するので単純比を無条件に使わない。

## 5-12 体積力と表面力

体積力ではないものは？

1. 材料密度ρと重力加速度gによるρg
2. 回転座標系での遠心力密度ρω²r
3. 帯電した体積に作用する電気力密度ρeE
4. 物体表面に作用する流体圧力

**正解：4**

流体圧力は物体表面に作用する表面力で、荷重ベクトルには表面積分として組み込む。他の三つは単位体積当たりの力である。浮力も、実際の作用面で見ると静水圧の表面合力である。合力を等価な体積力として表す場合と、元の荷重の分類を区別する。

## 5-13 変形に追従しない荷重

本問ではdead loadを、解析中に固定した大きさ・全体座標方向の荷重と定義する。該当するものは？

1. 固定方向の一定集中力
2. 常に変形後の面法線へ向く圧力
3. 時間とともに変わる移動力
4. 変位に比例するばね力

**正解：1**

この意味でのdead loadとfollower loadを比較する。建築の固定荷重・積載荷重という別の分類との混同を避ける。

## 5-14 指定変位

u=ūを課すディリクレ条件の適切な処理は？

1. 力として右辺に足すだけ。
2. 既知自由度を消去し、未知自由度の右辺にも既知変位の寄与を反映する。
3. 変位と力を常に同一の境界条件とする。
4. 構造解析には存在しない。

**正解：2**

自由自由度を $f$、既知自由度を $c$ とすると、$K_{ff}u_f=f_f-K_{fc}\bar u_c$。非零の強制変位では、自由自由度の右辺にも既知変位の寄与を反映する必要がある。

## 5-15 境界条件の実装

正しい記述は？

1. 有限のペナルティ係数で必ず厳密な拘束になる。
2. 縮約は未知数を減らさない。
3. 対角置換は対角0・非対角1にする。
4. 縮約は既知値を代入して自由方程式を解き、ペナルティ法は有限係数では近似拘束となる。

**正解：4**

対称性を保つ対角置換では、既知変位の列寄与を右辺へ移してから該当行・列の非対角項を0、対角を1、右辺を指定値にする。ペナルティを過大にすると条件数が悪化する。行だけ置換する実装もあるが対称性を失い得る。

## 5-16 境界条件の意味

構造の変位型解析について適切なのは？

1. 指定変位は0に限る。
2. 指定表面力はディリクレ条件。
3. ディリクレは変位、自然境界条件は表面力。非零変位も指定できる。
4. 表面力を与えるだけで必ず一意解になる。

**正解：3**

十分な拘束により剛体運動を除くことが必要。指定変位を一つ加えるだけで、すべての機構・剛体運動が除けるとは限らない。熱伝導では対流境界などにより定常問題を一意化できる場合もある。

## 5-17 対称面

微小変形の変位型ソリッドで、形状・材料・荷重・拘束が鏡映対称、対称な解を考える。切断面の条件は？

1. 全変位を0にする。
2. 自由面にする。
3. 法線変位を0、接線方向は自由にする。
4. 架空の外力を加える。

**正解：3**

対称面ではun=0、接線表面力=0。ビーム・シェルでは回転自由度にも対応する条件が必要で、この三並進成分の説明をそのまま流用しない。

## 5-18 温度境界

熱伝導のディリクレ条件は？

1. 熱流束指定
2. 断熱
3. 温度指定
4. 熱伝達係数と流体温度の指定

**正解：3**

温度が基本未知量。熱流束はノイマン、断熱は熱流束0、対流はロビン条件。

## 5-19 強制変位と直列ばね

k1=100、k2=k3=200 N/mm。節点1–2–3–4が直列で、u1=0、u4=6 mm、内部節点外力0。u2は？

1. 3 mm
2. 2 mm
3. 4 mm
4. 6 mm

**正解：1**

合成コンプライアンスは0.01+0.005+0.005=0.02 mm/N。力は300 N、伸びは3,1.5,1.5 mm。u2=3、u3=4.5。柔らかいk1が最も大きく伸びる。

## 5-20 直列棒の変位

節点1固定、1–2のEA/L=600 N/mm、2–3のEA/L=900 N/mm。節点3に3600 Nの引張力。u3は？

1. 6 mm
2. 4 mm
3. 2.4 mm
4. 10 mm

**正解：4**

伸びは3600/600=6 mmと3600/900=4 mm。u3=10 mm。両要素軸力3600 Nで検算できる。

## 5-21 荷重の組込み

微小変形・線形弾性で、変形に依存しない既知外力について適切なのは？

1. 等価節点力を右辺へ加え、Kは変更しない。
2. 対角に大きな係数を加える。
3. 荷重自由度の変位を固定する。
4. 荷重自由度の行と列を削除する。

**正解：1**

本問の線形・固定方向荷重ではKd=f。大変形の追従荷重、圧力、接触などでは荷重の線形化による接線行列への寄与があり、一般に「荷重は行列と無関係」とは言えない。

## 5-22 熱応力の材料定数

温度場 $T$ と無応力基準温度 $T_{\mathrm{ref}}$ は既知とする。等方線形弾性の静的熱応力を計算する際、$E,\nu$ に加えて必要な材料定数は？

1. 密度
2. 比熱
3. 線膨張係数
4. 熱伝導率

**正解：3**

熱ひずみは $\varepsilon^{\mathrm{th}}=\alpha(T-T_{\mathrm{ref}})$ なので、線膨張係数 $\alpha$ が必要である。温度場を別途解く場合には熱伝導率、非定常熱伝導では密度・比熱も必要となる。

## 5-23 自由熱膨張

α=1.2×10⁻⁵/K、ΔT=50 K。自由熱ひずみは？

1. 6×10⁻⁴
2. 6×10⁻⁵
3. 1.2×10⁻³
4. 3×10⁻⁴

**正解：1**

αΔT=1.2×10⁻⁵×50=6×10⁻⁴。自由で一様な等方膨張なら応力は生じない。

## 5-24 ブロックの要素

三方向寸法が同程度の塊の内部三次元応力を求める。適切な要素は？

1. ソリッド
2. 薄板シェル
3. 軸力のみのトラス
4. 一次元ビーム

**正解：1**

寸法比と求めたい応力成分から選ぶ。縮約した梁・板理論の仮定が成り立たない局所三次元場にはソリッドが適する。

## 5-25 薄板曲げ

薄板を、通常の完全積分一次ソリッド一層と粗い面内分割で表す場合、起こり得る問題は？

1. 必ずシェルより高精度になる。
2. 必ず自由度が少ない。
3. 面外変位が数学的に一切生じない。
4. 曲げに伴う不要なせん断ひずみで過剰な剛性が現れる。

**正解：4**

標準低次変位要素のせん断ロッキングを問う。一次ソリッド一層のすべてが不適切ではなく、低減積分・非適合モード・連続体シェルなどの定式化で性能が変わる。

## 5-26 径方向のしめしろ

共通の参照径D=200 mmで穴と軸を作図し、穴材の初期ひずみを0とする。自然状態の軸径はD+δ、δ=0.10 mm。微小ひずみの径方向モデルで軸のx,y初期ひずみを同値とする。ε0x=ε0yは？

1. −5×10⁻⁴
2. +5×10⁻⁴
3. +0.10
4. 0

**正解：2**

軸の自然径を大きくする固有ひずみδ/D=5×10⁻⁴。穴側にも−δ/Dを入れると相対干渉量を二重計上する。これは横断面の寸法差のモデルであり、軸方向の固有ひずみは製造履歴・解析条件に従い別に定める。接触干渉として直接扱う方法も可能。

## 5-27 異材二層の熱変形

異なるαをもつ二枚の弾性薄板を、無応力で接着後、外部拘束なしで一様に加熱する。完全接着、αの差とΔTは非零。適切なのは？

1. 必ず平坦なまま。
2. 一方の層だけに応力が生じる。
3. 膨張差による熱応力と曲率が生じる。
4. 接着面は必ず滑る。

**正解：3**

αの大きい層が曲率の外側となる。純弾性で元の温度へ戻れば、初期の無応力状態へ戻るので加熱中の応力を無条件に「除熱後の残留応力」と呼ばない。塑性や接着温度の違いがあれば残留し得る。

## 5-28 予ひずみを与えて接着

Aをx方向σ=200 MPaで引張った形状を参照配置としてBを接着し、除荷する。AのE=200000 MPa、ν=0.3。微小ひずみ近似でAの自然形状への回復を表す初期ひずみ(ε0x,ε0y,ε0z)は？

1. (+10⁻³,−3×10⁻⁴,−3×10⁻⁴)
2. (0,0,0)
3. (−10⁻³,+3×10⁻⁴,+3×10⁻⁴)
4. (−10⁻³,−3×10⁻⁴,−3×10⁻⁴)

**正解：3**

接着時のAのひずみは(σ/E,−νσ/E,−νσ/E)。その逆符号を、接着形状を基準とする固有ひずみに与える。原点となる参照配置を変えれば入力表現も変わるので、符号だけを暗記しない。

## 5-29 計算手順

標準的な線形変位法の計算順序は？

1. 求解→要素剛性→組立→条件→応力
2. 応力→要素剛性→組立→条件→求解
3. 組立→求解→要素剛性→条件→応力
4. 要素剛性→組立→境界条件適用→求解→ひずみ・応力

**正解：4**

解いた節点変位からε=Bd、σ=D(ε−ε0)+σ0を評価する。境界条件の選定・確認は解析準備段階でも行う。この順序は行列への適用の段階を指す。

## 4-1 有限要素法の目的

有限要素法を用いる主な理由として適切なのはどれか。

1. 複雑な形状・境界条件の問題を、有限個の自由度によって近似的に解く。
2. 支配方程式を使わずに必ず厳密解を得る。
3. 材料定数を測定なしに自動決定する。
4. 要素を粗くするほど常に精度が上がる。

**正解：1**

領域を要素に分け、節点自由度から場を補間し、離散方程式を解く。適切な要素・形状・正則性などの条件の下で細分化により収束を調べる。細分化だけで入力誤りが直るわけではない。

## 4-2 離散化と方程式の解法

線形の連続体問題について、離散化を行う方法に当たらないものはどれか。

1. 重み付き残差法
2. レイリー・リッツ法
3. ガウス・ザイデル法
4. 差分法

**正解：3**

ガウス・ザイデル法は、既に得られた連立一次方程式を反復的に解く方法である。非線形問題の離散化では、得られる代数方程式も非線形になり得る。

## 4-3 ガラーキン法

線形弾性の対称な双線形形式を、同じ試行・重み関数の空間で離散化する。適切な説明はどれか。

1. 対称な剛性行列が得られ、仮想仕事に基づく定式化と対応する。
2. 剛性行列が必ず対角行列になる。
3. 変位境界条件を課す必要がなくなる。
4. 重み関数を同じにするだけで自由度数が半分になる。

**正解：1**

Kij = a(Nj,Ni) であり、a(v,u)=a(u,v) なら Kij=Kji となる。ガラーキン法一般が対称性を保証するのではなく、元の作用素・双線形形式の対称性が必要である。試行関数と試験（重み）関数を区別する。

## 4-4 段付き棒のひずみエネルギー

左端固定の棒に P=10 kN の引張力を加える。E=200 GPa、区間1は A1=200 mm²、L1=100 mm、区間2は A2=100 mm²、L2=200 mm。棒全体のひずみエネルギーは？

1. 0.125 J
2. 1.25 J
3. 0.5 J
4. 0.625 J

**正解：4**

U = Σ P²Li/(2EAi)。E=200000 N/mm² を用いると U1=125 N mm=0.125 J、U2=500 N mm=0.5 J。合計は0.625 J。

## 4-5 二次元のエネルギー密度

初期応力・初期ひずみのない線形弾性体の平面応力、または平面ひずみ状態を考える。γxy は工学せん断ひずみ。ひずみエネルギー密度の正しい式は？

1. σxεx+σyεy+τxyγxy
2. (σxεy+σyεx)/2
3. (σxεx+σyεy+τxyγxy)/2
4. (σx²+σy²)/2

**正解：3**

U0=σ:ε/2。工学せん断ひずみ γxy=2εxy を使うと、せん断項は τxyγxy/2 となる。平面応力ではσz=0、平面ひずみではεz=0なので、面外の積が寄与しない。

## 4-6 変位と力の変分原理

安定な線形弾性問題の変分原理について適切なのはどれか。

1. 全ポテンシャルエネルギーは許容変位場、全補エネルギーは許容応力場を主な変数として扱う。
2. 両方とも力のつり合いを満たさない任意の応力場を比較する。
3. 補エネルギーは変位境界条件があると定義できない。
4. 補エネルギーは動的問題でしか使えない。

**正解：1**

変位場には変位境界条件、応力場には平衡方程式と指定表面力の条件を課す。線形弾性ではひずみエネルギーと補ひずみエネルギーが双対になる。非線形材料まで同一の二次形式とは限らない。

## 4-7 全ポテンシャルエネルギー

正定値の弾性材料、保守的な荷重、剛体運動を除いた適切な拘束をもつ微小変形問題を考える。真の平衡変位は？

1. 全ポテンシャルエネルギーを最大にする。
2. 拘束を満たさない変位場も含めた平均で決まる。
3. 許容変位場の中で全ポテンシャルエネルギーを最小にする。
4. 荷重点変位だけを最大にする。

**正解：3**

Π=U−W。平衡は δΠ=0 に対応し、本問の正定値性により最小になる。「停留」は一階変分がゼロという意味で、「最小」と同義ではない。座屈などでは安定性の追加評価が必要。

## 4-8 変位法と力法

変位法と力法について適切なのはどれか。

1. 変位法の主要未知数は応力である。
2. 力法だけが不静定構造を扱える。
3. 変位法は節点変位、力法は力・不静定力を主要未知数とする。
4. すべての有限要素は応力だけを未知数にする。

**正解：3**

汎用構造FEMでは変位に基づく定式化が広く使われる。混合定式化など、変位以外も未知数にする要素があるため「すべて」とは言えない。

## 4-9 節点の仮想仕事

図の節点Cは、左上へ水平から30°の棒CA、右上へ60°の棒CBに接続される。両端はピン接合。Cに下向き20 kNを加える。任意の仮想変位 (δx,δy) に対して仕事がつり合うことを用い、引張を正とする NCB を求めよ。

1. 10.00 kN
2. 23.09 kN
3. 34.64 kN
4. 17.32 kN

**正解：4**

仮想仕事は (−NCA cos30°+NCB cos60°)δx +(NCA sin30°+NCB sin60°−20)δy=0。δx,δy が独立なので各係数がゼロ。NCA=10 kN、NCB=10√3=17.32 kN。

## 4-10 仮想仕事の原理

静的平衡にある物体について適切なのはどれか。

1. 許容仮想変位のすべてに対して、内部仮想仕事と外部仮想仕事が等しい。
2. 仮想変位は実変位の一定倍に限られる。
3. 非線形材料では仮想仕事を使えない。
4. 外部仮想仕事は必ずゼロになる。

**正解：1**

変位が指定された境界では δu=0。指定変位が非零でも、仮想変位に同じ非零値を与えるのではない。適切な応力・ひずみと配置を用いれば大変形でも仮想仕事を定式化できる。

## 4-11 平衡の弱形式

仮想仕事の式が積分形にまとめるものはどれか。

1. 材料の構成則だけ
2. ひずみと変位の関係だけ
3. 領域内の平衡方程式と指定表面力の境界条件
4. 変位境界条件だけを満たす罰則項

**正解：3**

平衡方程式に許容仮想変位を掛けて部分積分すると、内部仮想仕事と境界の外部仮想仕事が現れる。変位境界条件は許容関数の空間に別途課す。

## 4-12 外部仮想仕事

δu を仮想変位、δ ε を仮想ひずみ、b を単位体積当たりの体積力、t を指定表面力、ρa を慣性項とする。指定表面 Γt の外部仮想仕事は？

1. ∫V b·δu dV
2. ∫V σ:δ ε dV
3. ∫Γt t·δu dS
4. ∫V ρa·δu dV

**正解：3**

表面力は単位面積当たりの力なので、表面上で積分する。応力と仮想ひずみの積は内部仮想仕事。

## 4-13 初期応力と初期ひずみ

σ = D(Bd−ε0)+σ0。初期項を Kd=f+fε+fσ の右辺へ移す。正しい組合せは？

1. fσ=+∫ Bᵀσ0 dV、fε=∫ BᵀDε0 dV
2. fσ=−∫ Bᵀσ0 dV、fε=∫ Bᵀε0 dV
3. fσ=−∫ Bᵀσ0 dV、fε=∫ BᵀDε0 dV
4. fσ=−∫ BᵀDσ0 dV、fε=∫ BᵀDε0 dV

**正解：3**

内力 ∫Bᵀσ dV に代入すると Kd−∫BᵀDε0 dV+∫Bᵀσ0 dV=f。従って初期ひずみ項は正、初期応力項は負。1D熱膨張棒の節点順1→2では fε=EAαΔT[−1,1]ᵀ。二つの端の符号を区別する。

## 4-14 弱形式の導出

静的弾性の平衡式から仮想仕事を得る説明として適切なのはどれか。

1. 残差に許容仮想変位を掛けて積分し、部分積分で内部仕事と表面項を得る。
2. 部分積分は慣性項を必ず消す。
3. 表面力境界条件を無視してよくなる。
4. ガラーキン法では部分積分を一切使えない。

**正解：1**

変位境界上の仮想変位はゼロ、力境界上では指定表面力を入れる。動的問題でも慣性項を保持して弱形式化できる。ガラーキン法一般の定義と、弾性の標準弱形式を得る操作を区別する。

## 4-15 節点補間の性質

標準的なラグランジュ型変位要素の形状関数について適切なのはどれか。

1. すべての形状関数が要素内で一定。
2. Ni(xj)=δij、ΣNi=1 であり、一様な平行移動を再現する。
3. ΣNi=0 により平行移動を再現する。
4. 形状関数だけで材料応力を直接決める。

**正解：2**

u(x)=ΣNi(x)ui。一様な節点変位 u0 を与えると u=u0ΣNi=u0。和が1だけで任意の剛体回転まで保証するのではなく、回転には座標の一次再現性も必要。一般の非節点型基底にデルタ性を無条件に要求しない。

## 4-16 一次要素の補間

長さLの一次棒要素で、u1=3 mm、u2=9 mm。x=3L/4での変位は？

1. 6 mm
2. 9 mm
3. 4.5 mm
4. 7.5 mm

**正解：4**

N1=1−x/L=1/4、N2=x/L=3/4。u=3/4+27/4=7.5 mm。節点2に近いので9 mm側の重みが大きい。

## 4-17 微小ひずみ

u はx方向、vはy方向変位。工学せん断ひずみを用いる正しい関係は？

1. εx=u,y、εy=v,x、γxy=u,x+v,y
2. εx=u,x、εy=v,y、γxy=u,y+v,x
3. εx=v,x、εy=u,y、γxy=u,y−v,x
4. εx=u,x、εy=v,y、γxy=u,y−v,x

**正解：2**

コンマは座標微分を表す。γxy=2εxy。差 (v,x−u,y)/2 は微小回転に対応し、せん断ひずみではない。

## 4-18 三節点三角形要素

直線辺のCST、微小ひずみ、要素内で一定のD、初期ひずみなしとする。適切なのは？

1. ひずみは要素内の一次関数。
2. 変位は一次式、ひずみと応力は要素内で一定。
3. 全節点でひずみが必ずゼロ。
4. 面積だけでひずみが決まる。

**正解：2**

一次変位を微分すると定数になる。ただしDや初期ひずみが空間変化すれば、ひずみが一定でも応力は一定とは限らない。応力勾配の表現には十分な分割が必要。

## 4-19 各行列の役割

微小変形の変位型FEMでBの役割は？

1. 変位の補間 u=Nd と全く同じ
2. 形状関数の座標微分から、ε=Bd を与える
3. 材料係数から、σ=Dε を与える
4. 節点力を直接 f=Bd で与える

**正解：2**

Nは変位の補間、Bはひずみへの変換、Dは材料則、Kは剛性。初期項なしなら σ=DBd、K=∫BᵀDB dV。

## 4-20 CSTのB行列

面積A>0の直線辺CSTのB行列について適切なのは？

1. 要素内の位置により変化する。
2. 節点座標から決まり、要素内で一定である。
3. 面積が同じなら形状にかかわらず全成分が同じ。
4. ポアソン比を直接含む。

**正解：2**

Bは 1/(2A) と bi=yj−yk、ci=xk−xj から構成される。形状を保って長さをs倍に拡大したとき Bは1/s倍になる。面積だけから成分の大小を判断できず、細長さや節点配置も重要。

## 4-21 平面応力と平面ひずみ

等方線形弾性、0<ν<0.5とする。適切な説明は？

1. 両者とも独立材料定数はE,νであり、面外条件によって一般にDが異なる。
2. 平面応力はεz=0、平面ひずみはσz=0。
3. せん断弾性係数GはE,νとは独立な第三の定数。
4. 平面ひずみの3×3行列は[εx,εy,εz]を[σx,σy,σz]へ変換する。

**正解：1**

平面応力：σz=τxz=τyz=0。平面ひずみ：εz=γxz=γyz=0。二次元Dは[εx,εy,γxy]を[σx,σy,τxy]へ写す。どちらもせん断係数はG=E/[2(1+ν)]。同じひずみなら「全応力成分が必ず大きい」とは言えない。純せん断では応力が同じ。

## 4-22 直列ばねの節点変位

節点1固定、1–2、2–3、3–4のばね定数は100,200,400 N/mm。節点4に右向き800 N。節点3の右向き変位は？

1. 4 mm
2. 8 mm
3. 14 mm
4. 12 mm

**正解：4**

各ばね力は800 N。伸びは8,4,2 mm。u3=8+4=12 mm、u4=14 mm。節点3までの区間だけを加える。

## 4-23 斜めばねの座標変換

軸方向ばね定数k=120 N/mm、x軸から反時計回り60°の二節点要素を考える。節点自由度順は[u1,v1,u2,v2]。同じ節点1のx,y自由度間の成分 K12 は？

1. 30.0 N/mm
2. 90.0 N/mm
3. 60.0 N/mm
4. 52.0 N/mm

**正解：4**

c=cos60°、s=sin60°。同じ端の2×2ブロックは k[[c²,cs],[cs,s²]]。K12=kcs=30√3=51.96 N/mm。反対端間の対応ブロックは負符号なので、行・列の指定が必要。

## 4-24 拘束前の剛性行列

自由な単一連結体の、標準的な線形弾性・変位型FEMの拘束前行列について適切なのは？

1. 必ず非対称。
2. 細分化すれば剛体モードが消える。
3. 対角成分の正負が混在することが安定性の条件。
4. 対称で、剛体モードにより特異。非零成分の配置は節点番号に依存する。

**正解：4**

剛体移動でひずみが生じないのでKに零空間がある。境界条件で剛体モードを除いても、未接続部や機構が残れば特異になり得る。疎性は接続関係による。帯幅は番号付けで変わり、必ず狭帯域とは限らない。

## 4-25 行和と剛体移動

拘束前の一次元軸方向ばね系で、全自由度が同一方向の並進変位である。各行の成分の和がゼロになる理由は？

1. ヤング率が一定だから。
2. 全節点を同量動かしてもばねが伸びず、K1=0となるから。
3. 要素数が必ず偶数だから。
4. 回転自由度を含むすべての行列で、すべての行和がゼロだから。

**正解：2**

同一並進 d=δ[1,…,1]ᵀ に対しKd=0。したがって各行和がゼロ。多次元系では方向別の剛体並進ベクトルを用いる。回転自由度を含む一般のKに単純な全成分行和ゼロを当てはめない。

## 4-26 ばね要素の組立て

直列の節点1–2–3–4、ばね定数k1=150、k2=250、k3=100 N/mm。拘束前のK33は？

1. 250 N/mm
2. 500 N/mm
3. 350 N/mm
4. 100 N/mm

**正解：3**

節点3へ接続する要素2–3と3–4の対角寄与を加える。K33=k2+k3=350 N/mm。要素1–2は寄与しない。

## 4-27 変位境界と荷重

線形静解析の境界条件について適切なのは？

1. 拘束自由度には集中荷重を一切加えられない。
2. 変位を指定した自由度では、反力を未知量としてつり合いから求める。
3. 指定変位があれば反力は必ずゼロ。
4. 荷重を加えるだけで剛体モードが必ず消える。

**正解：2**

変位が自由な境界では表面力を指定し、指定変位の境界では反力が解の一部になる。拘束節点への既知の外力は許され、反力計算へ含める。同一成分の総表面力と変位を任意に独立指定することとは区別する。

## 4-28 未知自由度の数

図の五節点二次元トラスで、節点1はx,yを拘束、節点3と5はyのみ拘束する。残る未知変位自由度の数は？

1. 6
2. 10
3. 4
4. 8

**正解：1**

総自由度は5×2=10、拘束は2+1+1=4。未知数は6。これは自由度数の計算であり、構造の安定性確認とは別。

## 4-29 三角形の面積座標

三角形の内部および辺上の点Pを考える。面積座標について適切なのは？

1. 各Liは長さの単位をもつ。
2. 0≤Li≤1、L1+L2+L3=1。一次三角形ではNi=Li。
3. 各Liは三角形全体の面積そのもの。
4. 三角形に面積座標は使えない。

**正解：2**

Liは節点iの対辺とPでできる符号付き部分面積を全体面積で割った無次元値。領域外では負値や1を超える値もあり得る。「0〜1」は内部・辺上に限る。

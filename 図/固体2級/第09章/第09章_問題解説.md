## Q 9-1　完全固定と節点自由度

**問題**

並進3自由度をもつ通常の変位型ソリッドと、並進3・回転3自由度をもつシェルを用いる。完全固定に必要な拘束はどれか。

**選択肢**

1. ソリッドは並進3、シェルは全6自由度
2. 両方とも回転だけ
3. ソリッドは回転3、シェルは並進3
4. 両方とも並進だけ

**正答** 1番：ソリッドは並進3、シェルは全6自由度

**解説**

【考え方】自由度とは、節点の動きを表す独立した数値です。並進は位置の移動、回転は向きの変化を表します。完全固定では、その要素が実際に持つ動きの自由度をすべてゼロにします。
通常の変位型ソリッドは $u_x,u_y,u_z$ の3成分、問題で指定されたシェルはこの3成分に $\theta_x,\theta_y,\theta_z$ を加えた6成分を拘束します。
【注意】ソリッドは節点に回転自由度がなくても、複数節点の変位の違いによって部材の回転を表せます。また、シェルの自由度は定式化によって異なるので、実際の要素仕様を確認します。

## Q 9-2　測定変位と反力

**問題**

支持・材料・他の荷重は既知で、1点の荷重方向変位だけを測定した。その点の荷重を推定する方法はどれか。

**選択肢**

1. 解析できない
2. 測定値を強制変位として与え、その自由度の反力を求める
3. 反力は変位を与えた点では得られない
4. 任意の荷重でよい

**正答** 2番：測定値を強制変位として与え、その自由度の反力を求める

**解説**

【考え方】「力を与えて変位を求める」計算を、測定変位を与える計算に置き換えます。その位置を測定された変位に保つために必要な力を求めれば、未知の荷重を推定できます。
例えば、他の荷重がないばねでは $F=k\delta$ です。剛性 $k$ と測定変位 $\delta$ が分かれば力が決まります。FEMでも強制変位を与えて全体を解き、その自由度の $K u-f_{\mathrm{既知}}$ に相当する力を取り出します。
【注意】支持・材料・他の荷重が既知という前提が必要です。表示される反力が物体に作用する力か、その逆向きの力かはソフトの符号規約で確認します。

## Q 9-3　平面要素の支持

**問題**

独立した節点回転自由度をもたない平面要素について、正しい支持の説明はどれか。

**選択肢**

1. ローラーは法線変位、ピンは並進2成分を拘束する
2. ローラーは並進2成分、ピンは法線成分だけを拘束する
3. 回転自由度がないので変形に回転を含められない
4. ピンは周辺の全節点を固定する

**正答** 1番：ローラーは法線変位、ピンは並進2成分を拘束する

**解説**

【考え方】ローラーは支持面を突き抜ける動きを止め、面に沿う滑りは許します。したがって法線方向の変位だけを拘束します。ピンは支点の位置を動かさないので、平面の並進2成分を拘束します。
平面要素に独立した節点回転自由度がなくても、周囲の節点が異なる量だけ動けば、線分や断面の向きは変化します。回転自由度がないことは、回転する変形を表せないことを意味しません。
【注意】1節点のピン拘束と、辺全体の固定は異なります。後者は辺に沿う変形まで止めるため、反力や応力が変わります。

## Q 9-4　斜面上の滑り

**問題**

斜面に沿う座標をt、法線方向をnとする。接触が保たれる節点について、摩擦のない滑りを許す拘束はどれか。

**選択肢**

1. ut=0、unは自由
2. 全体座標のuy=0だけ
3. un=0、utは自由
4. ut=un=0

**正答** 3番：un=0、utは自由

**解説**

【考え方】斜面に沿う方向を $t$、斜面に垂直な方向を $n$ とします。接触を保ちながら摩擦なしで滑る節点は、面を突き抜けず、面に沿って移動できます。したがって $u_n=0$、$u_t$ は自由です。
全体座標の $u_y=0$ は水平面に対しては使えますが、一般の斜面では滑り方向そのものも制限してしまいます。局所座標を設定するか、$\boldsymbol n\cdot\boldsymbol u=0$ という関係式で拘束します。
【注意】この等式は接触が保たれる場合です。面から離れる可能性がある接触では、離間を許す片側の条件も必要です。

## Q 9-5　三点曲げの不足拘束

**問題**

微小変位の平面はりで、中央鉛直荷重を受ける単純支持ばりを解く。水平剛体並進が残る条件はどれか。回転は各支点で自由とする。

**選択肢**

1. 両端の鉛直変位だけを固定
2. 左端の水平・鉛直と右端の鉛直を固定
3. 両端の鉛直と中央の水平を固定
4. 両端の水平・鉛直を固定

**正答** 1番：両端の鉛直変位だけを固定

**解説**

【考え方】両端の鉛直変位を止めれば、鉛直並進と全体の面内回転は止まります。しかし全節点を同じ量だけ水平に動かしても、この拘束条件は満たされ、部材のひずみも変わりません。水平剛体並進が残るのは選択肢1です。
この状態では変位の水平位置を一意に決められず、剛性行列が特異になります。通常は一方の支点だけで水平変位も止め、もう一方は水平方向を自由にします。
【注意】はりの完全固定には節点回転の拘束も必要です。両端の水平変位まで固定すると、熱膨張や軸伸びを余計に妨げる場合があります。

## Q 9-6　物体力の離散化

**問題**

正しい説明はどれか。

**選択肢**

1. 圧力の合力は常に全節点へ等分する
2. 適切に配分した節点質量と重力加速度から自重荷重を与えられる
3. 遠心加速度は半径の2乗に比例する
4. 変化する表面力を常に一様とみなせる

**正答** 2番：適切に配分した節点質量と重力加速度から自重荷重を与えられる

**解説**

【考え方】自重は質量と重力加速度の積です。節点へ適切に配分した質量を $m_i$ とすれば、その節点の荷重は $\boldsymbol f_i=m_i\boldsymbol g$ として与えられます。全節点の荷重の合計がモデルの総重量に一致することも確認します。
体積に広がる荷重を節点へ置き換える別の方法が、形状関数を使った整合荷重です。これは単なる等分ではなく、要素内の変位の表し方に合わせて配分します。
【誤答の確認】遠心加速度は $a=r\omega^2$ で、半径 $r$ に比例します。圧力や変化する表面力を、全節点へ無条件に同じ力で置き換えることもできません。

## Q 9-7　一次辺の荷重配分

**問題**

同じ長さの一次辺4本に一様な下向き荷重が作用し、合力800 Nとなる。内側の共有節点1個の力はどれか。

**選択肢**

1. 100 N
2. 160 N
3. 200 N
4. 400 N

**正答** 3番：200 N

**解説**

【手順】同じ長さの4辺に一様荷重があるので、1辺の合力は $800/4=200\ \mathrm N$ です。一次辺では一様荷重を両端へ半分ずつ配分し、各端の寄与は $200/2=100\ \mathrm N$ となります。
内側の節点は左右2辺に共有されています。したがって節点力は $100+100=200\ \mathrm N$、正解は3です。
【確認】左からの配分は $100,200,200,200,100\ \mathrm N$ となり、合計は800 Nです。両端は1辺分、内側は2辺分という違いがあるため、5節点へ160 Nずつ配る方法とは異なります。

## Q 9-8　反力の向き

**問題**

幅b=200 mm、高さh=400 mmの矩形の上辺に右向き合力P=10 kNが作用する。下辺の両隅A（左）・B（右）をピン支持する。鉛直反力の組合せはどれか。

**選択肢**

1. A上向き20、B下向き20 kN
2. 両方上向き10 kN
3. A下向き10、B上向き10 kN
4. A下向き20、B上向き20 kN

**正答** 4番：A下向き20、B上向き20 kN

**解説**

【手順】上辺の右向き荷重は、支点A回りに時計回りのモーメント $Ph$ を作ります。これを打ち消すには、右支点Bの鉛直反力を上向きにします。
反時計回りを正として、$bR_{By}-Ph=0$。したがって $R_{By}=Ph/b=10\times400/200=20\ \mathrm{kN}$ です。外力に鉛直成分がないので $R_{Ay}+R_{By}=0$、よってAは下向き20 kNです。
【注意】この反力対は荷重による転倒モーメントを打ち消します。水平反力は合計が左向き10 kNですが、AとBへの分担はつり合い式だけでは決まりません。支点は引張方向の反力も伝えられるピン支持とします。

## Q 9-9　三角形分布荷重

**問題**

長さ6 mmの一次辺で、下向き線荷重が左0から右6 N/mmへ線形に増える。右節点の整合荷重はどれか。

**選択肢**

1. 6 N
2. 9 N
3. 12 N
4. 18 N

**正答** 3番：12 N

**解説**

【考え方】右ほど荷重が大きいので、右節点の配分も左より大きくなります。ただし合力を単に右端へ全部集めるのではなく、一次辺の変位補間に合わせて配分します。
左端から $x$ を測ると $q(x)=q_{\max}x/L$、右節点の形状関数は $N_R=x/L$ です。したがって $F_R=\int_0^L N_R q\,dx=q_{\max}L/3=6\times6/3=12\ \mathrm N$ です。
【確認】三角形の面積から全荷重は $q_{\max}L/2=18\ \mathrm N$。左節点は6 N、右節点は12 Nで合計18 Nとなり、右節点の力は左の2倍です。

## Q 9-10　整合荷重の配分比

**問題**

一定厚さの矩形要素、一定物体力、一様線荷重の直線辺を考える。誤っている配分はどれか。

**選択肢**

1. Q4の物体力は各隅1/4
2. 一次辺の一様線荷重は両端1/2ずつ
3. 二次辺の一様線荷重は隅1/6・中間2/3・隅1/6
4. Q8の物体力は全8節点へ1/8ずつ

**正答** 4番：Q8の物体力は全8節点へ1/8ずつ

**解説**

【考え方】整合節点力は $f_i=\int N_i b\,dV$ のように、節点ごとの形状関数 $N_i$ を積分して求めます。節点数で等分する方法とは限りません。
矩形Q4の一様物体力は各隅1/4、一次辺の一様線荷重は両端1/2です。直線二次辺では隅・中間・隅の配分が $1/6,2/3,1/6$ となります。
矩形Q8セレンディピティ要素の一様物体力は、各隅が $-1/12$、各辺中間が $1/3$ です。合計は $4(-1/12)+4(1/3)=1$。従って全8節点へ1/8ずつとする選択肢4が誤りです。
【注意】隅の負の寄与は形状関数による仕事の対応から生じます。形状・厚さ・荷重が変われば同じ比を無条件に使えません。

## Q 9-11　Q4による自重

**問題**

L=1 m、高さ0.1 m、厚さ0.08 m、密度8000 kg/m³、g=10 m/s²の矩形を長さ方向8個の同寸法Q4で分割する。高さ方向は1要素。内部の上辺または下辺の共有節点1個の自重はどれか。

**選択肢**

1. 20 N
2. 40 N
3. 80 N
4. 160 N

**正答** 2番：40 N

**解説**

【手順】体積は $V=1\times0.1\times0.08=0.008\ \mathrm{m^3}$。総重量は $W=\rho Vg=8000\times0.008\times10=640\ \mathrm N$ です。
同寸法の8要素なので1要素の重量は $640/8=80\ \mathrm N$。矩形Q4では一定の自重を4隅に等分し、1要素から1隅への寄与は20 Nです。内部の上辺・下辺の節点は2要素に共有されるため、$20+20=40\ \mathrm N$ となります。
【確認】上下それぞれの節点力は端20 N、内側7点は各40 N、端20 Nで計320 N。上下の合計が640 Nです。Q4の節点は要素の4隅にあり、高さ方向1要素の中央線上には節点を置きません。

## Q 9-12　一様表面力の入力

**問題**

Q4平面応力モデルの上辺に一様な法線方向表面力を与える方法として適切なのはどれか。

**選択肢**

1. 要素辺に分布表面力として定義する
2. 全節点へ同じ集中力を与える
3. 全節点へ同じ変位を与える
4. 中央だけに合力を与える

**正答** 1番：要素辺に分布表面力として定義する

**解説**

【考え方】一様な表面力は「辺全体に広がる力」として入力し、各要素辺で積分して節点力に置き換えるのが適切です。選択肢1が該当します。

## Q 9-13　二次辺の共有節点力

**問題**

直線状の等長な二次辺が2本つながり、各辺に同じ方向の一様線荷重が作用する。各辺の合力は240N。接続する隅節点の力はどれか。

**選択肢**

1. 40 N
2. 60 N
3. 80 N
4. 160 N

**正答** 3番：80 N

## Q 9-14　円孔板の対称面

**問題**

鉛直引張を受ける円孔板の右上1/4を平面要素で解析する。下辺はy=0、左辺はx=0の対称面である。条件はどれか。

**選択肢**

1. 両辺の並進を全固定
2. 両辺とも自由
3. 下辺ux=0、左辺uy=0
4. 下辺uy=0、左辺ux=0

**正答** 4番：下辺uy=0、左辺ux=0

**解説**

【考え方】鏡に映したように変形が対称なら、対称面上の点は面を横切って動けません。一方、面に沿う動きは許されます。従って「面の法線方向だけをゼロにする」のが基本です。
下辺 $y=0$ の法線はy方向なので $u_y=0$、左辺 $x=0$ の法線はx方向なので $u_x=0$ とします。選択肢4が正解です。
【注意】両辺の並進を全固定すると、引張による伸びや幅方向の縮みまで止めます。対称モデルには形状だけでなく、材料・荷重・支持条件にも対応する対称性が必要です。

## Q 9-15　円筒の軸方向対称面

**問題**

形状・材料・荷重がz=0に対称な内圧円筒の上半分をr-z軸対称要素で解析する。切断した下端z=0の条件はどれか。

**選択肢**

1. uz=0、ur自由
2. ur=0、uz自由
3. ur=uz=0
4. 両方自由

**正答** 1番：uz=0、ur自由

**解説**

【考え方】軸対称モデルの $r$ は半径方向、$z$ は軸方向です。切断面 $z=0$ に関して鏡映対称なら、この面を横切る軸方向変位 $u_z$ をゼロにします。
内圧によって円筒は半径方向に膨らむので、面に沿う $u_r$ は自由にします。したがって $u_z=0$、$u_r$ 自由が正解です。
【注意】この拘束は実際の端を固定する条件ではなく、対称面の条件です。閉端に作用する圧力の軸方向合力や実際の支持は別に再現します。単に長い円筒という理由だけで、荷重や支持の対称性を省略できません。

## Q 9-16　対称半ばりの拘束

**問題**

x方向の単純支持ばりが中央の鉛直荷重を受ける。節点自由度ux,uy,θzのはりで左半分を解析する。中央の対称面で必要な条件はどれか。

**選択肢**

1. uyだけ固定
2. 全自由度固定
3. θzだけ固定
4. ux=0、θz=0、uy自由

**正答** 4番：ux=0、θz=0、uy自由

**解説**

【考え方】中央を境に左右が同じ形にたわむので、中央ではたわみ曲線の傾きがゼロです。はりの面内回転 $\theta_z$ をゼロにし、対称面を横切る水平変位 $u_x$ もゼロにします。
中央は下向きにたわむ必要があるため $u_y$ は自由です。よって $u_x=0,\theta_z=0$、$u_y$ 自由が正解です。

## Q 9-24　ゼロひずみエネルギー

## Q 9-31　傾斜拘束の式

**問題**

2. v=√3u

【手順】直線の傾きは「鉛直の変化/水平の変化」です。水平から30°傾いた線に沿う変位では、$v/u=\tan30^\circ=1/\sqrt3$。従って $v=u/\sqrt3$、正解は1です。
法線方向の変位がゼロという方法でも確認できます。法線ベクトルは $n=(-\sin30^\circ,\cos30^\circ)$ なので、$-u/2+\sqrt3\,v/2=0$ となり、同じ関係を得ます。
【注意】拘束しているのは線に垂直な動きだけです。$u=v=0$ とすると、線に沿う滑りまで止めてしまいます。反時計回り30°という角度の符号にも注意します。

## Q 9-32　回転を含む剛体結合

**問題**

x-y面のはり基準節点Bの変位をuB,vB、z軸まわり反時計回りの微小回転をθzとする。Bから(0,y)にある平面側節点を剛体結合するとどうなるか。

**選択肢**

1. u=uB、v=vBで回転を無視する
2. u=uB+yθz、vは自由
3. u=v=θz
4. u=uB−yθz、v=vB

**正答** 4番：u=uB−yθz、v=vB

**解説**

【考え方】剛体結合では、基準点の並進に、基準点回りの回転による移動を加えます。反時計回りの微小回転 $\theta_z$ をすると、Bより上にある点は左へ動くので、水平の増分は $-y\theta_z$ です。
一般の位置 $(x,y)$ なら回転増分は $(-y\theta_z,x\theta_z)$。本問は $x=0$ なので、$u=u_B-y\theta_z,\ v=v_B$ となり、正解は4です。
【確認】$y$ は長さ、角度はラジアンで扱うため、$y\theta_z$ は変位の次元を持ちます。面内の回転軸はz軸で、正の反時計回りを図と式で統一します。大回転にはこの微小回転式をそのまま使えません。

## Q 9-33　自由円管の一般化平面ひずみ

**問題**

軸方向に一様な温度T(r)を受ける長い円管の端部から十分離れた領域をr-zモデルで切り出す。軸力の合力はゼロで、断面は平面を保つとする。適切な条件はどれか。

**選択肢**

1. 両端のuzをゼロ
2. 軸方向基準を一切与えない
3. 他端に未検証の熱膨張量を固定値として与える
4. 片端uz=0、他端uzを共通の未知変位へMPC結合し、その軸力合力をゼロとする

**正答** 4番：片端uz=0、他端uzを共通の未知変位へMPC結合し、その軸力合力をゼロとする

**解説**

【考え方】温度が半径方向で異なると、各部分が自由に伸びたい量も異なります。しかし断面が平面を保つという仮定では、軸方向の伸びを断面で共通にし、その値をつり合いから求めます。
片端の $u_z=0$ は軸方向位置の基準です。他端は各節点の $u_z$ を共通の未知値 $U$ へMPC結合します。$U$ を固定せず、その自由度へ軸方向合力ゼロを課して、$\int_A\sigma_z\,dA=0$ を満たす伸びを求めます。
【注意】合力ゼロでも、温度差による局所の軸応力は残り得ます。両端固定は自由膨張を妨げる別の条件です。この切断面は、長い円管の端部から離れた領域を表す近似条件です。

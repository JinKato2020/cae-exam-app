## 9-1 完全固定と節点自由度

並進3自由度をもつ通常の変位型ソリッドと、並進3・回転3自由度をもつシェルを用いる。完全固定に必要な拘束はどれか。

1. ソリッドは並進3、シェルは全6自由度
2. 両方とも回転だけ
3. ソリッドは回転3、シェルは並進3
4. 両方とも並進だけ

**正解：1**

要素が実際にもつ自由度を拘束する。シェルの自由度数は定式化に依存するため、問題では6自由度型に限定した。

## 9-2 測定変位と反力

支持・材料・他の荷重は既知で、1点の荷重方向変位だけを測定した。その点の荷重を推定する方法はどれか。

1. 解析できない
2. 測定値を強制変位として与え、その自由度の反力を求める
3. 反力は変位を与えた点では得られない
4. 任意の荷重でよい

**正解：2**

既知変位による境界値問題を解き、拘束自由度の残差から必要な力を求める。反力の符号はソフトの定義を確認する。

## 9-3 平面要素の支持

独立した節点回転自由度をもたない平面要素について、正しい支持の説明はどれか。

1. ローラーは法線変位、ピンは並進2成分を拘束する
2. ローラーは並進2成分、ピンは法線成分だけを拘束する
3. 回転自由度がないので変形に回転を含められない
4. ピンは周辺の全節点を固定する

**正解：1**

変位勾配で局所回転を表せる。節点回転自由度をもたないことと、回転する変形を表せないことは異なる。点の並進拘束は辺全体のクランプではない。

## 9-4 斜面上の滑り

斜面に沿う座標をt、法線方向をnとする。摩擦のない滑りを許す拘束はどれか。

1. ut=0、unは自由
2. 全体座標のuy=0だけ
3. un=0、utは自由
4. ut=un=0

**正解：3**

接触を保つ条件は法線変位ゼロ。全体座標の成分だけを固定すると、斜面の方向と整合しない。

## 9-5 三点曲げの不足拘束

微小変位の平面はりで、中央鉛直荷重を受ける単純支持ばりを解く。水平剛体並進が残る条件はどれか。回転は各支点で自由とする。

1. 両端の鉛直変位だけを固定
2. 左端の水平・鉛直と右端の鉛直を固定
3. 両端の鉛直と中央の水平を固定
4. 両端の水平・鉛直を固定

**正解：1**

1では全体の水平並進が残り剛性行列が特異になる。4は水平移動を過剰に制約するが、軸力と曲げが分離した線形問題では鉛直解が同じになる場合もある。並進2成分の拘束だけでは、はりの完全固定にならない。

## 9-6 物体力の離散化

正しい説明はどれか。

1. 圧力の合力は常に全節点へ等分する
2. 適切に配分した節点質量と重力加速度から自重荷重を与えられる
3. 遠心加速度は半径の2乗に比例する
4. 変化する表面力を常に一様とみなせる

**正解：2**

遠心加速度はrω²で、rに比例する。整合荷重は形状関数の積分で求める。集中質量による自重は質量配分と精度を確認する。

## 9-7 一次辺の荷重配分

同じ長さの一次辺4本に一様な下向き荷重が作用し、合力800 Nとなる。内側の共有節点1個の力はどれか。

1. 100 N
2. 160 N
3. 200 N
4. 400 N

**正解：3**

各辺の合力200 Nを両端へ100 Nずつ配分する。内側は2辺分で200 N、全体は100,200,200,200,100 N。

## 9-8 反力の向き

幅b=200 mm、高さh=400 mmの矩形の上辺に右向き合力P=10 kNが作用する。下辺の両隅A（左）・B（右）をピン支持する。鉛直反力の組合せはどれか。

1. A上向き20、B下向き20 kN
2. 両方上向き10 kN
3. A下向き10、B上向き10 kN
4. A下向き20、B上向き20 kN

**正解：4**

A回りのモーメントつり合いよりb RBy=Ph、RBy=20 kN。鉛直力つり合いよりRAy=−20 kN。水平方向の反力の配分は、このつり合いだけでは決まらない。

## 9-9 三角形分布荷重

長さ6 mmの一次辺で、下向き線荷重が左0から右6 N/mmへ線形に増える。右節点の整合荷重はどれか。

1. 6 N
2. 9 N
3. 12 N
4. 18 N

**正解：3**

右の形状関数x/Lを用い、∫(x/L)(qmax x/L)dx=qmax L/3=12 N。左は6 N、合計18 N。

## 9-10 整合荷重の配分比

一定厚さの矩形要素、一定物体力、一様線荷重の直線辺を考える。誤っている配分はどれか。

1. Q4の物体力は各隅1/4
2. 一次辺の一様線荷重は両端1/2ずつ
3. 二次辺の一様線荷重は隅1/6・中間2/3・隅1/6
4. Q8の物体力は全8節点へ1/8ずつ

**正解：4**

Q8セレンディピティ要素では各隅−1/12、各辺中間1/3である。負の整合節点力があっても全体の合力と仮想仕事は整合する。形状・ヤコビアン・荷重が変わる場合に同じ比を流用しない。

## 9-11 Q4による自重

L=1 m、高さ0.1 m、厚さ0.08 m、密度8000 kg/m³、g=10 m/s²の矩形を長さ方向8個の同寸法Q4で分割する。高さ方向は1要素。内部の上辺または下辺の共有節点1個の自重はどれか。

1. 20 N
2. 40 N
3. 80 N
4. 160 N

**正解：2**

総重量8000×1×0.1×0.08×10=640 N。1要素80 Nを4隅へ20 Nずつ配分し、内部の共有節点は2要素分で40 N。中立軸上の節点を想定した図は削除した。

## 9-12 一様表面力の入力

Q4平面応力モデルの上辺に一様な法線方向表面力を与える方法として適切なのはどれか。

1. 要素辺に分布表面力として定義する
2. 全節点へ同じ集中力を与える
3. 全節点へ同じ変位を与える
4. 中央だけに合力を与える

**正解：1**

要素辺で積分された荷重を使う。等間隔の一次辺でも、端点と共有点の力は等しくならない。圧力の正方向と厚さを確認する。

## 9-13 二次辺の共有節点力

直線状の等長な二次辺が2本つながり、各辺に同じ方向の一様線荷重が作用する。各辺の合力は240 N。接続する隅節点の力はどれか。

1. 40 N
2. 60 N
3. 80 N
4. 160 N

**正解：3**

二次辺の各隅は1/6で40 N。共有点には2辺分の80 Nが加わる。曲線の圧力では法線方向とヤコビアンが変わるため、単純な1:4:1を一般化できない。旧円弧条件を直線条件へ置き換えた。

## 9-14 円孔板の対称面

鉛直引張を受ける円孔板の右上1/4を平面要素で解析する。下辺はy=0、左辺はx=0の対称面である。条件はどれか。

1. 両辺の並進を全固定
2. 両辺とも自由
3. 下辺ux=0、左辺uy=0
4. 下辺uy=0、左辺ux=0

**正解：4**

鏡映対称面では法線方向変位をゼロにし、接線方向は自由とする。

## 9-15 円筒の軸方向対称面

形状・材料・荷重がz=0に対称な内圧円筒の上半分をr-z軸対称要素で解析する。切断した下端z=0の条件はどれか。

1. uz=0、ur自由
2. ur=0、uz自由
3. ur=uz=0
4. 両方自由

**正解：1**

法線のz方向だけを拘束する。円筒端の実際の荷重・支持も別途再現する。長い円筒というだけで対称性が成立するとは限らない。

## 9-16 対称半ばりの拘束

x方向の単純支持ばりが中央の鉛直荷重を受ける。節点自由度ux,uy,θzのはりで左半分を解析する。中央の対称面で必要な条件はどれか。

1. uyだけ固定
2. 全自由度固定
3. θzだけ固定
4. ux=0、θz=0、uy自由

**正解：4**

対称面の法線並進uxと面内回転θzを固定する。荷重が中央にある場合、半モデルに与える中央鉛直荷重は全体のP/2。

## 9-17 中立軸に関する反対称

片持ちの矩形平面部材に端面純曲げモーメントを与える。長手方向x、断面高さ方向yとし、中立軸y=0で上半分を解析する。条件はどれか。

1. uy=0、ux自由
2. ux=0、uy自由
3. ux=uy=0
4. 拘束なし

**正解：2**

純曲げの変位は鏡映に対して反対称で、接線成分uxはy=0でゼロ、法線成分uyは自由。固定端と端面の曲げ表面力も半領域に整合させる。

## 9-18 中央き裂の1/4モデル

右上の矩形領域で、左辺x=0にux=0、下辺y=0のx≥aにuy=0を課す。下辺0≤x<aは無荷重で自由、上辺に鉛直引張を与える。このモデルはどれか。

1. 水平引張の片側き裂
2. 鉛直引張の片側き裂
3. 鉛直引張の中央き裂板1/4
4. 水平引張の中央き裂板1/4

**正解：3**

下辺の自由区間はき裂面、拘束区間は未き裂部の対称面である。左辺の対称性により中央き裂が復元される。どの区間が自由かを明示した。

## 9-19 周期条件と剛体回転

8個の等配穴をもつ自由円板を、内圧を受ける45°周期セクターで静解析する。切断面の周期条件だけで解が一意にならない理由はどれか。

1. 周期条件は常に無効
2. 剛体回転が周期条件を満たして残る
3. 8穴には周期性がない
4. 必ず曲げ機構が生じる

**正解：2**

微小剛体回転u=Ω e_z×rは回転周期条件を満たす。円板の回転の基準を1つ与え、変形を余計に拘束しない。鏡映対称で取れる22.5°領域は、45°の回転周期とは別の条件である。

## 9-20 扇形の鏡映対称条件

円板の形状・荷重が扇形の両半径境界に鏡映対称である。境界Aはx軸上、境界Bは傾斜し、局所tが半径方向、nが法線方向である。条件はどれか。

1. Bを完全固定
2. Aでuy=0に加え外周uxも固定
3. 両外周の半径変位も固定
4. Aでuy=0、Bでun=0、接線変位は自由

**正解：4**

鏡映面の法線だけを固定する。互いに平行でない2つの半径境界では平面剛体運動も除かれる。外周の半径変位を追加固定すると圧力による膨張を抑えてしまう。

## 9-21 反対称半ばり

両端固定ばりの中央に対して対称な位置に逆向きの鉛直力が作用する。左半分をux,uy,θzのはりで解析する。中央の反対称条件はどれか。

1. uy=0、uxとθzは自由
2. ux=θz=0、uy自由
3. 全固定
4. ux=uy=0、θz自由

**正解：1**

反対称面では接線方向uyを固定し、法線uxと軸性ベクトルのθzは自由。純曲げで軸方向が分離する特別な場合を、一般の拘束条件と混同しない。左の実固定端が剛体運動を除く。

## 9-22 対向圧縮の四分割

円板上側に合力P、下側に合力Pの対向圧縮を、左右対称の有限幅接触域に与える。右上1/4モデルの荷重と条件はどれか。

1. 上接触域の合力P/2、左辺ux=0・下辺uy=0
2. 上接触域の合力P、左辺ux=0・下辺uy=0
3. 上接触域P/2、下辺全固定
4. 上接触域P/4、両辺自由

**正解：1**

上側接触域を左右で二分するので、右上モデルの合力はP/2。上下も含めて機械的にP/4としない。点荷重による特異性を避けるため有限幅とした。

## 9-23 剛体モードの数

連結した自由弾性体がもつ通常の剛体モード数はどれか。機構や要素の余分なゼロエネルギーモードは含めない。

1. 2次元3、3次元6
2. 2次元2、3次元3
3. 2次元3、3次元5
4. 2次元2、3次元6

**正解：1**

2次元では並進2と面内回転1、3次元では並進3と回転3。自由体の動解析では剛体モードを物理的に扱えるが、静解析の一意性には基準が必要。

## 9-24 ゼロひずみエネルギー

微小変位の剛体モードについて誤っている説明はどれか。

1. ひずみエネルギーはゼロ
2. 自由な剛体モードがあれば剛性行列は特異
3. 外力の仕事は、荷重と運動によりゼロとは限らない
4. 剛体モードを加えると非零の一定ひずみが加わる

**正解：4**

剛体運動の対称変位勾配はゼロで、ひずみは変わらない。ゼロエネルギーとは内部ひずみエネルギーのことであり、外力の仕事まで常にゼロという意味ではない。

## 9-25 最小拘束

つり合う外力を受ける2次元連結弾性体で、剛体運動だけを除く方法として適切なのはどれか。

1. 並進1成分だけ固定
2. 1点の並進2成分だけ固定
3. 多数の節点を全固定
4. 並進2と回転1の独立した剛体モードを除く

**正解：4**

例えばAのux,uyと、Aから水平に離れたBのuyを固定する。数だけでなく拘束の独立性を確認する。

## 9-26 内部機構と剛体運動

左右の柱・上はりがすべて剛体棒で、四隅が摩擦のないピン、下の2点の位置が固定された四節リンクを考える。斜材はない。横方向の不安定性は何か。

1. 構造全体の剛体並進
2. 構造全体の剛体回転
3. 部材が互いに回転する内部機構
4. 必ず軸ひずみを伴う弾性変形

**正解：3**

2つの固定支点により全体の剛体運動は除かれるが、四節リンクは横倒れの機構をもつ。全体の剛体モードと内部機構を区別する。

## 9-27 不足拘束の修正

矩形平面モデルの下辺全節点をuy=0としたが、水平剛体並進が残った。余分な変形拘束を最小限にして除くにはどうするか。

1. 下辺のuyを外す
2. 荷重点を両方向固定する
3. 下辺の1節点にux=0を追加する
4. 左辺全体のuxを固定する

**正解：3**

水平剛体並進を独立な1条件で除く。拘束点に荷重を与えること自体は可能だが、その成分は主に反力となり、自由点の荷重と同じ変形を生まない。

## 9-28 MPCの従属自由度

従属自由度を消去し、消去済み自由度を後続式に利用しない処理系を考える。最も適切な入力はどれか。

1. 消去済み自由度を後続式の独立変数にする
2. 1自由度を異なる式で重ねて従属にする
3. 独立自由度を複数の適合する拘束式に共通利用する
4. 入力順や循環依存は常に無関係とする

**正解：3**

同じ独立自由度を複数式で用いることは可能。重複従属・循環・順序は処理系の仕様に従う。一般の連立拘束を扱える実装もあり、消去方式の制約を全ソフトへ一般化しない。

## 9-29 不整合メッシュの結合

粗い一次辺の端点1,3の中点に、細かい側の節点2が接する。平面の両変位を連続にするMPCはどれか。

1. ux2だけを平均にする
2. uy2だけを平均にする
3. ux2=(ux1+ux3)/2、uy2=(uy1+uy3)/2
4. 接していれば拘束は不要

**正解：3**

一次辺の中点補間は端点値の平均。2成分を拘束する。高次辺や中点以外では対応する形状関数を用いる。

## 9-30 剛体圧板の接触

回転せず鉛直方向だけに移動する水平剛体圧板に、下側の節点1〜4が摩擦なしで接触し、全点で接触が保たれる。条件はどれか。

1. 拘束不要
2. 全点のuxを一致させる
3. 全点のux,uyを一致させる
4. 全点のuyを一致させ、uxは自由

**正解：4**

摩擦なしなので接線uxを結合しない。離間しうる場合は単なる等式MPCではなく接触の片側条件が必要となる。

## 9-31 傾斜拘束の式

節点は、原点を通り水平から反時計回り30°傾いた直線に沿ってだけ微小移動できる。変位u,vの関係はどれか。

1. v=u/√3
2. v=√3u
3. u=v=0
4. v=−u/√3

**正解：1**

法線n=(−sin30°,cos30°)との内積をゼロにすると−u/2+√3v/2=0。

## 9-32 回転を含む剛体結合

x-y面のはり基準節点Bの変位をuB,vB、z軸まわり反時計回りの微小回転をθzとする。Bから(0,y)にある平面側節点を剛体結合するとどうなるか。

1. u=uB、v=vBで回転を無視する
2. u=uB+yθz、vは自由
3. u=v=θz
4. u=uB−yθz、v=vB

**正解：4**

δu=θ×rより(−yθz,0)。x-y面の回転軸はzであり、旧稿のx軸表記を修正した。

## 9-33 自由円管の一般化平面ひずみ

軸方向に一様な温度T(r)を受ける長い円管の端部から十分離れた領域をr-zモデルで切り出す。軸力の合力はゼロで、断面は平面を保つとする。適切な条件はどれか。

1. 両端のuzをゼロ
2. 軸方向基準を一切与えない
3. 他端に未検証の熱膨張量を固定値として与える
4. 片端uz=0、他端uzを共通の未知変位へMPC結合し、その軸力合力をゼロとする

**正解：4**

他端の共通変位を未知として、∫σz dA=0から軸方向伸びを求める。半径方向は自由に膨張できる。切断面は実端面ではなく遠方断面の近似条件である。

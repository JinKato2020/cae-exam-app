## Q 8-1　解析の活用

**問題**

開発における構造解析の用途として適切なのは？

**選択肢**

1. 概念設計・詳細設計・原因調査などの意思決定を支援する。
2. 詳細設計だけに使う。
3. 破損後だけに使う。
4. どんな実験も必ず置換する。

**正答** 1番：概念設計・詳細設計・原因調査などの意思決定を支援する。

**解説**

【解析の役割】構造解析は、荷重に対する変形や応力を予測し、設計案の比較、安全性の評価、破損原因の調査などに使います。概念設計から運用後まで活用できるため、肢1が適切です。
【目的を先に決める】全体のたわみを知りたいなら簡略モデルが有効な場合があり、局所接触応力を知りたいなら細かな三次元モデルが必要になることがあります。評価量と必要精度が、要素種類・解析領域・メッシュを決める基準になります。
【検証】結果は材料、荷重、支持、接触などの入力仮定に依存します。計算が終了しただけで正しいとは言えません。釣合い、理論解との比較、メッシュ収束、実験・実測との照合を行い、目的に対して使える結果か判断します。

## Q 8-2　横置き容器の長手荷重

**問題**

xを容器長手、yを横水平、zを鉛直とする。形状・材料・支持はy=0に鏡映対称。片側サドルのx移動を拘束し、他方のx移動を許す。支持の指定変位は0とする。x方向の静的加速度荷重だけを扱う線形解析で、通常の鏡映対称縮約は？

**選択肢**

1. y=0で切る半モデル
2. x中央面で切る半モデル
3. 両面で切る四分の一モデル
4. いかなる縮約も不可

**正答** 1番：y=0で切る半モデル

**解説**

【対称性の条件】鏡に映したとき、形状だけでなく材料、支持、荷重のベクトルも元の問題と一致する必要があります。本問では支持の指定変位は0です。
【y=0面】yを反転しても、長手x向きの荷重は同じ向きです。左右のサドルの固定・スライド配置も変わりません。この面では通常の対称半モデルが使えるので、肢1です。ソリッドの切断面では $u_y=0$、$u_x,u_z$ は自由です。
【x中央面】xを反転するとx向き荷重の方向が反転し、固定サドルとスライドサドルも入れ替わります。問題全体が同一にならないため、通常の鏡映対称条件で四分の一にできません。容器の見た目だけで縮約面を選ばないことが大切です。

## Q 8-3　横置き容器の横荷重

**問題**

横置き容器の長手方向をx、横水平をy、鉛直をzとする。形状・材料・支持はy=0に鏡映対称であり、片側サドルのx移動を拘束し、他方のx移動を許す。y方向の静的加速度荷重だけを作用させる。支持の指定変位は0とする。線形解析で解は一意とし、反対称条件も利用できる。適切な縮約は？

**選択肢**

1. y=0で通常の対称条件
2. x中央面で通常の対称条件
3. y=0で反対称条件を用いる半モデル
4. z水平面で通常の対称条件

**正答** 3番：y=0で反対称条件を用いる半モデル

**解説**

【反対称荷重】y=0面で鏡映すると、y向きの荷重は反対方向を向きます。形状・材料・0変位の支持は対称、荷重は反対称です。一意な線形解では、反対称条件を使った半モデルが可能なので肢3です。
【切断面】ソリッドでは面に沿う $u_x=u_z=0$ とし、面の法線方向 $u_y$ は自由です。通常の対称条件とは拘束する成分が逆です。六自由度シェルでは $\theta_y=0$、$\theta_x,\theta_z$ は自由となります。回転成分は並進と異なる鏡映の変換をします。
【併用荷重】重力のような対称荷重も加えるなら、線形解析では対称ケースと反対称ケースに分けて解き、全体座標で重ね合わせます。非線形解析や非対称支持では、この重ね合わせをそのまま使えません。

## Q 8-4　中央脚の沈下

**問題**

脚が左からa,b,c,o,c,b,aと並ぶ全体が左右対称な有限橋を考える。oだけが沈下し、他の条件も対称。効率よく全橋の影響を保つ解析領域は？

**選択肢**

1. 全橋を必ずそのまま使う。
2. 沈下脚を含まない端部だけ。
3. 片側の中央径間だけを自由端で切る。
4. 対称面oから実際の端aまでを含む半橋。

**正答** 4番：対称面oから実際の端aまでを含む半橋。

**解説**

【全体の対称性】中央脚oだけの沈下は、左右反転しても同じ条件です。対称な解なら片側だけを解けるため、中央oから実際の端aまで全三径間を残す肢4が適切です。
【境界条件】中央には対称条件を課し、中央脚の指定沈下量も反映します。実際の端aには元の橋の端条件を与えます。対称面で全変位を0にすると、沈下による鉛直移動まで止めてしまいます。
【領域を残す理由】脚の沈下による力は、連続する橋桁を通じて周辺径間へ伝わります。途中を自由端に切ると別の構造になります。遠方を省略できる範囲は剛性・支持・評価量に依存し、「隣の隣なら影響0」と一律には判断できません。

## Q 8-5　ノズル局所熱応力

**問題**

厚肉ノズル交差部の有限半径フィレットで、既知温度場から局所三次元熱応力を評価する。全体変形は別の適切なモデルで得られている。効率的な方法は？

**選択肢**

1. 切断境界に全体解を受け渡す局所ソリッドモデル
2. 全体を理由なく一律に極細分割
3. 切断面をすべて固定して周辺を切り出す
4. 板厚方向応力を捨てた平面応力だけで評価

**正答** 1番：切断境界に全体解を受け渡す局所ソリッドモデル

**解説**

【二段階モデル】全体モデルで容器全体の変形を求め、ノズル付近だけを細かなソリッドで解くサブモデルを使います。切断境界に全体解の変位などを受け渡す肢1が適切です。
【境界の意味】切り出した部品は周囲とつながっているため、切断面を勝手に固定すると、実物にはない拘束と応力を作ります。着目部から十分離して境界を置き、境界位置を変えた影響も調べます。局所の温度場も整合させます。
【局所応力】厚肉の交差部では板厚方向を含む三次元応力が重要です。有限半径のフィレットを実形状として解像します。鋭い角や点荷重の数学的特異点では、細分化してもピーク応力が有限値へ収束しない場合があるため、評価対象を区別します。

## Q 8-6　スカート取付け部

**問題**

形状・材料・温度・荷重・支持がすべて軸対称。厚肉取付け部の有限フィレットの局所熱応力を効率よく評価する。適切なのは？

**選択肢**

1. 軸対称シェルで局所板厚応力を捨てる。
2. 軸対称ソリッドで着目部を細分し、周辺へ滑らかに粗くする。
3. 全領域を必ず同じ極小寸法にする。
4. トラスだけで局所熱応力を求める。

**正答** 2番：軸対称ソリッドで着目部を細分し、周辺へ滑らかに粗くする。

**解説**

【軸対称化】形状、材料、温度、荷重、支持が周方向に変わらないので、半径rと高さzの断面だけを使えます。厚肉取付け部の局所場を扱うため、軸対称ソリッドが適切です。
【分割】フィレット付近では応力が急変するので細かくし、遠方へ滑らかに粗くします。肢2を選びます。急な要素寸法の変化や大きな歪みを避け、着目応力の収束を確認します。
【シェルとの違い】全体の薄肉挙動ならシェルが効率的な場合もありますが、本問は厚肉部の局所応力が目的です。周方向の離散支持や不均一な溶接が支配的なら、軸対称条件が崩れます。形状だけでなく荷重・支持まで一周同じか確認します。

## Q 8-7　円筒タンク

**問題**

厚肉円筒タンクの形状・均質化材料・定常温度・内外圧・支持が軸対称。壁内部の応力を効率的に扱う要素は？

**選択肢**

1. 一般三次元シェルのみ
2. 全体三次元ソリッドのみ
3. 軸対称ソリッド
4. 任意の一ラジアン領域を自由に切り出す

**正答** 3番：軸対称ソリッド

**解説**

【r-z断面】軸対称ソリッドは、断面を回転してできる三次元領域を二次元のメッシュで表します。厚肉壁の内部応力を効率的に扱えるので、肢3です。
【残る成分】ねじりなしなら $\sigma_r,\sigma_z,\sigma_\theta,\tau_{rz}$ を扱います。周方向ひずみは $\varepsilon_\theta=u_r/r$ で、半径変位による円周の伸びを表します。単なる平面要素にはない成分です。
【前提】均質化材料を含め、温度・圧力・支持まで軸対称であることが必要です。局所支持や鉄筋の離散配置を均質化する場合は、着目する応力に対してその近似が妥当か確認します。一ラジアン領域を切り出す方法でも、切断面条件とソルバーの荷重の定義が必要です。

## Q 8-8　丸棒引張

**問題**

等方ダンベル形丸棒の形状・材料・荷重・拘束が軸対称。段差近くの応力を効率的に解くのは？

**選択肢**

1. 平面ひずみ
2. 平面応力
3. 全体三次元だけ
4. 軸対称ソリッド

**正答** 4番：軸対称ソリッド

**解説**

【モデルの選択】丸棒の形と荷重・拘束が軸対称なら、半径と軸方向の断面を使う軸対称ソリッドが適切です。肢4を選びます。二次元メッシュでも、回転体の三次元応力を扱います。
【段差付近】断面が変わる部分では軸応力が一様でなく、半径・周方向の応力やせん断も現れます。単なる一様棒の $\sigma=F/A$ だけでは局所分布を表せないため、フィレットの形と分割を確認します。

## Q 8-9　有孔薄板

**問題**

薄い等方板、板厚面が自由、面内引張、面外曲げ・座屈を扱わない。孔周辺の面内応力に適するのは？

**選択肢**

1. 平面応力
2. 平面ひずみ
3. 軸対称
4. 軸力だけのトラス

**正答** 1番：平面応力

**解説**

【平面応力】板厚方向をzとすると、自由な板厚面と面内荷重の条件から $\sigma_z,\tau_{xz},\tau_{yz}\simeq0$ と近似します。面内の孔周辺応力を効率的に解ける肢1が適切です。
【ひずみは残る】等方弾性で初期ひずみがなければ $\varepsilon_z=-\nu(\sigma_x+\sigma_y)/E$。引張ると厚さが縮むため、面外応力0でも面外ひずみは一般に0ではありません。
【範囲】本問は面外曲げ・座屈を対象としていません。それらを調べるならシェルなどを検討します。板厚面の接触圧や局所三次元場が重要な場合も平面応力仮定を見直します。薄いという寸法だけでなく、荷重と評価目的が選択の理由です。

## Q 8-10　ボルト近傍

**問題**

周方向に離散配置されたボルトの接触部・根元の局所三次元応力を評価する。適切なのは？

**選択肢**

1. 軸対称ソリッドだけ
2. 必要なボルト・接触・有限形状を含む三次元ソリッド
3. 軸対称シェルだけ
4. トラスの軸力だけ

**解説**

## Q 8-11　鉄塔の部材

**問題**

脚柱・横材は軸力とモーメント、斜材は軸力だけを負担する。端部リリースは使わない。適切なのは？

**選択肢**

1. 全部ビーム
2. 全部トラス
3. 脚柱・横材ビーム、斜材トラス
4. 全部平面応力

**正答** 3番：脚柱・横材ビーム、斜材トラス

**解説**

【部材の役割】脚柱・横材には軸力に加えて曲げモーメントを伝える能力が必要なので、ビームを使います。斜材は軸力だけを負担する条件なので、トラスで表します。肢3です。

## Q 8-12　トンネル断面

**問題**

長手に一様なトンネルの端部から十分離れた領域で、長手方向のひずみ・せん断ひずみが0と近似できる。横断面のモデルは？

**選択肢**

1. 軸対称
2. 平面応力
3. 軸力トラス
4. 平面ひずみ

**正答** 4番：平面ひずみ

**解説**

【平面ひずみ】横断面をx-y、長手をzとすると、$\varepsilon_z=\gamma_{xz}=\gamma_{yz}=0$ と近似します。長手方向の伸縮・せん断を無視できる領域を指定しているので、肢4です。

## Q 8-14　開断面の局所ひずみ

**問題**

厚肉の開断面部材が曲げとねじりを受け、拘束端近くの局所反りひずみを三次元的に評価する。適切なのは？

**選択肢**

1. 反り自由度のない通常ビームだけ
2. 三次元ソリッド
3. 平面ひずみだけ
4. 平面応力だけ

**正答** 2番：三次元ソリッド

**解説**

【反り】開断面をねじると、断面内の各点が軸方向に異なる量だけ動くことがあります。これを反りと呼びます。端部で反りが拘束されると、追加の軸ひずみ・応力が現れます。

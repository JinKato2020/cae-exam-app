## Q 3-1　熱流束と温度勾配

**問題**

熱流束と温度勾配の関係 $q_x=-\lambda\,dT/dx$ を表す法則はどれか。

**選択肢**

1. フックの法則
2. オームの法則
3. フーリエの法則
4. ダルシーの法則

**正答** 3番：フーリエの法則

**解説**

【熱流束とは】熱流量Qは単位時間に通過する熱の量で単位はW、熱流束qはそれを通過面積で割った量で単位はW/m²です。温度勾配 $dT/dx$ は、x方向へ単位距離進んだときの温度変化を表し、単位はK/mとなります。
【フーリエの法則】$q_x=-\lambda\,dT/dx$ がフーリエの法則で、正答は3です。$\lambda>0$ は熱伝導率で、単位はW/(m K)。例えば温度がx方向へ100 K/mずつ低下し、λが10 W/(m K)なら、$q_x=-10\times(-100)=1000\,\mathrm{W/m^2}$ と正のx方向へ熱が流れます。
【負号の意味】自然な熱伝導は高温から低温へ向かうため、熱流束は温度が増える方向と逆です。負号は「熱量が常に負」という意味ではありません。フックの法則は応力とひずみ、オームの法則は電気、ダルシーの法則は多孔質中の流れに関する関係で、ここでは対象を区別します。

## Q 3-2　一次元の構造解析と熱伝導解析

**問題**

一次元の線形弾性棒と、一次元の線形熱伝導を、有限要素法の基本未知量・勾配・構成則の係数という観点で比較する。対応が適切なものはどれか。

**選択肢**

1. 温度―応力、熱流束―変位、熱伝導率―ひずみ。
2. 温度―変位、温度勾配―ひずみ、熱流束―応力、熱伝導率―弾性係数。
3. 温度―ひずみ、熱流束―弾性係数、熱伝導率―変位。
4. 温度―弾性係数、温度勾配―変位、熱流束―ひずみ。

**正答** 2番：温度―変位、温度勾配―ひずみ、熱流束―応力、熱伝導率―弾性係数。

**解説**

【未知量から順に対応】一次元の棒では節点変位uを求め、微分してひずみ $\varepsilon=du/dx$、材料則で応力 $\sigma=E\varepsilon$ を計算します。熱伝導では節点温度Tを求め、微分して温度勾配dT/dx、フーリエ則で熱流束 $q=-\lambda dT/dx$ を計算します。
【正しい組合せ】温度と変位、温度勾配とひずみ、熱流束と応力、熱伝導率と弾性係数が対応します。基本未知量、その空間微分、微分に係数を掛けて求める量という式の構造が似ており、正答は2です。負号や単位まで同じという意味ではありません。
【FEMへの応用】どちらも要素内を形状関数で補間し、微分・積分・行列組立てを行う枠組みを使えます。ただし多次元では温度は一つの値、変位は方向成分を持つベクトル、応力やひずみはテンソルです。既存の弾性要素の自由度や材料行列を変更せず熱伝導へ流用できるわけではありません。

## Q 3-3　非定常熱伝導

**問題**

一定断面・一定熱伝導率の棒が、一様な初期温度 $T_c$ にある。側面を断熱し、内部発熱はない。時刻0以後、左端を $T_h>T_c$、右端を $T_c$ に保つ。温度分布について正しいものはどれか。

**選択肢**

1. 瞬時に棒全体が最終的な直線分布になる。
2. 左端の昇温は棒内部の温度に影響しない。
3. 非定常に変化し、十分な時間が経つと定常の直線分布へ漸近する。
4. 両端を含め全体の温度が常に一様に上昇する。

**正答** 3番：非定常に変化し、十分な時間が経つと定常の直線分布へ漸近する。

**解説**

【時間を追う熱伝導】左端だけを高温に保つと、棒内部の温度は時間とともに変わります。この途中状態を非定常と呼びます。温度の時間変化を含む式は $\partial T/\partial t=\alpha\,\partial^2T/\partial x^2$、$\alpha=\lambda/(\rho c_p)$ は温度伝導率です。ここでc_pは比熱です。
【最後に近づく分布】十分な時間が経つと温度の時間変化が小さくなり、発熱なし・一定熱伝導率の条件から二階微分が0になります。したがって $T(x)=T_h+(T_c-T_h)x/L$ の直線分布へ近づきます。瞬時に最終分布になるのではなく、正答は3です。
【時間尺度とモデル】無次元時間はフーリエ数 $Fo=\alpha t/L^2$。長い棒ほど変化に長い時間を要する目安です。古典的な熱伝導方程式では、数学的には任意の正の時刻で温度の変化が全域へ及びますが、早い時刻の遠方の変化は極めて小さくなります。「有限速度の波が進む」とは説明しません。

## Q 3-4　平板と円筒の定常温度分布

**問題**

発熱なし・一定の熱伝導率で、(a)一定断面平板の厚さ方向だけの定常熱伝導、(b)円筒壁の半径方向だけの定常熱伝導を考える。形の組合せはどれか。

**選択肢**

1. (a)一次関数、(b)対数型。
2. (a)対数型、(b)一次関数。
3. (a)二次関数、(b)一次関数。
4. (a)一次関数、(b)二次関数。

**正答** 1番：(a)一次関数、(b)対数型。

**解説**

【平板の温度分布】発熱がなく断面積が一定なら、定常状態では各位置を同じ熱流量が通過します。$q=-\lambda T'$ でλも一定なので温度の傾きT'が一定です。$T''=0$ を積分すると $T=ax+b$ という一次関数になります。
【円筒で変わること】円筒の熱が通過する面積は $2\pi rL$ で、外側ほど大きくなります。同じ熱流量Qでも熱流束は $q_r=Q/(2\pi rL)$ と小さくなるため、温度勾配は一定ではありません。$Q=-2\pi rL\lambda T'$ から $T'=C/r$、積分して $T=C\ln r+D$ という対数型になります。正答は1です。
【形状と条件】平板と円筒の違いは、熱が通る断面積が位置で変わるかどうかです。円筒でも熱流量は一定ですが、熱流束は一定ではありません。また内部発熱や熱伝導率の変化があると、ここで得た直線・対数型から変わることがあります。与えられた条件を先に確認します。

## Q 3-5　二層平板の界面温度

**問題**

一次元・定常・発熱なしの二層平板を考える。Aは厚さ0.01 m・熱伝導率10 W/(m K)、Bは厚さ0.01 m・熱伝導率20 W/(m K)。断面積は共通で、接触熱抵抗はない。A側表面200℃、B側表面50℃の場合、界面温度はどれか。

**選択肢**

1. 125℃
2. 100℃
3. 150℃
4. 75℃

**正答** 2番：100℃

**解説**

【直列の熱抵抗】熱はA層、B層を順番に通ります。定常・発熱なしで断面積が共通なので両層の熱流束qは同じです。単位面積当たりの伝導抵抗は $R_i=t_i/\lambda_i$ で、同じqに対する温度降下は $qR_i$。熱伝導率が小さい層ほど抵抗が大きくなります。
【計算】$R_A=0.01/10=0.001$、$R_B=0.01/20=0.0005\,\mathrm{m^2K/W}$。$q=(200-50)/(0.001+0.0005)=100000\,\mathrm{W/m^2}$。Aの温度降下は100 Kなので、界面温度は $200-100=100\,{}^\circ\mathrm C$ で正答は2です。
【検算】Bの温度降下は50 Kで、$100-50=50\,{}^\circ\mathrm C$ と外側の指定値に一致します。厚さが同じでもλが違うため、界面温度は200℃と50℃の単純平均ではありません。接触熱抵抗がなければ界面温度は連続ですが、各層の温度勾配は異なり、Aの方が急になります。

## Q 3-6　等温線と断熱境界

**問題**

等方性材料の二次元定常熱伝導を考える。温度勾配がゼロでない滑らかな断熱境界近傍について、正しいものはどれか。

**選択肢**

1. 等温線は断熱境界に平行となる。
2. 断熱境界では温度そのものが必ずゼロとなる。
3. 熱流束を規定した境界では、温度が必ず境界全体で一定となる。
4. 熱流は断熱境界に沿い、等温線はその境界と直角に交わる。

**正答** 4番：熱流は断熱境界に沿い、等温線はその境界と直角に交わる。

**解説**

【断熱が指定する量】断熱境界では、境界を横切る熱流束の法線成分がゼロです。式は $\mathbf q\cdot\mathbf n=0$。温度Tを0に固定する条件でも、熱流束ベクトル全体を0にする条件でもありません。境界に沿う熱の流れはあり得ます。
【等温線の向き】等方性材料では $\mathbf q=-\lambda\nabla T$ なので、断熱境界で温度勾配も境界に沿います。等温線の接線は温度勾配に直交するため、等温線は断熱境界と直角に交わります。熱流は境界に沿うとする4が正答です。
【前提に注意】温度勾配がゼロの点では等温線の方向をこの議論で一意に決められないため、本問ではゼロでないと指定しています。また異方性材料では熱流束と勾配が平行とは限りません。温度を指定する境界も、境界上の指定値が一定のときに初めて一本の等温線になります。

## Q 3-7　内部発熱のある平板

**問題**

一定の正の体積発熱率 $s>0$ と熱伝導率 $\lambda>0$ を持つ平板を、一次元・定常で解析する。両面は同じ温度 $T_0$ に保つ。温度分布の形はどれか。

**選択肢**

1. 一次関数
2. 二次関数
3. 三次関数
4. 正弦関数

**正答** 2番：二次関数

**解説**

【発熱を運び出す】内部で熱が生じるので、両面が同じ温度でも内部はそれより高温になります。一定λ、一定の体積発熱率sを持つ一次元定常式は $\lambda T''+s=0$。$T''=-s/\lambda<0$ が一定なので、温度分布は下向きに曲がる二次関数です。
【境界条件を使う】左面をx=0、右面をx=Lとすると、両面でT=T₀です。式を二回積分して境界条件を入れると $T=T_0+[s/(2\lambda)]x(L-x)$。正答は2です。中央 $x=L/2$ が最高温度で、上昇量は $sL^2/(8\lambda)$ になります。
【熱流束で確認】$q=-\lambda T'=s(x-L/2)$。左半分では負のx方向、右半分では正のx方向へ流れ、中央でq=0です。中央が断熱されたわけではなく、対称性により左右へ熱が分かれます。発熱を0にすると二次項が消え、同じ温度の両面の間は一様温度となります。

## Q 3-8　熱流入と内部発熱のある壁

**問題**

厚さ $L$、一定熱伝導率 $\lambda>0$ の平面壁を、一次元・定常で考える。左面 $x=0$ から正の熱流束 $q_0$ が流入し、内部には一様な正の体積発熱率 $s$ がある。右面 $x=L$ は温度 $T_0$ に保つ。温度分布として正しいものはどれか。

**選択肢**

1. 傾きが一定の直線となる。
2. 二階微分が正で、左面ほど傾きの絶対値が大きい。
3. 二階微分が負で、右面へ向かうほど傾きの絶対値が大きい。
4. 中央が最低温度となる。

**正答** 3番：二階微分が負で、右面へ向かうほど傾きの絶対値が大きい。

**解説**

【右へ進むほど熱が増える】左面から流入する熱流束q₀に、内部で発生した熱が加わります。定常の熱収支は $dq/dx=s$ なので $q(x)=q_0+sx$。sとq₀が正のため、右面へ近づくほど通過する熱流束が増えます。
【温度の傾き】$q=-\lambda T'$ より $T'=-(q_0+sx)/\lambda<0$、さらに $T''=-s/\lambda<0$。温度は右へ低下し、傾きの絶対値は右へ行くほど大きくなります。正答は3です。右面温度をT₀とすると $T=T_0+q_0(L-x)/\lambda+s(L^2-x^2)/(2\lambda)$ です。
【左右の違い】両面を同じ温度にする対称発熱問題とは違い、本問では左からも熱が入ります。そのため最高温度は左面、最低温度は右面で、中央が最低ではありません。λが位置や温度で変わる場合は二階微分が一定とは限らず、この結果の前提を保つ必要があります。

## Q 3-9　円筒保温材の熱損失

**問題**

内半径0.05 m、外半径0.10 m、熱伝導率0.04 W/(m K)の円筒状保温材で、内面90℃、外面10℃とする。一次元半径方向・定常・発熱なしの場合、単位管長当たり熱損失 $Q/L=2\pi\lambda(T_1-T_2)/\ln(r_2/r_1)$ はどれか。

**選択肢**

1. 67 W/m
2. 20 W/m
3. 14.5 W/m
4. 29 W/m

**正答** 4番：29 W/m

**解説**

【円筒の熱流量】半径方向の定常熱伝導では、外側ほど通過面積が大きくなります。温度差を熱流量へ換算する式は $Q/L=2\pi\lambda(T_1-T_2)/\ln(r_2/r_1)$ です。全管長の熱流量Qではなく、長さ当たりの損失を求めるので、単位はW/mです。
【計算】半径比は $0.10/0.05=2$、温度差は80 K。$Q/L=2\pi\times0.04\times80/\ln2\simeq29.01\,\mathrm{W/m}$ となり、正答は4です。対数は自然対数を使い、$\ln2\simeq0.6931$ とします。
【流束と区別】局所の熱流束は $q_r=(Q/L)/(2\pi r)$。内面では約92.3 W/m²、外面では約46.2 W/m²で、外面は面積が2倍なので流束が半分です。同じQが流れていてもqは違います。平板の $\lambda\Delta T/t$ を一定面積のまま使う方法では、円筒の面積変化を正しく扱えません。

## Q 3-10　熱貫流率

**問題**

平板の両面の熱伝達率は $h_1=20,\ h_2=10\,\mathrm{W/(m^2\,K)}$、厚さ $t=0.05\,\mathrm m$、熱伝導率 $\lambda=0.5\,\mathrm{W/(m\,K)}$ である。一次元・定常・発熱なしの場合、両流体間の熱貫流率 $U=[1/h_1+t/\lambda+1/h_2]^{-1}$ はどれか。

**選択肢**

1. 6.67 W/(m² K)
2. 5.0 W/(m² K)
3. 4.0 W/(m² K)
4. 0.25 W/(m² K)

**正答** 3番：4.0 W/(m² K)

**解説**

【三つの抵抗を足す】熱は高温流体から壁表面へ伝達され、壁を伝導し、外側表面から低温流体へ伝達されます。単位面積当たりの抵抗は順に $1/h_1,\ t/\lambda,\ 1/h_2$。直列なので合計し、その逆数が熱貫流率Uです。
【計算】$1/20=0.05$、$0.05/0.5=0.10$、$1/10=0.10\,\mathrm{m^2K/W}$。合計は0.25 m² K/Wなので、$U=1/0.25=4.0\,\mathrm{W/(m^2K)}$、正答は3です。例えば両流体の温度差が10 Kなら、熱流束は $q=U\Delta T=40\,\mathrm{W/m^2}$ となります。
【面積の規約】本問は単位面積当たりで扱うため、壁の抵抗はt/λです。全熱流量Qを使う抵抗なら $1/(h_1A),t/(\lambda A),1/(h_2A)$ と全てに面積Aが必要です。一項だけにAを付けると単位が一致しません。また0.25は抵抗であり、Uそのものではありません。

## Q 3-11　同率で改善する直列熱抵抗

**問題**

単位面積当たりの直列熱抵抗は、高温側対流0.05、壁0.10、低温側対流0.50 m² K/Wである。このうち一つだけを同じ割合で低減できるとき、全抵抗を最も減らす改善対象はどれか。

**選択肢**

1. 高温側対流
2. 低温側対流
3. 壁の熱伝導
4. どれも同じ

**正答** 2番：低温側対流

**解説**

【同じ割合の改善を比較】直列の全抵抗は $R_{\rm total}=0.05+0.10+0.50=0.65\,\mathrm{m^2K/W}$。一つの抵抗を割合ηだけ小さくすると、全抵抗の減少量は $\eta R_i$ です。同じηなら、元の抵抗が最大の項を改善するのが最も効果的です。
【例で確認】20%ずつ下げられるなら、高温側対流の減少は0.01、壁は0.02、低温側対流は0.10 m² K/W。したがって低温側対流を改善する2が正答です。全抵抗は0.55へ下がり、同じ流体温度差での熱流束は元の $0.65/0.55\simeq1.18$ 倍になります。
【律速の読み方】大きい抵抗が伝熱を妨げる主要因となるため、律速抵抗と呼びます。ただし全抵抗が最大項だけで厳密に決まるわけではなく、常に三項の和です。「同じ割合」ではなく「同じ抵抗値だけ減らす」という条件なら効果は同じになるので、比較条件を読み取ります。

## Q 3-12　壁の外表面温度

**問題**

厚さ0.1 m・熱伝導率0.5 W/(m K)の平板で、内側流体200℃・熱伝達率10 W/(m² K)、外側流体20℃・熱伝達率5 W/(m² K)とする。一次元・定常・発熱なしの場合、外表面温度はどれか。

**選択肢**

1. 164℃
2. 56℃
3. 72℃
4. 92℃

**正答** 4番：92℃

**解説**

【流体と表面を分ける】200℃と20℃は両流体の温度であり、壁の内外表面温度ではありません。熱伝達抵抗があるため、流体と表面の間にも温度差が生じます。まず内側対流、壁、外側対流の三抵抗から熱流束qを求めます。
【計算】$R=1/10+0.1/0.5+1/5=0.1+0.2+0.2=0.5\,\mathrm{m^2K/W}$。$q=(200-20)/0.5=360\,\mathrm{W/m^2}$。外側では $q=h_{\rm out}(T_{s,\rm out}-20)$ なので $T_{s,\rm out}=20+360/5=92\,{}^\circ\mathrm C$。正答は4です。
【全温度差で検算】内表面は $200-360/10=164\,{}^\circ\mathrm C$。内側対流36 K、壁72 K、外側対流72 Kの低下があり、合計180 Kで両流体の差に一致します。外表面を流体温度20℃と同じにしたり、壁内だけで全180 Kを分担させたりしないことが重要です。

## Q 3-13　熱伝導率と熱伝達率

**問題**

正しいものはどれか。

**選択肢**

1. 金属では自由電子が熱も運ぶため、電気伝導率が高い金属は熱伝導率も高い傾向がある。
2. 熱伝達率は物質固有の定数で、流れや形状に依存しない。
3. 熱伝導率は固体表面と流体間の伝熱係数である。
4. 発泡断熱材は金属より熱伝導率が高いので、断熱性に優れる。

**正答** 1番：金属では自由電子が熱も運ぶため、電気伝導率が高い金属は熱伝導率も高い傾向がある。

**解説**

【二つの係数の対象】熱伝導率λは物体内部の温度勾配と熱流束を結ぶ材料特性で、単位はW/(m K)。熱伝達率hは表面と周囲流体の温度差と熱流束を結ぶ係数で、単位はW/(m² K)です。同じ「熱の流れやすさ」でも、どこを通る熱を表すかが違います。
【選択肢を判断】金属では自由電子が電気だけでなく熱も運び、電気伝導率と熱伝導率に関連が見られます。この一般的な傾向を述べる1が正答です。hは流体の種類、流速、形状、流れの状態などで変わり、材料だけに固有な一定値ではありません。
【断熱材の働き】発泡材は低い有効熱伝導率によって熱を通しにくくします。熱伝導率が高いから断熱性が高いのではありません。気泡中の気体だけでなく固体骨格の伝導や放射も寄与するため、発泡材の構造全体での有効値として扱います。またλも温度や組成などによって変わることがあります。

## Q 3-14　熱伝達率と温度差

**問題**

定常平板の両面で同じ非零熱流束の大きさ $|q|$ が流れる。$h_1>h_2>0$ のとき、流体と表面の温度差の絶対値はどちらが大きいか。

**選択肢**

1. $h_1$ 側
2. 等しい
3. $h_2$ 側
4. 熱伝達率とは無関係

**正答** 3番：$h_2$ 側

**解説**

【表面の温度差】熱伝達では熱流束の大きさと温度差の大きさが $|q|=h|T_s-T_f|$ で結ばれます。T_sは表面、T_fは流体の温度です。同じ熱流束を通すには、熱伝達率が小さい側ほど大きな温度差が必要になります。
【大小関係】両側の温度差は $|\Delta T_1|=|q|/h_1$、$|\Delta T_2|=|q|/h_2$。$h_1>h_2>0$ なので $1/h_1<1/h_2$、したがって温度差が大きいのはh₂側で、正答は3です。例えばh₁がh₂の2倍なら、h₂側の温度差はh₁側の2倍になります。
【条件の役割】本問では両面の熱流束が同じで、かつ非零と指定されています。熱流束が0なら両方の温度差が0となり、大小が付きません。またこの比較は流体とその側の表面の間の温度差で、壁内部の温度降下の比較ではありません。壁内部では厚さと熱伝導率を使います。

## Q 3-15　円筒の支配熱抵抗

**問題**

内半径 $r_1=0.05\,\mathrm m$、外半径 $r_2=0.06\,\mathrm m$、長さ $L=1\,\mathrm m$、熱伝導率 $\lambda=10\,\mathrm{W/(m\,K)}$ の円筒壁を、半径方向・定常・発熱なしで考える。内外の熱伝達率は $h_1=100,\ h_2=5\,\mathrm{W/(m^2\,K)}$。内側流体は外側流体より高温である。温度低下が最大の区間はどこか。

**選択肢**

1. 内側流体―内表面
2. 外表面―外側流体
3. 管壁内部
4. すべて等しい

**正答** 2番：外表面―外側流体

**解説**

【円筒では面積も変わる】内外の対流抵抗は $R_1=1/(h_1\,2\pi r_1L)$、$R_2=1/(h_2\,2\pi r_2L)$。壁の抵抗は $R_w=\ln(r_2/r_1)/(2\pi\lambda L)$ です。定常・発熱なしなら三つの区間を同じ熱流量Qが通り、それぞれの温度低下は $QR_i$ になります。
【数値を比較】$R_1=1/(100\times2\pi\times0.05\times1)\simeq0.03183\,\mathrm{K/W}$、$R_w=\ln1.2/(2\pi\times10)\simeq0.002902\,\mathrm{K/W}$、$R_2=1/(5\times2\pi\times0.06)\simeq0.5305\,\mathrm{K/W}$。外側対流の抵抗が最大なので、正答は2です。
【判断の根拠】外側hが小さいだけで結論を出さず、面積と壁の抵抗も含めて比べます。hの大小だけでは、寸法が大きく違う別の円筒まで同じ結論を保証できません。本問では外側対流の抵抗が全抵抗の大部分を占め、外表面から外側流体へ大きな温度差が生じます。

## Q 3-16　断熱境界の数式

**問題**

正の等方的な熱伝導率を持つ材料の二次元熱伝導で、x軸に垂直な面を断熱とする。この面で正しい条件はどれか。

**選択肢**

1. $T=0$
2. $q_y=0$
3. $\partial T/\partial y=0$
4. $q_x=0$、すなわち $\partial T/\partial x=0$

**正答** 4番：$q_x=0$、すなわち $\partial T/\partial x=0$

**解説**

【面の法線を確認】x軸に垂直な面の法線はx方向です。断熱とはその面を横切る熱流束が0という条件なので、$\mathbf q\cdot\mathbf n=0$、この場合は $q_x=0$ になります。境界に沿うy方向の熱流束まで0にする必要はありません。
【勾配へ書き換える】正の等方熱伝導率では $q_x=-\lambda\,\partial T/\partial x$。λは0ではないため、$q_x=0$ と $\partial T/\partial x=0$ は等価です。この組合せの4が正答です。T=0は温度を固定する条件で、断熱条件ではありません。
【一般化するときの注意】y方向の勾配や熱流束は境界に沿う成分なので、2や3を指定しても断熱とは限りません。異方性材料では $q_x=-\lambda_{xx}T_{,x}-\lambda_{xy}T_{,y}$ のように他方向の勾配も入る場合があります。その場合も断熱の本来の条件は法線熱流束0であり、単独のx微分0とは限りません。

## Q 3-17　配管の熱境界条件

**問題**

軸方向に材料・寸法・内外流体温度・熱伝達率が一様で、端部から十分離れた直管を、軸対称のr-z断面で定常解析する。内部発熱と軸方向温度勾配は無視できる。内側は高温流体、外側は大気と熱交換する。適切な条件はどれか。

**選択肢**

1. 内面・外面はそれぞれの流体との熱伝達境界、軸方向切断面は断熱。
2. 全境界を同じ固定温度とする。
3. 内面を断熱、外面を固定温度、切断面に任意の熱流束を与える。
4. 内面に外気条件、外面に高温流体条件を与える。

**正答** 1番：内面・外面はそれぞれの流体との熱伝達境界、軸方向切断面は断熱。

**解説**

【内外の熱交換】内面では高温流体、外面では大気と熱を交換します。したがって各面に、それぞれの流体温度と熱伝達率を使う熱伝達境界条件を設定します。流体温度をそのまま固体表面の固定温度にする条件とは、熱伝達抵抗の扱いが違います。
【切断面の条件】本問は軸方向温度勾配を無視できるため、$\partial T/\partial z=0$。軸方向を横切る熱流束も0とできるので、モデルの軸方向切断面は断熱です。内外面を熱伝達、切断面を断熱とする1が正答です。r方向には内から外へ温度勾配と熱流が生じます。
【仮定を確認】管が長いことだけで全ての切断面を断熱にできるわけではありません。流体温度が長さ方向へ変わる場合や端部の影響が残る場合には、軸方向熱流も検討します。また周期条件は二面の温度と熱流を対応させる条件であり、必ず熱流を0にする断熱条件とは別です。

## Q 13-1　倫理と法

**問題**

技術者の判断について最も適切なものはどれか。

**選択肢**

1. 法に禁止がなければ、危険や虚偽を知っていても常に許される
2. 法令の遵守に加え、安全・誠実さ・専門的責任も検討する
3. 自分の判断があれば法令や契約は不要
4. 顧客の利益だけを唯一の基準にする

**正答** 2番：法令の遵守に加え、安全・誠実さ・専門的責任も検討する

**解説**

法令の遵守だけで職業上の判断が完了するとは限らない。公衆の安全、データの誠実な扱い、専門能力と責任を考慮する。倫理を個人の好みだけ、法をあらゆる問題の完全な判断基準として扱わない。

## Q 13-2　根拠のない材料係数の変更

**問題**

顧客から「基準を満たすため、実材は変えずEだけ20%大きくし、変更は報告書に書かないで」と頼まれた。適切な対応はどれか。

**選択肢**

1. 係数の代わりに安全率だけ書き換える
2. 顧客の指示を書けば虚偽の実材データでも問題ない
3. 根拠のない変更と隠蔽には応じず、実際の条件の結果と改善・追加検討案を示す
4. 要望どおり変更を隠して提出する

**正答** 3番：根拠のない変更と隠蔽には応じず、実際の条件の結果と改善・追加検討案を示す

**解説**

材料の根拠と解析条件を正直に示す。仮定変更の感度解析を、仮想条件と明示して実施することは別である。圧力が続けば適切な責任者・窓口へ相談する。

## Q 13-3　指定外PCの利用

**問題**

この製品の契約は指定した1台だけの利用を認め、別PCへの一時移設も認めない。バックアップを隣席PCへ入れ、そこで解析した。契約上の判断はどれか。

**選択肢**

1. 指定条件を超えるので、許可や適切なライセンスを得て利用する
2. 後で削除すれば必ず許可される
3. 同じ会社なら契約は無関係
4. バックアップなので全PCで使える

**正答** 1番：指定条件を超えるので、許可や適切なライセンスを得て利用する

**解説**

本問で与えた契約では、バックアップの作成と別PCでの使用は別の権限。全ソフトの契約が1台限定という一般論にはしない。契約違反と著作権侵害を無条件に同一視しない。

## Q 13-4　購入と複製権限

**問題**

個人購入ソフトの契約が会社PCへの複製と業務利用を認めていない。適切な対応はどれか。

**選択肢**

1. 短時間なら許可は不要
2. 購入者なら全用途で自由に複製できる
3. 権利・契約の範囲を確認し、会社利用の許可または適切なライセンスを取得する
4. 業務に役立つなら無条件で複製できる

**正答** 3番：権利・契約の範囲を確認し、会社利用の許可または適切なライセンスを取得する

**解説**

購入したことだけで複製・移設・業務利用の権限が全て得られるとは限らない。一方で、許諾や法令上の例外が認められる場合もあるため、「他PCは目的・期間を問わず必ず侵害」と断定しない。

## Q 13-5　適切な情報管理

**問題**

契約が自分用バックアップ1部を認め、第三者配布を禁じている。組織は承認済みの暗号化・アクセス制限を求める。適切なのはどれか。

**選択肢**

1. 解析アカウントを無断で第三者へ渡す
2. 機密ファイルを承認なく公開URLへ置く
3. 許諾のない改変版を第三者へ配布する
4. 許された範囲でバックアップを作り、安全に保管する

**正答** 4番：許された範囲でバックアップを作り、安全に保管する

**解説**

許可範囲と情報管理の条件を守る。ネット接続を維持すること自体は倫理違反とは限らず、業務要件と情報管理対策に依存する。

## Q 13-6　同一社内の別部署からの依頼

**問題**

A社X部の機密案件を受託中、A社Y部から似た依頼が来た。受託の事実も開示制限の対象である。最も適切なのはどれか。

**選択肢**

1. 判断せず黙って両件を重ねて受託する
2. Y部へX部の資料をすぐ送る
3. 自社の権限ある管理者とX部の窓口へ相談し、許された範囲で重複・利益相反を調整する
4. 同じ会社なので全部公開する

**正答** 3番：自社の権限ある管理者とX部の窓口へ相談し、許された範囲で重複・利益相反を調整する

**解説**

同じ法人内でも情報の閲覧権限は同じとは限らない。調整の必要性と秘密の開示権限を分け、必要最小限の情報を適切な窓口で扱う。

## Q 13-7　固定額契約と効率化

**問題**

成果物に対する固定額1000万円の契約で、所定の品質・範囲を満たし検収された。適切な手法により実工数は700万円相当となった。精算・値下げ条項はない。最も適切なのはどれか。

**選択肢**

1. 差額分の不要な作業を無断で追加する
2. 1000万円になるよう実工数を虚偽記載する
3. 実工数が減れば自動的に700万円へ変更しなければならない
4. 契約条件に沿って請求し、工数の説明を求められたら事実を伝える

**正答** 4番：契約条件に沿って請求し、工数の説明を求められたら事実を伝える

**解説**

固定額の成果対価と実工数精算を区別する。効率化は直ちに不正でも調査不足でもない。双方が合意して値下げ・範囲変更することは可能だが、本条件から自動的な変更義務は導けない。

## Q 13-8　追加計算の誤り

**問題**

納品した参考の追加計算で入力値が10倍だったと判明した。追加分は契約範囲外だが、顧客が判断に使う可能性がある。対応はどれか。

**選択肢**

1. 速やかに誤りと影響を通知し、利用を止める必要性を伝え、再計算・検証した訂正版を報告する
2. 手元のファイルだけ直す
3. 誤りを言わず参考程度とだけ伝える
4. 契約外なので隠す

**正答** 1番：速やかに誤りと影響を通知し、利用を止める必要性を伝え、再計算・検証した訂正版を報告する

**解説**

提供した誤った結果を放置しない。訂正値が未確定でも先に既知の誤りと影響範囲を知らせる。版・訂正理由・影響した判断を記録し、訂正版への置換を確認する。

## Q 13-9　過去に知った評価基準

**問題**

元在籍先A社から計算だけを受託した。記憶している非公開の評価基準は、今回利用する許可を得ていない。適切なのはどれか。

**選択肢**

1. 親切な提案なら全ての秘密を使ってよい
2. 許可なく秘密基準を用いず、必要なら利用権限と評価・提案の追加範囲を正式に相談する
3. 記憶にあれば秘密ではない
4. 同じA社の案件ならどんな情報でも自動的に利用許可される

**正答** 2番：許可なく秘密基準を用いず、必要なら利用権限と評価・提案の追加範囲を正式に相談する

**解説**

知っていることと、今回利用してよいことは別。設計変更の提案自体が常に越権となるとは限らない。許可・契約範囲・役割を確認する。安全に関わる懸念があれば、適切な窓口へ事実を報告する。

## Q 13-10　派遣の役割と未達

**問題**

技術者XはB社からA社へ派遣され、A社の指揮命令で業務に従事する。契約は技術者の就業を対象とし、研究目標達成の保証条項はない。目標未達時の適切な対応はどれか。

**選択肢**

1. 役割・契約・実態を確認し、未達の原因と今後の対応を関係者と協議する
2. 担当者の能力不足だけと断定する
3. 達成保証がないので報告も人員管理も不要
4. 必ず全費用を返金する

**正答** 1番：役割・契約・実態を確認し、未達の原因と今後の対応を関係者と協議する

**解説**

労働者派遣では派遣先が指揮命令を行う。目標未達だけから返金や無償投入を一律に導かず、契約上の対応と各当事者の責任を確認する。指揮命令権の所在だけで全ての責任が決まるわけではない。

## Q 13-11　複数の誤りの訂正

**問題**

納品済み解析でEが正しい値の半分、指定のトレスカ評価を誤ってミーゼス評価にしていた。適切な対応はどれか。

**選択肢**

1. 2つの誤りが打ち消すと仮定して放置する
2. Eはどんな解析でも応力に無関係なので修正しない
3. 評価差は常に15%なので口頭連絡だけにする
4. Eと評価方法を正し、結果・安全率・影響を再検証し、経緯と訂正成果物を報告する

**正答** 4番：Eと評価方法を正し、結果・安全率・影響を再検証し、経緯と訂正成果物を報告する

**解説**

各誤りを個別に修正し、結果への影響を確認する。トレスカは主応力差の最大値等で評価し、材料の降伏値と整合させる。Eへの依存や基準間の差を、解析条件・応力状態を問わず固定値で断定しない。

## Q 13-12　機密データの正式な入手

**問題**

必要な機密設計基準の正式提供が遅れ、納期へ影響しそうである。適切なのはどれか。

**選択肢**

1. 遅れる側の責任として何も連絡しない
2. 権限ある窓口へ提供を依頼し、版・用途・利用範囲を確認し、納期影響も早めに共有する
3. 出所・利用権限不明の古い私的メモで代用する
4. 友人経由で無断入手する

**正答** 2番：権限ある窓口へ提供を依頼し、版・用途・利用範囲を確認し、納期影響も早めに共有する

**解説**

正式な経路と利用権限、最新の適用版を確保する。待つだけでなく進捗・納期への影響を共有し、未入手の条件による暫定検討は仮定として明示して合意する。

## Q 13-1　倫理と法

**問題**

技術者の判断について最も適切なものはどれか。

**選択肢**

1. 法に禁止がなければ、危険や虚偽を知っていても常に許される
2. 法令の遵守に加え、安全・誠実さ・専門的責任も検討する
3. 自分の判断があれば法令や契約は不要
4. 顧客の利益だけを唯一の基準にする

**正答** 2番：法令の遵守に加え、安全・誠実さ・専門的責任も検討する

**解説**

【答え】技術者は法令を守るだけでなく、公衆の安全、誠実さ、専門家としての責任を考えて判断します。正解は2です。倫理は「自分が好きか嫌いか」だけで決めるものではありません。
【例】解析結果が計算上は出ていても、材料データの根拠がなく、試験との比較もしていないとします。この状態を、十分に確認された安全な結果として伝えるのは不適切です。分かっている条件、未確認の部分、結果の限界を説明する必要があります。
【誤答】法律が個別に禁止していないからといって、知っている危険や虚偽を無視してよいわけではありません。顧客の利益だけを唯一の基準にすると、使用者や周囲の人の安全を見落とします。自分の判断が法令や契約より無条件に優先するという考えも誤りです。
【行動】能力や情報が足りないときは、確かでないことを確かだと言わず、追加検証や適切な相談を行います。誠実な説明と専門的な判断が、解析結果への信頼につながります。

## Q 13-2　根拠のない材料係数の変更

**問題**

顧客から「基準を満たすため、実材は変えずEだけ20%大きくし、変更は報告書に書かないで」と頼まれた。適切な対応はどれか。

**選択肢**

1. 係数の代わりに安全率だけ書き換える
2. 顧客の指示を書けば虚偽の実材データでも問題ない
3. 根拠のない変更と隠蔽には応じず、実際の条件の結果と改善・追加検討案を示す
4. 要望どおり変更を隠して提出する

**正答** 3番：根拠のない変更と隠蔽には応じず、実際の条件の結果と改善・追加検討案を示す

**解説**

【問題点】Eはヤング率で、弾性範囲の変形しにくさを表す材料定数です。実材を変えず、根拠なくEを大きくし、変更を隠すと、実物とは違う条件の結果を実物の結果として提示してしまいます。正解は3です。
【数値の例】一様な棒を力Fで引く線形弾性の例では、伸びδ=FL/(EA)です。Lは長さ、Aは断面積です。Eを1.2倍にすると伸びは1/1.2≈0.833倍、約16.7%小さくなります。材料を変えていないのに、計算上だけ変形を小さく見せられます。ただしこの式は指定した棒の条件であり、すべての応力や変形が同じ倍率になるわけではありません。
【適切な検討】実際の材料条件の結果を示し、形状変更、材料変更、追加試験など、根拠のある改善を検討します。「Eを変えたらどうなるか」を仮想条件と明示した感度解析は、変更を隠すこととは別です。
【対応】顧客の指示があるだけで虚偽を正当化できません。圧力が続く場合は適切な責任者へ相談し、条件と経緯を記録します。

## Q 13-3　指定外PCの利用

**問題**

この製品の契約は指定した1台だけの利用を認め、別PCへの一時移設も認めない。バックアップを隣席PCへ入れ、そこで解析した。契約上の判断はどれか。

**選択肢**

1. 指定条件を超えるので、許可や適切なライセンスを得て利用する
2. 後で削除すれば必ず許可される
3. 同じ会社なら契約は無関係
4. バックアップなので全PCで使える

**正答** 1番：指定条件を超えるので、許可や適切なライセンスを得て利用する

**解説**

【条件を読む】この製品の契約は指定された1台だけでの利用を認め、別PCへの一時移設も認めません。したがって、バックアップを隣のPCへ入れて解析することは、与えられた条件を超えます。正解は1です。
【区別】バックアップは故障やデータ損失に備えるための保存であり、別のPCで計算する使用権と同じではありません。仮にバックアップの作成が認められていても、そのコピーを使って別PCで業務をする権限まで自動的に付くわけではありません。
【誤答】バックアップという名前、短い使用時間、後から削除すること、同じ会社のPCであることは、示された契約条件を変えません。
【適切な対応】指定PCを使う、移設の許可を得る、別の使用権を取得するなど、認められた方法を確認します。本問の判断はこの契約条件に基づくもので、すべてのソフトが1台限定とは限りません。契約条件に反することと、法令上の著作権侵害が成立するかも、無条件に同一視しません。

## Q 13-4　購入と複製権限

**問題**

個人購入ソフトの契約が会社PCへの複製と業務利用を認めていない。適切な対応はどれか。

**選択肢**

1. 短時間なら許可は不要
2. 購入者なら全用途で自由に複製できる
3. 権利・契約の範囲を確認し、会社利用の許可または適切なライセンスを取得する
4. 業務に役立つなら無条件で複製できる

**正答** 3番：権利・契約の範囲を確認し、会社利用の許可または適切なライセンスを取得する

**解説**

【答え】購入代金を払ったことだけで、あらゆるPC・目的へ自由に複製して使えるとは限りません。本問は会社PCへの複製と業務利用を認めない契約を明記しているため、会社利用の許可または適切なライセンスを取得する3が正しいです。
【身近な例】個人向けの利用券を持っていることと、会社全員が使える利用券を持っていることは違います。ソフトも、認められた利用者、台数、用途などを確認する必要があります。
【誤答】短時間なら条件が消えるわけではなく、仕事に役立つから権限が増えるわけでもありません。購入した物の所有と、プログラムの複製・利用に関する権利の範囲を分けて考えます。
【確認すること】使用許諾契約の対象者・用途・台数・移設条件などを読み、不明なら権限ある窓口へ確認します。許諾や法令上の例外がある場合もあるため、「別PCへの複製は目的や条件を問わず必ず侵害」と断定するのではなく、この設問で明示された条件から判断します。

## Q 13-5　適切な情報管理

**問題**

契約が自分用バックアップ1部を認め、第三者配布を禁じている。組織は承認済みの暗号化・アクセス制限を求める。適切なのはどれか。

**選択肢**

1. 解析アカウントを無断で第三者へ渡す
2. 機密ファイルを承認なく公開URLへ置く
3. 許諾のない改変版を第三者へ配布する
4. 許された範囲でバックアップを作り、安全に保管する

**正答** 4番：許された範囲でバックアップを作り、安全に保管する

**解説**

【答え】契約が自分用バックアップ1部を認め、組織が承認済みの暗号化とアクセス制限を求めています。許可された範囲で作成し、その条件で安全に保管する4が適切です。
【二つの確認】一つは「コピーを作る権限があるか」、もう一つは「作ったコピーをどう守るか」です。前者が認められていても、公開URLへ置いて誰でも読める状態にすれば、情報管理の条件を満たしません。
【管理の例】許可された保存先を使い、必要な人だけがアクセスできるようにします。版や作成日を記録し、必要なときに復元できるかを確認します。暗号化しても鍵を紛失すると戻せなくなるので、鍵の管理も組織の手順に従います。
【誤答】解析アカウントを無断で渡すことは、第三者に利用・閲覧の機会を与えます。改変版の配布も許可のない範囲では認められません。本問はネット接続そのものを禁止しているのではなく、権限と情報の扱いを守ることを問うています。

## Q 13-6　同一社内の別部署からの依頼

**問題**

A社X部の機密案件を受託中、A社Y部から似た依頼が来た。受託の事実も開示制限の対象である。最も適切なのはどれか。

**選択肢**

1. 判断せず黙って両件を重ねて受託する
2. Y部へX部の資料をすぐ送る
3. 双方の案件の開示制限を確認し、権限ある自社管理者・窓口で必要最小限の情報を扱い、許された範囲で重複・利益相反を調整する
4. 同じ会社なので全部公開する

**正答** 3番：双方の案件の開示制限を確認し、権限ある自社管理者・窓口で必要最小限の情報を扱い、許された範囲で重複・利益相反を調整する

**解説**

【答え】同じA社でも、X部とY部が同じ情報を閲覧・利用できるとは限りません。受託の事実も機密なら、「X部からこの案件を受けている」と伝えること自体にも注意が必要です。正解は3です。
【二つを分ける】似た案件の重複や利益相反を調整する必要性と、秘密を誰へ開示してよいかは別です。相談が必要だからといって、X部の資料をY部へ渡したり、Y部の機密依頼をそのままX部へ伝えたりしてよいわけではありません。
【対応】まず両案件の開示制限を確認し、閲覧・調整権限のある自社管理者や窓口で扱います。案件名や資料の詳細を伝える前に、相手の権限と許可範囲を確かめ、必要最小限の情報で調整します。必要な承認を得てから受託範囲や担当を決めます。
【誤答】同一法人という理由だけで全部公開するのは不適切です。判断せず二件を重ねて受けると、守秘義務や公平な業務遂行の問題を見落とします。相談先を適切に選ぶことも守秘義務の一部です。

## Q 13-7　固定額契約と効率化

**問題**

成果物に対する固定額1000万円の契約で、所定の品質・範囲を満たし検収された。適切な手法により実際の作業費用（原価）は700万円となった。精算・値下げ条項はない。最も適切なのはどれか。

**選択肢**

1. 差額分の不要な作業を無断で追加する
2. 1000万円になるよう作業実績や費用を虚偽記載する
3. 実際の作業費用が減れば自動的に700万円へ変更しなければならない
4. 契約条件に沿って請求し、実績や費用の説明を求められたら事実を伝える

**正答** 4番：契約条件に沿って請求し、実績や費用の説明を求められたら事実を伝える

**解説**

【契約の種類】本問は、決められた成果物に対して1000万円を支払う固定額契約です。品質と範囲を満たして検収され、実際の作業費用が700万円となっても、費用に応じた精算や値下げの条項はありません。したがって、契約条件に沿って請求し、実績や費用を事実どおり説明する4が適切です。
【効率化】よりよい手法で同じ成果を少ない費用で得ることは、直ちに不正や調査不足を意味しません。1000万円の成果対価と700万円の原価との差は、この条件では自動返金の根拠にはなりません。
【誤答】請求額に合わせて作業実績を偽ることは不適切です。差額を埋めるため、不要な作業を勝手に追加してよいわけでもありません。値下げや範囲変更をする場合は、双方で合意します。
【単位にも注意】工数は人時や人日などで表す作業量、原価は円で表す費用です。両者を混同しません。実績精算型など別の契約では判断が変わるので、固定額か、どんな精算条件かを確認します。

## Q 13-8　追加計算の誤り

**問題**

納品した参考の追加計算で入力値が10倍だったと判明した。追加分は契約範囲外だが、顧客が判断に使う可能性がある。対応はどれか。

**選択肢**

1. 速やかに誤りと影響を通知し、利用を止める必要性を伝え、再計算・検証した訂正版を報告する
2. 手元のファイルだけ直す
3. 誤りを言わず参考程度とだけ伝える
4. 契約外なので隠す

**正答** 1番：速やかに誤りと影響を通知し、利用を止める必要性を伝え、再計算・検証した訂正版を報告する

**解説**

【答え】契約範囲外の参考計算でも、渡した結果が顧客の判断に使われる可能性があります。既知の誤りを速やかに知らせ、影響を調べ、再計算・検証した訂正版を報告する1が適切です。
【連絡の順序】正しい値がまだ出ていなくても、「どの入力が誤っていたか」「どの結果が対象か」「何が未確認か」を先に伝えます。誤った結果の利用を止める必要性を説明し、確認できた影響と調査中の部分を区別します。必要な対応の範囲は、結果の用途や安全への影響で判断します。
【再計算】入力を正し、出力や評価がどこまで変わるかを検証します。入力が10倍だから結果も必ず10倍とは限りません。非線形性や拘束条件などで変わり方が異なります。
【記録】元の版、誤りの原因、訂正の版、影響した判断を記録し、顧客が訂正版を識別できるようにします。手元だけ直しても、相手の誤ったファイルは残ります。「参考程度」とだけ伝えて誤りを伏せることも、適切な訂正報告になりません。

## Q 13-9　過去に知った評価基準

**問題**

元在籍先A社から計算だけを受託した。記憶している非公開の評価基準は、今回利用する許可を得ていない。適切なのはどれか。

**選択肢**

1. 親切な提案なら全ての秘密を使ってよい
2. 許可なく秘密基準を用いず、必要なら利用権限と評価・提案の追加範囲を正式に相談する
3. 記憶にあれば秘密ではない
4. 同じA社の案件ならどんな情報でも自動的に利用許可される

**正答** 2番：許可なく秘密基準を用いず、必要なら利用権限と評価・提案の追加範囲を正式に相談する

**解説**

【答え】過去に知った非公開基準を記憶していても、今回の仕事で使う許可があるとは限りません。本問は利用許可がないと明示しているので、勝手に用いず、必要な利用権限と追加業務の範囲を正式に相談する2が適切です。
【区別】一般に身に付けた工学知識や計算技能と、特定企業の非公開評価基準は同じではありません。記憶していることだけで、秘密情報が公開情報へ変わるわけではありません。同じA社の案件でも、担当部門、目的、開示範囲などの条件を確認します。
【役割】今回は計算だけを受託しているため、評価や設計変更の提案が必要なら、求められる役割と追加範囲を相談します。提案自体が常に越権という意味ではなく、権限のない秘密を使ったり、未合意の責任を引き受けたりしないことが大切です。
【安全】安全に関わる懸念を見つけた場合は、守秘と権限に配慮し、適切な窓口へ事実と懸念を報告します。親切のつもりならすべての秘密を使ってよい、という判断はしません。

## Q 13-10　派遣の役割と未達

**問題**

技術者XはB社からA社へ派遣され、A社の指揮命令で業務に従事する。契約は技術者の就業を対象とし、研究目標達成の保証条項はない。目標未達時の適切な対応はどれか。

**選択肢**

1. 役割・契約・実態を確認し、未達の原因と今後の対応を関係者と協議する
2. 担当者の能力不足だけと断定する
3. 達成保証がないので報告も人員管理も不要
4. 必ず全費用を返金する

**正答** 1番：役割・契約・実態を確認し、未達の原因と今後の対応を関係者と協議する

**解説**

【関係】技術者XはB社に雇用され、派遣先A社の指揮命令を受けて業務を行います。労働者派遣は、完成した成果物の納品だけを約束する形とは区別して、雇用と指揮命令の関係を確認します。
【答え】本問の契約には研究目標達成の保証条項がありません。目標未達だけから必ず全費用を返金すると判断せず、役割、契約、実際の業務を確認し、原因と対応を協議する1が適切です。
【調べること】入力情報や設備がそろっていたか、目標や指示が明確だったか、時間と人員が足りたか、技術的な難しさや担当者の能力に問題があったかなどを事実に基づいて確認します。能力不足だけを先に決めつけません。
【責任】達成保証がないことは、進捗報告や適切な業務遂行が不要という意味ではありません。また、指揮命令権がA社にあるだけで、すべての責任がA社に決まるわけでもありません。具体的な対応は契約と実態を確認して関係者で調整します。

## Q 13-11　複数の誤りの訂正

**問題**

納品済み解析でEが正しい値の半分、指定のトレスカ評価を誤ってミーゼス評価にしていた。適切な対応はどれか。

**選択肢**

1. 2つの誤りが打ち消すと仮定して放置する
2. Eはどんな解析でも応力に無関係なので修正しない
3. 評価差は常に15%なので口頭連絡だけにする
4. Eと評価方法を正し、結果・安全率・影響を再検証し、経緯と訂正成果物を報告する

**正答** 4番：Eと評価方法を正し、結果・安全率・影響を再検証し、経緯と訂正成果物を報告する

**解説**

【答え】ヤング率Eと強度評価方法という二つの誤りをそれぞれ修正し、再計算・再評価したうえで結果、安全率、影響と経緯を報告する4が適切です。誤り同士が都合よく打ち消すとは仮定しません。
【Eの影響】一様な棒の線形弾性で、力Fと断面積Aが指定される静定の例では応力σ=F/AはEに依存せず、伸びFL/(EA)が変わります。一方、伸びuを指定する例ではσ=Eu/Lで、Eを半分にすると応力も半分になります。複雑な構造、接触、塑性などでは影響がさらに異なるため、「Eはいつでも応力に無関係」は誤りです。
【評価基準】主応力をσ₁、σ₂、σ₃とすると、同じ単軸降伏値と比べる等価応力は、トレスカでmax(|σ₁−σ₂|,|σ₂−σ₃|,|σ₃−σ₁|)、ミーゼスで√{[(σ₁−σ₂)²+(σ₂−σ₃)²+(σ₃−σ₁)²]/2}です。
【差は一定でない】単軸引張では両者が一致します。純せん断で主応力がτ,0,−τなら、トレスカは2|τ|、ミーゼスは√3|τ|です。比は2/√3≈1.155で、この状態では前者が後者より約15.5%大きいです。これはどんな応力状態でも15%違うという意味ではありません。指定基準へ直して影響を検証し、口頭連絡だけで終えず訂正成果物を残します。

_図: なし_

## Q 13-12　機密データの正式な入手

**問題**

必要な機密設計基準の正式提供が遅れ、納期へ影響しそうである。適切なのはどれか。

**選択肢**

1. 遅れる側の責任として何も連絡しない
2. 権限ある窓口へ提供を依頼し、版・用途・利用範囲を確認し、納期影響も早めに共有する
3. 出所・利用権限不明の古い私的メモで代用する
4. 友人経由で無断入手する

**正答** 2番：権限ある窓口へ提供を依頼し、版・用途・利用範囲を確認し、納期影響も早めに共有する

**解説**

【答え】機密設計基準は、権限ある窓口から正式に提供を受け、当該業務に適用する版、用途、利用範囲を確認します。遅れそうなら納期への影響も早めに共有します。正解は2です。
【版の確認】新しい版が出ていても、その案件へ適用する版が契約や計画で指定されている場合があります。単に「最新ならよい」と考えず、文書番号、改訂番号、適用対象を確認します。古い私的メモは、正確さだけでなく出所や利用権限も不明なことがあります。
【待つだけにしない】必要な資料、必要時期、資料がないため進められない検討を整理して伝えます。日程変更、対象範囲の調整、正式提供までの暫定検討などを関係者と相談します。
【仮定の扱い】暫定条件で計算する場合は、仮定と未確認事項を明示して合意し、正式な基準に適合した確定結果と混同しません。友人から無断で入手する方法は正規の権限確認にならず、相手の遅れだから何も連絡しないことも適切な業務管理ではありません。

_図: なし_

## Q 10-1　解析実行前の確認

**問題**

受領したモデルを解析する前に行うべき確認はどれか。

**選択肢**

1. 拡張子だけを確認する
2. 単位系・材料・荷重・拘束・解析設定とモデルの版を確認する
3. ファイルサイズが大きければ正しいと判断する
4. まず本番結果として報告する

**正答** 2番：単位系・材料・荷重・拘束・解析設定とモデルの版を確認する

**解説**

【考え方】解析結果は入力条件から決まります。ファイルが開けることや容量の大きさだけでは、目的に合ったモデルか判断できません。
実行前には、長さ・力・材料定数の単位、材料と板厚、荷重の大きさと方向、支持条件、要素と解析方法を確認します。また、モデルの版が違えば形状や条件も変わるため、どの版を使ったか記録します。
【実務での確認】荷重の合計と支持位置を図で点検し、単位系を数値例で確かめてから計算します。終了した結果も、そのまま本番評価とはせず検証する必要があります。

## Q 10-2　CAEの工程

**問題**

一般的な順序はどれか。

**選択肢**

1. ソルバ→プリ→ポスト
2. ポスト→プリ→ソルバ
3. プリ→ソルバ→ポスト
4. プリ→ポスト→ソルバ

**正答** 3番：プリ→ソルバ→ポスト

**解説**

【考え方】プリ処理は計算するための準備、ソルバは数式を解く工程、ポスト処理は結果を取り出して評価する工程です。従って基本の順序は「プリ→ソルバ→ポスト」で、正解は3です。
例えば、板の形状を要素に分け、材料・荷重・支持を設定するのがプリ処理です。節点変位などを計算するのがソルバで、応力や変位を表示して許容値と比較するのがポスト処理です。
【注意】この流れは一度で終わるとは限りません。反力がつり合わない、変形が不自然などの問題が見つかれば、入力やメッシュへ戻って修正します。

## Q 10-3　プリ処理

**問題**

プリ処理の作業はどれか。

**選択肢**

1. 形状・メッシュ・材料・境界条件の設定
2. 連立方程式の求解
3. 応力コンタの評価
4. 設計の最終決裁

**正答** 1番：形状・メッシュ・材料・境界条件の設定

**解説**

【考え方】プリ処理では、実物を計算可能なモデルへ置き換えます。形状を用意し、要素へ分割するメッシュを作り、材料・荷重・拘束などの境界条件を設定します。選択肢1が該当します。
連立方程式を解くのはソルバ、応力コンタを見て結果を評価するのはポスト処理です。設計の最終決裁は解析結果だけでなく、設計条件や判断基準に基づく別の活動です。
【注意】数値を入力できたことと、モデルが適切であることは異なります。例えば薄板をどの要素で表すか、実際の支持が過度な固定になっていないかも準備段階で確認します。

## Q 10-4　開発における解析計画

**問題**

強度評価のため最初に決めるべきことはどれか。

**選択肢**

1. 配色だけ
2. モデルの節点番号だけ
3. 最も細かいメッシュだけ
4. 評価目的・荷重条件・許容値・確認方法

**正答** 4番：評価目的・荷重条件・許容値・確認方法

**解説**

【考え方】最初に「何を判定するか」を決めます。強度評価なら、どの荷重状態で、どの位置のどの応力を、何の許容値と比較するかを明確にします。理論値・実験・メッシュ収束など、結果を確認する方法も計画します。
その目的に応じて必要な形状、材料モデル、要素、荷重・支持を選びます。配色や節点番号は整理に役立ちますが、解析目的を決める代わりにはなりません。
【注意】全体を最細メッシュにしても、荷重や支持が違えば目的に合う答えは得られません。計算が終了したことより、目的に対して信用できる評価ができたかが重要です。

## Q 10-5　メッシュ密度

**問題**

効率よく応力を評価する方針はどれか。

**選択肢**

1. 一様な粗いメッシュなら全て正確
2. 勾配の大きい箇所を重点的に細分化し、評価量の収束を確認する
3. 応力集中部を粗くする
4. 境界条件のある箇所以外は必ず粗くする

**正答** 2番：勾配の大きい箇所を重点的に細分化し、評価量の収束を確認する

**解説**

【考え方】応力が短い距離で大きく変わる場所では、粗い要素だとその変化を十分に表せません。穴・切欠き・荷重導入部などを重点的に細分化し、必要な評価量が安定するか確認します。
例えば要素寸法を順に小さくして、指定位置の応力や先端変位の変化を比較します。このように細分化に伴う結果の変化を調べることを、メッシュ収束の確認といいます。
【注意】一様メッシュも十分細かければ有効です。ただし全体を細かくすると自由度と計算負担が増えます。また鋭い角や点荷重の特異応力は、細分化しても最大値が有限値へ収束しない場合があります。

## Q 10-6　粗密の遷移

**問題**

穴や段差の周囲を細分化するとき適切なのはどれか。

**選択肢**

1. 集中部から遠方へ要素サイズを徐々に大きくする
2. 集中部を最も粗くする
3. 極端なサイズ差を直接接続する
4. 全体を最小サイズにすることが唯一の方法

**正答** 1番：集中部から遠方へ要素サイズを徐々に大きくする

**解説**

【考え方】小さな要素から急に大きな要素へつなぐと、間に極端に細長い要素や傾いた要素ができやすくなります。穴や段差の近くは細かくし、遠方へ向けて要素寸法を徐々に大きくすると、遷移部分を整えやすくなります。
穴の近くは応力変化を捉えるため、遠方は計算負担を抑えるための分割です。全体を同じ最小寸法にすることだけが解決策ではありません。
【確認】生成後にはアスペクト比、角度、ヤコビアンなどを確認し、目的の応力や変位が収束するかも調べます。見た目が整っていても、精度を自動的に保証するわけではありません。

## Q 10-7　円孔の応力集中

**問題**

幅が穴径より十分大きい薄板をx方向に一様引張する。穴縁の重点細分化箇所と要素はどれか。

**選択肢**

1. x軸上の穴縁だけ、平面ひずみ
2. 遠方だけ、平面応力
3. y軸上の上下の穴縁、平面応力
4. 穴内部の中心、ソリッド

**正答** 3番：y軸上の上下の穴縁、平面応力

**解説**

【考え方】穴のない遠方の引張応力を $\sigma_\infty$ とします。幅が十分大きい板の円孔縁では、x軸から測る角度を $\theta$ として、周方向応力は $\sigma_\theta=\sigma_\infty(1-2\cos2\theta)$ です。
y軸上の上下、すなわち $\theta=90^\circ,270^\circ$ では $\cos2\theta=-1$ となり、$\sigma_\theta=3\sigma_\infty$ で最大です。この付近を重点的に細分化します。
【要素の選択】薄板で板厚面に荷重がなく、厚さ方向応力を無視できるので平面応力要素が適切です。穴内部は材料がないので要素を置きません。有限幅や厚い板では理論の適用条件を改めて確認します。

## Q 10-8　曲げ部材の分割

**問題**

穴のある片持ち部材を通常の完全積分Q4平面応力要素で解析する。適切な方針はどれか。

**選択肢**

1. 穴周辺だけ細かく、せい方向は必ず1要素
2. 全域でせい方向1要素に固定
3. 穴を粗くして固定端だけ細分化
4. 穴周辺の細分化と、曲げを捉えるせい方向の分割・収束確認

**正答** 4番：穴周辺の細分化と、曲げを捉えるせい方向の分割・収束確認

**解説**

【考え方】片持ち部材の曲げでは、断面の片側が伸び、反対側が縮みます。この高さ方向の変化を捉える分割と、穴周囲の急な応力変化を捉える分割の両方が必要です。
Q4は4節点の一次四辺形要素です。通常の完全積分Q4では、曲げに不要なせん断変形が混ざり、実際より硬い結果になることがあります。せい方向の分割を増やし、変位と応力が安定するか確認します。
【注意】必要な分割数は形状、要素の定式化、評価量によって異なります。「必ず1要素で十分」とは言えません。高次要素やはり要素には別の性質があり、同じ分割数を一律に要求することも適切ではありません。

## Q 10-9　丸み付き切欠き

**問題**

有限の先端半径をもつ切欠きの応力評価に適切なのはどれか。

**選択肢**

1. 先端を粗くする
2. 先端半径を形状に含め、周囲を細分化して収束を調べる
3. 一様サイズなら細かさを問わず正確
4. 丸みをゼロにして最大応力を読む

**正答** 2番：先端半径を形状に含め、周囲を細分化して収束を調べる

**解説**

【考え方】丸みのある切欠きでは、その小さな先端半径によって応力集中が決まります。まず実際の半径を形状へ入れ、丸みに沿って十分に分割し、応力の収束を確認します。
丸みをゼロにすると鋭い角を作り、理想化した連続体で応力が発散する特異点になる場合があります。これは有限半径の応力集中を調べるモデルとは異なります。
【注意】粗い要素では丸みの形状も応力変化も十分に表せません。一様メッシュでも必要な細かさがあれば使えますが、半径の小さな領域を重点的に細分化する方が効率的です。

## Q 10-10　円板の対称解析

**問題**

対称な有限幅接触域から上下に圧縮される円板の適切なモデルはどれか。

**選択肢**

1. 1/4モデルに対称条件を与え、接触域付近を細分化する
2. 全体を粗いままにする
3. 対称条件なしの1/4モデル
4. 中央だけ細分化する

**正答** 1番：1/4モデルに対称条件を与え、接触域付近を細分化する

**解説**

【考え方】円板の形状・材料と、上下の接触域・荷重・支持が上下左右に対称なら、右上1/4モデルを使えます。左の切断面では水平変位、下の切断面では鉛直変位をゼロにし、各面に沿う変位は自由にします。
荷重が入る有限幅接触域では応力が変化しやすいので、周囲を細分化して評価量を確認します。対称条件なしで切り出すと、切断面が自由面になり、全体円板とは別の問題です。
【注意】接触域の合力と圧力分布を正しく縮約します。点荷重の最大応力には特異性があり、単に細分化すれば有限値へ収束するとは限りません。

## Q 10-11　評価位置と要素寸法

**問題**

溶接止端の特異な最大応力を使わず、止端から3 mmの指定位置で応力を評価する。要素寸法について正しいものはどれか。

**選択肢**

1. 必ず3 mmと一意に決まる
2. 必ず板厚と等しくする
3. 指定された評価法のメッシュ規定に従い、その位置での補間・収束を確認する
4. 止端の最大応力が収束するまで細分化する

**正答** 3番：指定された評価法のメッシュ規定に従い、その位置での補間・収束を確認する

**解説**

【考え方】「止端から3 mm」は応力を読む位置であり、「要素を3 mmにする」という指定ではありません。要素寸法は、評価法の規定、要素次数、応力の外挿・補間方法を合わせて決めます。
例えば指定位置が要素内にあるなら、その位置の値をどの方法で取り出すかを定め、メッシュを変えて結果が安定するか確認します。
【注意】溶接止端を鋭い角として表した場合、直近の最大応力が特異になることがあります。その最大値の収束を目標にする方法と、離れた指定位置で評価する方法を混同しません。評価法の根拠なしに要素寸法を一意に決めることはできません。

## Q 10-12　三次元要素と求解コスト

**問題**

通常の20節点六面体H20について正しい説明はどれか。

**選択肢**

1. 8隅と12辺中間に節点をもつ
2. 8隅と6面中心だけをもつ
3. 27節点要素と同一である
4. 計算量は要素数だけで一意に決まる

**正答** 1番：8隅と12辺中間に節点をもつ

**解説**

【考え方】H20は20節点の六面体要素です。立方体の隅は8個、辺は12本なので、8隅と12辺の中間に各1節点を置くと $8+12=20$ 節点です。通常のH20には面中心・体積中心の節点はありません。
27節点の六面体は、さらに6面中心と体積中心を加えた別の要素です。二次要素というだけで両者を同じと考えてはいけません。
【計算負担】通常の3変位成分なら1要素の節点自由度は60成分ですが、隣接要素は節点を共有します。全体の自由度数、結合の仕方、直接法・反復法などの解法によって求解時間や記憶量が変わり、要素数だけでは決まりません。

## Q 10-13　スキューの点検

**問題**

同じ寸法比の平行四辺形Q4を比較する。スキューが小さい形状はどれか。

**選択肢**

1. 中点結線が90°に近い
2. 中点結線が0°に近い
3. 面積だけ大きい
4. 対角線だけ長い

**正答** 1番：中点結線が90°に近い

**解説**

【考え方】スキューは、要素が直角の形からどの程度斜めに偏っているかを見る指標です。本問の平行四辺形では、向かい合う辺の中点を結ぶ2本の線が90°に近いほど、長方形に近い形です。
したがって選択肢1が正解です。角度が0°へ近づくと、2方向がほぼ同じ向きになり、要素がつぶれた形へ近づきます。
【注意】面積や対角線の長さだけではスキューを判断できません。また、90°でも極端に細長ければ別の品質上の問題があります。スキューの数値定義はソフトによって異なるため、ここでは幾何学的な角度の比較をしています。

## Q 10-14　台形のテーパ

**問題**

凸な台形を対角線で2三角形に分ける。テーパだけの指標として適切なのはどれか。

**選択肢**

1. 面積差が大きいほど良い
2. 2三角形の面積比が1に近いほどテーパが小さい
3. 高さだけで決まる
4. 最大角が180°に近いほど良い

**正答** 2番：2三角形の面積比が1に近いほどテーパが小さい

**解説**

【考え方】台形を対角線で分けると、2つの三角形はそれぞれ上底・下底を底辺とし、高さは台形の高さと同じになります。従って面積比は上底と下底の長さの比に一致します。
その比が1に近いほど上下の幅の変化が小さく、テーパが小さいと判断できます。選択肢2が正解です。面積差が大きいほど良いわけではありません。
【注意】これは台形のテーパを比較するための幾何学的な指標です。辺が傾くスキュー、細長さ、写像のヤコビアンなどは別に確認します。市販ソフトのテーパ指標は定義を確認して使います。

## Q 10-15　複数の品質指標

**問題**

寸法比を同程度にした凸Q4を比較する。一般に望ましいのはどれか。

**選択肢**

1. スキューもテーパも大きい
2. スキューは小さいがテーパが極端
3. スキューとテーパが小さく、ヤコビアンが適正
4. ほぼ一直線に潰れた形

**正答** 3番：スキューとテーパが小さく、ヤコビアンが適正

**解説**

【考え方】スキューは斜めへの偏り、テーパは幅の変化を表します。どちらも小さい方が通常の要素として扱いやすく、さらにヤコビアンが適正であることを確認します。
ヤコビアンは、基準要素の座標から実際の要素へ移したときの、長さ・面積などの換算を表す量です。要素がつぶれたり反転したりすると、写像や数値積分に問題が生じます。
【注意】1つの指標だけが良くても十分ではありません。形状の品質を確認した後、要素種類とメッシュ密度が対象の変形・応力を捉えられるか、収束も確認します。正解は3です。

## Q 10-16　形状品質と解析設定

**問題**

形状品質の指標そのものではない項目はどれか。

**選択肢**

1. ヤコビアン
2. スキュー
3. アスペクト比
4. 数値積分の次数

**正答** 4番：数値積分の次数

**解説**

【考え方】ヤコビアン、スキュー、アスペクト比は、要素のつぶれ・傾き・細長さなど形状の状態を確認するための情報です。

**正答** 2番：頂点で得た色や輝度を面内で補間する

**解説**

【考え方】Gouraudシェーディングでは、面の各頂点で色・明るさを求め、その値を面の内側へ補間して滑らかに見せます。正解は2です。

## Q 10-37　片持ちの結果量

**選択肢**

1. 下向きたわみ
2. 曲げ応力
3. 一様軸応力

## Q 10-38　自由表面の主応力

**問題**

**選択肢**

1. σ3と法線せん断
2. σzとミーゼス応力
3. 6成分を同方向へ重ねる
4. σ1=100のx方向とσ2=40のy方向

**正答** 4番：σ1=100のx方向とσ2=40のy方向

**解説**

## Q 10-39　主方向の急変

**問題**

最大・中間主応力がほぼ等しい近傍で、主方向が急変した。適切な対応はどれか。

**選択肢**

2. 固有値の接近による方向の不安定性を考慮し、応力テンソルと近傍結果を確認する
3. 必ずメッシュ異常と断定する
4. 方向は常に一定でなければならない

**正答** 2番：固有値の接近による方向の不安定性を考慮し、応力テンソルと近傍結果を確認する

## Q 10-40　一様引張の応力

**問題**

**選択肢**

1. 固定端から増加
2. 自由端だけ集中
3. 全長で10 MPaの一様値
4. 正負が交互に変わる

**正答** 3番：全長で10 MPaの一様値

**解説**

【手順】物体力のない1次元棒では、どこで断面を切っても同じ軸力 $P$ を伝えます。断面積も一定なので、$\sigma=P/A=1000/100=10\ \mathrm{N/mm^2}=10\ \mathrm{MPa}$ です。

## Q 10-41　色と物理量

**問題**

ミーゼス応力の塗りコンタの解釈で正しいものはどれか。

**選択肢**

1. 青は必ず圧縮
2. 負のミーゼス応力が必ず現れる
3. 凡例の範囲を変えても図は同じ
4. 値は非負で、色の対応は凡例と設定による

**正答** 4番：値は非負で、色の対応は凡例と設定による

**解説**

【考え方】ミーゼス相当応力は、応力状態から降伏評価に用いる1つの大きさを求めたもので、非負です。主応力で書くと $\sigma_{\mathrm{v}}=\sqrt{[(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2]/2}$ となります。
二乗の和の平方根なので、青い部分が圧縮を意味するわけでも、負の相当応力を意味するわけでもありません。正解は4です。
【読む手順】表示量、単位、凡例の最小・最大値、平均化の有無を確認します。同じ数値でも凡例範囲を変えると色は変わります。説明用の色見本と実際の解析結果も区別します。

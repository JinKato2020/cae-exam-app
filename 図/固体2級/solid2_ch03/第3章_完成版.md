# 第3章 熱伝導の基礎・完成版

全17問。以下の本文・選択肢・正解・解説を使用する。回答前は問題と選択肢のみ、回答後に正解と解説を追加する。見出し横の補足は削除する。熱流量 $Q$ [W]、熱流束 $q$ [W/m²]、単位長さ当たり熱流量 $Q/L$ [W/m]を区別する。

## 3-1 熱流束と温度勾配

**問題** 熱流束と温度勾配の関係 $q_x=-\lambda\,dT/dx$ を表す法則はどれか。

1. フックの法則
2. オームの法則
3. フーリエの法則
4. ダルシーの法則

**正解：3。解説：** フーリエの法則である。$\lambda>0$ は熱伝導率、負号は熱流が温度の低下方向へ向くことを示す。回答前の設問名に法則名を書かない。

## 3-2 一次元の構造解析と熱伝導解析

**問題** 一次元の線形弾性棒と、一次元の線形熱伝導を、有限要素法の基本未知量・勾配・構成則の係数という観点で比較する。対応が適切なものはどれか。

1. 温度―応力、熱流束―変位、熱伝導率―ひずみ。
2. 温度―変位、温度勾配―ひずみ、熱流束―応力、熱伝導率―弾性係数。
3. 温度―ひずみ、熱流束―弾性係数、熱伝導率―変位。
4. 温度―弾性係数、温度勾配―変位、熱流束―ひずみ。

**正解：2。解説：** 基本未知量は温度と変位、そこから計算する勾配は温度勾配とひずみである。構成式は $\sigma=E\,du/dx$ と $q=-\lambda\,dT/dx$。符号の定義は異なるが、離散化・組立て・線形方程式を解く枠組みに対応がある。多次元の温度はスカラー、変位はベクトル、ひずみと応力はテンソルなので、弾性要素の自由度や構成行列を変更せずそのまま熱伝導へ流用できるという意味ではない。

## 3-3 非定常熱伝導

**問題** 一定断面・一定熱伝導率の棒が、一様な初期温度 $T_c$ にある。側面を断熱し、内部発熱はない。時刻0以後、左端を $T_h>T_c$、右端を $T_c$ に保つ。温度分布について正しいものはどれか。

1. 瞬時に棒全体が最終的な直線分布になる。
2. 左端の昇温は棒内部の温度に影響しない。
3. 非定常に変化し、十分な時間が経つと定常の直線分布へ漸近する。
4. 両端を含め全体の温度が常に一様に上昇する。

**正解：3。解説：** $\partial T/\partial t=\alpha\,\partial^2T/\partial x^2$ に従って温度分布が変化し、最終的に $T=T_h+(T_c-T_h)x/L$ へ漸近する。古典的なフーリエ熱伝導方程式は、数学的には擾乱が任意の正の時間で全域へ及ぶモデルである。「有限の伝播速度を持つ波」とは説明しない。早い時刻では高温端近くの変化が大きく、離れた位置での変化は極めて小さい。

## 3-4 平板と円筒の定常温度分布

**問題** 発熱なし・一定の熱伝導率で、(a)一定断面平板の厚さ方向だけの定常熱伝導、(b)円筒壁の半径方向だけの定常熱伝導を考える。形の組合せはどれか。

1. (a)一次関数、(b)$C_1\ln r+C_2$。
2. (a)対数関数、(b)一次関数。
3. (a)二次関数、(b)一次関数。
4. (a)一次関数、(b)二次関数。

**正解：1。解説：** 平板では $T''=0$、円筒では $(rT')'=0$。それぞれ積分すると一次関数と対数型になる。円筒で一定なのは熱流量 $Q=-2\pi rL\lambda\,T'$ で、熱流束は半径によって変わる。温度そのものが常に $\ln r$ に比例するわけではなく、積分定数を含む。

## 3-5 二層平板の界面温度

**問題** 一次元・定常・発熱なしの二層平板を考える。Aは厚さ0.01 m・熱伝導率10 W/(m K)、Bは厚さ0.01 m・熱伝導率20 W/(m K)。断面積は共通で、接触熱抵抗はない。A側表面200℃、B側表面50℃の場合、界面温度はどれか。

1. 125℃
2. 100℃
3. 150℃
4. 75℃

**正解：2。解説：** 単位面積当たり抵抗は $R_A=0.001$、$R_B=0.0005$ m² K/W。熱流束は $q=150/0.0015=100000$ W/m²で、界面は $200-qR_A=100$℃。各層内は直線で、A側の温度降下が100 K、B側が50 Kとなる。

## 3-6 等温線と断熱境界

**問題** 等方性材料の二次元定常熱伝導を考える。温度勾配がゼロでない滑らかな断熱境界近傍について、正しいものはどれか。

1. 等温線は断熱境界に平行となる。
2. 断熱境界では温度そのものが必ずゼロとなる。
3. 熱流束を規定した境界では、温度が必ず境界全体で一定となる。
4. 熱流は断熱境界に沿い、等温線はその境界と直角に交わる。

**正解：4。解説：** 断熱条件は $\boldsymbol q\cdot\boldsymbol n=0$。等方性では $\boldsymbol q=-\lambda\nabla T$ なので温度勾配も境界に接する。等温線は勾配に直交するため、境界と直角に交わる。勾配がゼロの点では等温線の方向を一意に定義できない。温度指定境界が一本の等温線になるのは、境界上の指定温度が一様な場合である。

## 3-7 内部発熱のある平板

**問題** 一定の正の体積発熱率 $s>0$ と熱伝導率 $\lambda>0$ を持つ平板を、一次元・定常で解析する。両面は同じ温度 $T_0$ に保つ。温度分布の形はどれか。

1. 一次関数
2. 二次関数
3. 三次関数
4. 正弦関数

**正解：2。解説：** $\lambda T''+s=0$。厚さを $L$、左面を $x=0$ とすると、$T=T_0+[s/(2\lambda)]x(L-x)$。中央が最高温度で、二階微分は $-s/\lambda<0$。発熱がないときはこの二次項が消える。

## 3-8 熱流入と内部発熱のある壁

**問題** 厚さ $L$、一定熱伝導率 $\lambda>0$ の平面壁を、一次元・定常で考える。左面 $x=0$ から正の熱流束 $q_0$ が流入し、内部には一様な正の発熱率 $s$ がある。右面 $x=L$ は温度 $T_0$ に保つ。温度分布として正しいものはどれか。

1. 傾きが一定の直線となる。
2. 二階微分が正で、左面ほど傾きの絶対値が大きい。
3. 二階微分が負で、右面へ向かうほど傾きの絶対値が大きい。
4. 中央が最低温度となる。

**正解：3。解説：** $q(x)=q_0+sx$、$T'=-(q_0+sx)/\lambda$、$T''=-s/\lambda<0$。$T=T_0+q_0(L-x)/\lambda+s(L^2-x^2)/(2\lambda)$。右側ほど通過する熱流束が増えるため、温度低下の傾きが急になる。熱伝導率が位置・温度で変化する問題とは区別する。

## 3-9 円筒保温材の熱損失

**問題** 内半径0.05 m、外半径0.10 m、熱伝導率0.04 W/(m K)の円筒状保温材で、内面90℃、外面10℃とする。一次元半径方向・定常・発熱なしの場合、単位管長当たり熱損失 $Q/L=2\pi\lambda(T_1-T_2)/\ln(r_2/r_1)$ はどれか。

1. 67 W/m
2. 20 W/m
3. 14.5 W/m
4. 29 W/m

**正解：4。解説：** $Q/L=2\pi\times0.04\times80/\ln2=29.01$ W/m。$q(r)=(Q/L)/(2\pi r)$ なので内面約92.3 W/m²、外面約46.2 W/m²。$Q/L$ は一定でも $q(r)$ は一定ではない。

## 3-10 熱貫流率

**問題** 平板の両面の熱伝達率は20、10 W/(m² K)、厚さ0.05 m、熱伝導率0.5 W/(m K)である。一次元・定常・発熱なしの場合、両流体間の熱貫流率 $U=[1/h_1+t/\lambda+1/h_2]^{-1}$ はどれか。

1. 6.67 W/(m² K)
2. 5.0 W/(m² K)
3. 4.0 W/(m² K)
4. 0.25 W/(m² K)

**正解：3。解説：** 抵抗の和は0.05+0.10+0.10=0.25 m² K/W、その逆数が4.0 W/(m² K)。0.25は抵抗で、熱貫流率とは単位も異なる。

## 3-11 同率で改善する直列熱抵抗

**問題** 単位面積当たりの直列熱抵抗は、高温側対流0.05、壁0.10、低温側対流0.50 m² K/Wである。このうち一つだけを同じ割合で低減できるとき、全抵抗を最も減らす改善対象はどれか。

1. 高温側対流
2. 低温側対流
3. 壁の熱伝導
4. どれも同じ

**正解：2。解説：** 全抵抗は0.65 m² K/W。低減率を $\eta$ とすると全抵抗の低減量は $\eta R_i$ なので、最大抵抗0.50を改善する効果が最大である。全抵抗はあくまで和であり、最大抵抗だけで厳密に決まるわけではない。図の棒の高さは0.05:0.10:0.50に統一する。

## 3-12 壁の外表面温度

**問題** 厚さ0.1 m・熱伝導率0.5 W/(m K)の平板で、内側流体200℃・熱伝達率10 W/(m² K)、外側流体20℃・熱伝達率5 W/(m² K)とする。一次元・定常・発熱なしの場合、外表面温度はどれか。

1. 164℃
2. 56℃
3. 72℃
4. 92℃

**正解：4。解説：** $R=0.1+0.2+0.2=0.5$ m² K/W、$q=180/0.5=360$ W/m²。外表面は $20+360/5=92$℃、内表面は $200-360/10=164$℃。温度降下は内側対流36 K、壁72 K、外側対流72 Kである。

## 3-13 熱伝導率と熱伝達率

**問題** 正しいものはどれか。

1. 金属では自由電子が熱も運ぶため、電気伝導率が高い金属は熱伝導率も高い傾向がある。
2. 熱伝達率は物質固有の定数で、流れや形状に依存しない。
3. 熱伝導率は固体表面と流体間の伝熱係数である。
4. 発泡断熱材は金属より熱伝導率が高いので、断熱性に優れる。

**正解：1。解説：** 熱伝導率の単位はW/(m K)、熱伝達率の単位はW/(m² K)。後者は流体・流速・形状などに依存する。発泡断熱材は気体を保持して有効熱伝導率を低くするが、固体骨格の伝導や放射なども寄与するため、「空気だけが断熱し、固体骨格は関係しない」とはしない。

## 3-14 熱伝達率と温度差

**問題** 定常平板の両面で同じ**非零**熱流束の大きさ $|q|$ が流れる。$h_1>h_2>0$ のとき、流体と表面の温度差の絶対値はどちらが大きいか。

1. $h_1$ 側
2. 等しい
3. $h_2$ 側
4. 熱伝達率とは無関係

**正解：3。解説：** $|\Delta T_i|=|q|/h_i$。熱伝達率が小さい側で大きくなる。$q=0$ なら両方ゼロなので、問題文で非零とした。

## 3-15 円筒の支配熱抵抗

**問題** 内半径 $r_1=0.05$ m、外半径 $r_2=0.06$ m、長さ $L=1$ m、熱伝導率 $\lambda=10$ W/(m K)の円筒壁を、半径方向・定常・発熱なしで考える。内外の熱伝達率は $h_1=100$、$h_2=5$ W/(m² K)。内側流体は外側流体より高温である。温度低下が最大の区間はどこか。

1. 内側流体―内表面
2. 外表面―外側流体
3. 管壁内部
4. すべて等しい

**正解：2。解説：** 熱流量に対する抵抗は $R_1=1/(h_1 2\pi r_1L)=0.03183$ K/W、$R_w=\ln(r_2/r_1)/(2\pi\lambda L)=0.002902$ K/W、$R_2=1/(h_2 2\pi r_2L)=0.53052$ K/W。各温度低下は $QR_i$ なので外側対流が最大。$h_2<h_1$ だけでは面積と壁抵抗を比較できず、この結論を一般に保証できないため数値条件を追加した。

## 3-16 断熱境界の数式

**問題** 正の等方的な熱伝導率を持つ材料の二次元熱伝導で、x軸に垂直な面を断熱とする。この面で正しい条件はどれか。

1. $T=0$
2. $q_y=0$
3. $\partial T/\partial y=0$
4. $q_x=0$、すなわち $\partial T/\partial x=0$

**正解：4。解説：** 一般的な断熱条件は $\boldsymbol q\cdot\boldsymbol n=0$。ここでは法線がx方向なので $q_x=0$。等方性のフーリエ則で勾配ゼロと対応する。異方性では熱伝導率テンソルの交差成分があるため、同じ勾配条件とは限らない。

## 3-17 配管の熱境界条件

**問題** 軸方向に材料・寸法・内外流体温度・熱伝達率が一様で、端部から十分離れた直管を、軸対称のr-z断面で定常解析する。内部発熱と軸方向温度勾配は無視できる。内側は高温流体、外側は大気と熱交換する。適切な条件はどれか。

1. 内面・外面はそれぞれの流体との熱伝達境界、軸方向切断面は断熱。
2. 全境界を同じ固定温度とする。
3. 内面を断熱、外面を固定温度、切断面に任意の熱流束を与える。
4. 内面に外気条件、外面に高温流体条件を与える。

**正解：1。解説：** 内外面はそれぞれ流体との熱交換を表す熱伝達条件となる。ここでは $\partial T/\partial z=0$ を仮定しているため切断面は断熱にできる。管が長いという理由だけでは、流体温度の軸方向変化や端部影響がある場合まで切断面を断熱にできない。また、周期条件は両側の温度・熱流を対応させる条件であり、熱流ゼロと同義ではない。
